# 武将战术技能总目录 (全 735 技)

底层的战术技能现已按照其“核心手法（六种）”严格拆分为六个子文件，请点击对应链接查阅明细：

- **[[战术技_1_攻战计]]** : 核心机制：强化己方战力（如乘数加成）。在标准映射下属于【优势技】。 (共 285 技)
- **[[战术技_2_胜战计]]** : 核心机制：直接削减敌方兵力。在标准映射下属于【优势技】。 (共 115 技)
- **[[战术技_3_敌战计]]** : 核心机制：扩大或锁定随机数方差。在标准映射下属于【均势技】。 (共 132 技)
- **[[战术技_4_混战计]]** : 核心机制：克制、偷取或废除敌方技能。在标准映射下属于【均势技】。 (共 40 技)
- **[[战术技_5_并战计]]** : 核心机制：减少战损或增加战后恢复。在标准映射下属于【劣势技】。 (共 76 技)
- **[[战术技_6_败战计]]** : 核心机制：殊死一搏，输了也让敌人付出巨大代价。在标准映射下属于【劣势技】。 (共 87 技)
