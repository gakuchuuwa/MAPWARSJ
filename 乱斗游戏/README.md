# 乱斗游戏/ —— 资料库（非开发依据）

这是本项目的 **Obsidian 资料/笔记库**，用于存放文化区、据点、武将技、武将百科、精锐图鉴等**可读资料**，方便查阅与双链浏览。

> ⚠️ **它不是开发依据。** 任何规则、口径、数据结构、代码行为的判断，一律以下面三处为准：
>
> 1. `AGENTS.md`（最新人令，冲突以最新为准）
> 2. `docs/02-design/`（系统设计与单一口径页）
> 3. `docs/PROJECT_PLAN.md`（产品总纲）

## 为什么单独放这里

- 用 Obsidian 打开本目录可以按 `[[双链]]` 浏览资料，但 Obsidian 的链接语法与图库**不参与构建**。
- `99_开发文档/` 是 `docs/` 的**历史副本**，可能落后于 `docs/`；**不要**以它为依据写代码或改数据。
- 若资料与 `docs/`、`AGENTS.md` 冲突：**以 `docs/` 与 `AGENTS.md` 为准**，并回改资料。

## 维护约定

- 新增资料写在本目录；**新增设计/规则写进 `docs/`**，不要只写在资料库里。
- 资料库里出现与现行口径冲突的旧内容，直接改掉或删掉（依据 `AGENTS.md`：以最新为准，冲突旧条删除）。
