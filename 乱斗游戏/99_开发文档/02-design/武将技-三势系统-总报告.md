## 一、想法（为什么做 + 核心设计）

**问题**:武将每人只挂 1 个技,每场战斗都放同一个 → 播报腻("岳飞·痛饮黄龙"每场重复)。

**解决**:
1. 每个武将改配 **3 个技**(优势/均势/劣势各一),开局按兵力比放对应局的技 → 播报随战局变化。
2. 每个武将贴一个 **"势"**(造势/借势/逆势),势与当前局匹配时加成 → 武将立体、有个性。

**判据(单一真理)**:一个技属哪套/哪局,只看它的 `baseEffect`:
`加己攻→攻战·优 / 减敌兵→胜战·优 / 更随机→敌战·均 / 克夺反→混战·均 / 减己损→并战·劣 / 败不垒→败战·劣`;
外加**劣势 condition 优先**(背水一战/破釜沉舟等劣势死战归劣势局)。

**目标对齐**:直播(播报多样)、尊重历史(以少胜多是奇迹不泛滥)、平衡(兵多者恒胜)、慢直播(离散档可预期)。

## 四、测了什么

| 测试 | 结果 |
|------|------|
| `npm run build` | 全程 ✅ exit 0(每步都跑,最近 10.97s) |
| `npm run tactical:assign-audit` | ✅ 通过 |
| 数据完整性 | 414 技**全部**有六套+三局(零遗漏);779 武将**全部**有势+3技(零遗漏) |
| 模拟器(B 脚本 `scratch/verify_aptitude_balance.py`,30万次) | 见下 |

**模拟器验证数据**:
- 逆势×劣势**翻盘率**:兵力比 0.67→**21%**、0.6→7%、0.5以下→0%(奇迹级,不泛滥);vs 造势强敌→0%;**基线(无三势)全 0%**(兵少必输)。
- **败不垒**:逆势劣势败时对方战损 34%→**51%**(过半,张巡式惨胜)。
- REV=1.5 被否决:会让 0.67 翻盘率飙到 **51%**(破坏平衡),故 REV 锁 1.3。

## 五、参数终值（都在 GeneralSkillCombat.ts,一处可调）

**`APTITUDE_POWER_MULT`(势×局开战战力系数)**:

| 势\局 | 优 | 均 | 劣 |
|-------|----|----|----|
| 造势 create | 1.35 | 1.15 | 1.0 |
| 借势 leverage | 1.1 | 1.35 | 1.15 |
| 逆势 reverse | 1.0 | 1.15 | **1.3** |

**`APTITUDE_LOSER_BITE_FLOOR = 1.5`**(逆势劣势败→对方战损保底)。
**判局阈值**(BattleField):我方/敌方 >1.5 优、<0.67 劣、中间均。

## 七、怎么核查（给你的验证清单）

1. **编译**:`npm run build` → 应 exit 0。
2. **审计**:`npm run tactical:assign-audit` → 应通过。
3. **看关键代码**:
   - `grep -n "APTITUDE_POWER_MULT\|APTITUDE_LOSER_BITE_FLOOR" src/combat/GeneralSkillCombat.ts`(3×3表+败不垒)
   - `grep -c "aptitude:" src/data/GeneralSkills.ts` → 应 779(每武将都有势)
   - `grep -c "advantageSkillId:" src/data/GeneralSkills.ts` → 应 779
4. **复跑模拟器**:`python3 scratch/verify_aptitude_balance.py` → 看翻盘率/战损率(改 REV/BITE 可重验)。
5. **游戏实测(最可信)**:跟拍一个逆势名将(如韩信/张巡),遇兵力占优之敌:看它劣势时是否放"背水一战/嚼齿吞贼"、是否偶尔翻盘(约2成)、打输时对方是否惨损过半。
