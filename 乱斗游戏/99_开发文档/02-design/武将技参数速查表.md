## 〇、体系速记

- **名将 = 1 战略技 + 1 战术技；普将 = 仅 1 战术技；无将 = 无技能。** 层级 **名将 > 普将 > 无将** 由技能数量自然拉开。
- **战术技 ①–⑩**：①–⑤ 开战即放（opening）；⑥–⑩ 己方兵力掉到 ≤80% 触发（comeback）。名将/普将通用。
- **战略技 S①–S⑧**：仅名将，条件生效（进攻/防守/地形），战力系倍数 ×1.5。
- **平衡目标**（模拟器实测，等兵力无其他加成）：
  - 同级对同级对称 → **50%**；
  - 每个战术技单发 ≈ **85%**（≈ ×1.2 效力），彼此平衡；
  - 战略技条件命中 → ×1.5 ≈ **100%**（名将在对口战场稳胜，符合"军团打据点少换跟随"的直播需求）。

**逆局触发**：`COMEBACK_TROOP_THRESHOLD = 0.80`（`GeneralSkillCombat.ts`）——己方兵力 ≤ 开战 80% 时触发；触发时**重算掷一次 luck**（每侧），使翻盘概率化、与开局技同档。

**① 的历史（2026-07-03 改）**：原为 `ally_add_troops`（真实 +20% 兵）。因满编军团开战 `troops==maxTroops`，加兵若封顶则无效；若突破上限则**名将军团连胜时越滚越多**（兵力膨胀）。故改为 `ally_mult_1_2`（己方有效战力 ×1.2，只影响胜负判定、不写真实兵力）——胜率仍 ≈85%，且**零膨胀**。代价：机制与 ③侵掠如火 相同（名字/风味不同的一对）。

**⑥哀兵必胜**（唯一的加兵技，逆局）：以 maxTroops 为基数 +20%，**封顶到 maxTroops**（恢复到接近满编，不超编 → 不滚雪球）。

### 二·补 胜后补给战略（S⑥ / S⑦，补给系，2026-07-12 定稿）

| 格 | 技能名 | effect | 基数 | 公式 | 战场 |
|:--:|:--|:--|:--|:--|:--|
| S⑥ | 招降纳叛 | `post_battle_recruit_enemy_pct` | **败方开战总兵** `initialTotalTroops` | `floor(敌开战总兵 × 0.10)` 加至胜方 | 攻城/野战，**须打赢** |
| S⑦ | 因粮于敌 | `post_battle_troop_pct` | **胜方当前兵**（恢复/咬人后） | 关隘 1% / 小城 2% / 中城 3% / 大城 4% | **仅攻城** |

**结算顺序**（`BattleField.resolve`）：① 斩根 → ② 伤兵恢复 → ③ 咬人 → ④ 胜方保底 → **⑤ 战略胜后补兵（S⑥/S⑦ 等）**。

**与战术技区别**：S⑥/S⑦ 均在**战后战略结算**触发，不走战术 opening/comeback 管线；S⑥ 收编的是**敌开战兵**，不是终局残兵。

## 三、系统技 / 全局加成（非武将技格）

| 项 | 常量（文件） | 值 | 说明 |
|:--|:--|:--:|:--|
| 有效战力随机 luck | `LUCK_MIN`~`LUCK_MAX`（GameConfig） | **0.8 ~ 1.2** | 开战每侧掷一次；援军编入再掷一次 |
| 精锐 tier 乘数 | `ELITE_TIER_MULT`（GameConfig） | T0 **1.5** / T1 **1.4** / T2 **1.3** / T3 **1.2** / T4 **1.1** | 与文化系数相乘 |

| 关隘守军（拒险而战） | `PASS_GARRISON_MULT`（GameConfig） | **1.2** | `type==='pass'` 守军；与文化系数相乘 |
| 援军编入（合兵一处） | `REINFORCEMENT_JOIN_SKILL`（GeneralSkills） | luck **0.8 ~ 1.2** | `waveIndex≥1` 编入时掷定 |
| 逆局触发阈值 | `COMEBACK_TROOP_THRESHOLD`（GeneralSkillCombat） | **0.80** | 见 §一 |

### 文化区系数 `TIER_TABLE`（region → [野战, 守城]，GameConfig）

| 类型 | 区域 | 野战 | 守城 |
|:--|:--|:--:|:--:|
| 骑射（高攻） | STEPPE / TIBET / CENTRAL_ASIA | **1.2** | 0.8 |
| 机动（偏攻） | NORTHEAST / HEXI / NORTH | **1.1** | 0.9 |
| 中性 | CENTRAL / WESTERN | 1.0 | 1.0 |
| 善守（偏防） | JAPAN / KOREA / JIANGNAN | 0.9 | **1.1** |
| 高防 | LINGNAN / DIANQIAN / BASHU | 0.8 | **1.2** |

**相乘关系**：一侧有效战力 = Σ(单位兵力 × 文化系数 × 精锐/远征系数) × luck × 战术乘区 × 战略乘区。
例：岭南关隘守军 = 1.2（文化守城）× 1.2（关隘）= **1.44**（不叠成 1.2³）。

## 四、模拟器实测胜率（等兵力 10000，A 带技 vs B 裸）

> 工具都在 `tools/`（战斗数学共用 `tools/combat-model.ts`，与游戏源同步）：
> - `npm run sim:skill` — 武将技/加成平衡总表；阈值扫描 `npx tsx tools/skill-balance-sim.ts --sweep-comeback`
> - `npm run sim:follow` — 跟随军团 7×10 组合测试（见 §四·跟随军团）

| 效力（等效倍数） | A 胜率 |
|:--|:--:|
| ×1.00（裸 vs 裸，校验） | ≈ 50% |
| ×1.10 | ≈ 71% |
| ×1.20（① ② ③ ④ ⑤、T3、远征、文化偏区） | ≈ 85% |
| ×1.30（T2） | ≈ 94% |
| ×1.40（T1） | ≈ 98.5% |
| ×1.50（T0、战略技条件命中） | ≈ 100%（达 luck 上限比 1.2/0.8=1.5，几乎必胜） |

- **开局战术 ①–⑤**：均 ≈ 85%，彼此平衡；③ vs ④ 对撞 ≈ 50%。
- **逆局战术 ⑥–⑩**：等兵力时 ≈ 82–87%（与开局技同档）；带劣势时的翻盘力：
  - −5% 兵：裸 ≈ 38% → ⑥ ≈ 77% / ⑦⑧⑨⑩ ≈ 70%
  - −13% 兵：裸 ≈ 21% → ⑥ ≈ 52% / ⑦⑧⑨⑩ ≈ 44%

### 四·跟随军团（`npm run sim:follow`）

名将军团（默认 40000，攻方）对战普将据点（默认 10000，守方，战术技随机），跑 **7 战略 × 10 战术 = 70 组**，报胜率 + 存活率（胜局剩余兵力/开战兵力），并给出「差别最大」组合。可调 `--legion / --enemy / --terrain`。

| 场景 | 结论 |
|:--|:--|
| **40000 vs 10000（4:1）** | 70 组**全部 100% 胜**（名将军团稳赢，永不用换跟随）；存活率 87–89%，唯 ②避实击虚略高（削敌真实兵→少死） |
| **40000 vs 35000（≈1.14:1）** | 差别拉开：**S③所向披靡 / S④长驱直入（攻·平原命中 ×1.5）→ 100%**；其余 5 战略在平原进攻**不生效**→ 跌回仅战术技 77–86%。**差别最大 = 战略技是否吻合战场**（胜率极差 23%） |

> 提示：战略技多为**情境技**（攻/守/地形），跟拍名将的实际强度取决于其战略技是否匹配当前战场；改地形 `--terrain mountain/sea` 可验 S⑤/S⑥。
