> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。

# 战斗系统说明

## 统一战斗逻辑

游戏中所有战斗都使用统一的战斗逻辑，详见 `game.js` 中的 `resolveSiege` 函数注释。

### 战斗公式

```
胜方剩余 = 原兵力 - (败方兵力 × 随机(0.6-0.8) / 2)
败方剩余 = 0（全灭）
```

### 说明

1. **胜负判断**：兵力多的一方获胜（相等时守方胜）
2. **伤亡计算**：胜方伤亡 = 败方兵力 × 0.6~0.8 / 2
3. **伤兵恢复**：除以2相当于50%伤兵恢复
4. **败方结果**：败方全灭

### 示例

```
15000 vs 8000
- 胜方：15000
- 败方：8000（全灭）
- 伤亡：8000 × 0.7 / 2 = 2800
- 剩余：15000 - 2800 = 12200
- 伤亡率：18.7%
```

### 平衡性调整

- **增大0.6-0.8范围** → 战斗更残酷
- **减小0.6-0.8范围** → 战斗更温和
- **修改/2系数** → 调整恢复比例

## 适用范围

此逻辑适用于所有战斗类型：

- ✅ AI攻城
- ✅ 玩家攻城
- ✅ 玩家打NPC
- ✅ 历史事件攻城
- ✅ 历史事件野战
- ✅ 玩家参与任何战斗

## AI战斗系统

### AI出兵条件

```
1. 城市兵力 ≥ 10000
2. 势力总兵力 ≥ 100000
3. 距离上次出兵 ≥ 1年
4. 出兵兵力 ≥ 敌方兵力 + 10000
```

### AI目标选择

```
- 搜索范围：300公里
- 目标类型：仅敌方城市（不攻打NPC）
- 优先级：距离最近的符合条件目标
```

### AI出兵规则

```
- 出兵数量 = 城市兵力 - 5000
- 城市留守 5000 兵
- 最低出兵数量：5000兵
```
