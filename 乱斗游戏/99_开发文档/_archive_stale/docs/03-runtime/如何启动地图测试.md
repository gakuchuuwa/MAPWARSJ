> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>

# 如何启动地图测试

## ❌ 问题：CORS错误

直接双击HTML文件会遇到CORS错误，因为浏览器不允许本地文件使用ES6模块。

## ✅ 解决方法：使用本地服务器

### 方法1：一键启动（最简单）

**双击运行这个文件：**
```
C:\Users\GAKU\Desktop\MAPWAR\start_server.bat
```

会自动：
1. 启动Python本地服务器
2. 在8000端口运行
3. 显示访问地址

然后在浏览器打开：
```
http://localhost:8000/test_tilemap.html
```

---

### 方法2：手动启动

1. **打开命令提示符（CMD）**
   - 按 Win+R
   - 输入 `cmd`
   - 按回车

2. **进入MAPWAR目录**
   ```cmd
   cd C:\Users\GAKU\Desktop\MAPWAR
   ```

3. **启动服务器**
   ```cmd
   python -m http.server 8000
   ```

4. **打开浏览器**
   - 访问：`http://localhost:8000/test_tilemap.html`

---

### 方法3：使用其他浏览器

**Firefox浏览器** 允许本地文件使用ES6模块：
1. 下载安装Firefox
2. 直接双击 `test_tilemap.html`
3. 应该可以正常运行

## 🐛 常见问题

### Q1: 浏览器打不开
**A**: 检查服务器是否启动
- 看CMD窗口有没有显示 "Serving HTTP on..."
- 尝试访问：`http://localhost:8000`

### Q2: 地图全是灰色方块
**A**: 瓦片文件路径不正确
1. 按F12打开控制台
2. 查看Network标签
3. 看哪些图片文件404
4. 告诉我错误信息

### Q3: 地图加载很慢
**A**: 正常现象
- 第一次加载会较慢（下载瓦片）
- 之后会使用缓存，速度变快
- 12级瓦片文件很大，加载较慢

### Q4: 控制台有错误
**A**: 请截图或复制错误信息告诉我
