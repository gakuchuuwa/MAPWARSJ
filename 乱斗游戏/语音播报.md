# 语音播报 (Voice Broadcast 台词库)

本百科条目整理了 MAPWAR 游戏中专业的解说语音播报台词库。

系统会根据战场态势（优势、均势、劣势）、将领品阶（无将、普将、名将）、攻守方、以及武将所使用的战术技能分类（六种分类）动态生成极具专业感和氛围感的战况解说。

---

## 1. 野战开战
当跟随军团在野外遭遇敌军时触发：

### 普将领军
- **优势局**：【张国】，【张三】，势不可挡，大战，【李国】，【李四】。
- **均势局**：【张国】，【张三】，势均力敌，大战，【李国】，【李四】。
- **劣势局**：【张国】，【张三】，孤军奋勇，大战，【李国】，【李四】。

### 名将领军
- **优势局**：【张国】名将【张三】，势不可挡，大战，【李国】名将【李四】。
- **均势局**：【张国】名将【张三】，势均力敌，大战，【李国】名将【李四】。
- **劣势局**：【张国】名将【张三】，孤军奋勇，大战，【李国】名将【李四】。

---

## 2. 野战结束
跟随军团在野战分出胜负时触发：

### 跟随军团【胜利】
- **优势局**：【跟随军团势力+军】，所向披靡，大破【守方势力+军】，【武将】败走而逃。
- **均势局**：【跟随军团势力+军】，奇兵制胜，击破【守方势力+军】，【武将】引军退却。
- **劣势局**：【跟随军团势力+军】，殊死一战，险胜【守方势力+军】，【武将】功亏一篑。

### 跟随军团【战败】
- **优势局**：【跟随军团势力+军】，前功尽弃，兵败如山倒。
- **均势局**：【跟随军团势力+军】，溃不成军，一败涂地。
- **劣势局**：【跟随军团势力+军】，全军覆没，尸横遍野。

## 3. 攻打据点 (开战)
当跟随军团对据点发起攻城时触发（示例中以白起攻廉颇为例）：

### 普将领军
- **优势局**：
  - 【白起】率领【秦国】军，大军压境，兵临【邯郸】。【赵国】【廉颇】，深沟高垒，披甲督战。
  - 【白起】率领【秦国】军，旌旗蔽谷，攻打【潼关】。【赵国】【廉颇】，整顿军备，严阵以待。
- **均势局**：
  - 【白起】率领【秦国】军，阵列而进，兵临【邯郸】。【赵国】【廉颇】，凭城据守，稳如泰山。
  - 【白起】率领【秦国】军，陈兵险隘，攻打【潼关】。【赵国】【廉颇】，据险而守，不动如山。
- **劣势局**：
  - 【白起】率领【秦国】军，师老军疲，兵临【邯郸】。【赵国】【廉颇】，洞若观火，见机行事。
  - 【白起】率领【秦国】军，强弩之末，攻打【潼关】。【赵国】【廉颇】，一夫当关，万夫莫开。

### 名将领军
- **优势局**：

## 4. 攻打结果 (胜负)

### 攻占【胜利】
- **无将**：【秦国】军，攻占【邯郸】。
- **优势局**：【秦国】军，势如破竹，攻占【邯郸】。【廉颇】，独木难支，甘拜下风。
- **均势局**：【秦国】军，顺势而为，攻占【邯郸】。【廉颇】，计穷力竭，解甲归降。
- **劣势局**：【秦国】军，力挽狂澜，攻占【邯郸】。【廉颇】，大势已去，俯首称臣。

### 攻占【失败】
- **无将**：不播报。
- **优势局**：【跟随军团势力+军】，丢盔弃甲，惨败于【据点】。
- **均势局**：【跟随军团势力+军】，无功而返，兵败于【据点】。
- **劣势局**：【跟随军团势力+军】，以卵击石，败于【据点】。

## 5. 战术技能释放 (最关键的高潮播报)
> **设计核心**：技能释放是战斗最具观赏性的高潮，解说必须要体现出专业分析。根据攻守双方的三类（优势/均势/劣势）和六种（机/全/衡/乱/借/险）进行精准的战役推演解说。
> **前置条件**：如果守方无将领，不播报技能。

### 攻击方技能释放
模板样例：`【攻方武将】，【武将技】，命，【攻方精锐】，【固定台词】。`

- **优势局 (优势技能 / 碾压计)** 
  - **加己攻 / 攻战计(机)**（主动增强自己去捕战机、抢主动）：【武将】，【武将技】，命，【精锐】，**厉兵秣马，先发制人。**（例：白起，歼锐无遗，命，秦之锐士，厉兵秣马，先发制人）
  - **减敌兵 / 胜战计(全)**（绝对优势开打就崩你一块，最小代价全胜）：【武将】，【武将技】，命，【精锐】，**摧枯拉朽，分割聚歼。**

- **均势局 (均势技能 / 破局计)**
  - **更随机 / 敌战计(衡)**（均势时搅浑水、造虚假优势，打破平衡）：【武将】，【武将技】，命，【精锐】，**声东击西，乱其阵脚。**
  - **克夺反 / 混战计(乱)**（废你、夺你、反弹你——乱中夺走对方的力）：【武将】，【武将技】，命，【精锐】，**攻其不备，出其不意。**

- **劣势局 (劣势技能 / 翻盘计)**
  - **减己损 / 并战计(借)**（借势保全自己、让敌人替你消耗，自身不折）：【武将】，【武将技】，命，【精锐】，**以逸待劳，反客为主。**
  - **败不垒 / 败战计(险)**（绝境死中求活、输也咬你成惨胜）：【武将】，【武将技】，命，【精锐】，**置之死地，而后生。**

### 守方技能释放
模板样例：`【守方武将】，【武将技】，命，【守方精锐】，【固定台词】。`

- **优势局 (优势技能 / 碾压计)**
  - **加己攻 / 攻战计(机)**：【武将】，【武将技】，命，【精锐】，**严阵以待，乘势掩杀。**（例：廉颇，骄敌聚歼，命，丛台绝剑，严阵以待，乘势掩杀）
  - **减敌兵 / 胜战计(全)**：【武将】，【武将技】，命，【精锐】，**请君入瓮，聚而歼之。**

- **均势局 (均势技能 / 破局计)**
  - **更随机 / 敌战计(衡)**：【武将】，【武将技】，命，【精锐】，**虚张声势，挫其锐气。**
  - **克夺反 / 混战计(乱)**：【武将】，【武将技】，命，【精锐】，**将计就计，后发制人。**

- **劣势局 (劣势技能 / 翻盘计)**
  - **减己损 / 并战计(借)**：【武将】，【武将技】，命，【精锐】，**坚壁清野，以拖待变。**
  - **败不垒 / 败战计(险)**：【武将】，【武将技】，命，【精锐】，**困兽犹斗，玉石俱焚。**
