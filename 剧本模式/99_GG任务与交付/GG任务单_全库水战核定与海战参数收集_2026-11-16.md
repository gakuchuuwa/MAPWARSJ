## 二、核定类别（每场必填，严格四选一）

| `核定类别` | 含义 | 游戏里怎么打 |
|---|---|---|
| **`海战`** | **双方都是舰队、在海上交战**（外海、近海、海峡、海湾、河口外海面均算），胜负主要靠船上的仗定 | 进**海战场面** |
| **`两栖登陆`** | 一方乘船来、仗主要在岸上或城下打（抢滩、登陆攻城、海岛攻城、筑堤攻海岛城），或「水陆会战」里陆上部分是主战 | 仍按**陆战或攻城战** |
| **`内河湖泊水战`** | 双方舰队交战，但在**江、河、湖**上（赤壁、鄱阳湖、萨莱哈特这类） | **单列，暂不进海战场面**，等主人另定 |
| **`非水战`** | 只是名字或播报里提到船、海，实际是陆战 | 不变 |

判定铁律：
1. **舰队对舰队才算海战**。舰队去打据点、港口城、海岛要塞，一律是 `两栖登陆`（游戏规则：舰队打据点按陆战算）。
2. 一场事件里**先海战后登陆**、或**水陆同时**的，看**决定胜负的是哪一段**：决定胜负的是海上那段 → `海战`；是陆上那段 → `两栖登陆`。拿不准的写进 `核定理由`。
3. 河口外的开阔海面算 `海战`；顺河而上进到江里打的算 `内河湖泊水战`。
4. 原库标了「水战」但其实是登陆或陆战的，照实改判，这正是这次要清理的。

## 三、每场要填的字段

### 3.1 所有场次都填
| 字段 | 填法 |
|---|---|
| `来源清单` | `A` / `B` / `补报` |
| `事件ID` | 清单 A 填 `evt_xxxx`；清单 B 填经典战编号如 `#478`；补报的填全库里对应的事件ID，全库没有就填 `无` |
| `年份year`、`事件名称` | 照清单原样抄，作核对锚点 |
| `原战斗类型` | 照清单原样抄 |
| `核定类别` | 第二节四选一 |
| `核定理由` | 纯汉字 10–40 字，说清为什么归这一类（如「双方舰队于海峡交锋，以撞角冲撞定胜负」） |

### 3.2 `核定类别` 为 `海战` 或 `内河湖泊水战` 时必填
| 字段 | 填法 |
|---|---|
| `水域类型` | 七选一：`外海` / `近海` / `海峡` / `海湾` / `河口` / `内河` / `湖泊` |
| `水域名称` | 如「萨拉米斯海峡」「鸣梁海峡」「鄱阳湖」 |
| `海战纬度`、`海战经度` | **交战水面上的点**，保留 3 位小数。🔴 **必须落在水上**：不能填港口城、岸上据点或岛上的坐标（原清单里的坐标很多是岸上据点，不能照抄）。海战打在海峡就取海峡中线上的点。 |
| `史载风向` | 九选一：`北风` / `东北风` / `东风` / `东南风` / `南风` / `西南风` / `西风` / `西北风` / `不详`（风从哪边来；史料有载才填方位，如赤壁「东南风」） |
| `史载天气` | 八选一：`晴` / `暴风雨` / `骤雨` / `烟雨` / `海雾` / `大雪` / `暴风雪` / `不详`（只填史料写明的，如元日战争「暴风雨」） |
| `潮流海流` | 史载潮流、暗流对战局的作用，纯汉字 30 字以内（如「午后潮流转向，平家船队被反推」），没有就填 `无` |
| `攻方船型`、`守方船型` | 史载船型的通称，如「三列桨座战船」「楼船」「蒙冲斗舰」「板屋船」「龟船」「安宅船」「盖伦帆船」「桨帆船」；不详填 `不详` |
| `攻方舰船数`、`守方舰船数` | 史载约数，纯数字，如 `300`；史料有多种说法取通行说法，在 `核定理由` 或 `备注` 里提一句；不详填 `0` |
| `关键战法` | 数组，从下列枚举里多选，至少一项：`撞角冲撞`、`接舷跳帮`、`火攻`、`火炮`、`投石`、`弓弩`、`封锁`、`诱敌伏击`、`借风`、`借潮` |
| `胜负判定` | 三选一：`攻方胜` / `守方胜` / `胜负未分`（本场本判，口径同 2026-11-15《全库2361场战争事件胜负标注》任务单） |
| `一手史料出处` | 书名、篇名，或通行史源 |

### 3.3 可选
- `备注`：原库攻守填反、坐标明显错位、事件其实是两场仗合写等情况写在这里。

## 五、自检清单（每批交付前过一遍）

1. 该批清单每一行都有对应 `items`，没有漏、没有多、顺序一致。
2. `核定类别`、`水域类型`、`史载风向`、`史载天气`、`胜负判定`、`关键战法` 只用规定的写法，没有第五种写法。
3. 每场 `海战` 和 `内河湖泊水战` 的坐标都在水面上，不是据点或岸上的坐标。
4. 史料没写的风向、天气一律填 `不详`，**不许为了好看编风向、编天气**。
5. 政权称呼与 2026-11-15 任务单同一红线：不用「朝、王朝」（朝鲜除外），公元 330 年后东罗马一律称 `东罗马帝国`。
6. `核定理由`、`潮流海流` 是纯汉字，不用阿拉伯数字、括号、引号、分号。

## 六、交付后导演部（CC）怎么用

- `海战` → 事件改为海战类型，开战时把双方舰队放在你给的**水面坐标**上，直接进海战场面。史载风向、天气直接定海战场面的开场风向与天气，船型给双方挑船，关键战法作为看点播报。
- `两栖登陆` → 保持陆战或攻城战，只清理原库误标的「水战」。
- `内河湖泊水战` → 单独列表交主人定怎么打（战略地图上江河是陆地，现在的海战场面放不进去）。
- 交一批核一批：导演部用脚本查格式、查坐标是否落在水上，有问题会写进 `CC修正记录_水战核定_2026-11-16.md`，请读后再交下一批。
