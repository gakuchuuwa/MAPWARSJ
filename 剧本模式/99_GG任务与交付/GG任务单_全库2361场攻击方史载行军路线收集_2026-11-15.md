## 二、史实收集硬性铁律（触碰即拒收）

1. **只写「攻击方」本军实际行军路线**：
   - 无论主线里玩家此前随哪一方出战，本任务**一律只查 `攻击方势力 / 攻击方武将` 从出发地开拔到战场之间的行军路线**。
   - **严禁混入防守方路线**，也严禁混入未抵达本场战场的另一路偏师/诱敌支线。
2. **没有史料记载的，直接留空 `[]`（「没有的就算了」）**：
   - 史书仅记载「某年某月某军攻某城/战于某地」、未记载中间经过了哪些地方 → `route` 填 `[]`，`note` 写 `"史料未载具体行军途经地"` 即可，**绝对不要硬凑途经点**。
   - 攻击方从相邻城池直扑战场、中间本无重要经由地 → 同样填 `[]`。
3. **节点纯净度与坐标要求**：
   - `route` **不含**出发点本身，也**不含**终点战场本身，只列**中间按先后顺序经过的地点**。
   - 每个节点 `{ "name": "当时地名", "lat": 34.62, "lng": 112.45 }` 必须是**单一纯净历史地名**（当时称呼）：
     - 严禁冒号、竖线、括号、数字编号；
     - 严禁「渡 / 登陆 / 绕道 / 直扑」等动作词（例如不得写 `佩文西登陆`、`阿姆河渡`，应写纯净地名/津渡名）；
     - 严禁把多个城粘连在一格（如 `潼关长安` 必须拆成两个独立节点）；
   - 经纬度保留 2 位小数，地理走向须与史料行军方向一致、不能回头折返。
4. **分战斗类型说明**：
   - **野战 / 攻城战 / 关隘战**：查攻击方陆军（或两栖远征军）从起兵地/集结地到战场的行军途经地（含关隘、渡口、沿途城邑）。
   - **水战**：如史载攻击方舰队有明确沿海/沿江途经港口或岛屿（如赤壁之战曹军经江陵、乌林），按先后列出；史书只记交战海域无航路记载的填 `[]`。
5. **史料出处必填**：
   - 凡 `route` 非空者，`source` 必须写明具体一手史料或权威正史出处（如《史记》《汉书》《资治通鉴》、希罗多德、阿里安、普鲁塔克等卷次章节）及简短行军脉络；禁写笼统空话。

### 交付 JSON 格式示例（数组，与 `batch` 内场次一一对应、不漏场）：

```json
[
  {
    "eventId": "evt_0001",
    "battleType": "野战",
    "fromName": "埃克巴坦那",
    "fromCityId": "city_hamadan",
    "route": [
      { "name": "加拜", "lat": 32.65, "lng": 51.67 }
    ],
    "source": "大马士革的尼古拉残篇；希罗多德 I.125–128：阿斯提阿格斯自米底王都埃克巴坦那南下波斯镇压居鲁士起兵"
  },
  {
    "eventId": "evt_0002",
    "battleType": "攻城战",
    "fromName": "曲沃",
    "fromCityId": "",
    "route": [],

```

- `fromName`：攻击方本战出发地当时地名（史未载可留空 `""`）。

- `route`：史载中间途经地数组；无史料记载必须填 `[]`。
- `source`：简明一手史料出处（必填）。
