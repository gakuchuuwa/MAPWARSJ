# GG 任务单：海战兵力配比收集（AI 导演部 → GG · 2026-11-16）

> 🔴 **任务定位（三大海战任务之二）**
> - **任务一**（`GG任务单_全库水战核定与海战参数收集_2026-11-16.md`）：定海战事件、时间、水面地点、武将、风向天气战法。
> - **任务二**（**本任务单**）：为任务一核定出的**真实海战**收集**双方真实兵力人数与战斗舰/辅船比例**，并按主人定下的口径标注**游戏兵力配比**。
> - **任务三**（`GG任务单_266军团海军历史资料收集_2026-11-16.md`）：收集 266 支军团的海军历史资料，供导演部为每支军团配齐 10 艘船的船模组合。

> 🔴 **核心折算铁律（主人拍板）**
> 1. **「胜利方兵多，就按历史走；胜利方兵少，就按 1:1 走」**：
>    - 史实胜方总兵力 **≥** 史实败方总兵力 → 游戏内战斗数值按**真实史实兵力比**走；
>    - 史实胜方总兵力 **<** 史实败方总兵力（以少胜多） → 游戏内战斗数值按 **1:1 对等**走；
>    - **HUD 与战前播报一律展示 100% 真实史料数字**（战船数 ＋ 官兵总人数）。
> 2. **一切按史**：史料直载的填实数；史料只载船数、未载人数的，按「该时代通行单船编制 × 船数」推算并在 `兵力推算说明` 写清；无载填 `0`。

## 一、输入与分批交付

- **输入**：任务一（`GG交付_水战核定_第N批_...`）中所有 `核定类别 === "海战"` 的场次（`内河湖泊水战` 暂不纳入）。
- **交付路径**：云盘 `剧本模式/99_GG任务与交付/`
- **分批**：与任务一同步推进，先交第 1 批（第 1–6 卷已核定的 **35 场海战**）：
  - `GG交付_海战兵力配比_第1批_第1至6卷_2026-11-16.json` / `.csv`（UTF-8 带 BOM）
  - 后续第 2–5 批随任务一结果跟进。

## 二、每场要填的字段

### 2.1 锚点字段（与任务一对齐）
- `来源清单`（`A` / `B` / `补报`）
- `事件ID`
- `年份year`
- `事件名称`
- `胜负判定`（`攻方胜` / `守方胜` / `胜负未分`）
- `攻方舰船数`、`守方舰船数`（沿用任务一总船数；若查出更准确史料可修订并在备注说明）

### 2.2 兵力与配比字段
| 字段 | 填法 |
|---|---|
| `攻方总兵力`、`守方总兵力` | 整数。双方参战官兵（水手/桨手 ＋ 战斗水兵/陆战队）**真实总人数**；不详填 `0`。 |
| `攻方兵员构成`、`守方兵员构成` | 纯汉字简述桨手水手与战斗兵比例（如「桨手约两万四千、陆战步兵约四千五百」）。 |
| `攻方主力战舰数`、`守方主力战舰数` | 整数。真正接战的**主力战斗舰**数（剔除纯运兵/粮船）；全为战斗舰则等于总舰船数；不详填 `0`。 |
| `攻方辅船与火船数`、`守方辅船与火船数` | 整数。运输船、补给船、火攻船、小艇数；没有或未分列填 `0`。 |
| `兵力数值口径` | 二选一：`按史实比例` / `以少胜多按1比1`（胜方 ≥ 败方填 `按史实比例`；胜方 < 败方填 `以少胜多按1比1`）。 |
| `游戏攻方兵力`、`游戏守方兵力` | 整数。若 `按史实比例`，直接填 `攻方总兵力` / `守方总兵力`；若 `以少胜多按1比1`，双方均填两者中较大值（或按胜方基准对等值，保底 1000）。 |
| `兵力推算说明` | 纯汉字说明史料原数与推算方式。 |
| `一手史料出处` | 书名、篇名。 |
| `备注` | 可选；异说或修订说明。 |
