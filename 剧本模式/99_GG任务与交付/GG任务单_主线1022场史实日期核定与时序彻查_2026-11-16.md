# GG任务单：主线 1022 场史实日期核定与时序彻查（2026-11-16）

## 一、为什么要做

本游戏是**历史模拟器，第一条原则是符合历史**。整部主线是一部编年史，**必须严格按历史发生的先后往前讲，不允许任何倒叙**。

上一轮 63 章重编按「战区」分章，同一时期的几条战线各成一章、先后排开，结果全书出现 **45 处年份倒退**（章与章之间 28 处，最大倒退 87 年；章内 17 处）。这违背了第一原则，必须从头彻查重排。

本单是彻查的**第一步：逐场核定每一仗的确切历史日期**。全部 1022 场都要查，不管上一轮有没有改写过。CC 拿到日期后严格按日期重排、按时期重新分章，再派第二单请你重写所有衔接有问题的场次。

## 三、每场要填什么

| 字段 | 填法 |
|---|---|
| `公历决战日` | 这一仗决出胜负的那一天（野战＝决战日；攻城／守城＝城破、受降或解围之日）。格式 `YYYY-MM-DD`，公元前写负号，如 `-0331-10-01`。查不到日就写到月 `YYYY-MM`；只能查到年就写 `YYYY`。**一律换算成公历**（中国、日本、朝鲜、越南的农历日期请换算；古代西方按史学界通行日期即可）。 |
| `日期精度` | `日` / `月` / `季` / `年` 之一。 |
| `核定季节` | 播报里写的季节。**中国及使用农历的东亚诸国按农历月份**：正月至三月春、四至六月夏、七至九月秋、十至十二月冬。**其他地区按公历月份**：三至五月春、六至八月夏、九至十一月秋、十二月至次年二月冬。 |
| `核定年份` | 库内年份**正确就填 null**；有误才填正确的公元年份（公元前为负数），并在 `依据` 里写明。注意：年份按**决战日所在的公历年**，跨年的战役以决出胜负那年为准。 |
| `同日先后` | 只有和别的场次**同一天**时才填 1、2、3 表示先后，其余 null。 |
| `依据` | 史料出处与原文日期，如「《资治通鉴》卷一百五：太元八年十一月」「Arrian, Anabasis 3.15：Pyanepsion 月」。不得用本项目的游戏文案当依据。 |
| `备注` | 发现的其他史实问题（地点、双方、胜负有误等）写在这里，CC 会另行处理。 |

## 四、硬要求

1. **1022 条一条不少**，`id` 与底表一致，按底表原顺序返回，其余字段原样保留。

3. 只做史实核定，**不改任何播报文字**；播报的重写是第二单。
4. 分 6 批交，一批一个文件：`99_GG任务与交付/GG交付_主线1022场史实日期核定_第N批_2026-11-16.json`。
