# GG 任务单：全库 2361 场史实局部战场兵力与 1:1 折算收集（2026-11-15）

## 一、核心原则（主人拍板）

1. **按史实布置兵力，封顶 20,000**：
   - 历史上主战场（局部实际交战战场）参战兵力 **≥ 20,000** 的，游戏内取上限 **`20000`**。
   - 历史上局部交战兵力 **< 20,000** 的，按**史实局部战场实际交战规模**填写（不虚高凑 2 万）。
2. **双方兵力严格 1:1**：
   - 游戏内 **攻方兵力 === 守方兵力 === `gameTroops`**（不搞以少胜多，不设兵力差）。
   - 原因：所谓“以少胜多”多为战略全局兵力对比，具体到**局部正面交战战场**，历史上双方投入的一线兵力往往相近。
   - 因此若史载某战一方仅 6,000 人、另一方虽号称数万但局部正面交战兵力相近或实际参战约 6,000–10,000 人，按史料考证出的**局部正面交战基准兵力**折中取值（一般取较小一方或双方实际一线接触兵力均值，封顶 `20000`）。

## 三、输出 JSON 格式要求

每批输出为 JSON 数组，每条包含以下字段（缺一不可）：

```json
[
  {
    "eventId": "evt_0001",
    "eventName": "帕萨尔加德之战",
    "historicalTroops": "希罗多德与大马士革的尼古拉载米底与波斯主力决战，双方投入局部战场各约1.5万—3万人（或史料未明载精确数但属立国主力决战规模≥2万）",
    "gameTroops": 20000,
    "source": "希罗多德《历史》1.127–128；大马士革的尼古拉残篇F66"
  }
]
```

### 字段规范
1. `eventId`：与输入清单完全一致，**不得漏场、多场、改 ID**。
2. `eventName`：与输入清单完全一致。
3. `historicalTroops`：简明说明史料记载的双方参战人数及局部战场兵力判定依据；若史料未明载具体数字，须注明“史未明载精确人数，依同期战区/军团常规规模估算为……”。
4. `gameTroops`：**整数**，范围 **`1000` 至 `20000`**（严格 `1000 <= gameTroops <= 20000`，建议按百或千取整，如 `1000`、`2000`、`3000`、`5000`、`8000`、`10000`、`12000`、`15000`、`20000`；史实不足 1,000 人的小规模奇袭/伏击一律按保底 **`1000`** 填写）。代表游戏内 **攻方 = 守方 = `gameTroops`**（1:1）。
5. `source`：真实一手/正史史料出处，不得留空。
