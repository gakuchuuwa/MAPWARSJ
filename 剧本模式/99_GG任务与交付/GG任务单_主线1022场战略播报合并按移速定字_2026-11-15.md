## 三、内容融合与历史红线（一条不许破）

1. **有机融合，禁机械腰斩**：
   - 必须从 `原衔接播报` 提炼「上一场打完发生了什么 / 为什么转到这一场」，从 `原战略播报` 提炼「公元某年某季、谁与谁因何在此开战」，融成文气贯通的一段（或两段）。
2. **真实时空关系（严禁伪造因果）**：
   - 同棒连战、顺时推进：写明真实历史因果与进军脉络；
   - **跨洲换棒 / 年份回拨**（如 `this.year < prev.year` 或东西方平行切换）：先用半句/一句收束上一棒余波，再诚实点明平行时空纪年切入新战区（如「当某地兵戈初定之际，公元前某某年……」或直接收束前局后以「公元某某年，某地……」落笔），**严禁在年份倒流时误写「此后」「随后」「数年后」**，也**严禁使用「目光转向」「镜头移至」「同一时代的西方」等现代解说腔套话**。
3. **严守战略与战术边界（零剧透、零复读）**：
   - `合并战略播报` 只写到**两军进抵战场/关隘/城下对峙或合围**为止，**绝不可把战中阵型变化、奇袭破城手法与最终胜负提前写进战略播报**（避免与紧接着念的 `战术播报_勿动` 重复）。
   - `合并战略播报` 最后一句与同场 `战术播报_勿动` 第一句**严禁出现连续 4 字及以上重合**。
4. **纪年、符号与称呼铁律（与全库一致）**：
   - **必含公元纪年**：全部 1,022 条每条都必须包含完整的 **「公元前某某年」** 或 **「公元某某某某年」**（零写作 **「〇」**，如 `公元前五五〇年秋`、`公元二〇八年冬`；严禁漏写「公元」二字，严禁只写年号）。
   - **零禁符**：正文中**严禁**阿拉伯数字 `0-9`、圆括号 `（）()`、引号 `“”‘’"'`、书名号 `《》`、方括号 `【】`（勿在正文里写 `【第1段】` 等标记！）、全角分号 `；`、换行符 `\n`（双段直接分成数组的两个字符串元素）。
   - **零兵力确数**：严禁出现具体兵力、舰船、死伤人数（如「率三万步骑」「斩首两万」；蒙古军制专名「万户」除外）。
   - **政权与时代称呼红线**：
     - 🔴 **严禁以「朝 / 王朝」称呼政权**（仅国号本含朝字的 `朝鲜` 允许；`朝廷 / 朝野 / 朝堂 / 朝臣 / 朝政 / 朝贡` 等非政权词允许；中国同国号政权用 `刘汉 / 东汉 / 曹魏 / 拓跋魏 / 李唐 / 赵宋 / 朱明 / 大元 / 大清` 等规范政权称呼，非华夏王朝用 `王国 / 帝国 / 汗国 / 苏丹国 / 哈里发国 / 幕府` 等）。
     - 🔴 **严禁近代词与后人剧透词**：严禁 `古城 / 古都 / 旧都 / 丝绸之路 / 丝路 / 解放 / 抗战 / 游击战 / 殖民主义 / 封建 / 中世纪 / 文艺复兴 / 十字军东征 / 希腊化`；公元 330 年后严禁称东罗马为 `拜占庭`（一律称 `东罗马帝国`）；严禁 `末王 / 末帝 / 末主 / 亡国之君 / 末代皇帝 / 气数已尽`。

## 五、交稿前必跑自检脚本（须 100% 零报错交稿）

请在完成 `战争编年史_主线1022场合并战略播报_定稿_2026-11-15.json` 后，执行以下 Python 验收脚本，确认输出 **`🎉 全部 1022 场验收通过，0 报错！`** 后再提交：

SRC = "GG底稿与验收台账_主线1022场战略播报合并改写_2026-11-15.json"
OUT = "战争编年史_主线1022场合并战略播报_定稿_2026-11-15.json"

base = json.load(open(SRC, encoding="utf-8"))["events"]
done = json.load(open(OUT, encoding="utf-8"))["events"]

errors = []
if len(done) != 1022:
    errors.append(f"总条数错误：期望 1022，实际 {len(done)}")

FORBID_CHARS = re.compile(r'[0-9０-９()（）“”‘’"\'《》【】\[\]；;\n\r]')
DYNASTY_BAD = re.compile(r'(王朝|[秦汉新晋隋唐宋元明清魏蜀吴齐梁陈周商夏辽金]朝)')

        errors.append(f"{tag}: ID 或序号被篡改")
    if d.get("战术播报_勿动") != b["战术播报_勿动"]:
        errors.append(f"{tag}: 战术播报被改动")

        if m:
            errors.append(f"{tag} 第{pi}段含禁符：{repr(m.group(0))}")

    full = "".join(paras)
    tlen = len(full)
    if tlen < b["minChars"] or tlen > b["maxChars"]:
        errors.append(f"{tag} 总字数越界：{tlen} 字（允许 {b['minChars']}–{b['maxChars']}）")

        errors.append(f"{tag} 命中禁词红线：{MODERN_BAD.search(full).group(0)}")
    if b["year"] >= 330 and "拜占庭" in full:
        errors.append(f"{tag} 330年后误称「拜占庭」（应称东罗马帝国；若指330年前拜占庭城池请留意年份）")
    if TROOP_NUM.search(full):
        errors.append(f"{tag} 疑似含具体兵力数：{TROOP_NUM.search(full).group(0)}")

    # 检查战略末尾 18 字与同场战术开头 18 字是否有 4 字复读（排除本场战场专名本身）
    tail = re.sub(r'[，。！？、]', '', full[-20:])

            errors.append(f"{tag} 战略结尾与战术开头四字重合：「{gram}」")
            break
