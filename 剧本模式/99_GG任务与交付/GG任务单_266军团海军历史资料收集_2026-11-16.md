## 二、每支军团要填的字段

### 2.1 锚点字段（照清单抄）
- `序号`
- `层级`（`二级` / `三级`）
- `军团名`
- `文明或母体`
- `时代`

### 2.2 史实海军资料字段
| 字段 | 填法 |
|---|---|
| `海军传统等级` | 严格四选一：`远洋强权` / `近海与内河水师` / `沿岸渔猎渡河` / `纯内陆无水师` |
| `旗舰级船型` | 史载主将指挥舰/最大型战船的中文史称（如「五列桨座旗舰」「高层楼船」「大安宅船」；无水师填「无」） |
| `主力重舰船型` | 史载中坚主力战船中文史称（如「三列桨座战船」「龟船」「盖伦帆船」「斗舰」；无填「无」） |
| `先锋快船船型` | 史载前锋突击、侦察、接舷或火攻快船（如「利布尔纳快船」「艨艟」「走舸」「小早船」「火船」；无独立快船填主力船型或「无」） |
| `远程支援船型` | 史载载有投石机、火炮、弓弩手或负责补给护卫的船型（如「投石舰」「板屋船」「卡拉维尔帆船」「海鹘」；无填「无」） |
| `史实舰队配比` | 纯汉字简述该时代该军团舰队各类船的大致构成比例（如「主力三列桨战船约占七成，轻型接舷快船占两成，重型旗舰与投石舰占一成」） |
| `单船兵员编制` | 史载或通行研究估算的主力战船单船人数（区分桨手水手与战斗兵，如「主力舰约二百人，含桨手一百七十名与陆战兵三十名」；不详写「不详」） |
| `主要舰载武装` | 数组，从下列枚举多选（无水师可填 `["无"]`）：`撞角`、`接舷水兵`、`弓弩`、`投石机`、`火炮`、`火攻焚船`、`希腊火`、`拍竿` |
| `史实海战特点` | 纯汉字 15–50 字，概括该军团所在文明与时代的海上/水上作战风格 |
| `一手史料出处` | 史书、兵书或权威历史研究出处（不详写「通行历史研究」或具体文献，禁编造书名） |

## 四、自检清单

1. 覆盖清单全部 266 支军团，序号、军团名、时代与清单完全一致。
2. 严守时代边界：古典时代不出现火炮、盖伦帆船；封建时代（除宋末元初火器过渡期外）不乱填近代风帆战列舰。
3. 政权称呼红线：不用「朝、王朝」（朝鲜除外），公元 330 年后东罗马一律称 `东罗马帝国`。
4. 不懂或确实无水师的内陆军团，如实填 `纯内陆无水师`，不得硬凑。
