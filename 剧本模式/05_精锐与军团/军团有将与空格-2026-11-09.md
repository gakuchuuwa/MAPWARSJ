# 军团「没有武将」清单与处置（2026-11-09）

> 起因：主人 2026-11-09「我发现很多军团都没有武将呀。」
> 口径：军团 ＝ **势力时代（`FACTION_ERA`）× 据点文化（`buildingStyle`）** 那一格（AGENTS §三.1）。
> 数据入口：`src/data/level2Civ62Legions.ts`（二级 251 支）、`src/types/CultureFormations.ts` 的 `getLegionNameOfGeneral`。
> 审计脚本：`scratch/audit_legion_occupancy_20261109.mts`（只读，逐将统计）。

## 一、结论

| | 改前 | 改后 |
|---|---|---|
| 二级军团（共 251 支）0 武将 | **40 支（16%）** | **8 支（3%）** |
| 三级军团（9 支）0 武将 | 0 | 0 |
| 整条文化一个武将都没有 | 0 | 0 |
| 武将总数（去重 generalId） | 1950 | 1950（未增未减） |

**根因不是「缺武将」，是「势力时代表把分段丢了」**：40 格里 32 格的势力，`FactionEra.ts` 的注释已经写明「古典 → 476 封建 → 1050 城堡 → 1500 帝国」这类分段，但**数组只写了一段**，于是这些势力的武将全被打进同一个时代，同文化其余三格就空了。
武将本身的成名年是对的（例：亨吉斯特 420 年＝古典、狮子亨利 1149 年＝城堡、约翰腓特烈 1523 年＝帝国），只是被一段式势力时代压成了一个时代。
