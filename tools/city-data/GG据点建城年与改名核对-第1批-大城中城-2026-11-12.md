# 据点建城年核对 ＋ 改名时间线设计 · 第 1 批（大城 20 座、中城 122 座）

> 这一份是**自包含**的：名单、坐标、现在登记的建城年全在下面第三节，你不用看任何本地文件，只按下面的名字联网查资料。

## 一、你在做什么

我们的游戏是一张亚欧非古代地图，从公元前五五〇年一路推到公元一九一二。地图上的每个据点（城）要做两件事：

1. **建城年**：这地方**什么时候开始有人筑城聚居**——到了这一年，地图上才画出这座城；没到就不画。
2. **改名时间线**：同一个地方，历史上不同时期叫什么名字。我们要按年份换名，比如一个地方在古典期叫「拜占庭」、罗马晚期叫「君士坦丁堡」、后来又变成「伊斯坦布尔」。

现在库里每个据点已经填了一个**建城年**（第四列的「现登记」），但里面有很多是估算的、也有错的。你要做的是：

- **核对**建城年：对就确认，错就给出正确的年份；
- **设计改名时间线**：按史实把这个地方历代的名字和「从哪一年开始用这个名字」列出来。

**只做本批这一百多座（都是大城、中城，最重要的一批）**。后面几批是小城和城寨，主人会说「做第 N 批」。

## 二、你只需要交这些格子

| 列名 | 要求 |
|---|---|
| `cityId` | 原样照抄名单第一列，一个字母都不许改。 |
| `现名` | 原样照抄名单第二列。 |
| `建城判` | 只能填 `确认` 或 `修正`。 |
| `建城年` | 你核对后的建城年：**公元前写负数**（如 `-1300`），公元后写正数（如 `1453`）。「确认」也要把年份照抄一遍。 |
| `建城依据` | 一句话说清凭什么：考古测年、最早文献记载、某王所筑、最早见于某史书。**要能点开查的史源链接**。 |
| `改名时间线` | 这个地方历代名字，按时间从早到晚，格式写死为：`名字(起始年) ； 名字(起始年) ； …`。**起始年写这个"在史料里开始用这个名字"的年份**，公元前写负数。例：`拜占庭(-667) ； 君士坦丁堡(330) ； 伊斯坦布尔(1930)`。只有一个名字、从没改过的，就写一个，如 `雅典(-1400)`。 |
| `名字依据` | 改名时间线的史料依据＋链接（一两条即可）。 |
| `现名对不对` | 只能填 `对`、`建议改为XXX`、`存疑`。指我们现在用的这个名字（第二列）合不合适；不合适就写出更好的。 |
| `备注` | 有异说、有争议、或这个"据点"其实是两座城要说明的，写在这里；没有就空着。 |

## 四、硬规则（照做，别自由发挥）

1. **建城年 ≠ 改名年**。建城年判的是「这地方什么时候有人筑城」，跟「这个名字什么时候才有」无关。
   例：北京这地方西周初年就有蓟城（建城年约前一〇四五），但「北京」这个名字是明朝才有的 —— 建城年填前1045，改名时间线里再写「蓟(-1045) ； 幽州(约220) ； 北平(1368) ； 北京(1421)」。
2. **建城年取「最早的筑城/成城证据」**：考古城墙、最早文献里的「城」、某位君主筑城的明确记载，三者取最早。
   **只找到「最早见于记载」也照填**，并在依据里写「最早见于文献」。
3. **纯军营、驿站、关隘，没有形成居民城的**，建城年填它成为据点的那一年，依据里说明是关隘/要塞而非居民城。
4. **改名时间线只收「真的改过名」的节点**：
   - 同一个名字的音译变体、异体字（如「撒狄／萨迪斯」）**不算改名**，只收一个你最推荐的写法；
   - 后世王朝的行政区划名如果只是「XX郡」「XX府」而城名没变，不算改名；
   - 帝国改称、征服者改名、语言更替（希腊名→拉丁名→阿拉伯名→土耳其名）算改名。
5. **名字写汉字通行译名**，不要写英文、不要写拼音。古典期用古典写法（拜占庭、撒狄、埃克巴坦那），不要用后世才有的名字替代。
6. **每行都要有史源链接**（`建城依据`、`名字依据` 两格各至少一条）。优先：英文维基的单条地名条目、中文维基专条、Pleiades（pleiades.stoa.org）、Barrington Atlas、Smith's Dictionary。
7. **不许编造**。查不到就写「存疑」或把年份留空并在备注里说明为什么定不下来，**不要给一个看起来合理的假数字**。
8. 这座城在史上是**两座城合并**（如安阳含殷墟与邺城）、或**坐标偏了**导致对不上号，写在备注里，别自己改坐标。

## 五、交稿格式

- 用**一个代码块**输出**制表符分隔（TSV）**，第一行是表头，九列依次为：
  `cityId`、`现名`、`建城判`、`建城年`、`建城依据`、`改名时间线`、`名字依据`、`现名对不对`、`备注`
- 格与格之间用**制表符**，不是空格；每格内不许有换行、不许有制表符。
- 顺序按名单原顺序（大城在前、中城在后，各自按名字排）。
- 一次输出不完（建议一次 40 座），主人说「继续」再往下，**第二次仍然带表头**。
- 代码块**之外**另列两段：
  1. 你判「修正」的城，一行一条，写「原名 → 新年份，一句话原因」；
  2. 你判「存疑」的城，写清卡在哪里、还需要什么资料。

## 六、交稿前自查

- [ ] 名单里的 cityId **一个不少、一个不多**，顺序没乱。
- [ ] `建城判` 只用 `确认`／`修正`；`现名对不对` 只用 `对`／`建议改为XXX`／`存疑`。
- [ ] `建城年` 是数字（公元前带负号），没有「约」「左右」「公元前」这类汉字。
- [ ] `改名时间线` 的格式严格是 `名字(年份) ； 名字(年份)`，分号是中文分号、括号是半角括号。
- [ ] 每一行 `建城依据` 和 `名字依据` 都有链接。
- [ ] 没有把「名字出现的年代」当成「建城年」。
