> # 🔴 铁律 · 兵种只认素材样貌，不认兵名
>
> 判断一个兵种能不能进某支军团，**只看 `public/SUCAI/` 里的素材长什么样**——甲胄形制、武器、马匹、旗号。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**全都不算数**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> 反面教材（都被主人当场抓过）：
> - 「契丹军团用女真铁浮屠精锐 = 乱炖」→ **错**。契丹有铁林军重甲骑兵，那副具装甲骑的样貌本来就对。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。那个素材的样貌和东北人本来就像。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**。胡斯军本来就用连枷 / 战锤。
>
> **没裁图看过素材，就不许下「不符合历史 / 跨国乱炖 / 时代不对」的结论。**
> 裁图工具：`scratch/tools_sprite_sheet.py`。判据优先级：**样貌 → 兵种类型 → 时代 → 名字**。

## 1. 闲置立绘统一改名 · `rename_idle_portraits.mjs`

把「闲置立绘」统一改名为 `__闲置__{文化区}_{编号}.png`，方便和「被套用」的立绘区分。

### 什么是「闲置立绘」
某张 png **没有被任何武将当专图使用**、也没有被代码硬编码引用。
- ✅ 算在用（保留不动）：某武将 `portrait` 字段指向它、或 `panjun.png` 这类兜底硬编码。
- ❌ 不算在用（可改名）：只在 `portrait_adjust.ts`（调校表）或 `portrait_canonical.ts`（去重表）里出现——这些只是派生数据，不代表被武将使用。

闲置图仍会被「随机池」按文化区随机抽给杂牌军，所以改名后**仍留在原文化区夹**，只是名字统一、一眼可辨。

### 用法
```bash
npm run portrait:idle-preview   # 只预览，不改盘（先看会改哪些）
npm run portrait:idle-rename    # 执行改名 + 自动重建 canonical 去重映射
```

### 安全保证
- **只改名，绝不删除/覆盖**内容；图片留在原文化区夹（不跨区搬运）。
- 每个文化区从现有 `__闲置__` 最大编号往后续。
- 跳过：已是 `__闲置__` 的、`_prev_` 备份、`avg/bgm_backup/inbox` 夹。
- 每次执行写还原日志 `claudedocs/idle-rename-log-{时间}.json`（新名→旧名，可还原）。
- 幂等：没有可改的图时报 0，重复跑安全。

### 常见场景
给武将换立绘后，旧立绘会变成孤儿（无人引用）。跑一次本工具即可把这类孤儿统一收成 `__闲置__`。
相关约定见项目记忆 `portrait-binding-rules`。
