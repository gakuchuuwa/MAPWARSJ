> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>
> 另一条同级铁律：**别人（主人 / 其他 AI）已经做好的编制，不许擅自改。**
> 只有改动前就是红的（格位不符阵型 / 兵种不存在 / 象攻城违规 / 战力离群）才准动，其余一律先问。
> 自动闸门：`npm run legion:no-unjustified-edits`（已挂 PostToolUse 钩子，改完自动拦）。

## 1. 闲置立绘统一改名 · `rename_idle_portraits.mjs`

把「闲置立绘」统一改名为 `__闲置__{文化区}_{编号}.png`，方便和「被套用」的立绘区分。

### 什么是「闲置立绘」
某张 png **没有被任何武将当专图使用**、也没有被代码硬编码引用。
- ✅ 算在用（保留不动）：某武将 `portrait` 字段指向它、或 `panjun.png` 这类兜底硬编码。
- ❌ 不算在用（可改名）：只在 `portrait_adjust.ts`（调校表）或 `portrait_canonical.ts`（去重表）里出现——这些只是派生数据，不代表被武将使用。

闲置图仍会被「随机池」按文化区随机抽给杂牌军，所以改名后**仍留在原文化区夹**，只是名字统一、一眼可辨。

### 用法
```bash
npm run portrait:idle-preview   # 只预览，不改盘（先看会改哪些）
npm run portrait:idle-rename    # 执行改名 + 自动重建 canonical 去重映射
```

### 安全保证
- **只改名，绝不删除/覆盖**内容；图片留在原文化区夹（不跨区搬运）。
- 每个文化区从现有 `__闲置__` 最大编号往后续。
- 跳过：已是 `__闲置__` 的、`_prev_` 备份、`avg/bgm_backup/inbox` 夹。
- 每次执行写还原日志 `claudedocs/idle-rename-log-{时间}.json`（新名→旧名，可还原）。
- 幂等：没有可改的图时报 0，重复跑安全。

### 常见场景
给武将换立绘后，旧立绘会变成孤儿（无人引用）。跑一次本工具即可把这类孤儿统一收成 `__闲置__`。
相关约定见项目记忆 `portrait-binding-rules`。

## 2. 启动期立绘自动分类 · `rename_duplicate_idle_portraits.mjs`

`npm run dev` **启动前自动跑**（`package.json` 的 `dev` 脚本第一段），把全库立绘按「是否被引用 / 是否重复」规范命名（只改名，绝不删除/覆盖/跨夹移动）。

> 🔴 [2026-10-21 主人令「把这个和多余合并。不在区别文件夹。」]
> **`__暂留__` 已作废**：旧口径「未引用 + 仅跨文件夹重复 → 暂留（保留观察、不删）」并入 `__多余__`。
> 判定不再区分同夹/跨夹，只剩两档：

| 判定 | 结果 | 含义 |
|---|---|---|
| **被代码引用**（武将 `portrait`、硬编码兜底…） | **原名不动** | 铁律 |
| 未引用 ＋ **全库有同图**（同夹、跨夹都算） | `__多余__{夹名}_{NN}.png` | 可删的重复件（主人审阅后手动删） |
| 未引用 ＋ **全库独一无二** | `__闲置__{夹名}_{NN}.png` | 库存资源，随机池继续抽用 |

**留活口（全库口径）**：每个同图组在全库至少保住 1 份非多余兜底 —— 组里有被引用正本就用正本兜底；没有就推选 1 份留守（优先已是 `__闲置__` 的）。所以「删光所有 `__多余__`」永远不会删绝版，但某个文化夹可能因此少一张图（内容仍在别处）。

- 删除前自查：`npm run portrait:surplus-audit`（判据＝全库还有非多余同图）。
- 预览/手动跑：`npm run portrait:dup-preview` / `npm run portrait:dup-rename`。
- 每次改名写还原日志 `claudedocs/idle-dup-rename-log-{时间}.json`，并同步迁移 `portrait_adjust.ts` 的 F2 调校键（失败整批回滚）。
- F2 换图/绑图时「被顶下来的旧立绘」也走同一套判定（`vite.config.ts` 的 `serverNextDemotedName`）。
