# 编年史古典地名 → 经纬度定位 · 查证任务（给 GG）

> 这是一份**纯查资料、纯定位**的任务：不要写文案、不要写战役解说、不要编剧情，只交「一个地名 → 一个经纬度 + 一条史源」。

## 一、你在做什么

我们的游戏要按《战争编年史》逐场重演史实战役。编年史里每场事件只写了**古典地名串**（例如「提姆布拉平原与撒狄」「诺提姆海角、羊河至雅典与撒狄」），而引擎需要一个**具体坐标**才能把战场摆到地图上。

请你把这些地名串，拆成一个个**单独的古代地点**，并给出每个地点的**经纬度**与**史源**。

**只做第一段（公元前五五〇年 — 公元前三六二年，共 50 场）**，就是下面第三节那张表。后面几段用同一格式，主人会说「做第 N 批」。

## 二、你只需要交这些格子（不要多写）

| 列名 | 要求 |
|---|---|
| `编号` | 原样照抄表里的 `chron_01_01_01` 这种编号；一场事件拆出几个地点就写几行，编号重复。 |
| `序` | 这场事件里第几个地点，`1`、`2`、`3`…按**地点原文的先后顺序**。 |
| `地点原文` | 原样照抄。 |
| `古典地名` | 你拆出来的**单个**地名，古典期通行写法，如「普特里亚」「提姆布拉平原」「撒狄」。**不要改写成今名**，今名另放一列。 |
| `今地` | 现代位置，写「国·省/大区·最接近的城镇」，如「土耳其·马尼萨省·萨尔迪斯村」。 |
| `纬度` | 十进制度，北纬正、南纬负；**保留 4 位小数**，如 `38.4800`。 |
| `经度` | 十进制度，东经正、西经负；**保留 4 位小数**，如 `28.0400`。 |
| `精度km` | 这个坐标的可信半径，写整数，如 `2`、`5`、`30`。学界有精确城址就写 1~3；只有大致区域就写 20~50。 |
| `性质` | 只能填这九个词之一：`城池`、`要塞关隘`、`平原战场`、`海岬海湾`、`河口海岸`、`山地隘口`、`岛屿`、`行军起点`、`行军终点`。 |
| `史源` | 一条可点开的链接（英文或中文维基条目／Pleiades／Barrington Atlas 页码＋书名）。**每行都要有，不许空。** |
| `备注` | 坐标有异说、或地点本身存疑、或「推定」的，写在这里；没有就空着。 |

## 四、硬规则（照做，别自由发挥）

1. **只定位，不评价**。不要写「这仗很关键」「决定了帝国命运」这类话；不要写兵力、不要写胜负、不要写战术。这不是播报文案。
2. **坐标取这场仗真正发生的地方**：城池就取古城址（不是现代同名城市中心）；战场取学界公认的战场范围中心；海战取那片海面／海岬的近岸点。
3. **拆地点的规矩**：
   - 用「与」「、」「和」「↔」连起来的，是**并列的几处**，各占一行；
   - 用「至」「到」连起来的，是**一条行军路线**，只交两个端点：前一个 `性质` 填 `行军起点`、后一个填 `行军终点`（中途经过的城不要另列）；
   - 括号里的补充名（如「（福西亚、米利都）」）属于要点名的城，照拆。
4. **精度km 要诚实**：有确切城址写 1~3；只有区域写 20~50；实在定不下来，`纬度`、`经度` 两格写 `未定`，`备注` 写「最接近的今地地标」和为什么定不下来。
5. **每行必须有史源链接**。优先用这几类：
   - 英文维基的单条地名/战役条目；中文维基有专条也可；
   - **Pleiades**（`pleiades.stoa.org`，古典地名坐标的权威库，最推荐）；
   - Barrington Atlas 的页码＋图幅；
   - Smith's Dictionary of Greek and Roman Geography。
6. **地名一律写古典期通行名**，不要写成我们游戏里的今名，也不要用后世王朝名去替换。
7. **不许编造坐标**。宁可写「未定」，也不要给一个看起来合理的假数字。
8. 一个事件如果只有一处地点，就只交一行，不要硬凑。

## 五、交稿格式

- 用**一个代码块**输出**制表符分隔（TSV）**，第一行是表头，十一列依次为：
  `编号`、`序`、`地点原文`、`古典地名`、`今地`、`纬度`、`经度`、`精度km`、`性质`、`史源`、`备注`
- 格与格之间用**制表符**，不是空格；每格内不许有换行、不许有制表符。
- 顺序：按表里编号从小到大，同一事件内按 `序` 升序。
- 50 场一次输出不完，先输出前 10 场，主人说「继续」再往下，**第二次仍然带表头**。
- 代码块**之外**，另列两段说明：
  1. 坐标有异说、或我判为「推定」的场次，一行一条；
  2. 完全没有把握、需要主人另行查证的地名。
