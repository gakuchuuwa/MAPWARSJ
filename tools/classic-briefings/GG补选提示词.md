# 经典战补选 · 写稿任务说明（给 GG）

> 先读同一文件夹里的《经典战播报·GG提示词》：两段播报的写法铁律在那里，这里全部照用。本说明只讲「补选」多出来的部分。

## 一、你在做什么

游戏里每位名将现在只有**一场**经典战。很多名将一生打过不止一场有名的大战（白起有伊阙、鄢郢、长平；汉尼拔有特雷比亚、坎尼、扎马）。

请你为名将**补选第二、第三场经典战**：

- **只收经典战役**：史上有名、史书有专门记载的大战。小规模冲突、无名接战、只见于一两句记载的，一律不收。
- **补几场按史实来**：一生打过几场够格的大战就补几场，没有够格的就**不补**，宁缺毋滥——大部分名将可能一场都补不出来，这完全正常。
- 补的场次**不能是他已有的第一场**（名单里写着）。
- 必须发生在他的**生卒年之内**，而且是**他本人亲自统兵**的仗。

游戏里每一场到了它的史实年份才会开放，玩家随名将去打；同一年代可能好几场挤在一起，所以年份要准。

## 二、你要读的文件（谷歌云盘「经典战播报任务」文件夹）

1. **本说明**，以及《经典战播报·GG提示词》（播报写法）。
2. **「经典战补选·名将名单」**：一行一位名将，共 530 位、分 18 批（每批 30 位）。列：`批次`、`序号`、`generalId`、`名将`、`游戏势力`、`生年`、`卒年`（公元前为负数）、`第一场经典战`、`第一场年份`、`已补选`。主人会说「补选第 N 批」，你只看这一批的 30 位。
3. **「经典战播报·任务表」**：全部 530 场已有的经典战。补选前先在这里查一下：**如果你要补的这一仗已经是别人的经典战**（例如为王龁补长平之战，而白起一行已有长平之战），`战役` 和 `年份` 必须和任务表里**一字不差**，这样游戏才认得出是同一场、一局里只打一次。

## 三、每一场要交的 15 个格子

| 列名 | 要求 |
|---|---|
| `generalId` | 从名单原样抄。同一位名将补几场就写几行。 |
| `战役` | 通行战役名，如「伊阙之战」。 |
| `年份` | **阿拉伯整数**，公元前写负数，如 `-293`。（这一格是给程序读的，可以用数字。） |
| `类型` | 只能写 `野战`、`攻城`、`守城` 之一，站在**这位名将一方**说：他去打别人的城＝攻城，别人来打他守的城＝守城。 |
| `战场或目标` | 屏幕上显示的地名，古典名，如「伊阙」「襄阳」。 |
| `纬度`、`经度` | 战场的十进制坐标，如 `34.56`、`112.47`。攻城、守城填那座城的坐标；野战填战场。 |
| `敌方国号` | 对手的国号或族名，用通行的写法，如「韩国」「罗马共和国」「匈奴」。 |
| `敌将` | 对方主将的通行中文译名；不详就空着。 |
| `会面台词` | 这位名将邀请主角同去的一句话，四十字以内，第一人称，如「韩魏合兵屯于伊阙，某欲先击其弱，壮士可愿同往？」 |
| `应答` | 主角的回答，二十字以内，如「愿随将军破敌！」 |
| `历史资料` | 同《播报提示词》：史实摘要，不上屏，三百字以内，异说和史料不足要写明。 |
| `史料出处` | 同《播报提示词》。 |
| `战略播报` | 同《播报提示词》：一整段，**八十九到一百四十四字**（可按内容略多几个字，但不能多太多，2026-11-11 改定），天下大势在前，不剧透本战结果。 |
| `战术播报` | 同《播报提示词》：一整段，**八十九到一百四十四字**（同上）。 |

## 四、交稿格式

- 用**一个代码块**输出**制表符分隔（TSV）**的表格，第一行是表头，十五个列名依次为：generalId、战役、年份、类型、战场或目标、纬度、经度、敌方国号、敌将、会面台词、应答、历史资料、史料出处、战略播报、战术播报。格与格之间用制表符，不是空格。
- 每个格子里不许有换行、不许有制表符；空着的格子（如敌将不详）什么都不填，但制表符要留。
- 这一批补不出任何一场，就只输出表头，并在代码块外说明。
- 一次输出不完，先输出一部分，主人说「继续」再接着输出，第二次**仍然带表头**。
- 代码块之外，列出这一批里**有异说、坐标不确定**的场次。

## 五、交稿前自查

- [ ] 每场都是史上有名的大战，是他本人统兵，在他的生卒年之内，不是他的第一场。
- [ ] 补的数量按史实，没有够格的不硬凑。
- [ ] 已经在任务表里出现过的仗，`战役`、`年份` 与任务表一字不差。
- [ ] `年份`、`纬度`、`经度` 是数字；`类型` 只用 野战 / 攻城 / 守城。
- [ ] 两段播报符合《播报提示词》的全部铁律：没有阿拉伯数字、没有括号、没有兵力数量、没有「你」，战略播报不剧透。

## 六、补充规则（2026-11-11 主人定）

- **敌将必填**：主将不详，就写对方当时的君主或最高统帅（必须是史有其名的人）。游戏里没有这个人，我会自动把他登记为战场人物。
- **敌方国号游戏里没有**：先在「经典战·新增势力表」登记这个势力和它的一位名将（见《播报提示词》第八节），再在补选表里用这个国号。
- **年份、坐标拿不准**：估算一个值写上，不能空；在 `历史资料` 里说明是估算。
- 攻城、守城的目标城必须在《据点名单》里有（坐标三十公里内要有据点）；没有的改成野战，或换一场。
- **第 1 批遗留一项**：卡布里亚斯的基奥斯之战，敌方「基奥斯」游戏里没有、也没写敌将。请二选一：在新增势力表登记「基奥斯」和一位史有其名的统帅；或者在补选回填表重交这一行，把敌方国号改成已有势力（如卡里亚）并写上敌将。
