# 云盘四张表 → 游戏数据

两条命令，不用手动下载、不用手动改名。

```
node tools/classic-briefings/fetch-sheets.mjs                                   # 从云盘取四张表进本文件夹
npx tsx tools/classic-briefings/run-batch.mts --dry                            # 先只审稿，不写游戏数据
npx tsx tools/classic-briefings/run-batch.mts                                  # 审稿通过再真导入
```

`fetch-sheets.mjs` 用你已登录的 Chrome 逐张下载（表要逐张下，一次连开多张 Google 会拒几
张），按表头认出是哪一张后改名放进本文件夹。云盘上的表重建过、ID 变了，改脚本里 `SHEETS` 的 id。

`run-batch.mts` 按表头认出四张表，按依赖顺序办：

1. 经典战·新增势力表（势力编号、国号、旗号…）
2. 经典战·史实定稿表（编号、项目、定值…）
3. 经典战播报·回填表（generalId、历史资料…、战略播报、战术播报）
4. 经典战补选·回填表（带「会面台词」那一张）

全部合格后表会移进 `done/<时间>/`（免得重复导入），并把要传回云盘的
「经典战播报·任务表.csv」「经典战补选·名将名单.csv」重新导出到上一层的 `out/`。

有错就停在出错的那一步，后面的不再跑——把报错原文转给写稿方改，改完再放回来跑一次。
重复导入是安全的：势力、人物、播报、补选都按编号覆盖，不会重复加。
