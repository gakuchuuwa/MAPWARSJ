## 命名铁律（GAKU 定，2026-07-05）
1. **四字词**，听起来像技能
2. **不带地名**（长社/鄱阳/阏与等一律不入技名）
3. **贴史料**：`sourceQuote` 引正史原句，技名扣该武将本人锚点/典故
4. **防重**：与 176 个现有技名无 2 字连续重复（先查 `existing_skill_names.txt`）
5. **同效不同名**：引擎效果就那几种（战力/削敌/掷点/减战损/逆转），名字繁衍不增平衡复杂度

## 引擎效果模板（只用已实现 baseEffect）
| baseEffect | series | phase | 参数 | 味道 |
|---|---|---|---|---|
| ally_power_mult | enhance | opening_roll | magnitude 1.3–1.4；劣势必配 `ratio_underdog` | 战力碾压 |
| enemy_sub_troops_opening | troop | pre_opening_troops | magnitude 0.15 | 火攻/奇袭/伏击削敌 |
| luck_variance_self | fate | opening_roll | magnitude + **luckMin/luckMax 必写** | 奇谋/翻盘 |
| luck_variance_enemy | fate | opening_roll | luckMin/luckMax（低）| 坚守挫敌锐 |

## 四步落地（每技）
1. UNIQUE_T1 数组加条目（538–1248 行，字段见上）
2. 自动进 `TACTICAL_SKILL_ENTRIES_V1`（`...UNIQUE_T1` spread，无需手动）
3. `TACTICAL_ASSIGN_TIER` 加 `ts_xxx: 'limited'`
4. `GENERAL_PROFILES` 把该 generalId 的 tacticalSkillId 改成新 id
→ `npm run tactical:assign-audit` + `npm run build`
