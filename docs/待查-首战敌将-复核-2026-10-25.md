# 首战敌将复核 2026-10-25

> 范围：`src/data/GeneralFirstBattles.ts` 全部 562 条「武将首战」。
> 口径：首战＝该武将最知名的战争（游戏里玩家首次会面打的那一仗）；双方武将必须实名且符合史实，**敌将必须是那一战当年在世、在任、在场的人**。
> 方法：① 机器扫描（寿命/自打/势力不符/同将复用）② 6 批人工逐条核（每批 ~94 条，核对史书与维基）。
> 结论：**「拿该势力挂着的那位名将顶替该战真实指挥官」是系统性现象**，562 条里约 60 条（≈11%）有此类问题；其中绝大多数真实指挥官在现有 1497 人库中根本没有。

## 三、机器扫描另两类（不属「敌将选人」问题）

1. **敌将档案势力 ≠ 首战敌方势力 id：48 条**。例：张辽合肥之战（215）敌方写「东吴」而 id 填 `nanqi`（南齐）；孙坚阳人聚（191）敌方写「董卓军」而 id 填 `wuzhou_d`（武周）。势力 id 多半是占位填充，显示名多为对的；属势力数据另一案。
2. **生卒年数据本身不准（人选正确）：约 20 条**。例：王建 847~918（应 877~943，高丽太祖）／亨利二世 1166~1197（应 973~1024）／博吉斯拉夫 1454~1523（1184 那位应卒 1187）／阿尔斯兰 940~998（1117 应为阿尔斯兰沙）／伊萨克·科穆宁 1007~1060（应卒 1196）／希尔库赫 1100~1146（应卒 1169）／阿只拔都 1500~1555（1380）／帖木儿灭里 1335~1378（1221）／严纲卒年写成 -191（应 191）等。修这些是改 `GeneralLifeYears`，属①档年份错误，但影响百岁模式登场，建议单独一批做。

## 四、修法建议

1. 二类表里 42 条：按既定办法新增**战场人物**（`BattlefieldCharacters`，只这一仗出场、不进城池掷将、立绘留空走势力池回落），逐条替换 `enemyGeneralId`；约 30 条可挂现成势力，其余需同时补势力。
2. 三-1 类（48 条势力 id）：单独批量把 `enemyFactionId` 改成与 `enemyFactionName` 相符的真实势力（缺势力的先补）。
3. 三-2 类（~20 条生卒）：单独批量改 `GeneralLifeYears`，逐条写依据。
4. 我方武将错的几条：需要重选该将的「最知名战争」，逐条定。
