## ① 三国志10（S10DB）—— 当前主力

**目录** `public/SUCAI/S10DB/`，共 931 个文件。

**命名** `{id}-1.png`。每个 id = 一张 8 帧横排 sheet（8 动画帧 × 1 方向）。

**尺寸（两档行高）**：
- 步兵 / 弓 / 弩 / 枪：`512×64`（8 帧 × 64px）
- 骑兵：`672×84`（8 帧 × 84px）
- 引擎用 `frameHeightNorm = frameH/64` 归一化，84px 骑兵自动换算成等效 64px 视觉高度。

**8 方向**：直接存 8 张（光荣素材自带完整 8 向），原始顺序 `0=南 → 7=东南`（顺时针）。
映射到游戏 `dir8()` 时，UnitAssets.ts 里的 id 数组**已经按游戏 dir8 顺序排好**（0=东北…7=北），直接对应，无需镜像。

**动作**：`MOVE / ATTACK / IDLE / DAMAGE / DEATH` 5 个基础，远程（弓/弩）额外有 `SHOOT`，骑兵额外有 `CHARGE`。

**玩家色**：光荣素材本身是中性灰，`SpriteTinter` 按亮度直接染色，无需转灰。

**映射写法**（UnitAssets.ts）：
```ts
'archer': {
    MOVE: [283,284,285,286,287,288,289,290].map(id => `/SUCAI/S10DB/${id}-1.png`),
    // 每动作 8 个连续 id = 8 方向（按游戏 dir8 顺序）
}
```

## ② 帝国征服（AoE2 原版/HD）—— 日本武士

**目录** `public/SUCAI/SAMURAI/`。

**命名** `{action}_{0-7}.png`，action ∈ `idle / move / attack / death`（4 个）。

**格式** SLP 2.0N，从原版 `Data/graphics.drs` 提取（武士 SLP 编号 attack=974 / death=977 / idle=980 / walk=984）。

**8 方向**：AoE2 原版只存 **5 方向**（`0=南 1=西南 2=西 3=西北 4=北`），东边 3 向运行时镜像（官方 "mirror west angles to east"）。`DIR_MAP`（游戏 dir8 → (AoE2 方向, 是否水平镜像)）：

```python
DIR_MAP = [
    (3, True),   # 0 NE 东北 = 西北镜像
    (2, True),   # 1 E  东   = 西镜像
    (1, True),   # 2 SE 东南 = 西南镜像
    (0, False),  # 3 S  南   = 南
    (1, False),  # 4 SW 西南 = 西南
    (2, False),  # 5 W  西   = 西
    (3, False),  # 6 NW 西北 = 西北
    (4, False),  # 7 N  北   = 北
]
```

**动作**：`idle / move / attack / death` 4 个，`DAMAGE` 复用 `attack`（原版无受击动画）。

**玩家色**：SLP 玩家色是蓝色调色板 `PAL[16..23]`，解码时用 `player_gray()` 转中性灰（否则亮蓝阶亮度 >180 会被 SpriteTinter 当金属高光保留成蓝边）。

**提取工具**：`scripts/slp2png.py`（纯 Python 解 DRS/SLP）+ `scripts/samurai_convert2.py`（5 向+镜像 → 8 向 → 8 帧抽稀）。

## ③ 帝国决定（AoE2 DE）—— 精锐武士、步弓手

**目录** `public/SUCAI/SAMURAI_ELITE/`、`public/SUCAI/ARCHER/`。

**命名** `{action}_{0-7}.png`，action ∈ `idle / move / attack / death`（4 个）。

**格式** SLDX（SLD），从 `resources/_common/drs/graphics/*.sld` 提取。主图层 DXT1(BC1) 压缩，另有 DXT4 阴影/玩家色遮罩（MAPWAR 忽略遮罩）。

**8 方向**：DE 直接存 **16 方向**（22.5°/格，DAT `angle_count=16`），取偶数角得 8 主方向：

```
DE 16 向顺序（顺时针）：0=东 1=东南东 2=东南 3=南东 4=南 5=南西 6=西南 7=西西
                        8=西 9=西北西 10=西北 11=北西 12=北 13=北东 14=东北 15=东北东
偶数角 = 8 主方向：0=东 2=东南 4=南 6=西南 8=西 10=西北 12=北 14=东北
```

`GAME_DIR_TO_DE_ANGLE`（游戏 dir8 → DE 偶数角）：

```python
GAME_DIR_TO_DE_ANGLE = [14, 0, 2, 4, 6, 8, 10, 12]
# 即 游戏0(NE)→14  1(E)→0  2(SE)→2  3(S)→4  4(SW)→6  5(W)→8  6(NW)→10  7(N)→12
```

**动作**：`idle / move / attack / death` 4 个，`DAMAGE`、`SHOOT` 均复用 `attack`（DE 无独立受击/射击动画，攻击帧即拉弓/挥刀）。

**帧数**（DAT 权威，`genieutils-py` 查 `angle_count` / `frame_count`）：

| 兵种 | idle | walk | attack | death |
|---|---|---|---|---|
| 精锐武士 u_inf_samurai_elite | 60 | 30 | 45 | 45 |
| 步弓手 u_arc_archer | 60 | 30 | 30 | 30 |

**玩家色**：DE 主图层已把玩家色区域（背旗等）渲成中性灰（16~109 灰阶），**无需转灰**，SpriteTinter 按亮度直接染色（实测无蓝边）。

**提取工具**：
- `scripts/sld2png.py`：通用 SLDX 解析器（DXT1/DXT4 + 命令数组），`--probe` 看帧结构。
- `scripts/aoe2de_unit_convert.py`：一个命令提取任意兵种：
  ```
  python aoe2de_unit_convert.py <SLD前缀> <输出目录> <idle帧> <walk帧> <attack帧> <death帧>
  ```
- `genieutils-py`：`DatFile.parse('empires2_x2_p1.dat')` 查兵种 angle_count / frame_count。

## 方向统一约定（游戏 dir8）

三套素材最终都输出成 **8 张方向 sheet**，命名 `{action}_{0-7}.png`（S10DB 例外，用数字 id），对应游戏 `dir8()`：

```
0=东北(NE) 1=东(E) 2=东南(SE) 3=南(S) 4=西南(SW) 5=西(W) 6=西北(NW) 7=北(N)
```

每张 sheet = 该方向 **8 动画帧横排**（8 × 64px = 512 宽，或骑兵 8 × 84px = 672 宽）。
