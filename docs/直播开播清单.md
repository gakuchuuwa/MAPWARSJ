# YouTube 直播开播清单

> 2026-10-27 傍晚按现行代码重写口令与积分两节。只做 YouTube 单平台演示；正式链路不使用其他聊天中转或站外打赏。F9 模拟测试不等于真实直播验收。
> 现阶段先涨粉、再挣钱，目标与步骤见 `docs/直播目标计划.md`。

## 一、一次性准备

1. 在 Google Cloud 新建项目，启用 **YouTube Data API v3**。
2. 创建 API 密钥，并把 API 限制设为 **YouTube Data API v3**。密钥由本机 Node 服务使用，不要按浏览器密钥设置“网站”限制，也不要公开。
3. Super Chat 要等频道进了 YouTube 合作伙伴计划（500 订阅起）才能开；现在没有真钱入口，免费口令和增长积分照常可用。
4. 启动游戏开发服务。`npm run dev` 会同时启动本机 `127.0.0.1:8787` 的 YouTube 服务；也可单独用 `npm run live:youtube` 启动它。

## 二、每次开播

1. YouTube 直播延迟选“超低延迟”。
2. 在直播控制室依次进入“修改 → 实时聊天”，把“谁可以发送消息”设为“订阅者”，所需订阅时长选最短，保存。这样新订阅者即可发免费指令，不需要游戏逐个查询订阅关系。
3. 游戏里按 F9：
   - 第一次填写 API 密钥和本场直播网址，回车。
   - 以后只换本场直播网址，密钥留空即沿用。
   - 密钥和账务保存在本机 `.local/youtube-live/`，不进入浏览器配置或 Git。
4. 等 F9 显示“YouTube 官方聊天流已连接”和“频道增长数据正常”。用订阅账号发一条测试弹幕，确认“最近弹幕”更新。
5. 只保留一个主记账页面；其他打开的游戏页面会等待接管。主页面关闭后，另一页可接管，不能同时记账。
6. 频道开通 Super Chat 以后，再另用一个**非订阅测试账号**验证它在「仅订阅者聊天」下还能不能付款；没实测前，不宣称真钱入口也只限订阅者。注意：**不公开（unlisted）的直播没有 Super Chat**，真钱验收必须用公开直播。
7. 在聊天里发下面「置顶留言」并置顶。

## 三、当前口令与积分（与代码一致，2026-10-27）

全体观众共同操作同一个主角。主角在战略地图上自己找武将投奔；只有主角本人在这一仗里、而且官职至少是斥候，才能放技。

| 口令 | 什么时候能用 | 花多少积分 | 结果 |
|---|---|---|---|
| `技3`（数字 1～100） | 打仗时 | 数字就是出价 | 主角爆发技：12 秒内满血、伤害×4、攻速×2、受伤只剩四分之一。斥候只管主角本人，探马是主角加本队。出价高的先放，同价先到先放；放完一发才放下一发 |
| `攻` `胜` `敌` `混` `并` `败` | 打仗时 | 每计 3 分 | 主角六计，按先后放；作用范围同样跟官职走（武将自己放的计仍是全军） |
| `名 新名字 5` | 任何时候 | 要高于当天最高价 | 立刻改主角名。最多 6 个字，带网址、长串数字、违规词的直接拦下、不扣分 |
| `投1 3` | 主角离开势力、在战略地图上时 | 不写分数＝在当前最高价上加 1 | 面板列出可去的地方（斥候：上次同文化的势力；探马：上次同文化的武将），主角当场改道。别人出更高价可改选，被改掉的人原数退回；没人选就照常自动找武将 |

- **积分怎么来**：普通弹幕不加分，只算「在场」（最近 10 分钟说过话）。在场的人在下面三种时候加分：
  - 点赞每满一档 +1 分（在线 10 人以下一个赞就是一档；人多了一档＝在线人数的十分之一，最多 50 个；一次最多 +3）；
  - 频道订阅数每涨 1，+2 分（一次最多 +6）；
  - 本场在线人数创新高 +1 分（10 人以下每多 1 人、50 人以下每多 5 人、再往上每多 10 人算一次）。
- 积分**一直保留**，不按天清零；单次出价最多 100 分，超过的口令直接拒收、不扣分。
- 这一仗打完还没轮到的技和计，积分原数退回；已经放出去的不退。
- 主播一键否决恶意名字：HUD 主角名字旁的「否决」。名字立刻恢复成上一个，该词以后都拦下，那笔积分退回给出价人。
- Super Chat / Super Sticker 现在只记成「实验点」鸣谢：原始金额、币种和事件编号由本机服务保存，**不放技、不换积分**。开通后怎么给付费效果，见 `docs/直播目标计划.md` 阶段三。

### 置顶留言（复制粘贴，不超过 200 字）

```
【弹幕操控主角】订阅后发言即算在场：点赞、新订阅、在线创新高时在场的人都加积分。打仗时发 技3 放主角爆发技（出分高先放），发 攻 胜 敌 混 并 败 放计（3分）。改主角名：名 新名字 分数。主角离队时发 投1 选去处。
```

## 四、恢复与排障

| 现象 | 检查 |
|---|---|
| 本地 YouTube 服务未启动 | 启动 `npm run live:youtube`，再刷新游戏 |
| 找不到直播视频或活动聊天室 | 确认本场正在直播、聊天已开启、网址是本场而非上一场 |
| 接口 403 | 检查 YouTube Data API v3 是否启用、密钥限制和当日配额 |
| 弹幕不到游戏 | 确认 F9 聊天流已连接、发送账号符合订阅者专享条件 |
| 刷新或断线 | 服务端会重发未 ACK 事件；已 ACK 事件凭事件编号去重，不重复入账 |
| 观众说口令没反应 | 先看面板最近记录：没在打仗、主角不在这一仗、官职还是平民、积分不够，都会写明原因 |
| 付款记录 | Super Chat 现在只记实验点；原始金额、币种、事件编号都在 `.local/youtube-live/state.json` 的 payments 里，不折算技能 |

**真实验收标准：**必须用真实 API 密钥、真实直播视频 ID 和订阅账号验证「观众发口令 → 主角在画面里真的做出来、只做一次」；本地 F9 与自动化测试通过，不算真实直播已跑通。真钱一项等频道开通 Super Chat 后用公开直播另验。
