# 直播开播清单

> 2026-10-25 写。只写「点哪里、填什么、看到什么算对」。规则数字是开播前定的初值，上播看效果再调。

## 一、一次性准备（只做一次）

### 1. 读弹幕：Social Stream Ninja（SSN，免费）
1. 装 SSN 浏览器扩展：socialstream.ninja
2. 扩展里 Global settings → Mechanics，打开两个开关：
   - Enable remote API control of extension
   - Send chat messages to API server
3. 扩展弹窗里抄下「会话 ID」。**这串等于密码，别给任何人看**——拿到它就能伪造打赏。

### 2. 读点赞、订阅：YouTube 接口密钥（免费）
1. 打开 console.cloud.google.com，新建一个项目
2. 「API 和服务 → 库」，搜 YouTube Data API v3，点启用
3. 「API 和服务 → 凭据 → 创建凭据 → API 密钥」
4. 点开这把密钥，加两个限制后保存：
   - 应用限制选「网站」，填 `http://localhost:5173/*`
   - API 限制选 YouTube Data API v3

### 3. 收钱：Ko-fi（YouTube 超级留言要 1000 订阅后才开，在那之前靠它）
1. 在 ko-fi.com 注册，绑定 PayPal 或 Stripe 收款
2. SSN 里打开 Monetization → Fourthwall, Ko-fi & Buy Me a Coffee alerts → 选 Ko-fi → Copy webhook URL
3. 打开 ko-fi.com/manage/webhooks，把这串贴进 Webhook URL，保存
4. 注意：观众打赏时勾了「私密」的，不会转进游戏

### 4. 游戏里按 F9 填一次（会记住，以后不用再填）
- SSN 会话 ID → 回车
- YouTube 接口密钥 → 回车
- 打赏方式：填你的 Ko-fi 地址，例如 `ko-fi.com/你的名字` → 回车。不填，面板就不显示打赏

## 二、每次开播

1. YouTube 开播，直播延迟选「超低延迟」（观众放的计才赶得上）
2. 复制本场直播网址 → 游戏里按 F9 → 粘到「本场直播网址」那一格 → 回车。**每场网址都不一样，每次都要换**
3. 在装了 SSN 的浏览器里，打开本场直播的聊天弹出窗口，开播期间别关
4. 看 F9 最上面那几行，都对了再开始：
   - 「直播间已连接　最近弹幕 N 秒前」：有人说话后 N 会变小
   - 「点赞接口正常」
   - 如果出现红字「游戏开在 5174 端口」：关掉多开的游戏，只留一个
5. 在 YouTube 聊天里发下面这段并置顶
6. 按 F9 收起测试区，开始

## 三、置顶留言（复制粘贴）

```
【发弹幕参战】打仗时发 1 站攻方、2 站守方，再发 攻 胜 敌 混 并 败 替本方放计。站队 +1 令，每 20 秒一条弹幕 +1 令，3 令放一计。点赞满一档、有新将士订阅，全军擂鼓加令。打赏每 $1 马上放一计，Ko-fi 留名请用你的 YouTube 名字。
```

## 四、怎么让人进来看

- **剪片段发 Shorts。** 每场挑一两段「观众一计翻盘」剪成 60 秒竖屏，发 YouTube Shorts。新频道的直播很难被推荐，Shorts 更容易被推给不认识你的人，再把人带回直播间。
- **固定时间开播。** 让看过的人知道几点再来。
- **简介里写清三句话玩法，加上 Ko-fi 链接。**

## 五、出了问题看这里

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 右边面板不出现 | SSN 没连上 | F9 看第一行；会话 ID 填对了吗，SSN 两个开关开了吗 |
| 「最近弹幕」秒数一直涨，观众说话没反应 | SSN 读的那个聊天窗口关了 | 重新打开本场直播的聊天弹出窗口 |
| 「点赞接口出错 403」 | 密钥的两个限制填错，或今天额度用完 | 对一遍第一节第 2 步；额度每天太平洋时间零点重置 |
| 「这场直播已结束，请填本场直播网址」 | F9 里还是上一场的网址 | 换成本场网址，回车 |
| 观众说打赏了却没放出计 | Ko-fi 留名和 YouTube 名字不一样 | 让他用 Ko-fi 上那个名字在直播间发一条弹幕，钱会自动认到他名下 |
| 面板说「免费那次用过了」之类的旧话 | 游戏还是旧版本 | 刷新游戏页面 |

## 六、现在的规则（我定的初值，上播看效果再调）

- 军令：开战后站队 +1；每 20 秒一条有效弹幕 +1（纯表情、重复的不算）；3 令放一计；最多攒 10 令；每天清零
- 免费计：全场每 10 秒最多放一计；每人同时只排一计，排着时再点的那一计，等前一计放完自动接上
- 付费计：每 $1 一计，不受上面两条限制，插到队伍最前面
- 点赞：一档 = 在线人数的五分之一，最少 5、最多 50；满一档，最近 10 分钟说过话的人每人 +1 令。一个人只能点一次赞，取消再点不重复算
- 订阅：每涨 1，在场每人 +2 令，并语音感谢
- 语音：付费计每次念「感谢某某」；免费计只在没别的话要念时才念（说话时战斗音效会停，念太多就听不到打仗声）
- 大字：武将放的计是白字；观众放的是金字，上面一行小字「某某 献计」，付费的名字带金框；观众的计不让武将立绘跳
