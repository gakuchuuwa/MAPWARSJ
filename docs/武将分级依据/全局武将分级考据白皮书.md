# MAPWARSJ 全局武将分级与定判考据白皮书

本文档记录了全图 15 个大区（中原、北方、草原、西域、中亚、青藏、东北、江南、滇缅、岭南、巴蜀、河西、朝鲜、日本）共计 700余名武将的“名将/普将”定级依据（锚点/落闸）。
此定级严格遵循历史真实性，**“只论亲手打赢的那一仗，非名气非道德”**。
