### 🔴 据点体系分类与定级铁律（2026-10-01 主人怒斥定死，唯一口径，禁止擅自乱改）

> 🔴 **主人原话（2026-10-01 主人怒斥定死最高准则）**：
> **「请记住，不要擅自乱改，**
> **据点先区分城市和险要和战场。**
> **关隘，要塞，堡垒，兵家必争之地，并且有石头城墙的为险要，PASS，其他为城市。**
> **城市标准，人口大于50万左右为大城，大于10万左右为中城，大于1万左右为小城，以下为城寨。查不到史料人口的推算，算不出来的一律按小城和城寨算。**
> **没有人迹的为战场。」**

- **区分三大体系**：
  1. **【战场】**：没有人迹的旷野/隘口/荒滩。
  2. **【险要 (PASS)】**：关隘、要塞、堡垒、兵家必争之地，**并且有石头城墙的**，两项缺一不可；其他一律为城市。
  3. **【城市】**：其他有人迹、非险要的聚落城池。
- **城市四大人口等级**：
  - **大城 (big_city)**：人口大于 **50万左右**；
  - **中城 (medium_city)**：人口大于 **10万左右**；
  - **小城 (small_city)**：人口大于 **1万左右**；
  - **城寨 (stockade)**：人口小于 **1万左右**；
- 🔴 **兜底铁律**：**查不到史料人口的推算，算不出来的一律按【小城】和【城寨】算！** 严禁盲目凭空提级。
- 🔴 **绝对铁律**：**不要擅自乱改！** 任何据点定级改动必须以史料人口为依据或经主人明确核准，AI 绝不许自作主张修改。

- **一路一句**：挂点只挂真机走过的据点，走到哪讲到哪；文中文案不写代词、不写兵力确数，严禁用“大帝”尊号（一律直呼“亚历山大”），**严禁使用“古城”、“古都”、“旧都”**（2026-10-02 主人定死：历史发生时城池是当下存在的，非后人视角的词眼，直呼城名或称“重镇”、“要塞”、“城池”、“首府”、“名城”），**严禁使用后人上帝视角与已知历史结果**（2026-10-02 主人怒斥定死：严禁使用「波斯末王」、「亡国之君」等已知结局词，当时大流士是当朝万王之王，直称「波斯国王大流士」；严禁使用「即将覆灭」「注定灭亡」等剧透词，全篇保持历史进行时的现场直播感）。

## 四、势力名称定名规则——【细则已外置】

> **外置**：完整规则见 **`docs/AGENTS/faction-naming.md`**（4.0 定名算法、4.1 五级优先级、4.2–4.8 各类型细则与示例表）。
> 定旗号/势力名相关任务**必须先读该文件**。

**核心红线（摘要）**：

1. **遍历单位 = 据点**（`cities_v2` 每个点），不是 `factions.ts` 表；从 §4.1 优先级 1→5 试，命中即停。
2. **旗号禁字**：旗面 1–2 字**不得含「州」「国」**（宿州→`宿`、黎国→`黎`）；势力全名不受限。
3. **旗号全局唯一**：字符串严格相等 = 同一势力；旗号 ↔ 据点名仅禁**严格相等**（共享汉字合法：井陉关+`井陉`）。
4. **后缀禁令**：族/人/国/朝/氏/家 剥除（苗族→`苗`、袁氏→`袁`）；史籍整词专名不截字（`月氏`≠`月`）。
5. **绝不用 panjun**：无 1–5 级可考依据，也要**新建一个符合史实的真实势力**（按该坐标可考身份/相邻据点立势），绝不落叛军旗。
## 五、5 文件一致性——【细则已外置】

> **外置**：完整规则见 **`docs/AGENTS/five-file-sync.md`**（5 文件清单、5.4 录入后验收步骤、5.5 骨架优先与势力 A/B/C 分级、录入阶梯）。
> 新增/修改/删除势力（5 文件同步）相关任务**必须先读该文件**。

**核心红线（摘要）**：

1. **5 文件必须同步**：`factions.ts` / `cities_v2.ts` / `StartingCapitals.ts` / `CityAssetManager.ts` / `SandboxDisplayNames.ts`；用 FactionEditor `/api/batch-import`（增/改）或 `/api/batch-delete`（删，自动清道路），**不要手动写 5 处**。
2. **⚠️ 首都映射铁律（血训）**：新建势力**必须**在 `StartingCapitals.ts` 写入首都映射（如 `'taizhou': 'city_hailing'`）——漏写 → 引擎把该据点强制降格给 `panjun` → 空旗不显示（海陵城血训，绝对禁止再犯）。
3. **录入顺序铁律（5.5）**：先定大中城 → 铺民族/家族密度 → 投名将/精锐；**禁止**为小势力腾位而改大中城坐标、据点名或旗号。
4. **势力 A/B/C/D 分级**：A（大城/国都/区中心，冻结，应有将精 T0–T1）、B（中城/州郡治，稳定，建议将精）、C（民族/小家族/关隘，可增，仍须配将/精，禁借将借精）、D（以上未覆盖者，一律满配将/精，禁止 panjun）。
5. **改完必跑**（硬缺口须为 0）：`npm run add:check -- <据点名>` / `faction:sync-audit` / `expedition:triple-check`（有精锐时）/ `city:spacing`（新坐标时）/ `city:dossier`。
