# MAPWAR 名将历史首征目标系统 — 设计与实现报告

> 更新:2026-07-06 ｜ 数据直接从代码提取 = 游戏实际生效配置。已配 76(含 16 个知名远征名将扩充),另 35 走文化中心。

## 一、系统是什么
慢直播叙事:跟拍名将军团远征时,默认先打该名将史上标志性的**进攻终点/宿敌老巢**(远征爽点),打下攥稳后转选文化中心;目标被夺回则下次再夺。绑 generalId,仅跟拍军团生效。

## 二、运行时规则(2026-07-06「达标即自动远征」,无按钮无面板)
```
跟拍名将军团兵力够4万 → 自动远征,查历史目标 H:
 ├ H 不在己方 → 自动出征 H(横幅显示 ⭐label,如⭐反攻丰臣)
 ├ H 已在己方 → 自动出征最近异文化中心
 └ 无 H       → 自动出征最近异文化中心
```
