# MAPWAR 名将历史首征目标系统 — 设计与实现报告

> 生成日期:2026-07-06 ｜ 本报告数据**直接从代码提取**,即游戏实际生效的配置。检查本报告 = 检查代码。

## 一、这是什么 / 为什么做

慢直播叙事增强功能。跟拍的**名将军团**攒够远征兵力后,系统**默认先带它去打该名将史上最有代表性的进攻终点 / 宿敌老巢**(制造直播看点),打下并稳定占领后才转为选文化中心;若目标被敌方夺回,下次远征会**再去夺回**。历史目标 = 这名将的"执念",反复拉锯,直播上很有戏。

两类看点:
- **封禅/成名之战**:霍去病封狼居胥、岳飞直捣黄龙、项羽入关灭秦、李世民虎牢擒两王
- **反攻宿敌老巢(包袱)**:李舜臣跨海讨秀吉、吴起远征打秦锐士、陈国峻反攻忽必烈、戚继光跨海讨倭、李定国北伐直捣清廷

## 二、运行时规则(玩家看到什么)

> **达标即自动远征**(2026-07-06 起):跟拍军团兵力够 4 万即自动出征,**无按钮、无选择面板、无倒计时**。

```
跟拍名将军团兵力够 4 万 → 自动远征,系统查该名将的历史目标 H:
 ├─ H 不在己方手里(没打下 / 打下后又被夺回) → 自动锁定 H,断粮出征
 │      · 顶部横幅显示:  🐎 远征中 → ⭐目标名
 ├─ H 已在己方手里(攥稳了)              → 自动选最近异文化中心(原有逻辑)
 └─ 该名将未配历史目标 / 军团无主将       → 自动选最近异文化中心
```
- 目标绑 **generalId**(执念跟名将本人走,占城不过户)
- **仅跟拍军团**会远征(镜头=玩家唯一干预通道;**AI 军团永不远征**);历史目标**不受"异文化"限制**(该打就打,无论文化区)
- 达标线有**滞回锁**:到过 4 万即解锁,战斗掉破 4 万仍保留资格,直到低于 2 万才重锁(避免按钮/资格在 4 万线抖动)
- DEV 快捷键 **X**:把跟拍军团补到 4.5 万,半秒内自动出征(历史目标优先),便于秒验证

## 七、怎么测

1. 跟拍任一名将军团(军团列表点一支带将的),兵力攒够 4 万即**自动出征**
2. 顶部横幅变`🐎 远征中 → ⭐目标`,军团直奔历史目标(断粮不回)
3. 想秒验证:跟拍后按 **X 键**(DEV)补到 4.5 万,半秒内自动出征
