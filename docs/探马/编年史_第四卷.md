# 编年史 · 第四卷 · 信英雄（终）：西去与汉武（公元前 199 — 前 87）

> 年份：平行宇宙，一律定数，参照史实、不差太多。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。
> 「主角所在」由 Claude 定（专业判断），大事凭已有知识整理、未逐条联网核对。
> 身份：西行流浪 → 塞琉古具装骑兵 → 巴克特里亚骑兵 → 欧克拉提德骑兵 → 安息骑兵 → 张骞的向导 → 汉军骑兵 → 相马官 → 李陵部下 → 匈奴中的俘虏。
> 西方战事由探马行会送马，主角通灵参与（前 165、前 142、前 100）；主角本人在西方的年份就亲身参战。
> 「信英雄」收尾：霍去病早逝（或被救活却默默无闻）、卫青病故、李陵投降、李广利投降被杀，武帝下诏停止远征——英雄救不了国家。下一卷转入「信制度」。
> 标签：★ 骑兵相关大事。没有大事的年份照样保留一行（主角在哪写清楚），那一年玩什么由游戏里的故事块决定。
