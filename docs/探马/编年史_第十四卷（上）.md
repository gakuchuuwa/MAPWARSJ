年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

主题「信大势」（终·上册）：接第十三卷公元 1368 年（主角五十四岁在山西太原扩廓帖木儿军中闻元亡北狩），主角随[扩廓帖木儿](https://zh.wikipedia.org/zh-cn/%E6%93%B4%E5%BB%93%E5%B8%96%E6%9C%A8%E5%85%92)（王保保）亲历 1369 年初太原十八骑突围、1370 年沈儿峪之战与 1372 年[岭北之战](https://zh.wikipedia.org/zh-cn/%E6%98%8E%E5%A4%AA%E7%A5%96%E7%AC%AC%E4%BA%8C%E6%AC%A1%E5%8C%97%E4%BC%90)大破明军徐达中路军，至 1375 年王保保病逝后（年六十一）离开北元，在阿尔泰山西麓乌伦古河畔以「马蜕」回春；回春后为严守「不投见过自己老年样子的人（避开北元与扩廓旧部）」与「不在同一场战争中倒戈打旧同袍（不投明军打北元）」两条铁律，主角西赴罗斯莫斯科公国，在 1380 年亲历[库利科沃之战](https://en.wikipedia.org/wiki/Battle_of_Kulikovo)伏击大破金帐汗国马迈；随后东返大兴安岭东麓投入兀良哈朵颜部（与和林旧部无交集），于 1388 年在驻地通过探马行会送来的参战战马通灵亲历蓝玉[捕鱼儿海之战](https://zh.wikipedia.org/zh-cn/%E6%98%8E%E5%A4%AA%E7%A5%96%E7%AC%AC%E5%85%AD%E6%AC%A1%E5%8C%97%E4%BC%90)覆灭北元汗廷，并在 1389 年亲历明朝设立「[朵颜三卫](https://zh.wikipedia.org/zh-cn/%E5%85%80%E8%89%AF%E5%93%88%E4%B8%89%E5%8D%AB)」，于 1399—1402 年作为朵颜三卫铁骑随燕王朱棣亲历[靖难之役](https://zh.wikipedia.org/zh-cn/%E9%9D%96%E9%9A%BE%E4%B9%8B%E5%BD%B9)（白沟河、东昌、夹河、藁城、灵璧之战），同时通过通灵马补齐西方[科索沃之战](https://en.wikipedia.org/wiki/Battle_of_Kosovo)（1389）、[特雷克河之战](https://en.wikipedia.org/wiki/Battle_of_the_Terek_River)（1395）、[尼科波利斯之战](https://en.wikipedia.org/wiki/Battle_of_Nicopolis)（1396）与[安卡拉之战](https://zh.wikipedia.org/zh-cn/%E5%AE%89%E5%8D%A1%E6%8B%89%E4%B9%8B%E6%88%98)（1402，[帖木儿](https://zh.wikipedia.org/zh-cn/%E5%B8%96%E6%9C%A8%E5%84%BF)对巴耶济德一世）；靖难之役结束后，主角不愿随明军北伐草原旧族，遂在天山巴里坤湖完成第二次「马蜕」回春并西赴欧洲，亲身参战 1410 年[格伦瓦尔德之战](https://en.wikipedia.org/wiki/Battle_of_Grunwald)（坦能堡之战）、1415 年[阿金库尔之战与 1420—143](https://en.wikipedia.org/wiki/Battle_of_Agincourt)4 年[胡斯战争](https://en.wikipedia.org/wiki/Hussite_Wars)（[扬·杰式卡](https://en.wikipedia.org/wiki/Jan_%C5%BDi%C5%BEka)以铁链大车阵配火铳火炮连败十字军重装骑士），并通过通灵马见证[明成祖远征漠北](https://zh.wikipedia.org/zh-cn/%E6%98%8E%E6%88%90%E7%A5%96%E8%BF%9C%E5%BE%81%E6%BC%A0%E5%8C%97%E4%BC%90)（1410 斡难河、1414 忽兰忽失温神机营配铁骑破瓦剌），至 1435 年在顿河霍皮奥尔河畔完成第三次「马蜕」回春。
