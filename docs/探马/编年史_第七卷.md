# 编年史 · 第七卷 · 信制度（续）：埃德萨、廉台、阿德里安堡、参合陂（公元 221 — 公元 395）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。
> 「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、未逐条联网核对。
> 身份：流浪者 → 萨珊具装骑兵（阿达希尔一世麾下）→ 萨珊东方边骑（呼罗珊）→ 萨珊具装骑兵（沙普尔一世麾下）→ 帕尔米拉具装骑兵 → 罗马机动骑兵（奥勒良麾下）→ 流浪者 → 西晋凉州骑兵（马隆麾下）→ 西晋边军骑兵 → 幽州突骑 → 石勒骑兵 → 慕容鲜卑骑兵（慕容廆、慕容皝麾下）→ 前燕具装铁骑（慕容恪麾下）→ 流浪者 → 萨珊具装骑兵（沙普尔二世麾下）→ 东罗马辅助骑兵 → 哥特骑兵 → 流浪者 → 前秦骑兵（慕容垂部下）→ 后燕骑兵 → 北魏骑兵（拓跋珪麾下）。
> 主题「信制度」：双马镫与甲骑具装让骑兵本身变成了一座座钢铁堡垒，但无论是西晋的分封与门阀制、还是罗马的军团与边境安置制，一旦统治者贪鄙背信，最坚固的制度也会从内部瞬间崩塌。
> 双马镫考古实物集中出土于四世纪中叶辽西前燕墓葬（单镫见于 302 年长沙西晋墓），平行宇宙里将双马镫与甲骑具装的成建制普及定于辽东慕容氏时期（323–352）。
