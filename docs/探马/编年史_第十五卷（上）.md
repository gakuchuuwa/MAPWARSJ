# **编年史 · 第十五卷（上） · 尽人事，知天命（起）：查尔迪兰、达比克草原、帕维亚、莫哈奇、川中岛、桶狭间（公元 1501 — 公元 1560）**

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长一个从军一生（四十年上下），老了离开后以「马蜕」回春、换名重来；同一时间只跟一个政权。

「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、重要节点已联网核对。

身份（第十五卷全卷）：流浪者（阴山呼和诺尔「马蜕」后西行河中与波斯）→ 波斯萨法维帝国「红头军」铁骑（沙阿伊斯梅尔一世麾下，回春换名）→ 埃及马穆鲁克苏丹国皇家骑兵（苏丹坎苏·古里、图曼贝伊二世麾下，换名）→ 流浪者 → 法兰西王室「敕令重装骑兵」（法王弗朗索瓦一世与「无畏无瑕骑士」巴亚尔麾下，换名）→ 匈牙利王国与哈布斯堡边防重骑兵（路易二世、帕尔·托莫里与斐迪南一世麾下，换名，随军变老）→ 流浪者（天山伊犁河谷赛里木湖「马蜕」回春、东渡日本）→ 日本甲斐武田氏「赤备」骑马队（武田信玄、饭富虎昌、山县昌景、武田胜赖麾下，回春换名，随军变老至六十二岁）→ 流浪者（日本信浓乘鞍岳深山「马蜕」回春、西渡明朝）→ 明朝蓟镇「车骑营」与辽东铁骑（戚继光、李成梁、李如松麾下，回春换名，随军变老）→ 流浪者（东渡日本）→ 丰臣大坂城「真田赤备」骑马队（[真田信繁 / 真田幸村](https://zh.wikipedia.org/zh-cn/%E7%9C%9F%E7%94%B0%E4%BF%A1%E7%B9%81)麾下，换名，至五十九岁於纪伊熊野深山「马蜕」回春）。

主题「尽人事，知天命（火药时代）」（起·上册）：接第十四卷公元 1500 年（主角六十岁在阴山北麓呼和诺尔完成第五次「马蜕」回春为二十岁青年，携蒙古—河曲混血乌骓小马「墨麟」），主角正式迈入两千三百年旅程的第五阶段——「尽人事，知天命（火药时代）」：面对火炮、火绳枪与长矛车阵不可逆转地主宰战场的时代洪流，明知传统骑兵冲锋已难改大局，仍与东西方最后一代骑士、马穆鲁克与武田赤备一道尽人事至最后一刻。为严守「绝不投奔见过自己老年模样的蒙古旧识」之铁律，二十一岁的主角于 1501 年骑着「墨麟」西行穿越河中前往波斯，投入萨法维帝国开国雄主沙阿伊斯梅尔一世麾下「红头军」（Qizilbash）铁骑，亲历 1510 年[梅尔夫之战](https://en.wikipedia.org/wiki/Battle_of_Merv)伪退全歼乌兹别克昔班尼汗，并在 1514 年亲历震动伊斯兰世界的[查尔迪兰之战](https://en.wikipedia.org/wiki/Battle_of_Chaldiran)（四万极端排斥火器的萨法维纯骑兵向奥斯曼苏丹塞利姆一世的大车阵火炮与耶尼切里火绳枪发起悲壮决死冲锋，在败方浴血突围）；随后主角南下叙利亚与埃及投入马穆鲁克苏丹国，在 1516 年[达比克草原之战](https://en.wikipedia.org/wiki/Battle_of_Marj_Dabiq)与 1517 年[里达尼亚之战](https://en.wikipedia.org/wiki/Battle_of_Ridaniya)中再度亲历传承两百六十年的马穆鲁克骑兵在奥斯曼火器面前覆灭；1518 年主角渡海赴意大利投入法兰西王室敕令重装骑兵（随法王弗朗索瓦一世与「骑士绝唱」巴亚尔），通过通灵马见证东方明武宗应州大捷（1517）与美洲科尔特斯[奥通巴之战](https://en.wikipedia.org/wiki/Battle_of_Otumba)（1520），并于 1524—1525 年亲睹巴亚尔被火绳枪击穿脊柱阵亡及[帕维亚之战](https://en.wikipedia.org/wiki/Battle_of_Pavia)（西班牙大方阵与火绳枪在猎苑泥林中全歼法兰西王室重装骑士、生擒法王弗朗索瓦一世）；紧接着主角东赴匈牙利亲历 1526 年[莫哈奇之战](https://en.wikipedia.org/wiki/Battle_of_Moh%C3%A1cs)（在败方突围）与 1529 年[第一次维也纳保卫战](https://en.wikipedia.org/wiki/Siege_of_Vienna_\(1529\))（在胜方守城），通过通灵马补齐 1526 年[第一次帕尼帕特之战](https://en.wikipedia.org/wiki/First_Battle_of_Panipat)（巴布尔以大车火炮配翼侧弓骑创建莫卧儿帝国）；1532—1533 年主角年满五十二岁在天山伊犁河谷赛里木湖完成「马蜕」回春，携赤红小马「流火」东行，通过通灵马见证印加[卡哈马卡之战](https://en.wikipedia.org/wiki/Battle_of_Cajamarca)（1532），并于 1540 年首次东渡日本进入甲斐国，投入二十岁的武田晴信（武田信玄）麾下，亲手参与缔造威震日本战国的「武田赤备」骑马队（[上田原合战](https://en.wikipedia.org/wiki/Battle_of_Uedahara)、前三次[川中岛之战](https://zh.wikipedia.org/zh-cn/%E5%B7%9D%E4%B8%AD%E5%B3%B6%E4%B9%8B%E6%88%B0)），并通过通灵马见证 1550 年蒙古俺答汗「庚戌之变」，至 1560 年[桶狭间之战](https://en.wikipedia.org/wiki/Battle_of_Okehazama)织田信长崛起，为下册第四次川中岛合战、三方原、长篠之战与真田幸村大坂夏之阵铺平道路。
