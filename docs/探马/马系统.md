# 马系统（第一版）

> 写于 2026-10-22。依据 `骨架.md` 主人定的规则：马是第二主角；马会老会死，死前生小马，通灵的联系传给下一代；马的谱系必选。
> 下面的数字都是 Claude 定的（专业判断），说明理由后可以调。
> 代码：`src/player/HorseStable.ts`（马厩本体）、`src/player/HorseStablePanel.ts`（马厩面板）。

## 一、玩家能看到什么

- 玩家面板上有一块坐骑小牌子：`🐎 初马 6岁 健壮`，颜色随状态变（绿＝健壮、黄＝疲劳、红＝受伤）。
- 点小牌子打开「马厩」：每匹马的名字、公母、马龄、状态、来历，通灵马标「✦通灵」，正在骑的标「坐骑」；可以点「骑这匹」换坐骑。
- 马厩下面是「通灵马谱系」：第几代、名字、生卒年。

## 二、规则

| 项 | 规则 | 理由 |
|---|---|---|
| 马龄 | 按游戏年份算，没有公元 0 年 | 和编年史一致 |
| 能骑 | 三岁起 | 军马三岁开始调教 |
| 寿限 | 通灵马 22–27 岁；普通马 18–25 岁 | 马常见寿命二三十年，战马更短；通灵马稍长，让一代能跟主角十来年 |
| 生小马 | 通灵马 12–15 岁时生一匹小马（公马就写「配种得了」） | 小马长到能骑、能接班时，老马正好老去 |
| 通灵传代 | 通灵马老死，通灵传给它生的小马，谱系记一代 | 骨架：马死前生小马，联系传给下一代 |
| 一代多长 | 约 14 年；从前 800 到 1860 约 190 代 | 模拟实测：300 年传了 22 代 |
| 疲劳 | 以「季」计，到期自动好；骑着累的马，单骑行军速度 ×0.85 | 一季＝游戏 15 秒，看得出来又不拖 |
| 受伤 | 以「季」计；受伤的马不能骑，自动换一匹能骑的；一匹能骑的都没有就牵马步行，速度 ×0.6 | 让「有几匹马」有用处 |
| 自动换坐骑 | 坐骑受伤、老死、被抢时自动换；同等状态优先骑通灵马 | 直播挂机时不用人管 |
| 普通马 | 会老死、可能被抢；通灵马不会被抢 | 谱系必选，不能断 |
| 海上 | 不受马影响 | 坐船 |
| 生老病死 | 只在百岁模式里发生 | 《探马》全部在百岁模式 |
| 跳年 | 马的年龄、疲劳受伤剩余季数不变 | 跳年是年代跳转工具，不是时间流逝 |
| 还没得到马 | 行军不受影响 | 开局醒来前那一刻 |

## 三·五、马的记忆（通灵）

- 有的马记得一场仗（`memoryId`，记忆表在 `src/story/horseMemories.ts`）。马厩里这匹马下面写「👁 记得：大马士革城下（前 796）· 还没通灵／同步／完全同步」，还没完全同步的有「通灵」按钮。
- 通灵＝以那匹马当年骑手的身份把那一仗再打一遍（战术模式小队战），不占游戏时间。
- 同步率三档：打赢＝同步（学到马经）；打赢且整场没落马＝完全同步（再学到一种兵模）；打输＝失步（记忆断开，可以再进去一次）。只记最好的一次。
- 新加一段记忆：在 `HORSE_MEMORIES` 里加一条（战场、年份、双方小队、马经、兵模），故事块里 `addHorse({ …, memoryId })` 把马交给玩家即可。

## 三·六、马经图鉴

- 条目表 `src/story/horseLore.ts`（唯一出处）：标记名、标题、全文、分类（养马／战法／传说）、在哪儿学到。学到＝玩家有那个剧情标记。
- 马厩面板最下面列出全部条目：学到的显示全文，没学到的显示「？？？」和提示。
- 「看牙口」（URT-07）有实际用处：外来的马（买来、缴来）学会之前马龄显示「？岁」（马厩和玩家面板的坐骑牌子都是），通灵马一脉一直知道。
- 通灵战役同步时学到的马经也从这张表取全文（`horseMemories.ts` 里只写标记名）。

## 三·七、马具名词（主人定，2026-10-22，写文案一律照此用词）

> 主人原话：「马嘴里含的叫衔，又叫马嚼子，通过衔可以链接缰绳，衔的左右插着的铁片叫镳，例如分道扬镳。一整套头部马具，叫勒。悬崖勒马。马背子上的垫子叫马鞍。赶马叫鞭，珠子做的叫策。」

| 名词 | 是什么 | 例 |
|---|---|---|
| 衔（马嚼子） | 马嘴里含的那根，缰绳就系在衔上 | — |
| 镳 | 插在衔左右两头的铁片 | 分道扬镳 |
| 勒 | 一整套头部马具 | 悬崖勒马 |
| 马鞍 | 马背上的垫子 | — |
| 鞭 | 赶马用的 | — |
| 策 | 竹子做的（赶马用的） | — |

> 主人更正（2026-10-22）：「是竹子的」——策是竹子做的，不是珠子。

Claude 注（只供参考，不改上表）：「马鞍」是马背上的座子，鞍下垫的毡子另叫「鞯」。
