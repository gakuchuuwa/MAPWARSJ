# 编年史 · 第十三卷（上） · 信大势（起）：成吉思汗怯薛、野狐岭、花剌子模、迦勒迦河、三峰山、莱格尼察、赛约河、艾因贾鲁特、襄樊、崖山（公元 1206 — 公元 1286）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长一个从军一生（四十年上下），老了离开后回春、换名重来；同一时间只跟一个政权。

身份（第十三卷全卷）：蒙古帝国「[怯薛](https://zh.wikipedia.org/zh-cn/%E6%80%AF%E8%96%9B)」铁骑（[成吉思汗](https://zh.wikipedia.org/zh-tw/%E6%88%90%E5%90%89%E6%80%9D%E6%B1%97)、哲别、[速不台](https://en.wikipedia.org/wiki/Subutai)麾下，随军变老）→ 流浪者（陇右回春）→ 南宋京湖「忠顺军」骑兵（孟珙麾下，回春换名）→ 流浪者（西行回春）→ 埃及马穆鲁克骑兵（拜巴尔、[忽都思](https://en.wikipedia.org/wiki/Qutuz)麾下，回春换名）→ 流浪者（帕米尔回春）→ 大元宿卫与南征铁骑（忽必烈、伯颜、阿术、张弘范麾下，回春换名，随军变老）→ 流浪者（阿尔泰山回春）→ 大元河西屯戍铁骑（安西王阿难答麾下，回春换名）→ 大元「钦察卫」亲军铁骑（床兀儿、海山、[燕帖木儿](https://zh.wikipedia.org/zh-cn/%E7%87%95%E5%B8%96%E6%9C%A8%E5%84%BF)麾下，土土哈卒后转调入卫，随军变老）→ 流浪者（西行回春）→ 英格兰王室骑兵与下马骑士（爱德华三世、[黑太子爱德华](https://en.wikipedia.org/wiki/Edward_the_Black_Prince)麾下，回春换名）→ 流浪者（东归）→ 元末察罕帖木儿、扩廓帖木儿（王保保）铁骑（换名）。

主题「信大势」（起）：在第十二卷风波亭看破庙堂制度之虚妄后，主角在本卷投身于席卷欧亚大陆的蒙古铁骑洪流——他向[成吉思汗](https://zh.wikipedia.org/zh-tw/%E6%88%90%E5%90%89%E6%80%9D%E6%B1%97)献马军治理与轮牧伴当之策，亲历一万亲卫「[怯薛](https://zh.wikipedia.org/zh-cn/%E6%80%AF%E8%96%9B)」的建立（推一把，怯薛由成吉思汗创立），在[野狐岭战役](https://zh.wikipedia.org/zh-cn/%E9%87%8E%E7%8B%90%E5%B6%BA%E6%88%B0%E5%BD%B9)、灭花剌子模、哲别与[速不台](https://en.wikipedia.org/wiki/Subutai)绕里海远征之[迦勒迦河之战](https://en.wikipedia.org/wiki/Battle_of_the_Kalka_River)中见证天下无敌的草原大势；成吉思汗病逝后，他在陇右回春，为严守不倒戈打旧同袍及不让蒙古旧识撞见年轻容貌之规，南下汉水投入南宋名将孟珙「忠顺军」骑兵，在[蔡州之战](https://zh.wikipedia.org/zh-cn/%E8%94%A1%E5%B7%9E%E4%B9%8B%E6%88%B0)站在宋军一边亲历宋蒙联军灭金，继而随孟珙亲历[端平入洛](https://zh.wikipedia.org/zh-tw/%E7%AB%AF%E5%B9%B3%E5%85%A5%E6%B4%9B)后的江陵、黄州抗蒙血战与 1239 年收复襄阳，并通过探马行会送来的通灵马见证[三峰山之战](https://zh.wikipedia.org/zh-cn/%E4%B8%89%E5%B3%B0%E5%B1%B1%E4%B9%8B%E6%88%98)与拔都、速不台长子西征的[莱格尼察之战](https://en.wikipedia.org/wiki/Battle_of_Legnica)、[赛约河之战](https://en.wikipedia.org/wiki/Battle_of_Mohi)、[克塞山之战](https://en.wikipedia.org/wiki/Battle_of_K%C3%B6se_Da%C4%9F)；然而当蒙古大军看似不可阻挡之时，大汗蒙哥陨落于[钓鱼城之战](https://zh.wikipedia.org/zh-cn/%E9%87%A3%E9%AD%9A%E5%9F%8E%E4%B9%8B%E6%88%B0)，主角又在埃及马穆鲁克军中亲历 1260 年[艾因贾鲁特之战](https://en.wikipedia.org/wiki/Battle_of_Ain_Jalut)首次正面挡住蒙古铁骑；东归大元后，他亲历[襄樊之战](https://zh.wikipedia.org/zh-cn/%E8%A5%84%E6%A8%8A%E4%B9%8B%E6%88%98)、[崖门海战](https://zh.wikipedia.org/zh-cn/%E5%B4%96%E9%97%A8%E6%B5%B7%E6%88%98)天下一统，并在下册亲历 1328 年[燕帖木儿](https://zh.wikipedia.org/zh-cn/%E7%87%95%E5%B8%96%E6%9C%A8%E5%84%BF)钦察卫的[两都之战](https://zh.wikipedia.org/zh-cn/%E5%A4%A9%E6%9B%86%E4%B9%8B%E8%AE%8A)、西行英法百年战争亲历[克雷西之战](https://en.wikipedia.org/wiki/Battle_of_Cr%C3%A9cy)与[普瓦捷之战](https://en.wikipedia.org/wiki/Battle_of_Poitiers)英格兰长弓破法兰西重骑，最终在 1368 年于山西太原军中听闻大都失守、元顺帝退回塞北草原（[北元](https://zh.wikipedia.org/zh-tw/%E5%8C%97%E5%85%83)）——主角由此顿悟：站到最强的一边以为顺应了天命，可最强的帝国也会内斗分裂、大势本身也会变，连骑兵本身都开始在步弓与火器面前走下坡路。
