# 编年史 · 第十三卷（下） · 信大势（起）：乃颜之乱、海都之战、两都之战、克雷西、普瓦捷、元亡北狩（公元 1287 — 公元 1368）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。  
原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长一个从军一生（四十年上下），老了离开后回春、换名重来；同一时间只跟一个政权。  
「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、重要节点已联网核对。  
身份（第十三卷下册）：大元宿卫与北征铁骑（忽必烈、玉昔帖木儿、李庭麾下，随军变老）→ 流浪者（阿尔泰山回春）→ 大元「钦察卫」亲军铁骑（土土哈、床兀儿、[燕帖木儿](https://zh.wikipedia.org/zh-cn/%E7%87%95%E5%B8%96%E6%9C%A8%E5%84%BF)麾下，回春换名，随军变老）→ 流浪者（西行回春）→ 英格兰王室骑兵与下马骑士（爱德华三世、[黑太子爱德华](https://en.wikipedia.org/wiki/Edward_the_Black_Prince)麾下，回春换名）→ 流浪者（东归）→ 元末察罕帖木儿、扩廓帖木儿（王保保）铁骑（换名）。  
主题「信大势」（起·下册）：接上册公元 1286 年（主角四十四岁在大都任忽必烈宿卫），主角随年逾七旬的忽必烈御驾亲征辽东平定乃颜之乱、北巡和林威慑海都，至五十岁隐入阿尔泰山回春；回春换名后，为避开旧怯薛同袍，他专门投奔由钦察人与西域牧人编成的大元「钦察卫」亲军（土土哈、床兀儿、[燕帖木儿](https://zh.wikipedia.org/zh-cn/%E7%87%95%E5%B8%96%E6%9C%A8%E5%84%BF)三代麾下），亲历铁坚古山大战海都、武宗海山夺位，并在 1319 年通过行会送来的西欧战马通灵感知[金马刺之战](https://en.wikipedia.org/wiki/Battle_of_the_Golden_Spurs)与[班诺克本之战](https://en.wikipedia.org/wiki/Battle_of_Bannockburn)步兵方阵破重装骑士之兆；1328 年他随燕帖木儿钦察卫亲历惨烈的[两都之战](https://zh.wikipedia.org/zh-cn/%E5%A4%A9%E6%9B%86%E4%B9%8B%E8%AE%8A)，目睹黄金家族铁骑在居庸关与潞水自相残杀；六十岁燕帖木儿死后他西行回春，赴欧洲投入英格兰爱德华三世与[黑太子爱德华](https://en.wikipedia.org/wiki/Edward_the_Black_Prince)麾下，在[百年战争](https://en.wikipedia.org/wiki/Hundred_Years%27_War)的[克雷西之战](https://en.wikipedia.org/wiki/Battle_of_Cr%C3%A9cy)（1346）与[普瓦捷之战](https://en.wikipedia.org/wiki/Battle_of_Poitiers)（1356）中亲历英格兰长弓配合下马骑士射翻法兰西重装骑士，亲眼见证统治欧洲千年的重装骑兵开始走下坡路；最后他东归中原投入察罕帖木儿与扩廓帖木儿（王保保）麾下，在 1368 年看着曾横扫天下的大元帝国在军阀内耗与明军北伐中失去中原、退往漠北（[北元](https://zh.wikipedia.org/zh-tw/%E5%8C%97%E5%85%83)）。
