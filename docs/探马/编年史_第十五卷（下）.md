# **编年史 · 第十五卷（下） · 尽人事，知天命（中）：川中岛八幡原、三方原、长篠铁炮、戚继光车骑营、李如松碧蹄馆、翼骑兵基尔霍尔姆、真田幸村大坂夏之阵（公元 1561 — 公元 1615）**

主题「尽人事，知天命（火药时代）」（中·下册）：接上册公元 1560 年（主角四十七岁在甲斐武田氏「赤备」骑马队驻守信浓海津城），主角于 1561 1565 年饭富虎昌自尽后转入其弟山县昌景重组的最强「山县赤备」；1572 年底亲历武田骑兵最后的巅峰绝唱——[三方原之战](https://zh.wikipedia.org/zh-cn/%E4%B8%89%E6%96%B9%E5%8E%9F%E4%B9%8B%E6%88%B0)（雪原冲锋彻底碾碎德川家康与织田援军）；1573 年武田信玄病逝于西上途中，1575 年五月六十二岁、白发苍苍的主角随山县昌景、马场信春、真田信纲在[长篠之战（设乐原合战）](https://zh.wikipedia.org/zh-cn/%E9%95%B7%E7%AF%A0%E4%B9%8B%E6%88%B0)向织田信长、德川家康的三千挺铁炮与三道马防栅发起明知必死而慷慨赴义的赤备冲锋！长篠劫后，主角在信浓与飞騨交界的乘鞍岳深山完成本卷第二次「马蜕」回春（回到二十岁，携甲斐黑驹—西域混血赤栗色小马「绯电」），为严守「绝不让见过自己老年模样的武田与真田昌幸旧部认出」之规，于 1577 年乘船西渡明朝，投入蓟镇总兵戚继光（整训偏厢车、佛郎机炮与骑兵协同的「车骑营」）与辽东总兵李成梁、李如松麾下，亲历辽东铁骑十余次出塞大捷、1583 年古勒寨之战（目睹二十五岁的努尔哈赤领回父祖遗体以十三副遗甲起兵）、以及 1592—1598 年万历朝鲜之役（壬辰倭乱：1593 年正月平壤大捷与[碧蹄馆之战](https://zh.wikipedia.org/zh-cn/%E7%A2%A7%E8%B9%84%E9%A6%86%E5%A4%A7%E6%88%B0)三千辽东铁骑死战小早川隆景两万日军、1597 年[稷山之战](https://en.wikipedia.org/wiki/Battle_of_Jiksan)），同时通过通灵马补齐摩洛哥[三王之战](https://en.wikipedia.org/wiki/Battle_of_Alc%C3%A1cer_Quibir)（1578）、[本能寺之变](https://zh.wikipedia.org/zh-cn/%E6%9C%AC%E8%83%BD%E5%AF%BA%E4%B9%8B%E5%8F%98)（1582）、[忠州弹琴台之战](https://en.wikipedia.org/wiki/Battle_of_Chungju)（1592）、[关原合战](https://zh.wikipedia.org/zh-cn/%E9%97%9C%E5%8E%9F%E4%B9%8B%E6%88%B0)与上田合战（1600）、以及波兰翼骑兵在[基尔霍尔姆之战](https://en.wikipedia.org/wiki/Battle_of_Kircholm)（1605）与[克卢希诺之战](https://en.wikipedia.org/wiki/Battle_of_Klushino)（1610）用六米空心长骑枪冲破火枪方阵的传奇；1613 年秋，五十七岁、须发皆白的主角在阔别日本三十八年后（昔日武田旧将及真田昌幸均已谢世）再度东渡日本，赶赴大坂城投入真田幸隆之孙——四十七岁的[真田信繁（真田幸村）](https://zh.wikipedia.org/zh-cn/%E7%9C%9F%E7%94%B0%E4%BF%A1%E7%B9%81)麾下，协助重组满城皆赤的「真田赤备」，亲历 1614 年大坂冬之阵·真田丸之战与 1615 年五月七日[大坂夏之阵·天王寺冈山决战](https://zh.wikipedia.org/zh-cn/%E5%A4%A7%E5%9D%82%E4%B9%8B%E5%BD%B9)——五十九岁的主角随真田幸村率三千五百赤备武士顶着漫天铁炮铅弹三冲德川家康十五万大军本阵，继四十二年前三方原之后第二次砍倒德川家康的「金扇马印」，直至真田幸村力战阵亡、获赞「日本第一兵」！同年冬，主角在纪伊熊野深山完成本卷第三次「马蜕」回春（回到二十岁，携奥州—蒙古混血连钱骢小马「苍雪」），而大陆辽东的努尔哈赤恰于本年十一月正式编立满洲「八旗」制度，引出第十六卷。
