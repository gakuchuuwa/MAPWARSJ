## 〇、为什么从乌拉尔图起步（Claude 的分析）

条件：在游戏日历内（公元前 800 年以后）；适合新手阶段（能输、能学马）；是骑兵史的起点；往后能连下去；游戏里有可用数据。

| 候选 | 优点 | 缺点 |
|---|---|---|
| **乌拉尔图（约前 745）** | 产马之国，适合学马；前 743 年战败，新手输得合理；败后被俘进亚述，自然转线；北边是后来辛梅里安、斯基泰南下的通道，以后能接草原；游戏里已有图什帕、萨尔杜里 | 观众陌生；年代是约数，史料多出自敌国亚述 |
| 亚述（约前 745） | 骑兵改革中心，史料最多；游戏里已有提格拉特、萨尔贡 | 亚述是赢家，新手战败只能是个人的；一开局就站在帝国一边 |
| 斯基泰、辛梅里安草原（约前 700） | 真正的骑马民族，骑射源头 | 几乎没有可靠纪年，游戏数据少；起点要推迟到约前 700 |
| 西周、春秋中国（前 800 起） | 观众熟悉，游戏数据最全 | 只有战车，骑兵还要等近 500 年 |
| 库施、埃及（约前 727） | 皮耶爱马，接得上努比亚 | 战车为主，离草原和后面的主线都远 |

**选乌拉尔图的理由：**
1. 新手阶段最顺：在产马之国学马，第一仗就战败、昏迷。
2. 转线不用硬接：战败被俘进亚述，接上游戏里已有的提格拉特、萨尔贡。
3. 往后的路是通的：北边高加索是草原骑兵南下的通道，后面接斯基泰、草原、中国。
4. 陌生反而是优点：玩家和主角一样不知道「这是哪里」，梦醒的开头才有效。

**缺点**：年代是约数、史料偏亚述一方，这一段细节要多核对，宁可粗写，不编。

## 一、乌拉尔图是什么（给主人的背景）

- **名字**：亚述人叫它乌拉尔图，它自称「比亚伊尼利」【待核】。
- **地方**：今土耳其东部、亚美尼亚、伊朗西北的高原，围着凡湖。都城**图什帕**，在凡湖东岸的岩山上【确】。游戏里已有据点「图什帕」。
- **国王**（约数，待核）：
  - 梅努阿（约前 810–前 786）：修了长长的引水渠，后世还在用【常见说法】。
  - 阿尔吉什蒂一世（约前 786–前 764）：前 782 年建埃里布尼城，即今天的埃里温【常见说法】。
  - **萨杜里二世（约前 764–前 735）**：乌拉尔图最强盛时，势力伸进叙利亚北部，与阿尔帕德结盟。游戏里已有武将「萨尔杜里」。
  - 鲁萨一世（约前 735–前 714）：在位时遭萨尔贡二世远征。
- **信仰**：主神哈尔迪；圣城穆萨西尔有哈尔迪神庙，前 714 年被萨尔贡洗劫【常见说法】。
- **马**：乌拉尔图及周边山地以养马、训马著称，是亚述骑兵马匹的重要来源；萨尔贡远征时的书信里写到当地为乌拉尔图王的骑兵养马【待核】。
- **别的特征**：山顶要塞、引水渠、葡萄酒、青铜器（头盔、盾、马具）【常见说法】。

## 二、开头框架（五幕）

### 第一幕　梦醒（约前 745，图什帕附近）
- 主角在凡湖边的牧场醒来，不知身在何处，也不知道自己是谁。
- 一匹马走近，他第一次与马通灵，从马的记忆里知道：**这里是乌拉尔图，王是萨杜里，神是哈尔迪。**
- 这一幕同时是通灵马的教学：玩家学会「读马的记忆」。

### 第二幕　平民（约前 745–前 744）
- 主角是平民，没有军籍，靠懂马活下来。做一些简单任务，每个任务教一样东西：
  - 放牧、饮马：沿引水渠赶马群喝水 → 学会在地图上走路。
  - 找回走失的小马 → 学会寻找、侦察。
  - 给病马、伤马治疗 → 学会治马。
  - 把一批马送到要塞或城里 → 学会长途行军、认路。
- 任务的具体地点、委托人，等框架确认后再定。

### 第三幕　从军（约前 744–前 743）
- 亚述新王提格拉特帕拉萨三世即位、建常备军（前 745）【常见说法】，西边的形势紧张。
- 萨杜里二世出兵叙利亚北部，援助盟友阿尔帕德【待核】。
- 主角因为懂马被征入军中，从马夫做起，凭侦察本事升为**斥候**。

### 第四幕　初战即败（前 743，阿尔帕德一带）
- 亚述大败乌拉尔图联军；亚述铭文说萨杜里二世**连夜骑一匹母马逃走**【待核】——国王靠一匹马保住了命，这一幕和主角的身份正好呼应。
- 主角受伤落马，昏迷。
- 地点：阿尔帕德离阿勒颇约 30 公里，按 40 公里规则可用游戏里现成的「阿勒颇」据点代表这一片；战场确切位置待核（亚述铭文另有地名，在库姆赫一带）。

### 第五幕　醒来（约前 740，亚述）
- 阿尔帕德被亚述围了约三年才陷落（前 743–前 740）【待核】。
- 主角醒来时，已是亚述的俘虏，被派去照料缴获的乌拉尔图战马。
- 从这里转入亚述线：后面接游戏里已有的提格拉特首战（前 732 大马士革围城）、萨尔贡首战（前 714 远征乌拉尔图）。这两段怎么排，下一步再定。
