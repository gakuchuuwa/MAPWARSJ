## 一、主角这一段的线（Claude 建议）

秦军骑兵 → 蒙恬北军打匈奴 → 王离统北军南下 → 巨鹿战败、新安逃生 → 投汉 → 灌婴骑兵 → 垓下追项羽 → 白登被围。

这条线的几个史实支点：
- **北军是一支连续的军队**：蒙恬率三十万北击匈奴；始皇死后蒙恬被赐死，北军由王离统领；前 208–前 207 年王离率北军南下围赵，在巨鹿被项羽击败、被俘。主角跟着这支军队走，不用换部队。
- **新安坑卒**：前 207 年项羽在新安坑杀投降的秦卒二十万。主角是秦卒，从这里逃生，是这一段最重的一场戏。
- **汉军骑兵是秦人骑士带出来的**：彭城大败后，刘邦要组建骑兵，众人推举秦朝旧骑士李必、骆甲，二人以自己是秦人为由推辞，于是以灌婴为将、李必骆甲为校尉（出自《史记·樊郦滕灌列传》）。主角也是秦朝旧骑兵，正好和他们一起进入灌婴的骑兵——「推一把，不抢功」。
- **垓下**：项羽突围，汉军派骑将灌婴率五千骑追击。

## 三、要注意的地方

1. **通灵马的时间差**：通灵要等马被带到身边。从意大利、北非到中国，按游戏速度路上要 4.5–10 个游戏年，所以坎尼（前 216）、扎马（前 202）的马最早几年后才到。玩家是在事后读记忆，这与「记忆是过去的事」一致，但读的时间要排在马走到之后。
2. **空年**：前 220–前 216、前 213–前 211 没有骑兵大战。按主人定的「骑兵不是主角的战争也可以参加」，可以去南征百越，或者守边练兵。
3. **主角在秦军中的阶段，前 229–前 221 年是「新手」还是已经是老兵**，取决于上一段怎么接过来，下一步再定。
4. **缺的武将**：灌婴、樊哙、李必、骆甲、头曼游戏里没有。要用到就要加（主人已授权「剧情需要可以加」），等这一段框架定了再加。
