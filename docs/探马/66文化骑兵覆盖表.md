# 66 文化骑兵覆盖表

> 主人定（2026-10-23）：「项目中有66个文化，有骑兵文化的，最好都掺和下，例如高句丽也有骑兵。日本武田，织田，真田也有骑兵。好像印度也有骑兵。」
>
> 规矩：游戏里 66 个建筑文化（＝66 支基础军团）中，**有骑兵传统的，每个文化至少要有一场本文化的骑兵仗能玩**（主角亲身参加，或者用通灵马参加）。主角**站在这个文化那一边**最好，至少要让玩家看到这个文化的骑兵怎么打；只当敌人一闪而过的不算数。
>
> 「已覆盖」是 Claude 按第一～十三卷「主角所在」栏粗查的结果（2026-10-23），只作参考。

## 一、没有骑兵传统的（不用硬塞）

美洲马匹 1492 年以后才引进，以下文化本土没有骑兵：**阿兹特克系（AMERICA）、印加（INCA）、穆伊斯卡（MUISCA）、图皮（TUPI）、玛雅（MAYANS）**。
另有几个文化以步兵、海军为主，骑兵很弱，可以不专门安排：**马来（MALAY）、维京（VIKINGS）、丹麦（DANES）、瓦良格（VARANGIANS）、雅典（ATHENIANS）、斯巴达（SPARTANS）、希腊（GREECE）**。

## 二、已覆盖得比较好的（不用补）

罗马、马其顿、色雷斯、法兰克、蒙古草原（匈奴、突厥、蒙古）、库曼（萨尔马提亚到钦察）、中原、河朔、江南、巴蜀、河西、东北（女真、八旗之前）、德意志、英格兰、拜占庭、西亚（阿拉伯、马穆鲁克）、匈人、突厥（塞尔柱）、中亚、萨珊、波斯、吐蕃、西域、鲜卑与契丹、旁遮普（贵霜、塔拉因）、意大利、西西里（诺曼）。
