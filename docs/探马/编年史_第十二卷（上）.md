# 编年史 · 第十二卷（上） · 信制度（终）：铁浮屠、靖康、背嵬军、郾城、卡特万、采石（公元 1116 — 公元 1161）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长约一个从军一生（约 40 年），老了离开后回春、换名重来；同一时间只跟一个政权。

身份（第十二卷全卷）：女真完颜部铁骑与金军「铁浮屠」（完颜阿骨打、完颜宗翰、完颜宗望、完颜娄室、完颜宗弼麾下，随军变老）→ 流浪者（嵩山回春）→ 南宋岳家军「背嵬军」铁骑（宗泽、岳飞、岳云、张宪麾下，回春换名，随军变老）→ 流浪者（河西回春）→ 西辽大石铁骑（耶律大石、萧塔不烟麾下，换名）→ 流浪者 → 南宋川陕与江淮骑兵（吴璘、刘锜、虞允文麾下，换名）→ 流浪者（西行回春）→ 意大利伦巴第同盟重装骑士（米兰「死神连队」，回春换名）→ 东罗马重骑兵（曼努埃尔一世麾下，换名）→ 阿尤布王朝马穆鲁克与突厥弓骑兵（萨拉丁麾下，换名）→ 流浪者（呼罗珊回春）→ 蒙古乞颜部「那可儿」铁骑（铁木真麾下，回春换名）。

主题「信制度」（终）→「信大势」（起）：亲历了女真「猛安谋克」制与重甲骑兵「铁浮屠」、左右翼「拐子马」在十余年间连灭辽朝与北宋（靖康之变），随后南渡投入岳飞麾下，将毕生相马、护马与破重骑之术倾注于整训南宋最强骑兵「背嵬军」，在[郾城之战](https://zh.wikipedia.org/zh-cn/%E9%83%BE%E5%9F%8E%E4%B9%8B%E6%88%B0)、颍昌正面击溃完颜宗弼（金兀术）的铁浮屠与拐子马；然而就在收复汴京在望之际，宋高宗赵构与秦桧以十二道金字牌强召班师，并在风波亭杀害岳飞父子——主角自第五卷（两汉与罗马）以来坚守千年的「信制度」（相信好军制能救国）在风波亭彻底破碎；下册西行亲历[莱尼亚诺之战](https://en.wikipedia.org/wiki/Battle_of_Legnano)、[密列奥塞法隆之战](https://en.wikipedia.org/wiki/Battle_of_Myriokephalon)、[哈丁之战](https://en.wikipedia.org/wiki/Saladin)与[阿苏夫之战](https://www.medievalists.net/2013/05/the-battle-of-arsuf-7-september-1191/)的东西重骑大战，最终在呼伦贝尔与斡难河畔见证[铁木真](https://zh.wikipedia.org/zh-tw/%E6%88%90%E5%90%89%E6%80%9D%E6%B1%97)崛起，迈向第十三卷「信大势」。
