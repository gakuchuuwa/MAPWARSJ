# 编年史 · 第十卷 · 信制度（续）：平凉、鸦儿军、幽州、莱希费尔德（公元 764 — 公元 960）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。 「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、未逐条联网核对。 身份：唐朔方骑兵（郭子仪、浑瑊麾下）→ 唐神策与河中骑兵（马燧、李晟、浑瑊麾下）→ 流浪者 → 法兰克重骑兵（查理曼、意大利王丕平麾下）→ 东罗马塔格玛重骑兵 → 流浪者 → 唐淮西骑兵（李愬麾下）→ 唐河东与北疆沙陀骑兵（柳公绰、刘沔、石雄、朱邪赤心麾下）→ 河西归义军骑兵（张议潮麾下）→ 流浪者 → 东罗马安纳托利亚骑兵（佩特罗纳斯麾下）→ 维京骑马步兵与威塞克斯骑兵（阿尔弗雷德麾下）→ 流浪者 → 沙陀鸦儿军（李克用麾下）→ 契丹腹心部骑兵（耶律阿保机麾下）→ 流浪者 → 东法兰克重骑兵（亨利一世、奥托一世麾下）→ 流浪者 → 后晋骑兵（符彦卿麾下）→ 后汉与后周殿前司铁骑（郭威、柴荣、赵匡胤麾下）→ 北宋殿前司铁骑。 主题「信制度」：亲历了唐代藩镇割据、吐蕃平凉劫盟、沙陀鸦儿军破黄巢后朱温上源驿背信、五代兵变迭起与契丹「打草谷」之祸，也见证了查理曼采邑重骑破阿瓦尔环堡、维京人骑马劫掠、马扎尔游牧西侵与莱希费尔德德意志重骑决战、拜占庭铁甲具装骑兵（尼基弗鲁斯二世）的复兴——旧的帝国军制在藩镇与骄兵悍将手中沦为篡逆工具，直到后周世宗柴荣与赵匡胤在高平之战后重整殿前司禁军，于 960 年陈桥兵变建立北宋，试图用一套严密防范武将的新制度终结乱世。 标签：★ 骑兵相关大事。没有大事的年份照样保留一行（主角在哪写清楚），那一年玩什么由游戏里的故事块决定。
