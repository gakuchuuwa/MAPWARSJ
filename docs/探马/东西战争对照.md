# 东西战争对照（分段）

> 用法：每段把这段时间里东西两边**所有**有骑兵或战车参战的战争摊开，只列事实，不排转场；主角在哪一方、走哪条线由主人定。
> 状态：凭已有知识整理，**联网未核对**。把握：【确】常见通说；【待核】年份、地点或细节不确定。年份多为通行纪年，近东年代学本身有出入。
> 兵种看点：只写有记载或公认的骑兵、战车作用；写不出的不硬写。

### 其他地区

- 印度：这一时期没有可靠纪年的战役记载（列国时代的战事多见于后世文献），暂缺。
- 草原东部：有骑马民族的考古遗存（如图瓦一带的大型墓葬马具），但没有可纪年的战争记载，暂缺。

### 这一段的事实概况（不含计划）

- **骑兵：** 这一段的骑兵战事几乎都在近东与安纳托利亚——亚述的常备骑兵，以及辛梅里安、斯基泰草原骑兵对定居国家的冲击。
- **战车：** 中国处在春秋战车时代，没有骑兵作战的记载；近东战车与骑兵并存。
- **年代：** 近东事件多出自亚述王室铭文与巴比伦编年史，年份通常可靠到一两年；中国事件出自《左传》《国语》，春秋以后纪年可靠。
