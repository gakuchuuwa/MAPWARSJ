# 编年史 · 第十六卷 · 尽人事，知天命（火药时代）：萨尔浒、宁远、布赖滕费尔德、吕岑、松锦、山海关入关、赫梅利尼茨基起义、维也纳翼骑兵、乌兰布通、昭莫多（公元 1616 — 公元 1700）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长一个从军一生（四十年上下），老了离开后以「马蜕」回春、换名重来；同一时间只跟一个政权。

「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、重要节点已联网核对。

主题「尽人事，知天命（火药时代）」：接第十五卷公元 1615 年冬（主角五十九岁在日本纪伊熊野完成「马蜕」回春回到二十岁，得连钱骢小马「苍雪」），主角于 1616—1617 年渡海返明，为避开昔日辽阳李氏家丁旧识，换名投入陕西援辽总兵杜松麾下，并严守「同一场战争不许倒戈」铁律，在明清战争全程站在明朝一边，亲历 1619 年[萨尔浒之战](https://zh.wikipedia.org/zh-cn/%E8%96%A9%E7%88%BE%E6%BB%B8%E4%B9%8B%E6%88%B0)（败方突围）、1626 年[宁远之战](https://en.wikipedia.org/wiki/Battle_of_Ningyuan)与 1627 年宁锦之战（随[袁崇焕](https://zh.wikipedia.org/zh-cn/%E8%A2%81%E5%B4%87%E7%84%95)关宁铁骑配红夷大炮击退努尔哈赤与皇太极）、1629 年己巳之变北京保卫战、1641—1642 年[松锦之战](https://en.wikipedia.org/wiki/Battle_of_Song-Jin)（败方突围）及 1644 年[山海关之战](https://en.wikipedia.org/wiki/Battle_of_Shanhai_Pass)（目睹多尔衮八旗入关后拒降西行）；期间通过通灵马补齐撞期的欧洲[三十年战争](https://en.wikipedia.org/wiki/Thirty_Years%27_War)（1631 年[布赖滕费尔德之战](https://en.wikipedia.org/wiki/Battle_of_Breitenfeld_\(1631\))、1632 年[吕岑之战](https://en.wikipedia.org/wiki/Battle_of_L%C3%BCtzen_\(1632\))古斯塔夫二世、1643 年[罗克鲁瓦之战](https://en.wikipedia.org/wiki/Battle_of_Rocroi)）与英国清教徒革命[克伦威尔](https://en.wikipedia.org/wiki/Oliver_Cromwell)「铁骑军」（1644 年[马斯顿荒原之战](https://en.wikipedia.org/wiki/Battle_of_Marston_Moor)、1645 年[内斯比之战](https://en.wikipedia.org/wiki/Battle_of_Naseby)）；1648—1651 年亲赴乌克兰参加[哥萨克赫梅利尼茨基起义](https://en.wikipedia.org/wiki/Khmelnytsky_Uprising)（黄水、科尔孙、[兹博里夫](https://en.wikipedia.org/wiki/Battle_of_Zboriv_\(1649\))、[别列斯特奇科](https://en.wikipedia.org/wiki/Battle_of_Berestechko)），于 1652—1653 年在北高加索库班河谷完成本卷第一次「马蜕」回春（得枣骝马「雷翼」）；随后赴西欧与奥地利亲历 1658 年[沙丘之战](https://en.wikipedia.org/wiki/Battle_of_the_Dunes_\(1658\))与 1664 年[圣哥达之战](https://en.wikipedia.org/wiki/Battle_of_Saint_Gotthard_\(1664\))（通灵补齐 1656 年[华沙之战](https://en.wikipedia.org/wiki/Battle_of_Warsaw_\(1656\))、印度莫卧儿[萨穆加尔之战](https://en.wikipedia.org/wiki/Battle_of_Samugarh)与马拉塔[希瓦吉](https://en.wikipedia.org/wiki/Shivaji)[普拉塔普加尔之战](https://en.wikipedia.org/wiki/Battle_of_Pratapgarh)、郑成功收复台湾），1671 年投入波兰统帅[扬·索别斯基](https://en.wikipedia.org/wiki/Battle_of_Vienna)麾下「波兰翼骑兵」，亲历 1673 年霍京之战与 1683 年[维也纳之战](https://en.wikipedia.org/wiki/Battle_of_Vienna)卡伦贝格山两万铁骑下山大冲锋；东归途中通灵 1680 年北美印第安[普韦布洛起义](https://en.wikipedia.org/wiki/Pueblo_Revolt)（战马扩散北美大平原），并于 1688 年（距 1644 年离关已隔四十四年且历经回春换名）投入[康熙帝](https://en.wikipedia.org/wiki/Kangxi_Emperor)清朝八旗军参加平定准噶尔[噶尔丹](https://en.wikipedia.org/wiki/Galdan_Boshugtu_Khan)之役，站在八旗一边亲历 1690 年[乌兰布通之战](https://zh.wikipedia.org/zh-cn/%E7%83%8F%E8%98%AD%E5%B8%83%E9%80%9A%E4%B9%8B%E6%88%B0)（火炮破驼城）与 1696 年[昭莫多之战](https://zh.wikipedia.org/zh-cn/%E6%98%AD%E8%8E%AB%E5%A4%9A%E4%B9%8B%E6%88%B0)，至 1699—1700 年在漠北鄂尔浑河谷完成本卷第二次「马蜕」回春（得铁连钱马「铁骊」）。
