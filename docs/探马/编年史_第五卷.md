# 编年史 · 第五卷 · 信制度（起）：卡莱、郅支、条顿堡、昆阳（公元前 86 — 公元 23）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。
> 「主角所在」由 Claude 定（专业判断），大事凭已有知识整理、未逐条联网核对。
> 身份：匈奴骑兵（俘虏出身）→ 乌孙骑兵 → 安息骑兵 → 郅支部下 → 安息骑兵 → 罗马辅助骑兵（东方、莱茵、瓦卢斯麾下）→ 东行 → 新莽边军骑兵 → 刘秀骑兵。
> 主题「信制度」：见过罗马职业军团、汉朝西域都护这样的好制度，又看着它们毁于内斗（罗马内战、王莽改制激起天下大乱）。
> 罗马降卒东流、郅支城「鱼鳞阵」是后世学者的推测，不是定论；平行宇宙里按推测写。
> 标签：★ 骑兵相关大事。没有大事的年份照样保留一行（主角在哪写清楚），那一年玩什么由游戏里的故事块决定。
