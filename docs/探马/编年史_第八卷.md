# 编年史 · 第八卷 · 信制度（中）：却月、卡塔隆、达拉、沙苑（公元 396 — 公元 589）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。
> 「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、未逐条联网核对。
> 身份：北魏骑兵（拓跋珪麾下）→ 东晋北府军骑兵（刘裕麾下）→ 北魏虎骑（拓跋焘麾下）→ 流浪者 → 西罗马辅助骑兵（埃提乌斯麾下）→ 流浪者 → 探马行会护商骑手 → 萨珊具装骑兵（卑路斯一世麾下）→ 流浪者 → 北魏羽林骑兵 → 武川镇边骑 → 梁白袍军骑兵（陈庆之麾下）→ 关陇骑兵（贺拔岳、宇文泰麾下）→ 突厥骑兵（木杆可汗、室点密可汗麾下）→ 北周府兵铁骑（宇文邕麾下）→ 隋军骑兵（杨坚、贺若弼麾下）。
> 主题「信制度」：北魏迁洛的门阀制与西罗马的雇佣同盟制先后崩塌，但主角在关中亲历并协助草创的「府兵制」（兵农合一、关陇六军），却在五十年间以弱胜强，从沙苑芦苇丛一路打到建康城下重新一统天下——这让他更加笃信：只要制度设计得当，好制度真的能救世定国。
> 西魏「八柱国、十二大将军、二十四开府」府兵制成形于大统八年（542）至大统十六年（550）之间，平行宇宙里统一定于邙山之战（543）后至 550 年间整编完成。
