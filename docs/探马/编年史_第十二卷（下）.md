# 编年史 · 第十二卷（下） · 信制度（终）→ 信大势（起）：莱尼亚诺、密列奥塞法隆、哈丁、阿苏夫、塔拉因、阔亦田（公元 1162 — 公元 1205）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长约一个从军一生（约 40 年），老了离开后回春、换名重来；同一时间只跟一个政权。

「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、重要节点已联网核对。

身份（本册下篇）：流浪者（西行回春）→ 意大利伦巴第同盟重装骑士（米兰「死神连队」阿尔贝托·达·朱萨诺麾下，回春换名）→ 东罗马重骑兵（曼努埃尔一世·科穆宁麾下，换名）→ 阿尤布王朝马穆鲁克与突厥弓骑兵（萨拉丁麾下，换名）→ 流浪者（呼罗珊回春）→ 蒙古乞颜部「那可儿」铁骑（铁木真麾下，回春换名）。

主题「信制度」（终）→「信大势」（起）：上册亲历女真铁浮屠灭辽破宋与岳飞背嵬军郾城大捷，却在风波亭岳飞被害中彻底看破庙堂制度之虚妄；下册西行欧洲与黎凡特，在 1176 年同一年内先后亲历意大利伦巴第自由市民与骑士在[莱尼亚诺之战](https://en.wikipedia.org/wiki/Battle_of_Legnano)击落神圣罗马皇帝「红胡子」腓特烈一世战马，以及拜占庭皇帝曼努埃尔一世在[密列奥塞法隆之战](https://en.wikipedia.org/wiki/Battle_of_Myriokephalon)山口遭罗姆苏丹突厥弓骑设伏惨败；随后在圣地亲历阿尤布苏丹[萨拉丁](https://en.wikipedia.org/wiki/Saladin)于 1187 年哈丁之战以弓骑断水纵火全歼十字军、收复耶路撒冷，以及 1191 年「狮心王」理查一世在[阿苏夫之战](https://www.medievalists.net/2013/05/the-battle-of-arsuf-7-september-1191/)以步弓护骑、雷霆反冲锋击败萨拉丁；东归途中通灵印度[塔拉因之战](https://en.wikipedia.org/wiki/Second_Battle_of_Tarain)与日本一之谷之战，最终在呼伦贝尔与斡难河畔成为[铁木真](https://zh.wikipedia.org/zh-tw/%E6%88%90%E5%90%89%E6%80%9D%E6%B1%97)的早期「那可儿」，亲历[阔亦田之战](https://zh.wikipedia.org/zh-cn/%E9%98%94%E4%BA%A6%E7%94%B0%E4%B9%8B%E6%88%B0)、[合兰真沙陀之战](https://zh.wikipedia.org/zh-cn/%E5%90%88%E5%85%B0%E7%9C%9F%E6%B2%99%E9%99%80-%E6%8A%98%E6%8A%98%E8%BF%90%E9%83%BD%E5%B1%B1%E4%B9%8B%E6%88%B0)、纳忽昆山平定草原诸部，直至 1205 年统一蒙古草原前夕，把成吉思汗建国与怯薛留给第十三卷。
