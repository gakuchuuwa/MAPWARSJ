# 12 战区按时间并排

> 用途：看清同一时期哪几个战区都有大战，再由主人决定主角在哪一边。**只列事实，不排主角路线。**
> 来源：`战区走向.md` 与 `骑兵战役总表.md` 里已列的战争；凭已有知识整理，**联网未核对**。
> 分格：按世纪。公元前的世纪：前 8 世纪＝前 800–前 701，依此类推。
> 战区：①西亚 ②地中海 ③西欧中欧 ④东欧黑海草原 ⑤中亚 ⑥蒙古高原 ⑦中原 ⑧印度 ⑨北非埃及 ⑩东亚边缘 ⑪美洲 ⑫东南亚。
> 战场归区按「战场所在地」：河西、青海、辽东、辽西归⑦；巴尔干归②；匈牙利、波兰归④；印度河上游归⑧。

## 三、重叠热点（同一时期多个战区都有骑兵大战）

> 判断时要分清两种情况：**同一支军队**连打几个战区（主角跟着走就行，不算冲突）；**不同军队**在不同战区同时打（主角只能在一边，另一边靠通灵马）。

| 时期 | 战区 | 情况 |
|---|---|---|
| 前 334–前 326 | ②①⑤⑧ | **同一支军队**：亚历山大东征一路打过去，不冲突 |
| 前 218–前 200 | ②⑨ 布匿战争 ↔ ⑦⑥ 楚汉、白登 | **不同军队**：坎尼、扎马与彭城、垓下、白登同时，主角只能在一边 |
| 前 53–前 36 | ①③② 卡莱、阿莱西亚、法萨卢斯 ↔ ⑤ 郅支城 | 不同军队，西方三场集中，东方一场 |
| 357–395 | ③①② 罗马诸战 ↔ ⑦⑥ 淝水、参合陂 | 不同军队 |
| 530–552 | ①⑨② 贝利撒留、纳尔塞斯 ↔ ⑦ 沙苑 | 西方多为同一支东罗马军队；东方一场 |
| 618–642 | ⑦⑥ 唐初诸战 ↔ ① 阿拉伯征服 | 不同军队，两边都是大转折 |
| 751–757 | ⑤ 怛罗斯 ↔ ⑦ 香积寺 | 两场都有唐军，但相隔数千公里 |
| 1066–1071 | ③ 黑斯廷斯 ↔ ① 曼齐克特 | 不同军队 |
| 1140–1141 | ⑦ 郾城 ↔ ⑤ 卡特万 | 不同军队，只隔一年 |
| 1187–1192 | ① 十字军诸战 ↔ ⑧ 塔拉因 | 不同军队 |
| 1204–1260 | ⑥⑧④⑦① 蒙古诸战 ↔ ③ 布汶 | 蒙古各战多为同一大势力的不同军团，分属多个方向 |
| 1514–1532 | ①②⑧④⑪⑨ | **最密集**：查尔迪兰、帕维亚、帕尼帕特、莫哈奇（同为 1526）、美洲征服同时 |
| 1605–1696 | ④③ 欧洲 ↔ ⑦⑥ 明清、准噶尔 | 不同军队，东西都密 |
| 1805–1860 | ③④ 拿破仑战争、克里米亚 ↔ ⑦ 八里桥 | 西方集中在前半段，东方只有终章 |
