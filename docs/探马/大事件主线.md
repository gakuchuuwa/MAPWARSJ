### 走向

### 这样排的理由
1. 身份跟着价值观走：乌拉尔图军人（学马、学打仗）→ 亚述骑兵（被俘，不得已）→ 马商·行会首领（看到养马人被杀，离开亚述）→ 米底雇佣教官（想亲手终结亚述）→ 马商（心愿已了）。288 年换四次。
2. 马商不投靠任何一方，所以能在辛梅里安、斯基泰、米底之间往来，不用在敌对民族之间来回投靠。
3. 马商年份也要有仗打：护商队、被劫道、给军队带路、受雇打一两场；大战可以靠通灵马参与。
4. 与游戏机制对应：军人、雇佣兵＝入伍状态；马商、行会首领＝无势力单骑状态。
5. 同期中原是春秋战车时代，骑兵尚未出现，主角在西方合理。

### 这样排的理由
1. **对上「信英雄」：** 主角先见小居鲁士冲阵战死，又追随亚历山大，亲眼看着两个英雄一死、大业崩解。
2. **身份转变都有价值观支撑：** 受雇于小居鲁士（想看一个英雄能不能改变命运）；投亚历山大的先遣骑兵（侦察就是探马的本行）；离开（英雄死了，帝国在继业者手里互相残杀，违背他守信、不出卖同伴的底线）。
3. **推一把，不抢功：** 马经传给色诺芬，《论骑术》仍是色诺芬写的；布西发拉斯由行会养出，卖马的仍是史书里的色萨利马商菲洛尼库斯，驯马的仍是亚历山大。
4. **为东去铺路：** 亚历山大打到中亚、印度，主角在他死后顺着这条路继续往东，十六年后赶上赵国胡服骑射，全程走过去。
5. **同期中国：** 前 506 柏举、前 453 晋阳、前 403 三家分晋、前 341 马陵，多为步兵、战车之战，主角不在场。

### 这样排的理由
1. **以参战为主：** 前 199–前 126 年主角一路跟着西方打得最凶的地方走——塞琉古、巴克特里亚、印度、安息，几乎年年有仗。
2. **勤换、不远：** 叙利亚 → 巴克特里亚 → 印度 → 安息 → 巴克特里亚，都是相邻地区；每段不超过三十年。
3. **先败方、后胜方：** 马格尼西亚在败方（塞琉古），后来在安息一边击败塞琉古。
4. **回汉与原方向一致：** 仍然是在巴克特里亚遇张骞、随他归汉。
5. **「信英雄」收尾：** 霍去病早逝（或被救活却默默无闻）、卫青病故、李陵投降、李广利投降被杀，武帝自己下诏停止远征。下一卷转入「信制度」。
