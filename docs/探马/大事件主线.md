# 大事件主线

> 主人定：**先定大方向、大事件，再回头做细节。** 本文只写大段年份的主角大方向与大事件；每年一行的编年史见 `编年史_第一卷.md` 起；每年玩什么由游戏里的故事块决定（`故事块样板_乌拉尔图开局.md`）。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；**以参战为主，哪里仗多去哪里**；同一个地方不超过一代人（约二三十年），到时换地方或换名字；同一时间只跟一个政权。
> 年份：平行宇宙，一律定数，参照史实、不差太多。
> 标注：「主角大方向」全部由 Claude 定（专业判断）；大事凭已有知识整理，未逐条联网核对。

## 第一卷 · 信马（前 800 — 前 513）

### 走向
骑兵从帝国的兵种，变成草原民族的天性：亚述骑兵到巅峰 → 草原骑兵（辛梅里安、斯基泰）南下 → 骑兵最强的亚述照样灭亡 → 波斯崛起，又一再被草原骑兵挫败。主角学到：**骑兵赢了仗，帝国照样崩解。**

### 这样排的理由
1. 一直跟着当时骑兵仗最多的地方走：乌拉尔图、亚述、辛梅里安、吕底亚、斯基泰、米底、巴比伦、波斯。
2. 换阵营都有事件：被俘、主帅战死、帝国灭亡、看到违背底线的事（前 714 养马人被杀）。
3. 每段不超过一代人；回到同一个国家时隔够久或换了名字。
4. 同期中原是春秋战车时代，骑兵尚未出现，主角在西方。

## 第二卷 · 信英雄（前 512 — 前 307）

### 走向
骑兵的中心从波斯移到希腊、马其顿：波斯骑兵在普拉蒂亚败给希腊重装步兵 → 希腊城邦开始重视骑兵 → 马其顿腓力二世改革骑兵 → 亚历山大的骑兵从希腊打到印度 → 亚历山大一死，帝国分裂。同期中国从春秋转入战国，前 307 年赵国胡服骑射。主角学到：**人有极限，英雄一死，大业照样崩解。**

1. 这两百年骑兵仗最多的就是希腊诸邦与马其顿，主角在其中不断换城邦参战。
2. 「信英雄」：先见小居鲁士冲阵战死，再追随亚历山大，又看着英雄死后部下互相出卖。
3. 推一把，不抢功：马经传给色诺芬，《论骑术》仍是色诺芬写的；布西发拉斯由行会养出，卖马的、驯马的都照史书。
4. 同一个人不能认识他太久：与色诺芬相识前 401–前 394，与小居鲁士相识前 408–前 401。

## 第五卷 · 信制度（起）：卡莱、郅支、条顿堡、昆阳（前 86 — 公元 23）

### 走向
东方：汉朝联合乌孙打垮匈奴，设西域都护，匈奴分裂，陈汤远征郅支城；之后三十多年少有战事，直到王莽篡汉、绿林赤眉起事、昆阳之战。西方：罗马与本都、亚美尼亚的战争，卡莱之战安息弓骑兵全歼罗马军团，罗马内战，安息入侵叙利亚，罗马东进与日耳曼战争，条顿堡森林。
主角转入「信制度」：**见过最强的制度（罗马职业军团、汉朝西域都护），又看着它们毁于内斗（罗马内战、王莽改制激起天下大乱）。**

1. 前 86–前 61 年东方汉匈、乌孙仗多，之后西域安定，主角西去赶上卡莱、罗马东进、日耳曼战争，再在王莽末年回中原。
2. 东西之间有现成的线：卡莱之战后罗马俘虏被押到木鹿；后世有学者推测郅支城下的「鱼鳞阵」就是流落康居的罗马降卒（推测，不是定论）。
3. 先败方、后胜方：前 71 匈奴→乌孙；前 36 郅支城破；公元 22 新莽边军→刘秀。
4. 守信的底线：条顿堡阿米尼乌斯倒戈，主角不从。
5. 每段不超过 30 年；回安息、进罗马都换了名字。
