# 故事块样板 · 乌拉尔图开局（公元前 800 — 前 790）

> 用途：试看「故事块」做法是否好玩。只是样板，未进代码。
> 做法来源：故事块（storylet，艾米莉·肖特）＝内容＋触发条件＋结果；选项与书信事件参照《十字军之王 3》事件；通灵战役参照《刺客信条》同步率。
> 游戏数据依据：据点「图什帕」`city_tushpa`（险要，势力乌拉尔图 `wulaertu_guo`，武将萨尔杜里）；官阶门槛（`src/player/PlayerConfig.ts`）：斥候 1000 功勋、探马 3000 功勋；游戏时间 1 季＝15 秒、1 年＝60 秒。
> 称呼：文中 `{玩家}` 是可替换的称呼（默认「探马者」，玩家可自起名）。

---

## 一、一个故事块要写什么

| 项 | 说明 |
|---|---|
| 编号、名称 | 例：URT-01 梦醒 |
| 类型 | 开场／任务／战斗／抉择／书信／通灵／收集／里程碑 |
| 触发条件 | 年份范围、季节、地点（据点）、玩家状态（官阶、功勋、是否入伍、拥有的马、完成过哪些块）、概率 |
| 内容 | 一两句第三人称旁白，或一句人物的话 |
| 选项 | 0–3 个；每个写清代价 |
| 结果 | 功勋、兵模、马、马经条目、标记；成功与失败分开写 |
| 天命锁 | 哪些结果是改不了的（历史大势） |
| 系统 | 用现有系统，还是要新做 |

## 二、样板（12 块）

### URT-01 梦醒　【开场】
- **触发：** 新开百岁模式，前 800 年春，必触发一次。
- **地点：** 图什帕东边的凡湖岸。
- **内容：** {玩家}在湖岸醒来，不记得自己是谁。岩壁上刻着一个骑马的人，刻痕已经很旧。一匹马走近，低头碰了碰他的手——他忽然看见了马记得的东西：这片湖叫凡湖，城叫图什帕，王叫梅努阿。
- **选项：** 无。
- **结果：** 得到第一匹马「初马」（马的谱系起点）；马经解锁第 1 条「马认人」；记下标记「见过岩壁骑马人」。
- **玩法教学：** 通灵＝靠近一匹马按键读取它的记忆。
- **系统：** 开场旁白用现有播报；**马、马经、通灵为新系统**。

### URT-02 赶马饮水　【任务】
- **触发：** 前 800–前 797 年，在图什帕，官阶平民；URT-01 已完成。
- **内容：** 图什帕城外的养马人家缺人手：「把马群赶到渠口饮水，太阳落山前赶回来。」
- **玩法：** 单骑把马群带到渠口（图什帕东南约 10 公里），再带回城下；马群跟在玩家后面走。
- **结果：** 成功 → 功勋 +150，马经「饮水：远路回来不能马上饮」；超时 → 功勋 +50，马群累垮一季不能用。
- **系统：** 单骑移动用现有；**「护送马群」目标为新做**。

### URT-03 走失的小马　【抉择】
- **触发：** 前 799–前 796 年，在图什帕，URT-02 已完成。
- **内容：** 一匹小马昨夜走失，蹄印往山里去。
- **选项：**
  - A. 循着蹄印上山：花一季，一定找到，功勋 +200。
  - B. 让初马通灵去找：当季找到，但初马疲劳一季；有一半机会找到时小马已受伤，带回治好 → 马经「治马：先止血，再敷草药」。
- **结果：** 见选项；小马带回后归养马人家，记下标记「养马人家欠你一份情」（后面送马任务会用到）。
- **系统：** **抉择面板可用现有对话面板**（`DialoguePayload`）；疲劳、受伤为马系统新做。

### URT-04 盗马贼　【小规模战斗】
- **触发：** 前 798–前 795 年，在图什帕一带，每年秋季 30% 机会；URT-03 已完成。
- **内容：** 夜里马厩有动静，几十个山民摸进来牵马。
- **选项：**
  - A. 叫醒养马人家一起追：带 20 人追击。
  - B. 一个人骑马先追：快，但以一敌众。
- **结果：** 胜 → 功勋 +300，缴获 1–2 匹山地马；败 → 马被抢走一匹，{玩家}受伤一季。
- **系统：** 进战术模式，用「小队模式」打（见第四节）。剧情战本来就不受 5000 兵门槛限制（`GameAppCombatHooks.ts` 里剧情战、首战直接放行）。

### URT-05 梅努阿王征兵　【书信／抉择】
- **触发：** 前 796 年冬，在图什帕，功勋 ≥ 500。
- **内容：** 王的使者到了：「大王要攻打曼纳的哈桑卢，各家出人出马。」
- **选项：**
  - A. 应征，随军当马夫 → 入伍乌拉尔图军（萨尔杜里的军团），开启军团玩法与兵模收集。
  - B. 推说马病了，不去 → 继续做平民任务；第二年春再征一次，**这次必须去**。
- **天命锁：** 不论选哪个，前 795 年哈桑卢都会被攻破。
- **系统：** 入伍用现有的入伍随军；书信弹窗可用现有对话面板。

### URT-06 攻破哈桑卢　【锚点战役】
- **触发：** 前 795 年，已入伍乌拉尔图军。
- **内容：** 哈桑卢城墙高厚，城里人以为攻不下。乌拉尔图的马夫们要在三天里把攻城的木料运到城下。
- **玩法：** 先送料（单骑往返任务），再攻城战（兵力够就进战术模式）。
- **结果：** 必胜（天命）；按战功分功勋；马经「哈桑卢的金碗」（传说条目）。
- **⚠ 数据缺口：** 游戏里没有哈桑卢据点。最近的马拉盖约 80 公里，超出 40 公里规则，要么加一个据点，要么改成野战战场。主人已授权「剧情需要可以加据点」，等确认后再加。
- **系统：** 攻城战、战术模式、分功勋都用现有（首战机制）。

### URT-07 看牙口　【收集】
- **触发：** 拥有 3 匹以上的马，任意季节，一次性。
- **内容：** 老马夫掰开一匹马的嘴：「看门牙磨到哪儿，就知道它几岁。」
- **结果：** 马经「看牙口辨马龄」；**此后玩家挑马、买马时能看到马龄**（收集带来实际用处）。
- **系统：** 马经、马龄为新做。

### URT-08 通灵：大马士革城下　【通灵战役】
- **触发：** 前 795 年以后，有商队从叙利亚经过图什帕，带来一匹亚述的退役战马（史实：前 796 年亚述围大马士革）。
- **内容：** 这匹马的左腿有一道箭疤。{玩家}把手放上去，看见了大马士革的城墙。
- **玩法：** 以那匹马的骑手身份打一场围城（亚述一方）。
  - **同步：** 跟着史实走，亚述迫使大马士革臣服。
  - **完全同步（可选目标）：** 整场不丢一匹马。
  - **失步：** 想让大马士革守住，记忆就断开，从头再来。
- **结果：** 同步 → 马经「亚述骑兵两人一组」；完全同步 → 额外学到一个亚述兵模放进收藏。
- **系统：** 战斗用现有战术模式；**同步率判定为新做**。

### URT-09 雪季送急信　【书信／抉择】
- **触发：** 前 793–前 790 年冬季，已入伍。
- **内容：** 北边要塞急报，要有人冒雪送到图什帕。
- **选项：**
  - A. 走山口：当季送到，但马有三成机会冻伤。
  - B. 绕河谷：晚一季，安全。
- **结果：** 准时 → 功勋 +400；晚到 → 功勋 +100；冻伤 → 马伤一年，可用 URT-03 学到的治马缩短。
- **系统：** 单骑移动、季节用现有；马伤为马系统新做。

### URT-10 数炊烟　【任务】
- **触发：** 官阶斥候以上，所在军团出征、战前一季。
- **内容：** 校尉说：「去看看敌营有多少人。」
- **选项：**
  - A. 摸近了数灶：数得准，但有四成机会被发现，打一场小规模战斗（小队模式）。
  - B. 远远看炊烟估：安全，但估得粗。
- **结果：** 数准了 → 下一场战斗本方获得「知敌」加成；估粗了 → 没有加成。
- **系统：** 战斗加成需在现有战力计算上加一个修正，新做。

### URT-11 升斥候　【里程碑】
- **触发：** 功勋达到 1000（现有官阶门槛），在乌拉尔图军中。
- **内容：** 萨尔杜里把一面小旗交给{玩家}：「以后你走在大军前头。」
- **结果：** 官阶升斥候（现有）；解锁 URT-10「数炊烟」类任务。
- **系统：** 全部现有。

### URT-12 岩壁骑马人　【伏笔】
- **触发：** 已有标记「见过岩壁骑马人」，官阶还不到探马，每次回到图什帕时 20% 机会。
- **内容：** 凡湖边那幅骑马人，好像比上次看时清楚了一点。
- **选项：** 无。
- **结果：** 无（只是伏笔）。等{玩家}升到探马，触发「刻下岩壁骑马人」，揭开开局那幅画就是他自己刻的。
- **系统：** 播报用现有。

## 三、这十年玩家大致的玩法流程

1. 前 800 年梦醒，学会通灵（URT-01）。
2. 前 800–前 796 年当平民：赶马、找小马、打盗马贼，攒到 500 功勋（URT-02～04）。
3. 前 796 年冬应征入伍（URT-05），前 795 年参加攻破哈桑卢（URT-06）。
4. 前 795 年以后：在军中送信、侦察，通灵打一场大马士革（URT-08～10），收集马经（URT-07）。
5. 功勋到 1000 升斥候（URT-11）；路过图什帕时偶尔看到岩壁骑马人（URT-12）。

## 四、现有系统与要新做的

| 能直接用的（项目已有） | 要新做的 |
|---|---|
| 单骑移动、入伍随军、官阶与功勋、兵模收集 | 故事块引擎：判断触发条件、弹出、结算结果 |
| 对话面板（可做抉择、书信） | 马系统：自己的马、疲劳、受伤、马龄、谱系 |
| 首战机制、攻城战、战术模式 | 马经图鉴 |
| 游戏日历（年、季） | 通灵战役的同步率判定 |
| 播报、旁白 | 战术模式的「小队模式」：1 个小兵＝1 个人，不排 10 队阵型，敌我各一到三个小队散开打；地图、兵模、攻防计算、玩家控制沿用现有（主人 2026-10-22：规则都可以改，技术能实现就行） |
