# 编年史 · 第六卷 · 信制度（续）：燕然、泰西封、白狼山（公元 24 — 公元 220）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。
> 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。
> 「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、未逐条联网核对。
> 身份：刘秀骑兵（幽州突骑）→ 汉边郡骑兵（马援部下）→ 流浪者 → 贵霜骑兵 → 安息骑兵 → 流浪者 → 汉军骑兵（窦固、班超部下）→ 度辽营骑兵（窦宪、耿秉麾下）→ 甘英向导 → 罗马辅助骑兵（图拉真麾下）→ 流浪者 → 西域长史骑兵（班勇部下）→ 凉州护羌骑兵（马贤、赵冲部下）→ 乌桓突骑（幽并边军）→ 鲜卑骑兵（檀石槐部下）→ 汉军骑兵（段颎部下、北塞）→ 北军骑兵 → 公孙瓒白马义从 → 曹操虎豹骑。
> 主题「信制度」：亲手帮着建起东汉（南匈奴附塞、西域都护、度辽营、护羌校尉）与罗马（军团与辅助骑兵、行省边界）最严密的军事制度，却一次次看着良将被朝廷党争逼死、好制度被庙堂内斗蛀空，最终东汉制度崩解为群雄骑兵混战。
> 丘就却统一贵霜、檀石槐统一鲜卑、虎豹骑建号年份在史学上有大致区间，平行宇宙里按规则取确定年份。
