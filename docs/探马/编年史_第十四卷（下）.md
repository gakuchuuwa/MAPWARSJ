# 编年史 · 第十四卷（下）：从土木堡、君士坦丁堡到南锡与达延汗中兴（公元 1436 — 公元 1500）

年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。

原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；主角在一地跟着岁月变老，一段最长一个从军一生（四十年上下），老了离开后以「马蜕」回春、换名重来；同一时间只跟一个政权。

「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、重要节点已联网核对。

身份（第十四卷下册）：流浪者（顿河霍皮奥尔河「马蜕」苏醒、东归）→ 明朝宣府与京营「三千营」「团营」铁骑（杨洪、[于谦](https://zh.wikipedia.org/zh-cn/%E4%BA%8E%E8%B0%A6)、石亨、范广麾下，回春换名，随军变老）→ 流浪者（外高加索阿拉斯河「马蜕」回春）→ 白羊王朝土库曼铁骑（乌尊·哈桑麾下，回春换名）→ 勃艮第公国敕令重装骑士（大胆查理麾下，换名）→ 流浪者（东归）→ 蒙古大汗[达延汗](https://en.wikipedia.org/wiki/Dayan_Khan)与满都海哈屯护卫铁骑（换名，随军变老至六十岁，阴山呼和诺尔「马蜕」回春）。

主题「信大势」（终·下册）：接上册公元 1435 年（主角五十岁在顿河支流霍皮奥尔河畔进入第三次「马蜕」），主角于 1436 年春苏醒回到二十岁，骑着波兰—钦察混血银鬃白马「银镝」东归明朝北方九边（距 1375 年离北元已隔六十二年、距 1404 年离朵颜三卫已隔三十四年，旧识尽殁），换汉名投入宣府与京军「三千营」骑兵；在 1447 年通过探马行会送来的巴尔干战马通灵亲历[瓦尔纳之战](https://en.wikipedia.org/wiki/Battle_of_Varna)（1444）；1449 年亲历震动天下的[土木堡之变](https://zh.wikipedia.org/zh-cn/%E5%9C%9F%E6%9C%A8%E5%A0%A1%E4%B9%8B%E5%8F%98)（在败方浴血突围）与十月[于谦](https://zh.wikipedia.org/zh-cn/%E4%BA%8E%E8%B0%A6)领导的[京师保卫战](https://zh.wikipedia.org/zh-cn/%E4%BA%AC%E5%B8%88%E4%BF%9D%E5%8D%AB%E6%88%98)（德胜门火器伏击配精骑反冲锋大破瓦剌也先，先败后胜），继而参与于谦「团营」步骑火器混成军制改革，并通过通灵马见证 1453 年[君士坦丁堡陷落](https://en.wikipedia.org/wiki/Fall_of_Constantinople)（乌尔班巨炮轰塌千年城墙）与[卡斯蒂永之战](https://en.wikipedia.org/wiki/Battle_of_Castillon)（野战排炮终结百年战争）；1457 年亲睹「[夺门之变](https://zh.wikipedia.org/zh-cn/%E5%A4%BA%E9%97%A8%E4%B9%8B%E5%8F%98)」冤杀救国功臣于谦，主角心寒辞军西行，在外高加索阿拉斯河谷完成第四次「马蜕」回春；随后他先后投入白羊王朝乌尊·哈桑麾下亲历 1473 年[奥特卢克贝利之战](https://en.wikipedia.org/wiki/Battle_of_Otlukbeli)（奥斯曼火炮与火绳枪大车阵击溃安纳托利亚纯骑兵），以及勃艮第公爵「大胆查理」麾下亲历 1476—1477 年格兰松、莫拉特与[南锡之战](https://en.wikipedia.org/wiki/Battle_of_Nancy)（瑞士五米长矛方阵配火绳枪击杀大胆查理，中世纪欧洲封建重装骑士彻底落幕）；东归途中于 1480 年目睹[乌格拉河对峙](https://en.wikipedia.org/wiki/Great_Stand_on_the_Ugra_River)（莫斯科火器防线终结金帐汗国两百四十年统治），最终回到阔别百余年的蒙古草原，投入满都海哈屯与七岁幼汗巴图蒙克（[达延汗](https://en.wikipedia.org/wiki/Dayan_Khan)）帐下，护卫黄金家族血脉完成六万户大中兴，并通过通灵马看尽英国玫瑰战争终局[博斯沃思原野之战](https://en.wikipedia.org/wiki/Battle_of_Bosworth_Field)（1485）与意大利战争火炮时代揭幕，至 1500 年满六十岁在阴山呼和诺尔完成第五次「马蜕」回春——至此主角彻底走完「信大势（终）」，准备在下一卷迈入「尽人事，知天命（火药时代）」。
