# 编年史 · 第九卷 · 信制度（摇）：玄甲、阴山、怛罗斯、香积寺（公元 590 — 公元 763）

> 年份：平行宇宙，一律定数，参照史实、不差太多。没有公元 0 年，公元前 1 年之后是公元 1 年。 原则（主人定）：以时间轴为核心，空间为补充，战争为框架，骑兵战争为着重点；以参战为主，哪里仗多去哪里；同一个地方不超过一代人；同一时间只跟一个政权。 「主角所在」由 Gemini 定（专业判断），大事凭已有知识整理、未逐条联网核对。 身份：隋军骑兵（杨素、长孙晟、宇文述麾下）→ 隋骁果骑兵 → 唐公骑兵（李渊、李世民部下）→ 唐玄甲军（李世民麾下）→ 唐朔方与陇右骑兵（李靖、李道宗麾下）→ 唐瀚海与安西骑兵（阿史那社尔、苏定方、薛仁贵麾下）→ 波斯都督府骑兵（卑路斯三世麾下）→ 唐河西与北疆骑兵（黑齿常之、裴行俭麾下）→ 安西与陇右骑兵（王孝杰、唐休璟、王晙麾下）→ 突骑施骑兵（苏禄可汗麾下）→ 河西、幽州与安西骑兵（王君㚟、信安王李祎、薛楚玉、张守珪、盖嘉运麾下）→ 朔方与安西骑兵（王忠嗣、高仙芝、李嗣业、郭子仪麾下）。 主题「信制度」：亲历了府兵制、监牧制与安西四镇最耀眼的骑兵盛世，却看到均田崩坏后府兵溃散、边帅为邀功背信弃义、朝廷宦官在潼关冤杀名将——再好的制度，一旦被庙堂政治与贪功藩镇蛀空，连帝国都城都守不住。 标签：★ 骑兵相关大事。没有大事的年份照样保留一行（主角在哪写清楚），那一年玩什么由游戏里的故事块决定。
