> 2026-07-16 定稿

## 一、四层总览

```
最终 roll = 兵力 × 运气 × 技能效果 × 势局系数 × 攻防风格系数
             ①       ②         ③           ④
```

| 层 | 含义 | 范围 | 谁决定 |
|----|------|------|--------|
| ① 运气 | 随机骰子 [0.9, 1.1] | ±10% | 无 |
| ② 技能 | 六计 magnitude（在册/不在册） | 0.5–1.2 | 武将技 |
| ③ 势 | aptitude × 当前局势（优/均/劣） | **0.6–1.4** | 武将天赋 |
| ④ 攻防 | attackStyle × 攻守角色 | **0.7–1.3** | 武将风格 |

四层全部乘法。单边链范围 0.19–2.40。同一场战斗中攻守局势绑定（一方优必一方劣），极端对战倍比：

```
攻最优: 造势优(1.40)·善攻攻城(1.30)·在册技(1.2)·运(1.1) = 2.40
守最劣: 造势劣(0.60)·善攻守城(0.70)·不在册技(0.5)·运(0.9) = 0.19
对战倍比 = 2.40 / 0.19 = 12.7 : 1
```

> 12.7:1 是四层全叠的极端——兵力相等时，一方碾压另一方近 13 倍。实际对战中技能通常不取极端相反值，且兵力差距会进一步放大或缩小倍比。

## 二、势层（0.6–1.4）

| aptitude | 优势(>1.5) | 均势 | 劣势(<0.67) | 设计意图 |
|----------|:---:|:---:|:---:|------|
| **造势 create** | **1.40** | 1.00 | **0.60** | 顺风碾压，逆风崩盘 |
| **借势 leverage** | 0.90 | **1.20** | 0.90 | 永不吃亏，永不高光 |
| **逆势 reverse** | **0.60** | 1.00 | **1.40** | 顺风松懈，逆风觉醒 |

- 造势/逆势互相对称（1.40 ↔ 0.60）
- 借势在均势局有 20% 优势，碾压其余二势

### 势层纯克制矩阵 · 同兵力·同攻防（双行 1.20）

```
           守造势    守借势    守逆势
均势(1:1)
 攻造势     49.9%     0.4%    49.9%
 攻借势     99.6%    50.0%    99.6%
 攻逆势     50.0%     0.4%    50.1%

攻优(2:1)
 攻造势    100.0%   100.0%   100.0%
 攻借势    100.0%   100.0%   100.0%
 攻逆势    100.0%   100.0%     2.6%  ← 逆势在优局被自己人反杀（0.60 vs 1.40，2:1 兵力翻不过）

攻劣(1:2)
 攻造势      0.0%     0.0%     0.0%
 攻借势      0.0%     0.0%     0.0%
 攻逆势      0.0%     0.0%    97.4%  ← 只有逆势在劣局存活
```

**结论**：借势克一切均势局，逆势在劣势无敌，造势在优势无可阻挡。

## 三、攻防层（0.7–1.3）

| attackStyle | 攻城(攻方) | 守城(守方) | 设计意图 |
|-------------|:---:|:---:|------|
| **善攻 attack** | **1.30** | **0.70** | 攻城碾压，被迫守城=自杀 |
| **善防 defense** | **0.70** | **1.30** | 守城铁壁，被迫攻城=自杀 |
| **双行 balanced** | **1.20** | **1.20** | 攻守双全，名将专属 |

- 善攻/善防互相对称（1.30 ↔ 0.70）
- 双行两面 1.20，全面但不到专精峰值
- **错位惩罚**：善攻被迫守城=0.70，善防被迫攻城=0.70

### 攻防层纯对撞 · 同兵力·无势无技

```
善攻攻城(1.30) vs 善防守城(1.30)  → 50.0%  (抵消)
双行攻城(1.20) vs 双行守城(1.20)  → 50.0%  (抵消)
善攻攻城(1.30) vs 双行守城(1.20)  → 82.0%  (专精 5% 优势)
善攻攻城(1.30) vs 善攻守城(0.70)  → 99.9%  (守方错位=碾压)
善防攻城(0.70) vs 善防守城(1.30)  →  0.0%  (攻方错位=自杀)
```

## 四、同型对决示例

> 以下有效战力含 ②技（攻1.2+胜0.92），但「= X」仅示 ③势×④攻防。

### 示例 1：攻方双重惩罚

```
攻方 4万(优): 逆势×0.60 + 善防攻城×0.70 = 0.42（双罚）
守方 2万(劣): 逆势×1.40 + 善防守城×1.30 = 1.82（双奖）

有效: 攻 1.85万 vs 守 4.02万  → 攻方 0.0%
```

攻方 4 万兵反被守方 2 万碾压——逆势将在优势松懈 + 善防将被迫攻城。

### 示例 2：攻方轻罚

```
攻方 4万(优): 借势×0.90 + 双行攻城×1.20 = 1.08
守方 2万(劣): 逆势×1.40 + 善防守城×1.30 = 1.82

有效: 攻 4.77万 vs 守 4.02万  → 攻方 98.9%
```

借势在优势只被轻罚 10%，双行又不拖后腿，2:1 兵力底子足够碾压。

### 示例 3：最强攻 vs 最强守

```
攻方 4万(优): 造势×1.40 + 善攻攻城×1.30 = 1.82
守方 2万(劣): 逆势×1.40 + 善防守城×1.30 = 1.82

有效: 攻 8.04万 vs 守 4.02万  → 攻方 ~100%
```

**势×攻防系数相消（1.82 = 1.82），胜负回到纯兵力比 2:1。**
同局下造势善攻对口 vs 逆势善防对口 → 系数相消，谁兵多谁赢。

## 六、引擎实现

### 文件改动

| 文件 | 改动 |
|------|------|
| `src/combat/TacticalConstants.ts` | `APTITUDE_POWER_MULT` 0.6–1.4 + `ATTACK_STYLE_POWER_MULT` 0.7–1.3 |

| `tools/combat-model.ts` | 同步势+攻防常量/函数 + `simulateOnce` 主路径 + `recompute` 逆局路径 |

### 掷色链（GeneralSkillCombat.ts:1918-1928）

```typescript
// ③ 势层
outAtt *= getAptitudePowerMult(attackerUnits, defenderUnits, attCommander);
outDef *= getAptitudePowerMult(defenderUnits, attackerUnits, defCommander);

// ④ 攻防层
const attGen = findEligibleGeneralUnit(attackerUnits, attCommander);
const defGen = findEligibleGeneralUnit(defenderUnits, defCommander);
outAtt *= getAttackStylePowerMult(attGen, true);
outDef *= getAttackStylePowerMult(defGen, false);
```

## 七、模拟器

### 独立模拟器

`scratch/combat_sim_v7.mjs` — 四层独立验证，不依赖 combat-model，纯 JS。

```bash
node scratch/combat_sim_v7.mjs
```

核心逻辑（与引擎一致）：

```javascript
const ATK = {
  attack:   { atk: 1.30, def: 0.70 },
  defense:  { atk: 0.70, def: 1.30 },
  balanced: { atk: 1.20, def: 1.20 },
};
const APT = {
  create:   { a: 1.40, b: 1.00, d: 0.60 },
  leverage: { a: 0.90, b: 1.20, d: 0.90 },
  reverse:  { a: 0.60, b: 1.00, d: 1.40 },
};

// 掷色 = ①运气 × ②攻战 × ③势 × ④攻防
const ar = a * luck() * 1.2 * aAptMul * ATK[aSt].atk;
const dr = d * luck() * 1.2 * dAptMul * ATK[dSt].def;
```

### combat-model 模拟器（接入引擎）

以下通过 `tools/combat-model.ts` 共享四层，与引擎严格对齐：

```bash
npm run sim:legion         # 攻城排名
npm run sim:campaign       # 连续攻城
npm run sim:skill          # 技能平衡
npm run sim:expedition     # 远征续航
```

> `combat_sim_v7.mjs` 是独立手写模拟器，不走 combat-model。其余模拟器经 combat-model 接入四层。
