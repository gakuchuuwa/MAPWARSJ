# 游戏底层机制备忘录：战斗、行军与特殊文化加成

本文档汇总了底层代码中关于行军速度、兵力上限、文化战力系数等机制，避免后续查阅源码时产生遗忘或混淆。

## 1. 军团行军速度机制（四系矩阵，2026-07-09）

行军速度 = `UNIFIED_MARCH_SPEED × MOVEMENT_MATRIX[兵种大类][地形]`（陆地），或水域统一倍率。

### 1.1 兵种大类 `MovementClass`（`CultureFormations.getCultureMovementClass`）

| 大类 | 文化区 | 阵型 |
|------|--------|------|
| **CAVALRY 纯骑** | 草原、青藏、**中亚** | 三角 123 |
| **MIXED 步骑** | 中原、北方、东北、朝鲜、河西、**西域** | 3×3 |
| **INFANTRY 纯步** | 日本、川蜀、江南 | 3×3 |
| **ELEPHANT 步象** | 岭南、滇缅 | 3×3 |

史地定案：中亚 = 河中突厥系纯骑；西域 = 绿洲城郭步骑。勿再写「西域纯骑」。

### 1.2 陆地矩阵 `MOVEMENT_MATRIX` + 水域 `SEA_SPEED_MULTIPLIER`

| 大类 | 平原 | 山地 | 水域 |
|------|------|------|------|
| CAVALRY | **2.4** | 1.2 | **1.2（全军统一）** |
| MIXED | 1.5 | 0.9 | 1.2 |
| INFANTRY | 1.4 | 1.1 | 1.2 |
| ELEPHANT | 1.2 | 0.7 | 1.2 |

- 登船后兵种加成失效，只吃水域统一倍率。
- 战略技「如履平地」：山地按该系**平原格**查表。
- **地形切换（2026-07-09）**：目标倍率查表后，`Army` 以 `TERRAIN_SPEED_LERP_TAU_SEC≈0.5s` 指数平滑；平原/山地翻转需连续 `LAND_TERRAIN_FLIP_CONFIRM_FRAMES` 帧确认，避免 hex 边界「突然一窜」。

## 3. 文化战力乘区与据点加成

在真实的战力计算中，所有的系统乘区**都会 100% 参与底层运算**（即便在 UI 上因为系数为 1.0 而被折叠隐藏）。

### 3.1 进攻方与防守方的判定 (Field vs Garrison)
- **城防 (Garrison)**：只有当据点被直接攻打时，据点内的防守部队才视为“城防”。
- **野战 (Field)**：**任何主动出征的军团**，无论是去打纯野战，还是去**攻打别人的城池**，全部套用“野战”系数。进攻方不吃亏。

### 3.2 典型文化系数
- **高攻脆皮组（草原、青藏、东北等）**：
  - 野战系数：`×1.2` 或 `×1.1`
  - 城防系数：`×0.8` 或 `×0.9`
- **铁壁防守组（岭南、滇黔、巴蜀等）**：
  - 野战系数：`×0.8`
  - 城防系数：`×1.2`

详见 `GAME_DIRECTION.md` 五级攻防表与 `CultureCombat`。
