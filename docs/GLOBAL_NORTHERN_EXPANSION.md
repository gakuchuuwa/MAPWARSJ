> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>
> 另一条同级铁律：**别人（主人 / 其他 AI）已经做好的编制，不许擅自改。**
> 只有改动前就是红的（格位不符阵型 / 兵种不存在 / 象攻城违规 / 战力离群）才准动，其余一律先问。
> 自动闸门：`npm run legion:no-unjustified-edits`（已挂 PostToolUse 钩子，改完自动拦）。

# 全球开放与北半球优先实施规范

## 已定路线

全球基础设施一次按完整世界设计；历史内容先完成北半球，再进入南半球。现有 ZOOM 8/9/10 模式保持原样，全球总览新增能力只放在 ZOOM 2–7。

## 第一阶段：全球底座

- Web Mercator 合法范围：纬度 `[-85.0511287798, 85.0511287798]`、经度 `[-180, 180]`。
- ZOOM 2–7 使用全球总览底图；ZOOM 8/9/10 继续使用现有本地模式。
- 所有距离、附近查询和折线必须按最短经度处理日期变更线。
- 内部跨线折线可以暂时展开到 `180°` 之外；请求全球瓦片和海陆数据前必须归一化。
- 新功能不得改变现有欧亚坐标的计算结果。

## 第二阶段：北半球内容

录入顺序为：现有欧亚查漏 → 北非 → 北美。每一座据点继续执行“一据点一势力一旗号一军一色”。

每批据点必须完成：

1. 冷兵器时代可考据点名与真实坐标。
2. 写入前运行 `--probe`，与全图任意已有据点均须相距至少50km。
3. 势力、首都、旗号、文化、军团与精锐按项目既有同步规则录入。
4. 补真实历史道路或可考海路，不允许用直线跨大陆凑连通。
5. 写入后运行 `npm run city:spacing`、`npm run world:audit` 和完整构建。

## 北半球文化原则

非洲与美洲文化不得回退为 `CENTRAL`，也不得为了省素材强套现有文化。新增文化前须先完成史实范围、城市立绘、军团编制、植被和战斗素材方案，再进入实体数据。

## 南半球进入条件

只有以下条件全部满足后才开放南半球内容：

- 北半球道路网络、跨洲海路和性能压力测试通过。
- 日历季节与战场环境支持南北半球反季节。
- 南部非洲、南美洲和大洋洲文化与植被素材经过独立史实审核。
- 日期变更线两侧的移动、战斗、增援与领土显示均通过实机验证。
