# 14文化四维属性平衡分析报告

## 一、当前状态

现有系统只有 2 个参数：野战系数、守城系数，14 文化分 5 档：

```
草原/青藏/中亚：     攻 1.2 / 守 0.8
东北/河西/北方：     攻 1.1 / 守 0.9
中原/西域：         攻 1.0 / 守 1.0
日本/朝鲜/江南：     攻 0.9 / 守 1.1
岭南/滇黔/巴蜀：     攻 0.8 / 守 1.2
```

## 二、目标系统

扩展为 4 属性 × 正负方向 = 8 项参数，每个文化独立配置：

| 属性 | 含义 | 游戏影响 |
|------|------|----------|
| 军团攻 | 野战/攻城攻击乘数 | 决定进攻能力 |
| 军团速 | 行军速度乘数 | 决定战略机动性 |
| 据点兵 | 守城兵力乘数 | 决定驻军数量 |
| 据点防 | 守城防御乘数 | 决定防守能力 |

### 平衡原则

**总和平权**：每文化 4 属性之和 = 4.0（基线 1.0×4），有加必有减。

**非对称设计**：不做全 1.0 的"平衡"——文化必须有特色、有强弱项，玩家才能做出有意义的战略选择。

**历史锚定**：数值反映真实历史军事特征（草原骑射强攻弱守、巴蜀天险善守不善攻等）。

## 四、设计逻辑

### 1. 攻击端（军团攻 + 军团速）

草原最高 (1.25+1.25=2.50)，巴蜀最低 (0.80+0.75=1.55)。差距 0.95，反映历史：蒙古骑兵横扫欧亚 vs 蜀地出兵艰难。

### 2. 防守端（据点兵 + 据点防）

巴蜀最高 (1.15+1.30=2.45)，草原最低 (0.85+0.65=1.50)。对称于攻击端。

### 3. 四维分布

- **草原/中亚/青藏**：攻高防低，速快兵少 → 必须主动出击，速战速决
- **东北/河西/北方**：攻守过渡带，略有进攻倾斜
- **中原/西域**：基准均衡
- **朝鲜/江南/日本**：守强攻弱，速慢但抗揍
- **岭南/滇黔/巴蜀**：极致防守，速度最慢

### 4. 速度作为独立轴

军团速不跟攻/防完全绑死。例如：
- 江南 (0.95) > 日本 (0.85)：江南水网虽不便陆战但漕运发达，日本岛内山多路险
- 朝鲜 (0.90) < 江南 (0.95)：朝鲜半岛南北狭长行军效率略低
- 中亚 (1.15) > 青藏 (1.05)：丝绸之路通道平坦，高原缺氧行军慢

## 五、实现成本

- 军团攻/据点防：已有配置，调整数值即可
- 军团速：需要新增 `MOVEMENT_MATRIX` 按文化区的速度乘数
- 据点兵：需要新增守城兵力乘数（影响 `CityConfig` 或 `SiegeManager` 的驻军计算）

其中速和兵两项是新系统。如果先只做攻/防 2 参数微调，上述数值可直接用 4 属性中的军团攻和据点防两列。要不要一步步来，先调现有 2 参数？
