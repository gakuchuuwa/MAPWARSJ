# 兵种四级分类（核对版）

认法补充（11-09 主人定）：科技树里没有的兵，即使兵模借用科技树兵，也一律算特殊兵。英雄不是兵，单列在最后，不分四级。华夏双手步兵＝德版剑士（吴独特）无盾形态，主人确认归城堡兵。

认法：德版科技树里标「独特单位」＝城堡兵；「区域单位」＝高级兵；普通单位及其升级＝正规兵；不在任何文明科技树里＝特殊兵。精锐版跟原版同级（科技树里精锐版标记与原版相同）。

统计：特殊兵 51，正规兵 47，城堡兵 160，高级兵 30，英雄 4（共 292 个，军团里实际用到的）
