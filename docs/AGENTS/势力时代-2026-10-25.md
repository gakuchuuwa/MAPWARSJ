# 势力时代（时代归势力，武将只带生卒/登场年）— 2026-10-25

> 主人令（2026-10-25）：「**武将有生卒登场年，势力有时代。**」「**按史分年段。**」「这样能保证一个势力的人，都是一个军团。」
>
> 落地：`src/data/FactionEra.ts`（新表 ＋ 唯一入口 `getGeneralEra()`）。原 `GENERAL_ERA` 仍保留，只作**兜底/原值**（武将查不到势力、或战场人物时用）。
> 验收：`tools/verify-general-legion.mts`（0 问题）、`npm run legion:full-audit`（0 位解析不到军团）、`npm run legion:fallback-audit`（全链路通过）、`npx tsc --noEmit`。

---

## 一、规则

0. **判定链（唯一，2026-10-25 主人令）**：**武将 → 所属势力（`factionId`）→ 势力时代（`FACTION_ERA`，按该将首战年/登场年落段）**；**武将 → 其据点（`cityId`）→ `buildingStyle` → 文化（`getGeneralCulture`）**；**军团 ＝ 该势力时代 × 该据点文化 那一格**（`getLegionNameOfGeneral`）。先看势力、再看据点；不看武将成名年、不跨势力借文化。

1. **时代属于势力**：`FACTION_ERA[factionId] = [{ from, era }, …]`。同一势力的同一段里只有一个时代 → 该势力的人走同一格（时代 × 据点文化）＝同一支军团。
2. **武将只带时间**：判段用**首战年（最知名那一战）**；无首战年取**登场年**（生年＋20，且不晚于卒年，`getGeneralDebutYear`）；两者都没有 → 保留 `GENERAL_ERA` 原值。
3. **段界按该政权的军制史**，不按全球 1050/1000 界尺——「宋＝宋军、大明＝明军、西夏＝铁鹞子、高丽＝三别抄、辽＝皮室」整段一个时代；「军区→普罗尼亚」「基辅罗斯→莫斯科」「加齐突骑→苏丹亲兵」「哈里发→撒拉森」这类真换过军制的才分年段。
4. **不改**器材/城墙/科技/剧本的年→时代门（`year < 1050` 那 5 处）：那是「某年有没有某种器械/城防」，不是「某势力带哪支军团」。军团跟势力走，器械跟年份走。
5. 据点文化仍按 §五.2（当地最著名本地政权）定，时代只决定「该文化的哪一格」；所以大明＝帝国江南/燕晋两条链（10-24 定案）不变。
