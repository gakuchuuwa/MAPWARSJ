## 二、结论：地图上「连马带车」比一个骑马的人还矮（现役 92px 口径）

- 战车的**马**在素材里本来就比骑兵的马大 20~45%（战车马 53/69px vs 骑兵马 40/48px），
  所以压到 0.70 时战车的马 ≈ 骑兵的马（93~100%），**不会出现「马比人小」**——2026-10-09 实测确认。
- 但**整车**（车盖＋车兵＋马）现役只有 **0.67~0.81 个骑兵高**：双轮 / 拉塔这两族最惨（0.67~0.71），
  因为它们本来就不是"大车"（整车只比骑兵高 1~3%），却被同一把 92px 宽度上限压掉三成。
- 战术 13 里一切都对（战车 1.42 个骑兵高、马的大小真实）。

## 三、为什么：战车跟「常数格距」天生打架

- 地图方阵格距是**常数**：横 46px / 纵 63px（不看兵种）。
- 战车素材宽 104~164px ＝ **2.3~3.6 倍格距**。2026-09-08 主人批的「走A」把宽度上限压到 **2 × 46 = 92px**
  （一对战车各露一半）—— 阵型整齐了，但**整车连马一起被砍掉三到五成**。
- ⇒ 常数格距下，「阵型整齐」与「车马真实比例」不可能同时满足，只能选一个点。
