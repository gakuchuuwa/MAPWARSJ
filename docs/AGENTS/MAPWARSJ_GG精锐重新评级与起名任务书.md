# MAPWARSJ 精锐重新评级与起名任务书（发给 GG）

## 一、任务背景与目标

当前项目共有 **1,977 位武将**（其中**名将 533 位**、**普将 1,444 位**），共挂有 **1,490 个精锐番号**。
现存精锐库中存在较多**名字不好听、干瘪敷衍（如纯「地名/国名＋兵/军」）、高档位用泛指（如「罗马军团」「匈奴骑兵」「陈军精锐」）、跨民族错挂（如塞尔柱挂「塞琉古步兵」）、或档位与史实战绩不匹配**的问题。

请你依据下方**《精锐评级标准 v3（五级制）》**，结合附件《武将与精锐全表_1977.csv》与《武将与精锐总览文档.md》，对全库武将的精锐进行**重新评级，并把不好听、太泛、不合规则的精锐名字改成好听、有历史质感与辨识度的名字**。

---

## 二、精锐评级标准 v3（五级制：传奇、战略、战术、知名、存在）

### 1. T0 传奇之兵 —— 扭转乾坤，青史巅峰
- **战力乘数**：`×1.5`（显示名：**传奇**）
- **挂将上限**：**只许挂 1 名符合历史的武将。普将不可挂。**
- **定位**：改变历史版图、决定政权兴替的战略核武。
- **核心门槛**：真实存在 + 绝境逆转 / 传奇大捷核心 + 深刻改变地缘格局。
- **与 T1 的分界**：T1 取得了重大战略胜利，但未达到「传奇颠覆版图」的级别。T0 必须是直接导致一个民族、政权、格局被重写的核心力量。**不能是泛指，例如「罗马军团」「蒙古骑兵」。**
- **代表**：玄甲军（虎牢关灭窦建德奠定唐朝）、背嵬军（岳飞抗金核心）、北府兵（淝水之战8万破87万）、怯薛军（蒙古西征重塑欧亚）、魏之武卒（阴晋5万破50万）。

### 2. T1 功勋之兵 —— 战略主力，名垂青史
- **战力乘数**：`×1.4`（显示名：**战略**）
- **挂将上限**：**可以挂 1–2 名符合历史的武将。**
- **定位**：撑起一个时代或一场全面战争的王牌野战军。
- **核心门槛**：真实存在 + 作为独立主力取得过重大战略级胜利 + 建制延续性强。
- **与 T0 的分界**：虽有辉煌战绩，但未达到颠覆版图的高度。
- **与 T2 的分界**：T1 是长期存在的正规野战主力，有建制延续性。T2 是特定战役中的战术突击分队或短期高光。
- **代表**：虎豹骑、关宁铁骑、戚家军、神策军、吐蕃大纛军。

### 3. T2 特色之兵 —— 战术尖刀，一战成名
- **战力乘数**：`×1.3`（显示名：**战术**）
- **挂将上限**：**可以挂 1–4 名符合历史的武将。**
- **定位**：在特定战役中打出惊艳表现的王牌突击队、战术奇兵。
- **核心门槛**：真实存在 + 在特定战役中有明确的战术高光（奇袭、经典阵法、关键突击等）。
- **与 T1 的分界**：缺乏 T1 级别的长久建制延续性或战略影响力，侧重于特定战役的高光。
- **与 T3 的分界**：T2 必须有明确的、可考的战术成就（打过硬仗的实绩）。T3 虽然有名，但其知名度来源于文化符号，而非战术大捷。
- **代表**：先登营（界桥破白马义从）、陷阵营（高顺百战百胜）、羽林军（神龙政变）、百保鲜卑（邙山大捷）、却月阵兵（刘裕以步破骑）。

### 4. T3 风土之兵 —— 赫赫有名，独具一格
- **战力乘数**：`×1.2`（显示名：**知名**）
- **挂将上限**：**可以挂 1–8 名符合历史的武将。**
- **定位**：名号本身具有显著文化辨识度、兵种特色极其鲜明、或与家喻户晓的历史事件紧密关联的部队。虽无明确的战术大捷记录，但绝非无名之辈。
- **核心门槛**：真实存在 + 以下两条至少满足一条：
  1. **文化知名度**：名号是广为人知的历史/文学符号，或与家喻户晓的事件紧密关联（例：楼兰弓手、藤甲兵）。
  2. **兵种特色**：兵种构成、武器装备、作战方式在同时代独树一帜（例：伊贺众、风魔党、九边夜不收）。
- **与 T2 的分界**：T3 的知名度来源于文化符号或兵种特色，而非战术战绩。T2 必须有打过仗的硬实绩。
- **与 T4 的分界**：T4 是纯粹的建制记录，名号缺乏辨识度，无文化符号价值或兵种独特性。
- **代表**：楼兰弓手、龟兹精兵、伊贺众、长坂血骑、康巴骁骑。

### 5. T4 存在之兵 —— 确有其军，建制可考
- **战力乘数**：`×1.1`（显示名：**存在**）
- **挂将上限**：**可以挂 1–8 名符合历史的武将。名将不可挂。**
- **定位**：构筑古代军事版图基石的常规部队。
- **核心门槛**：史籍明确记载的独立建制、地方戍兵或豪强部曲。
- **代表与底线**：居延戍卒。**「地名＋兵种＋兵」可以，纯「地名＋兵」不行（例如：四川枪兵能留，四川兵不行）。**

## 三、起名规范与硬性约束（代码校验红线）

1. **精锐起名看武将、看武将所属势力**：
   - 归属优先级：**① 符合历史 → ② 跟武将 → ③ 跟势力 → ④ 跟民族 → ⑤ 区域 → ⑥ 据点**。
   - 优先使用该武将亲自统率的专属番号，其次是其所属政权/军制中有据可考的精锐建制名，再其次是结合其所属势力/部族与核心兵种特征的响亮名称。
2. **字数要求（4–8 字，4–6 字最佳）**：
   - **新起或改名的精锐番号统一为 4–8 个汉字（推荐 4–6 字）**，不带标点或括号。
   - **唯一例外**：正史或权威史籍中传承已久的 **3 字固有专名**（如玄甲军、背嵬军、北府兵、怯薛军、虎豹骑、戚家军、神策军、先登营、陷阵营、羽林军、伊贺众、风魔党、白毦兵、白杆兵、铁浮图、铁鹞子、拐子马、神机营、八字军、三别抄、翼骑兵、银盾兵、不死军等，见 CSV「史源3字白名单」列）可保留 3 字原名；**自拟名严禁 3 字**。
3. **重点整改的「不好听 / 不合规」名字类型**：
   - **严禁纯「地名/国名＋兵/军/卫/卒」**（无兵种、无建制、无特色词）：如 `孟加拉兵`、`百济兵`、`隆武兵`、`霍尔木兹兵`、`拉帕努伊兵`、`塞尔维亚军`、`花剌子模`（直接拿国名当精锐名）等，必须全部重起。即便是 T4，也至少要做到「地名/部族＋具体兵种/器械/甲具」（如 `居延戍卒`、`四川枪兵`）。
   - **T0 / T1 / T2 严禁敷衍泛称**：如 T1 中的 `罗马军团`、`匈奴骑兵`、`瓦剌骑兵`、`西哥特骑兵`、`河西骑兵`、`伽色尼骑兵`、`陈军精锐`、`安西精兵` 等，名字过于平庸或泛指，请按该将真实统率的王牌番号或史实建制改名（若实绩不达 T1 则同步下调档位）。
   - **清理 18 处「跨民族共用」错配**：CSV 中标记了 `跨民族共用` 的条目（如塞尔柱帝国挂了 `塞琉古步兵`、萨珊挂了 `安息步兵`、高棉/孟加拉混挂等），必须按各自武将与所属势力拆开重命名。
4. **五大代码校验闸门（交付结果必须 100% 满足）**：
   - **闸门 ① · 名将与普将红线**：CSV 中 `武将级别 = 名将` 的 **533 人严禁给 T4**（最低 T3）；`武将级别 = 普将` 的 **1,444 人严禁给 T0**（最高 T1）。
   - **闸门 ② · 人数上限（按「势力ID × 精锐番号」统计）**：同一势力下，T0 最多 **1 人**、T1 最多 **2 人**、T2 最多 **4 人**、T3 最多 **8 人**、T4 最多 **8 人**。
   - **闸门 ③ · 同号同档**：全库凡使用同一个 `精锐番号` 的武将，其 `档位` 必须完全一致（严禁A将挂某番号为 T2、B将挂同一番号为 T3）。
   - **闸门 ④ · 跨势力不乱串**：不同 `势力ID` 原则上不共用同一番号（仅当两势力 `民族键` 相同且史实确系同一部族/军制传统时才允许共用；T0 番号全库绝对唯一，仅限 1 人）。
   - **闸门 ⑤ · 不增删武将、不改武将所属势力与驻地**：只改 `精锐番号`（`eliteName`）和 `精锐档位`（`eliteTier`）。

## 五、交付格式要求

请输出一份完整的 CSV 文件 **`精锐重新评级与起名核定表_1977.csv`**（覆盖全部 1,977 位武将，不漏一人，已合适的可保留原名原档，有问题的一律修改），表头固定为以下 10 列：

```csv
武将ID,武将名,武将级别,势力ID,势力名,原精锐番号,原档位,新精锐番号,新档位,核定依据与说明
```

- `新档位` 只填：`T0`、`T1`、`T2`、`T3`、`T4` 之一。
- `新精锐番号` 填定稿后的番号名（4–8 字，或保留已登记的 3 字史源专名）。
- `核定依据与说明`：若维持原样写 `保留`；若改名或改档，简述史实出处、部队特色与定级理由（30～80 字即可）。
- 同时请附一份简短的 Markdown 结论说明（汇总 T0–T4 各档变动人数、全库 T0/T1 完整名单、以及五大校验闸门自查结果）。
