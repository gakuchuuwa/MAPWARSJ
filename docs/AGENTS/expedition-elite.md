## 十二、远征精锐（2026-06-11 立，AI 必读）

> **项目主人多次重申**：精锐不是另占一城，也不是用人名立势力；玩家眼里旗号、据点名、番号 **三者不得完全相同**；**番号与据点名允许共享汉字**（例：武川镇 + 武川镇军），旗号仍须与据点、番号防重（§12.1）。  
> 本节为远征精锐的**唯一真理**；与 `docs/GAME_DIRECTION.md`「远征细则」冲突时，**本节 + 史料**为准。

### 12.1 玩家可见：三样东西，三个专名（极重要，重复三遍）

| # | 名称 | 玩家在哪看见 | 示例 |
|---|------|-------------|------|
| ① | **旗号** | 地图据点旗面 1–2 字 | `山越`、`潼津`、`唐` |
| ② | **据点名** | 地图地点标注 | `宛陵城`、`潼关`、`伊瓜苏` |
| ③ | **远征番号** | 跟拍军团名（远征下令后改名） | `丹阳兵`、`督标秦军`、`玄甲军` |

**红线**：

1. **严格不相等** — 旗号 ≠ 据点名 ≠ 番号（任意两两**字符串不得完全相同**）。
2. **共享汉字** — 仅约束 **旗号** 与其余二者：
   - ✅ 旗号 ↔ 据点名：允许共享汉字（旗号是简称，`潼津`+`潼关` 正常）。
   - ❌ 旗号 ↔ 番号：默认不得共享；**例外**见 §12.1.1（民族/政权/家族）。
   - ✅ **番号 ↔ 据点名：允许共享汉字**（主人 2026-06-17 定；例：✅ 据点 `武川镇` + 番号 `武川镇军`）。
3. **旗号 ↔ 据点名防重** — 仅禁止**严格相等**（逐字完全相同）；据点名呈 `XX关/城/邑/州` 且旗号 = `XX` 属正常简称共享（§4.1），不违规。

### 12.1.1 旗号↔番号重复：仅民族 / 政权 / 家族（主人 2026-06-11 定，再强调）

> **只有** 势力按 §4.1 定为 **1·民族、2·政权、4·家族** 时，**旗号与番号之间** 才允许共享汉字、允许番号包含旗号。  
> **郡名(3)、州名(5)、军镇专名、关名、以番号命名的势力** → **不适用**，旗号与番号 **仍须零共享**。

| 类型 | 旗号 | 番号 | 判定 |
|------|------|------|------|
| **2·政权** | `魏` | `魏武卒` | ✅ 允许旗号⊂番号 |
| **4·家族** | `戚` | `戚家军` | ✅ 允许 |
| **2·政权** | `北府` | `北府兵` | ✅ 允许（东晋北府军事体系） |
| **军镇专名** | `天雄` | `天雄军` | ❌ 旗号与番号共享「天雄」 |
| **藩镇旗号** | `魏博` | `天雄军` | ✅ 三字各一（推荐写法） |

**天雄军 正确写法（照抄）**：

| 旗号 | 据点名 | 番号 | 说明 |
|------|--------|------|------|
| `魏博` | `大名` | `天雄军` | 大名系魏博藩镇治所；《明史·卢象升传》号天雄军 ✅ |

代码白名单：`src/data/ExpeditionTripleNameAllow.ts`（审计脚本读取）。

**错误示例（已从 §12.1 移除，勿再写进禁止列表误导）**：

~~❌ `魏` + `魏武卒`~~ → 政权例外，**允许**。  
~~❌ `戚` + `戚家军`~~ → 家族例外，**允许**。

**仍禁止（与例外无关）**：

- 用 **人名** 作势力/旗号（例：❌ `孙策` 挂丹阳兵；✅ `山越`@宛陵城）。
- 为精锐 **新建城池** 或 **迁坐标**（除非定旗/间距 §2.1 需要）；精锐只加 `factionId → 番号` 映射。
- 番号 **3–6 字、全局不重复**（与区无关）。

### 12.2 唯一锚点：据点（势力 / 精锐 / 时代 均只和据点有关）

> **项目主人定调**：**势力、据点、精锐，都只和据点有关系**——彼此（势力↔精锐）、与「时代」**均无绑定**。

| 锚定对象 | 只问「这座据点（lat/lng + 史地名）」 | **不问** |
|----------|--------------------------------------|----------|
| **据点名** | 真实可考的一个地点专名；不要求必须是城市 | — |
| **旗号（势力）** | 该点按 §4.1 定旗（1 点 1 旗） | 与番号是否同族、同代、同战役无关 |
| **远征番号（精锐）** | 该点标志战 / 成军地（史料具名） | 与旗号是否同族、同代、同战役无关 |

**代码实现（2026-06-16；将领锚点 2026-06-22 修订）**：

- **数据录入**：`*ExpeditionLegions.ts` 仍写 `factionId → 番号`；经 `STARTING_CAPITALS` 推导为 `cityId → 番号`（`CITY_ELITE_LEGIONS`）。
- **运行时募兵**：番号查 **`homeCityId` / `sourceCityId`**（番号随城），见 `getLegionEliteLegionName`。
- **将领档案**：`FactionGenerals.ts` 绑 `factionId` → `cityId`（四位一体，谁占城谁得将）。
- **将领出场**：仅 **锚点据点**（默认 `STARTING_CAPITALS[factionId]`）的军团或该城守城城防；**军团与城防互斥**，共用 `spawnGeneralUsed`。

```
① 据点（主）→ 史地地名 + 可考坐标（cities_v2 已存在）
② 旗号     → 该据点 §4.1 定旗（与③④无关）
③ 远征番号 → 该据点标志战/成军地专名 → 运行时按 **出兵 cityId** 查（与②④无关）
④ 将领     → 档案随势 factionId；**出场仅锚点据点**（军团 home/source 或守城城防，互斥）
```

| 步骤 | 说明 |
|------|------|
| **据点优先** | 先定番号/旗号各自锚定的**据点**；**禁止**为番号或旗号去迁点、迁势力、改坐标。 |
| **标志战场** | 戚家军 → **横屿**；孙传庭秦军 → **潼关**；先登死士 → **乐成**（界桥·河间）。 |
| **故里例外** | 乡土兵锚 **成军/故里据点**，不锚千里外战场（白杆兵 → **石柱**，❌ 浑河）。 |
| **已有势力可复用** | 据点已定、已有合格旗号 → 直接给该 `factionId` 加番号，**不必**另立势力。 |
| **无合格势力** | 据点尚无旗号 → 走 **5 文件 batch-import**（§五）；**禁止人名**。 |
| **宁缺毋滥** | 该据点无史料专名番号，或三者防重无解 → **不收**。 |

**禁止的推理**（一律视为违规）：

- ❌ 「先登是袁绍的 → 袁氏要迁乐成 / 汝南要挂先登」
- ❌ 「旗号是北齐 → 番号必须北齐 / 不能挂东汉先登」
- ❌ 「势力与精锐要配套、同时代、同一家族」

### 12.3.1 精锐 tier 判定标准 v3（五级体系）

**T0「传奇之兵」—— 扭转乾坤，青史巅峰** (开战战力乘数 ×1.5)
- **定位**：改变历史版图、决定政权兴替的战略核武。
- **核心门槛**：真实存在 + 绝境逆转 / 传奇大捷核心 + 深刻改变地缘格局。
- **与 T1 的分界**：T1 取得了重大战略胜利，但未达到"传奇颠覆版图"的级别。T0 必须是直接导致一个民族，政权，格局被重写的核心力量。
- **代表**：玄甲军（虎牢关灭窦建德奠定唐朝）、背嵬军（岳飞抗金核心）、北府兵（淝水之战8万破87万）、怯薛军（蒙古西征重塑欧亚）、魏之武卒（阴晋5万破50万）

**T1「功勋之兵」—— 战略主力，名垂青史** (开战战力乘数 ×1.4)
- **定位**：撑起一个时代或一场全面战争的王牌野战军。
- **核心门槛**：真实存在 + 作为独立主力取得过重大战略级胜利 + 建制延续性强。
- **与 T0 的分界**：虽有辉煌战绩，但未达到颠覆版图的高度。
- **与 T2 的分界**：T1 是长期存在的正规野战主力，有建制延续性。T2 是特定战役中的战术突击分队或短期高光。
- **代表**：虎豹骑、关宁铁骑、戚家军、神策军、吐蕃大纛军

**T2「特色之兵」—— 战术尖刀，一战成名** (开战战力乘数 ×1.3)
- **定位**：在特定战役中打出惊艳表现的王牌突击队、战术奇兵。
- **核心门槛**：真实存在 + 在特定战役中有明确的战术高光（奇袭、经典阵法、关键突击等）。
- **与 T1 的分界**：缺乏 T1 级别的长久建制延续性或战略影响力，侧重于特定战役的高光。
- **与 T3 的分界**：T2 必须有明确的、可考的战术成就（打过硬仗的实绩）。T3 虽然有名，但其知名度来源于文化符号，而非战术大捷。
- **代表**：先登营（界桥破白马义从）、陷阵营（高顺百战百胜）、羽林军（神龙政变）、百保鲜卑（邙山大捷）、却月阵兵（刘裕以步破骑）

**T3「风土之兵」—— 赫赫有名，独具一格** (开战战力乘数 ×1.2)
- **定位**：名号本身具有显著文化辨识度、兵种特色极其鲜明、或与家喻户晓的历史事件紧密关联的部队。虽无明确的战术大捷记录，但绝非无名之辈。
- **核心门槛**：真实存在 + 以下两条至少满足一条：
  - 文化知名度：名号是广为人知的历史/文学符号，或与家喻户晓的事件紧密关联（例：楼兰弓手、藤甲兵）。
  - 兵种特色：兵种构成、武器装备、作战方式在同时代独树一帜（例：伊贺众、风魔党、九边夜不收）。
- **与 T2 的分界**：T3 的知名度来源于文化符号或兵种特色，而非战术战绩。T2 必须有打过仗的硬实绩。
- **与 T4 的分界**：T4 是纯粹的建制记录，名号缺乏辨识度，无文化符号价值或兵种独特性。
- **代表**：楼兰弓手、龟兹精兵、伊贺众、长坂血骑、康巴骁骑

**T4「存在之兵」—— 确有其军，建制可考** (开战战力乘数 ×1.1)
- **定位**：构筑古代军事版图基石的常规部队。
- **核心门槛**：史籍明确记载的独立建制、地方戍兵或豪强部曲。
- **代表**：居延戍卒、各类地方部曲/土司兵/常规禁卫/州郡戍兵

**战力设计意图**：T3 弱加成；**打过胜仗（T1 起）才是真精锐战力**。乘数单一来源：`GameConfig.COMBAT.ELITE_TIER_MULT`（引擎 `GeneralSkillCombat.getElitePowerMult` / 面板 `CultureCombat.getEliteCombatMultiplier` 同读此表）。

> **⚠️ 精锐环（第 7 环）只有这 5 个档：1.5 / 1.4 / 1.3 / 1.2 / 1.1，无精锐 1.0。**
> 2026-08-01 删除了并列的 `CAMPAIGN_LEGION_MULT = 1.2`（"是远征军团 / 精锐但查不到 tier → 给 1.2"）：
> 它自 2026-07-24 起就不进引擎、只在战斗面板「军」角标显示，长期让人以为"远征军自带 ×1.2 战力"。
> **远征身份（`expeditionTargetCityId`）不进任何战力环**，禁止再往精锐环加第 6 个乘数或兜底常量。

**定级顺序**：从 T0 向下试，命中最高一级即定，不得跳级凑数。

**降级红线**（实例，非穷举）：
- T1→T2：非稳定政权（乞活军/常山义军）、体量过小（女国禁卫）
- T1→T3：纯仪仗护卫（内禁卫）
- T0→T1/T2：无「以少胜多」战绩（真田赤备/武田赤备降 T1，以警固番役替代日本区锚点）

**数量不设配额**（2026-07-30 项目主人重申）：T0 **既无每区下限、也无每区上限**。唯一标准是**符合史实、符合本节判定**。该区没有够格的就是 0 支（宁缺毋滥），够格的有 4 支就是 4 支（如中原：魏之武卒、江东子弟、玄甲军、云台突骑）。**为填下限抬举不合格番号、为消上限降级合规 T0，都属 §392 主人红线禁止的「为跑通审计而改数据」。**

**替代规则**：下调某支 T0 前，本区须有合格接任番号（晋升或新收录）；改锚点须同步更新 `elite_tier_region_anchors.json`。（旧条文此处还写「且全区 T0 仍 ≥1」，与上条冲突，已删。）

**审计**：`expedition:audit` 校验锚点仍为 tier:0，T0 数量**只报数不判定**；`expedition:triple-check` 三者防重。

### 12.3.2 武将分级标准 · 终版

**定性**
- **名将** = 史书有载、本人实际指挥打赢过够格战役的军事决断者（战略技随机持有 + 战术技六槽）。
- **普将** = 有明确史载的参战/守土/领兵者，但无够格胜绩，或定位为从属/一隅（仅战术技）。
> 纯武勇、单挑、声名、开国头衔、献策未决、后勤、君主坐领——皆不入名将。前提是带兵打仗、上过战场的统帅，不是名人。

**必要闸**（一票否决，缺一不可，先过闸才谈名将）
1. **本人是实际军事指挥决断者**：不论头衔是帅、将、军师还是丞相。判准＝有一场"你亲自指挥、史书有载"的具体战役胜绩。纯献策而不决断、纯后勤、君主坐领用人，不算。
2. **史书有载的胜绩**：哪怕一场；败绩不扣分——李陵以少败多不入，是无胜可锚，非因败。
3. **分量够格配战略技**：是战略级/战役级的胜，不是一次冲阵斩将。

**两轴**（过闸之后定档，不是入场券）
- **轴一 · 统帅分量（主轴）**：独立指挥（含决定性防守）打赢国家级/战役级战 → 刻度高，名将实至名归；只在一隅争雄、胜负只动一隅 → 普将。
- **轴二 · 军事名气（放大器 / 平局手）**：本文化正史/主流物语内的顶级军事符号（独传 + 固定军事典故）。
> 过不了必要闸，名气再顶也不升；过闸后仅用于拉开名将内部分量。政治/忠义/后勤/谋士符号（商鞅之变法、文天祥之忠义、萧何之后勤、张良管仲之谋政）不算军事符号。

**裁决细则**
- **成败不论、胜绩为凭**：只问打赢过没有，不看最终结局（项羽败、岳飞冤死，仍名将）。
- **君主抽刀**：开国≠名将。抽掉手下名将谋士，本人还剩不剩亲统胜绩——剩（刘邦、努尔哈赤、姬发）名将；不剩（孙权、齐桓公、杨坚）普将。
- **守将并入轴一**：决定性防守且具全局价值（张巡蔽江淮）名将；局部殉城未改大局（阶伯）普将。
- **神话/传说零战绩**：（金首露卵生）普将。
- **精锐解绑**：分级只决定给不给战略技，不决定精锐强弱。名将可带 T3 边军（王玄策），普将可带 T2 名骑（蹋顿领乌桓突骑）。战略技 × 精锐 × 立绘，三层各自独立拉开差距。

**一句话记忆**：过三闸（本人指挥 · 史载胜绩 · 够战略级）者为名将，名气只是放大器；成败不论，头衔不论，道德不论，只论有没有你亲手打赢的那一仗。
