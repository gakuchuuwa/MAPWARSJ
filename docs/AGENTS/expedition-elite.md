> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>

### 12.3.1 精锐 tier 判定标准 v3（五级体系）

**T0「传奇之兵」—— 扭转乾坤，青史巅峰** (开战战力乘数 ×1.5)
- **定位**：改变历史版图、决定政权兴替的战略核武。
- **核心门槛**：真实存在 + 绝境逆转 / 传奇大捷核心 + 深刻改变地缘格局。
- **与 T1 的分界**：T1 取得了重大战略胜利，但未达到"传奇颠覆版图"的级别。T0 必须是直接导致一个民族，政权，格局被重写的核心力量。
- **代表**：玄甲军（虎牢关灭窦建德奠定唐朝）、背嵬军（岳飞抗金核心）、北府兵（淝水之战8万破87万）、怯薛军（蒙古西征重塑欧亚）、魏之武卒（阴晋5万破50万）

**T1「功勋之兵」—— 战略主力，名垂青史** (开战战力乘数 ×1.4)
- **定位**：撑起一个时代或一场全面战争的王牌野战军。
- **核心门槛**：真实存在 + 作为独立主力取得过重大战略级胜利 + 建制延续性强。
- **与 T0 的分界**：虽有辉煌战绩，但未达到颠覆版图的高度。
- **与 T2 的分界**：T1 是长期存在的正规野战主力，有建制延续性。T2 是特定战役中的战术突击分队或短期高光。
- **代表**：虎豹骑、关宁铁骑、戚家军、神策军、吐蕃大纛军

**T2「特色之兵」—— 战术尖刀，一战成名** (开战战力乘数 ×1.3)
- **定位**：在特定战役中打出惊艳表现的王牌突击队、战术奇兵。
- **核心门槛**：真实存在 + 在特定战役中有明确的战术高光（奇袭、经典阵法、关键突击等）。
- **与 T1 的分界**：缺乏 T1 级别的长久建制延续性或战略影响力，侧重于特定战役的高光。
- **与 T3 的分界**：T2 必须有明确的、可考的战术成就（打过硬仗的实绩）。T3 虽然有名，但其知名度来源于文化符号，而非战术大捷。
- **代表**：先登营（界桥破白马义从）、陷阵营（高顺百战百胜）、羽林军（神龙政变）、百保鲜卑（邙山大捷）、却月阵兵（刘裕以步破骑）

**T3「风土之兵」—— 赫赫有名，独具一格** (开战战力乘数 ×1.2)
- **定位**：名号本身具有显著文化辨识度、兵种特色极其鲜明、或与家喻户晓的历史事件紧密关联的部队。虽无明确的战术大捷记录，但绝非无名之辈。
- **核心门槛**：真实存在 + 以下两条至少满足一条：
  - 文化知名度：名号是广为人知的历史/文学符号，或与家喻户晓的事件紧密关联（例：楼兰弓手、藤甲兵）。
  - 兵种特色：兵种构成、武器装备、作战方式在同时代独树一帜（例：伊贺众、风魔党、九边夜不收）。
- **与 T2 的分界**：T3 的知名度来源于文化符号或兵种特色，而非战术战绩。T2 必须有打过仗的硬实绩。
- **与 T4 的分界**：T4 是纯粹的建制记录，名号缺乏辨识度，无文化符号价值或兵种独特性。
- **代表**：楼兰弓手、龟兹精兵、伊贺众、长坂血骑、康巴骁骑

**T4「存在之兵」—— 确有其军，建制可考** (开战战力乘数 ×1.1)
- **定位**：构筑古代军事版图基石的常规部队。
- **核心门槛**：史籍明确记载的独立建制、地方戍兵或豪强部曲。
- **代表**：居延戍卒、各类地方部曲/土司兵/常规禁卫/州郡戍兵

**战力设计意图**：T3 弱加成；**打过胜仗（T1 起）才是真精锐战力**。乘数单一来源：`GameConfig.COMBAT.ELITE_TIER_MULT`（引擎 `GeneralSkillCombat.getElitePowerMult` / 面板 `CultureCombat.getEliteCombatMultiplier` 同读此表）。

### 12.3.2 武将分级标准 · 终版（2026-10-25 主人新版·四闸）

**定性**
- **名将**（战略技 + 战术技）：史书有载、本人作为军事决断者，亲自打赢过「格局够大、对阵有名」之经典战役的统帅。
- **普将**（仅战术技）：史载的参战/守土/从属统兵者，但无够格胜绩，或战果仅限一隅、敌帅不详。
- 铁律：排斥纯武勇、单挑、开国头衔、纯献策、纯后勤、君主坐领。选的是打赢过硬仗的统帅，不是历史名人。

**必要闸（一票否决 · 缺一不可）**
1. **亲统决断闸**：必须是战役的第一线军事指挥与决断者。纯后勤（萧何）、纯谋划未决断（张良）、君主后方坐镇，一律不计。
2. **史载实胜闸**：史书必须明确记载其打赢过。成败不论，败绩不扣分（项羽、岳飞仍是名将），但只有悲壮失败而无实质大胜者（李陵）不入。
3. **格局分量闸**：胜绩必须达到战役/战区级以上，足以动摇一邦兴灭或战区攻守态势，非百人冲阵、斩将夺旗的战术小胜。
4. **对阵有名闸**：所锚定的代表战役，史书必须明确记载敌方主帅或关键将领姓名；打击无统帅记载的流民、散兵、模糊蛮夷，战果再大只算治安战，不可作为名将胜绩立论。判准：霍去病破折兰王、周瑜破曹操、陈庆之破丘大千均合格；若对手仅记为「贼众数万」而史失其帅，该战役降级。

**裁决双轴（过闸后排定席位）**
- **主轴 · 战役分量**：灭国决战 ＞ 战区决战 ＞ 决定性防守。分量仅及一隅者，哪怕过闸也只能列为准名将或降入普将。
- **副轴 · 军事名气**：仅作放大器和平局手。仅采纳正史与主流典籍中的纯军事符号（独传、兵书、成语战典）；文治、忠义、政治符号严禁跨界加分。

**判定细则与设计解绑**
- **君主抽刀**：抽掉麾下名将与谋士，看君主本人是否剩亲统胜绩。剩（刘邦、努尔哈赤、姬发）入名将；不剩（孙权、杨坚、齐桓公）入普将。
- **守将准则**：决定性防守且保全大局、击退有名敌帅（张巡守睢阳阻尹子奇）为名将；仅局部殉城未改大局（阶伯）为普将。
- **三层解绑**：分级只决定给不给战略技。精锐兵种按历史实际配置（名将可带 T3 弱兵，普将可带 T2 乌桓骑兵），立绘包装按知名度自定，三者互不干涉。
- **一句话判准**：亲指、实胜、战略级、敌有名。头衔道德皆不论，手下败将是何人？存疑一律列普将。

**2026-10-25 补充口径（执行细则）**
- **「准名将」无游戏落点**：两档制里一律归 **普将**（不给战略技）。
- **④闸锚定经典战（＝代表战役）**：取该将最知名、且敌将有实名的够格战役；最知名那一仗敌将史失其名时，按「没名字就换」换到另一场敌将有实名的够格战役（经典战随之换），**换无可换**才列普将。
- **本闸只管新增与重评**；存量名将不主动全库回溯，除主人另批全库体检。
