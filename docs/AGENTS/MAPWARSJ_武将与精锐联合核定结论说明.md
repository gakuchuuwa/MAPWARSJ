# MAPWARSJ 全库武将分级（两档四闸）与精锐评级（五级制 v3）联合核定结论说明

## 一、核定总览与核心统计

本次联合核定严格依照《MAPWARSJ\_GG武将分级与精锐评级联合任务书》，对全库 **1,977 位武将**执行「武将两档四闸」与「精锐五级制 v3」独立双轨核定，并在 **T0（传奇 ×1.5，限 1 人、普将禁挂）** 与 **T4（存在 ×1.1，限 1–9 人、名将禁挂）** 两端严格执行交叉红线咬合：

- **武将级别变动**：原库名将 **533 人**、普将 **1,444 人**；经「穷尽找胜」与「四道硬闸（①一线亲统＋②史载实胜＋③战役级分量＋④敌帅实名＋正史/权威史料原文出处）」逐一核验，本轮**由「普将 → 名将」晋升 84 人**，**由「名将 → 普将」下调 18 人**，同时对 **32 位原名将**原表所挂成名败仗/后方战役按「穷尽找胜」铁律替换为一生真正过四闸的代表胜仗。核定后全库共 **名将 599 人**、**普将 1,378 人**。  
- **精锐评级与连带调整**：严格贯彻「武将与精锐独立评定、仅在 T0/T4 两端咬合」原则，对本轮晋升名将中原处 T4 的 **12 人**同步升级精锐至 T2/T3（彻底清零名将挂 T4），对本轮下调为普将且部队无独立战术/文化专名支撑的 **16 人**顺势回调至 T4，并修正原表 `加兹温近卫` 泛称提示 **1 人**（共调整精锐 **29 人**）。普将统率 T1（曾国藩 `湘军水陆师`、黎来 `蓝山义军`）及 T2（列奥尼达 `温泉关三百士`、真田幸村 `赤备众` 等 35 人）均按史实独立保留。
