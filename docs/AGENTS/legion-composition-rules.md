# 军团编制规则（单一口径）

> 二级军团（`src/data/level2Civ62Legions.ts`，251 支）的兵种归属、落位与替换口径。
> 本文只管「兵种怎么挑、怎么换」；**排与档、三排顺序按代码与 `AGENTS.md` §3.5**，本文不另立档位规则。

## 〇、军团成立条件（2026-11-09 主人定）

1. **军团 ＝ 据点文化 ＋ 势力时代**。
2. 一支二级军团要成立，必须同时满足：
   - 那个时代有**公认的政权或民族**（势力）；
   - 这个势力在那个时代占着的据点，**属于 67 文化之一**，且就是这支军团的文化。
3. **有这个时代的势力，就要有这个时代历史上有名字的武将**挂在这个文化的据点上——军团是套给武将用的，没有武将就没人用。
4. 所以判一个「没有武将的军团」时，按顺序问：
   - 那个时代有没有公认的政权或民族占着这个文化的据点？**没有 → 这支军团不成立，删格**。
   - 有 → **补一位那个时代史有其名的武将**（据点＋势力＋时代＋名将/普将＋精锐配齐，立绘留空），不许拿不存在的人或拟名凑数。
5. 🔴 **最终目的（2026-11-09 主人）：不要有多余的军团，每支军团都要套上势力和武将。** 0 武将的军团要么补将，要么删格，不许长期空着。
6. **传说武将算，神话武将不算（2026-11-09 主人）**：传说＝史实存疑但被当作凡人记载的人物（如亚瑟王、罗宾汉）；神话＝神、半神或带超自然身份的人物，不能拿来给军团凑武将。
7. **一级母体军团（东亚军团、中东军团等 16 支）2026-11-09 主人令全部删除**：军团只剩二级、三级（＋剧本层）。取军团的兜底不再落一级，查不到就返回空；攻城武器的兜底表改按 16 母体文化区代码（`BASE16_xxx_时代`）作键，不是军团。
8. **动物类兵种（战犬）不要求套进军团**，`npm run legion:unit-coverage` 已排除，不算「未套用」。

## 一、排与档（几何口径，程序为准）

- `slots[0]`＝前排、`slots[1]`＝中排、`slots[2]`＝后排；每排人数由 `FORMATION_ROW_COUNTS` 按阵型定（`triangle` 2-3-4、`crane_wing` 2-4-3、`echelon` 4-3-2、`balance_yoke` 4-2-3、`fish_scale` 3-4-2、`crescent` 3-2-4、`square` 3-3-3）。
- 三排先后的唯一口径＝主人 2026-11-02 的**占位排序**：**战象 → 战车 → 步兵 → 骑兵 → 投掷 → 弩手 → 弓手 → 弓骑 → 法术 → 火器**（每支军团按这张表把三排从前往后摆）。
  - 每个兵种**带着自己的档数走**（例：罗马 步3｜弓4｜骑2 → 步3｜骑2｜弓4），阵型按重排后的人数模式套（3-2-4 → `crescent`）。2026-11-02 已按此落库二级 251 ＋ 三级 9 支。
  - **档位排序**（🔴 2026-11-09 主人改定，取代 11-02 版）：**法术 → 战象 → 战车 → 火器 → 骑兵 → 弓骑 → 投掷 → 弩手 → 弓手 → 步兵**，**前面是档位少的**——排第一拿 2 档，依次 3 档，最后拿 4 档；步兵挪到最后＝步兵档最多。11-09 已按此重排二级 109 ＋ 三级 6 ＋ 剧本 12 支，排序审计不符 0。

- 🔴 **主将队站位**（2026-11-04 主人令「主将在2档之间」）：第 10 队站在 2 档那一排两队正中；方阵站前排正中再往前。战略与战术一致。
- 代码唯一定义：`src/types/LegionRowOrder.ts`（两套排序、兵种十类归类 `rowClassOf`、`arrangeLegionRows`、`commanderRowOf`）；战略与战术都读它。改编制后跑 `npm run legion:row-order-audit`（二级、三级必须 0 不符）。

## 三、特色兵种落位规则

1. **一个兵种替换 2 个时代**：古典兵种→「古典+封建」、封建兵种→「封建+城堡」、城堡兵种→「城堡+帝国」。
2. **有升级版**（`elite_` 变体）：前一个时代用升级版、后一个时代用基础版。
3. **无升级版**（单档）：两个时代都用普通档。
4. 🔴 **所有替换必须替换普通兵，不能替换已落位的特色兵种**：同军团先后落多个特色兵种时，后落位的只许替换普通兵档；冲突时把先落位的换到其它仍空着的档位，不是删掉它。
5. **同文明同批多个兵种**：先落位的占一个档、后落位的占相邻档。
6. 🔴 **落位前必查目标档是不是已落特色/区域兵**（血训：黑光铠落城堡时擅自替换草原枪兵 `steppe_lancer` 区域兵）。动手前先 grep 目标档兵种 id 归属：是特色兵/区域兵就跳过该档并报告，只替换普通兵。
7. 🔴 **兵种时代以主人定的为准，考据年代只当参考**（血训：黑光铠考据写「公元3世纪」被机械按「古典≤400」判成古典，实际主人定的是封建时代）。AI 给的考据年代不能反过来决定落位时代。

## 四、兵种名字权威源

- 一律用 **de-wiki** 名字（`DE_UNITS_CATALOG`，`src/legion-editor/main.ts`），核对/报告兵种名别凭记忆或昵称。
- 常见易混：`elite_antiquity_skirmisher` 古典掷矛手高级（antiquity）≠ `elite_skirmisher` 掷矛手高级（feudal）；`guardsman` WarTypes 叫「近卫步兵」但 de-wiki 叫「古典长枪兵」；`swordsman` WarTypes 叫「剑士」但 de-wiki 叫「链甲剑士」。
- 报告/沟通军团用军团名（`name` 字段「古典时代XX军团」），不用文明名（`civ` 字段）。
