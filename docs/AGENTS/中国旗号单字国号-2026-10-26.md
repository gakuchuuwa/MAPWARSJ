# 中国旗号单字国号（2026-10-26 主人令）

> 主人原话：「东晋势力，旗号改为晋。中国旗号能用一个字的就用一个字，但是要符合历史。」
> 同日主人选定标准：**按史照国号写单字，允许重旗**（同国号按史同字，靠势力色＋旗形区分）。
> 规则口径见 `AGENTS.md` §二.3 与 `docs/AGENTS/faction-naming.md` §4.4。

## 一、落地原则

1. **中国政权旗号＝史籍正式国号**；**国号本为一字的写一字**。
2. **没有通行一字简称的两字国号仍写两字**（大顺、大西、大周、大夏、大燕、大理、南越、吴越、南诏、天完…）；不许为凑一字丢「大」或截字。
3. 非国号旗号（民族／部族／家族／州郡／起义）不适用，仍按 `faction-naming.md` §4.1 五级优先级写史称原貌。
4. **同国号按史允许同字重旗**；非中国的同名异政权仍不许重旗。
