# MAPWARSJ 武将分级（两档四闸）与精锐评级（五级制 v3）联合核定任务书（发给 GG）

## 一、核心原则：武将评级与精锐评级分开独立判定，仅在 T0 / T4 两端咬合

1. **两套标准各自独立**：
   - **武将评级（名将 / 普将）**：只看**武将本人**是否打赢过「① 一线亲统 ＋ ② 史载实胜 ＋ ③ 战役级分量 ＋ ④ 敌帅实名」的代表胜仗（严格执行「穷尽找胜」铁律）。
   - **精锐评级（T0 传奇 / T1 战略 / T2 战术 / T3 知名 / T4 存在）**：只看**这支部队本身**的历史定位、实战战绩、建制延续性或文化/兵种辨识度，以及精锐名字是否符合武将与所属势力。
   - **二者解绑示例**：
     - 普将完全可以统率 T1 / T2 / T3 的精锐部队（例如：列奥尼达本人因温泉关战败无胜绩，按四闸判为**普将**，但他统率的「温泉关三百士」是战术传奇奇兵，独立评为 **T2 战术**；高顺、公孙瓒若判普将，其「陷阵营」「白马义从」仍为 **T2 战术**）。
     - 名将若无专属王牌部队，其所统常规主力也可以评为 **T3 知名**（只要有文化知名度或兵种特色）。
2. **仅有的两条交叉硬红线**：
   - **T0（传奇 ×1.5）只许挂 1 名符合历史的武将，普将不可挂**（即挂 T0 的武将本人必须过四闸为**名将**）。
   - **T4（存在 ×1.1）可以挂 1–9 名符合历史的武将，名将不可挂**（即凡过四闸定为**名将**者，其精锐最低为 **T3**；反之，若某原名将经四闸复核实为**普将**，降为普将后其精锐即可顺理成章定为 **T4**）。

## 二、第一部分标准：历史武将分级标准（两档制 · 四道硬闸）

你是历史武将分级评审员。严格照以下标准判，只出表，不解释、不寒暄、不评价标准。

### 1. 两档定义与「穷尽找胜」铁律
- **两档制**：只有**名将**、**普将**两档，中间没有第三档。
  - **名将** ＝ 生平至少打赢过一场「一线亲统、战役级以上、敌帅实名」之胜仗的统帅。
  - **普将** ＝ 其余全部。
- **穷尽找胜铁律（核心判准）**：
  - **严禁拿成名败仗直接定普将**。评审任何一人，必须先检索其一生全部战绩，优先寻找他最够格的一场胜仗来过闸。
  - 只要一生有一场胜仗全过，哪怕他后来兵败身死、晚节不保（如项梁、庞涓、李秀成、维钦托利），也必须拿那场胜仗立论，判为**名将**。
  - 只有在他一生连一场够格胜仗都找不到时，才拿他最具代表性的战例说明卡在哪一条，降为**普将**。

### 2. 四道硬闸（就代表战例核验，缺一即普将）
- **① 亲统**：他本人必须在第一线指挥拍板。纯后勤、只出主意没拍板、后方坐镇派将出征、别人打赢他挂名领功——都不算。
- **② 实胜**：史书明确写着打赢，或达成战役目的（击溃、击退、守住、逼降、夺下核心城池）。一生只输过、只有悲壮失败——不算。赢过够格的仗，输过别的仗不扣分。
- **③ 分量**：战役级以上，能动摇一国兴灭或一个战略方向的攻守。剿匪、治安战、打一座孤立小城、局部遭遇战——不算。
  - *自检标尺*：这仗打赢，那个方向一年内的攻守态势会不会变？不会变就是不够分量。
- **④ 敌帅**：所拿来立论的那场胜仗，史书必须记有明确的敌方主帅或核心统兵将领姓名。敌将只记「贼众数万」「某部首领」「蛮夷」而无实名的仗，一律不能拿来立论。

### 3. 证据与防伪铁律（五项缺一即缺证，降普将）
- **五要素核验**：哪一仗、哪一年、敌方主帅叫什么、他当时在一线做什么、正史/权威史料出处。
- **原文要求**：出处栏写明书名与篇卷，并照抄一句或半句关键原文（外国史无汉文正史者，写明权威史料或战役史实记录；完全查无实据者，出处栏写「无原文」或「缺证」，直接按缺证判普将）。
- **三不许**：不许编人名、不许编书名卷次、不许拿演义小说当史实。
- **存疑处理**：不认识的人、重名错乱的人、把官职当人名的，直接写「缺证，普将」，不推测、不硬凑。名单里没有的人不要自己添。

### 4. 两个例外与名气禁区
- **君主例外**：亲自上前线指挥的按四闸判；坐镇后方、派将出征的一律判普将，功劳归前线那个人（如孙权、杨坚是普将）。
- **守将例外**：击退实名敌帅、守住战略大局的算名将（如张巡守睢阳、王坚守钓鱼城）；城破身死、没改大局的不算（如阶伯）。守城不看兵力多少。
- **名气清零**：头衔、爵位、道德、忠义、单挑武勇、演义名气，统统不进判据。

### 5. 武将六栏标准示例
`武将｜名将/普将｜靠哪一仗｜敌方主帅｜出处｜卡在哪一条`
- `霍去病｜名将｜元狩二年河西破折兰王｜折兰王｜《史记·卫将军骠骑列传》「过焉支山千余里，击匈奴，得胡首虏骑万八千余级，破得休屠王祭天金人」｜全过`
- `项梁｜名将｜秦二世二年东阿、濮阳破秦军｜章邯｜《史记·项羽本纪》「项梁引兵攻亢父，与齐、田荣、司马龙且军救东阿，大破秦军于东阿」｜全过（定陶虽败不扣分）`
- `李陵｜普将｜天汉二年浚稽山之战｜且鞮侯单于｜《汉书·李广苏建传》「陵军五千人，兵矢既尽，士死者过半」｜②一生只有败绩，无够格胜仗`

- `王龁｜普将｜秦昭王四十七年拔上党皮牢｜敌帅失载｜《史记·白起王翦列传》「王龁攻邯郸，不拔」｜④独统胜仗史失敌帅名，长平决胜主帅为白起`

## 三、第二部分标准：精锐评级标准 v3（五级制：传奇，战略，战术，知名，存在）

### 1. T0 传奇之兵 —— 扭转乾坤，青史巅峰
- **定位**：改变历史版图、决定政权兴替的战略核武。
- **核心门槛**：真实存在 + 绝境逆转 / 传奇大捷核心 + 深刻改变地缘格局。
- **与 T1 的分界**：T1 取得了重大战略胜利，但未达到「传奇颠覆版图」的级别。T0 必须是直接导致一个民族、政权、格局被重写的核心力量。**不能是泛指，例如罗马军团、蒙古骑兵。**
- **代表**：玄甲军（虎牢关灭窦建德奠定唐朝）、背嵬军（岳飞抗金核心）、北府兵（淝水之战8万破87万）、怯薛军（蒙古西征重塑欧亚）、魏之武卒（阴晋5万破50万）。
- **乘数与挂将**：`T0*1.5`，传奇，**只许挂 1 个符合历史的武将。普将不可挂。**

### 2. T1 功勋之兵 —— 战略主力，名垂青史
- **定位**：撑起一个时代或一场全面战争的王牌野战军。
- **核心门槛**：真实存在 + 作为独立主力取得过重大战略级胜利 + 建制延续性强。
- **与 T0 的分界**：虽有辉煌战绩，但未达到颠覆版图的高度。
- **与 T2 的分界**：T1 是长期存在的正规野战主力，有建制延续性。T2 是特定战役中的战术突击分队或短期高光。
- **代表**：虎豹骑、关宁铁骑、戚家军、神策军、吐蕃大纛军。
- **乘数与挂将**：`T1*1.4`，战略，**可以挂 1–2 名符合历史的武将。**

### 3. T2 特色之兵 —— 战术尖刀，一战成名
- **定位**：在特定战役中打出惊艳表现的王牌突击队、战术奇兵。
- **核心门槛**：真实存在 + 在特定战役中有明确的战术高光（奇袭、经典阵法、关键突击等）。
- **与 T1 的分界**：缺乏 T1 级别的长久建制延续性或战略影响力，侧重于特定战役的高光。
- **与 T3 的分界**：T2 必须有明确的、可考的战术成就（打过硬仗的实绩）。T3 虽然有名，但其知名度来源于文化符号，而非战术大捷。
- **代表**：先登营（界桥破白马义从）、陷阵营（高顺百战百胜）、羽林军（神龙政变）、百保鲜卑（邙山大捷）、却月阵兵（刘裕以步破骑）。
- **乘数与挂将**：`T2*1.3`，战术，**可以挂 1–4 名符合历史的武将。**

### 4. T3 风土之兵 —— 赫赫有名，独具一格
- **定位**：名号本身具有显著文化辨识度、兵种特色极其鲜明、或与家喻户晓的历史事件紧密关联的部队。虽无明确的战术大捷记录，但绝非无名之辈。
- **核心门槛**：真实存在 + 以下两条至少满足一条：
  1. **文化知名度**：名号是广为人知的历史/文学符号，或与家喻户晓的事件紧密关联（例：楼兰弓手、藤甲兵）。
  2. **兵种特色**：兵种构成、武器装备、作战方式在同时代独树一帜（例：伊贺众、风魔党、九边夜不收）。
- **与 T2 的分界**：T3 的知名度来源于文化符号或兵种特色，而非战术战绩。T2 必须有打过仗的硬实绩。
- **与 T4 的分界**：T4 是纯粹的建制记录，名号缺乏辨识度，无文化符号价值或兵种独特性。
- **代表**：楼兰弓手、龟兹精兵、伊贺众、长坂血骑、康巴骁骑。
- **乘数与挂将**：`T3*1.2`，知名，**可以挂 1–8 名符合历史的武将。**

### 5. T4 存在之兵 —— 确有其军，建制可考
- **定位**：构筑古代军事版图基石的常规部队。
- **核心门槛**：史籍明确记载的独立建制、地方戍兵或豪强部曲。
- **代表**：居延戍卒。**「地名＋兵种＋兵」可以，纯「地名＋兵」不行。四川枪兵能留，四川兵不行。**
- **乘数与挂将**：`T4*1.1`，存在，**可以挂 1–9 名符合历史的武将。名将不可挂。**

### 6. 精锐起名与字数铁律
- **精锐起名看武将和看武将所属势力**。
- **精锐名字 4–8 个字（以 4–6 字最佳）**；仅正史固有 3 字专名（白名单内如玄甲军、背嵬军、北府兵、怯薛军、虎豹骑、戚家军、神策军、先登营、陷阵营、羽林军、伊贺众、风魔党等）可保留 3 字。
- **同号同档**：同一精锐番号在全库只能有一个档位（T0–T4），不得跨档。

### 1. 重点复核对象
- **原标「普将」但实有四闸全过胜绩者**（如古斯塔夫二世、熙德、努尔丁、图特摩斯三世、公孙瓒、辛弃疾、种师道，以及最近新增势力/补将中尚未过筛的统帅）：按「穷尽找胜」升为**名将**，并确保其精锐在 T0–T3。
- **原标「名将」但四闸缺证/敌帅失名/仅坐镇后方者**：严格按四闸降为**普将**；降为普将后，若其部队本身无 T1–T3 实绩或特色，可顺势调整精锐至 T4。

  - T1 限 1–2 人；
  - T2 限 1–4 人；
  - T3 限 1–8 人；
  - T4 限 1–9 人（名将禁挂）；
