## 一、工作方式

- 影响范围：改代码前 `codegraph callers <函数名>`、`codegraph impact <函数名>`，改完对照清单逐处确认。
- 运行时错误角标：启动完成后的未捕获错误在左下角小行显示（`#game-runtime-error-badge`，约 20s 消失）；启动阶段错误整屏显示。
- 直播计划：`docs/直播目标计划.md`。

- 势力时代 `FactionEra.ts`（`FACTION_ERA`，`panshu` 豁免），存续年 `FactionLifeYears.ts`；武将落段 `getGeneralEra`。

- 三排排序（`src/types/LegionRowOrder.ts`，`npm run legion:row-order-audit`）：占位排序＝战象→战车→步兵→骑兵→投掷→弩手→弓手→弓骑→法术→火器；档位排序（依次拿 2、3、4 档，`FORMATION_ROW_COUNTS`）＝法术→战象→战车→火器→骑兵→弓骑→投掷→步兵→弩手→弓手；主将站「2 档」排两队正中（3-3-3 站前排正中前方）。
