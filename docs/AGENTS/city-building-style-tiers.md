## 三层结构

| 层 | 是什么 | 数量 | 权威 |
|---|---|---|---|
| **一级** | 建筑风格母体，**每座据点必属其一** | **16** | `cityDeStyle.BASE_16_BUILDING_STYLES` |
| 二级 | 文明（各有专属城堡） | 59 | `cities_v2.BuildingStyle` 的 59 文明值 |
| 三级 | 皮肤级细分（草原毡帐 YURT 是其中之一） | 3 | `cityDeStyle.TIER3_STYLE_TO_BASE16` |

一级 16 套：东亚 ASIA / 西欧 WEST / 东南欧 EAST / 东北欧 SLAV / 地中海 MEDI / 中东 ORIE /
中亚 CEAS / 印度 INDI / 普鲁 PURU / 东南亚 SEAS / 中美 MESO / 安第斯 ANDE / 非洲 AFRI /
波斯 PERSIAN / 希腊 GREEK / 色雷斯 THRACIAN。

🔴 **草原毡帐的一级是东亚 ASIA**（46 座据点），主人 2026-09-16、2026-09-18 两次口述
「漠北蒙古属于东亚」「草原毡帐是东亚」。⚠️ 别按「DE 把蒙古归 Central Asian 建筑集」

修之前的账：`resolveCityDeBuildingStyle()` 直接返回 'YURT'，全仓按它统计就会数出「17 种风格」，
等于凭空多出一种一级风格。现在：

- `resolveCityDeBuildingStyle()` —— **渲染用**，照旧返回三级皮肤 'YURT'（毡帐贴图 + MONG_CASTLE_AGE3），行为一点没变；
- `resolveCityBase16Style()` —— **归属用**，保证返回 16 之一。凡是要回答「这座城属于哪种建筑风格」，一律走它。

## 铁律

1. **一级永远只有 16 种**。任何统计、面板、审计说出「17 种」就是把三级皮肤当成了一级，是 bug。
2. **新增三级皮肤必须在 `TIER3_STYLE_TO_BASE16` 里登记它挂哪一级**，否则 `city:style-audit` 报红。
3. 三级共 3 种（青藏 / 西域 / 漠北蒙古毡帐），与 `_citytest.html` 的 `LAYER3_CUSTOM_GROUPS` 一一对应，改一边必须同步另一边。
4. 改动前后各跑一次 `npm run city:style-audit`，必须 0 处不合格。

## 建筑风格 ↔ 军团：只在「三级军团被删」时当保底用

> 🔴 [2026-09-18 主人原话]「军团和建筑风格是用来保底的，只有三级军团被删的时候，保底用。」

平时选军团走势力自己挂的那支番号军团。
🔴 [2026-09-18 主人连说三遍]「文化区早就取消了」—— 据点的身份只有建筑风格三层，
别再拿「据点所属文化区」当判据；代码里残留的 region / CULTURE_LEGION_NAMES 是没清干净的旧账。
建筑风格只在一种场合起作用：**三级军团被删除**，挂它的势力要重新安置
（`src/systems/LegionFallbackOnDelete.ts`）。安置顺序：

1. 据点是三级专属风格 → 用主人指名的**保底军团**：
   | 三级风格 | 据点数 | 保底军团 |
   |---|---|---|
   | 青藏 TIBET | 60 | 封建时代吐蕃军团 |
   | 西域 WESTERN | 41 | 古典时代西域军团 |
   | 漠北蒙古毡帐 YURT | 46 | 城堡时代蒙古军团 |
2. 否则二级 59 里有「同建筑风格 + 同武将时代」的 → 安置那支；
3. 再否则退到该风格的**一级母体军团**（16 支）。

🔴 **母体军团就是 16 支**，不是 19 支。三级的那 3 种风格有自己的保底军团（见上表），
不是另外 3 支母体军团 —— 别把 16 和 3 加起来当成一层。

⚠️ 一级 16 + 二级 59 不可删除，只有三级可增可减；保底军团与武将时代无关，就是上表那三支。
