# 「一势力一文化」修复建议（2026-10-24 · 只读体检后提案，未动数据）

> 起因：全库体检发现 **75 家势力旗下武将跨文化**（涉 274/1484 位武将，18%）。主人要求「一势力一文化」，并指出这需要拆势力、属大动作，先提修复建议。
> 本页只是方案，**未改任何数据、未拆任何势力**。

## 一、现状（体检数字）

| 项 | 数 |
|---|---|
| 旗下武将跨文化的势力 | **75 / 609 家** |
| 涉及的「少数文化」武将 | **274 / 1484 位（18%）** |
| 其中只有 1 位跨文化武将的势力 | 35 家 |
| 只有 2 位的 | 20 家（≤3 位合计 59 家） |
| ≥4 位的真·多民族大政权 | 16 家（大明 44 将/9 文化、汉国 46/7、宋国 40/5、唐国 35/8、大清 26/6、起义 23/4、魏国 17/5、罗马帝国 22/6、阿契美尼德 17/5、大元 10/4、倭马亚 9/5、法兰克 8/4、蜀国 19/3、奥斯曼 11/4、马其顿 9/5、大金 7/3） |
| 若按「势力×文化」硬拆 | 75 家 → **208 家（净增 133 家）** |

两条关键事实：

1. **大部分「跨文化」不是错**：2026-10-23 已定「武将文化＝所在据点 `buildingStyle`」，而大帝国的大将常驻在外（明将守江南、汉将屯河西、罗马将驻叙利亚），文化自然跟着驻地走。59/75 家只有 1–3 位这种「驻防在外」的武将。
2. **「势力首城风格」不是可靠的主体文化来源**：26 家的武将多数文化与首城风格不符（例：罗马帝国首城＝里昂/FRANKS，奥斯曼首城＝阿尔及尔/BERBER），因为首城只是数据里的第一座城，不代表政权核心。

## 二、三条路线对比

| 路线 | 做法 | 代价 | 历史风险 |
|---|---|---|---|
| **A. 主体文化＋客将（推荐）** | 不拆势力；给每家定一个「主体文化」；武将文化仍＝据点文化，超出主体文化的即为「客将」，军团/精锐/兵模按他自己的文化 | 1 张 609 行表 + 1 处显示口径 + 审计改法，约 **0.5–1 天**；不动实体 | 无。符合「所有势力必须是历史上有依据、有称呼的政权」「武将按历史上本该归属的政权」 |
| B. 按文化拆势力 | 一家拆成「大明·中原／大明·江南…」 | 净增 133 家，每家要配势力名/旗号/编制/据点/武将/首都 | 高：产生非历史政权名，同朝名将被拆进不同「国」，与历史归属冲突 |
| C. 把少数文化武将迁去同文化势力 | 274 位迁将 | 274 条改写 + 重新校验 | 高：明将／唐将／罗马将历史上不属于「江南国／巴蜀国」这类同文化政权 |

## 三、推荐方案 A 的落地步骤（不动实体，属②口径）

1. **新增 `FACTION_CORE_CULTURE` 表**（新数据文件，键＝势力 id，值＝66 文化之一）：
   - 534 家单文化势力：自动＝该文化；
   - 75 家跨文化势力：按「历史主体（开国核心区／主体民族）」逐家定（下表给 16 大政权的建议值）；
   - `panjun`（起义占位势力）不参与。
2. **势力级显示改用它**：`eraFactionDisplay.getEraFactionDisplayName` 的势力级兜底，从「势力首城风格」改为 `FACTION_CORE_CULTURE`；**据点旗号仍按据点文化**（2026-10-24 已定，不动）。顺带修掉「罗马帝国→法兰克系名、奥斯曼→柏柏尔系名」这类首城带歪。
3. **明确「客将」概念**：武将文化＝据点文化（不动）；武将文化≠势力主体文化时即客将，军团／精锐／兵模按武将文化（已如此），不要求换势力、不拆势力。
4. **审计改口径**：`scratch/audit_culture_chain.mts` 增加「每家势力有 coreCulture 且 ∈ 66」检查；「旗下武将跨文化」由待办降为**合规信息项**（可列出客将名单）。
5. **文档**：`docs/AGENTS/一据点一整套-单一口径.md` §八 补一句「『一势力一文化』＝一势力一**主体**文化；客将按本文化随将，不拆势力」。

唯一历史正确的拆法＝按**武将历史上所属政权**拆（不是按文化拆）。数据里只有少数几家是 2026-10-23「前后相承、彼此不打并成一家」合并过头的：

- 其余 71 家（大明、唐、汉、宋、罗马、马其顿、阿契美尼德等）跨文化是「驻防在外」或「多民族帝国」的史实，不建议拆。
- 拆势力属**新增实体（③档）**，需主人授权；每家要同时配：势力名、旗号、编制、首都、据点归属、武将归属，约半天–1 天/家。

## 五、建议

## 六、取舍决定：以「武将多数」为准（2026-10-24 定）

**结论：势力主体文化 = 该势力全部武将文化按人数取多数；「名将」只用于并列裁决，不单独作主口径。**

理由（全部是体检数据，不是偏好）：

1. **多数 = 名将 在 65/75 家一致**；剩 10 家不一致的，「名将」口径明显被「名将驻地在哪」带歪：倭马亚（名将 4 位在西班牙据点 → 判成 SPANISH，实为阿拉伯／近东 ORIE）、隋国（2 位名将 → WEI，实为中原）、起义（仅 1 位名将 → WEI）、斯巴达（→ 雅典）、回鹘（→ 中原）、塞尔柱（→ 萨珊）、亚美尼亚（→ 近东）。名将口径不可作主判据。
2. **「都城」口径数据不足、不可用**：75 家跨文化势力里只有 **2 家**有 tier0 都城，其余 72 家只有「数据第一座城」——正是这次要修的病根（罗马帝国首城＝里昂/FRANKS、奥斯曼首城＝阿尔及尔/BERBER）；用它等于把旧 bug 换个名字。
3. **「登场最早」不可用**：最早登场的常是冷门武将（大明最早＝陶洪→巴蜀、唐最早＝李靖→鲜卑），偶然性太大。
4. **多数是唯一可自动生成、可复核、无主观的统计口径**；534 家单文化势力天然一致，不产生新决定。

**完整裁决链（写死、可复现，按顺序取第一个命中的）**：

1. **覆写表**（显式的数据表，键＝势力 id，值＝66 文化之一；必须 ∈ 该势力武将文化集合）——只收「统计口径与史实主体明显不符」的少数几家；
2. 否则：**武将多数**（人数最多者）；
3. 并列 → **名将（tier=famous）多数**；
4. 再并列 → **首城建筑文化**（须落在并列集合内，否则跳过）；
5. 再并列 → **登场最早武将的文化**。
