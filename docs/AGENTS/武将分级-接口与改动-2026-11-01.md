# 武将分级·接口与改动（2026-11-01）

> 《武将分级标准-简版-2026-11-01.md》的配套说明。内部用，不随标准外发。

## 接口

1. `tier==='famous'` 决定两件事：挂将时随机分配战略技（`LegionSpawnTier.attachFactionGeneralToArmy`）；成名战触发（`getGeneralFirstBattle` 只对名将生效）。
2. 普将的成名战条目：**数据保留、不触发、不删**。旧令「普将的直接删除」作废，免得反复删建。
3. 名将缺成名战条目不降档，但档案注释里要按证据规则写清「战役—年份—敌帅实名—本人身份—出处」，列入待补录。条目是演出数据，注释是定档证据。
4. 成名战兵力按史录入，运行时经 `clampFirstBattleTroops` 夹到双方 1 万～6 万。这是游戏兵力规则，与定档判据各管一段，不互相套用（守城按战略后果判）。
5. 定档变动在档案注释追加：`名将→普将：<哪一条>｜<依据>`，原件先备份。

## 相对旧版（四闸＋双轴）的改动

| 改动 | 原因 |
|---|---|
| 四闸→三闸，④「对阵有名」并入证据规则 | ④本是②的验证手段；单列会造出「实胜但敌无名就降级、败仗但敌有名不算不合格」的荒谬判定 |
| 删双轴（主轴排序、副轴名气） | 两档制没有名次可排，排序无消费方；名气不可证伪且与三闸重复计分 |
| 删「准名将」 | 旧版正文与补充口径自相矛盾 |
| 君主抽刀→「亲临／坐镇」硬判据，功劳不折给君主 | 抽刀法没有功劳归属判据，抽不干净 |
| 新增守城规模豁免 | 旧版「决定性防守」与「首战 1 万～6 万」互斥 |
| 新增举证责任与禁止拟名 | 旧版「存疑一律普将」把判定交给审核者的记忆，结果随人漂移 |
