## 二、铁律正文

> **AI 只做主人点名的那一处改动。凡主人没说「建 / 加 / 补 / 删」的，一律不许动。**

### 2.1 一律禁止擅自「新建 / 补」

**势力、据点、战场、事件、人物（含战场人物）、精锐番号、旗号、势力色、势力色块、
字段、数据表、机制、规则、行政区、道路、立绘、UI 控件、脚本与工具** ——
**一个都不许**，无论它看起来多合理、多缺、多"符合历史"。

### 2.2 一律禁止擅自「删」

不许删任何数据 / 文件 / 条目 / 注释（除非主人明说「删」）。

### 2.3 禁止的借口（这些**不是**动手的理由）

- ❌ 「审计报警告，补齐就干净了」 → **审计警告只报给主人看，AI 不许自己动手补**
- ❌ 「补齐实体 / 填满字段 / 消除报错」
- ❌ 「符合历史 / 游戏合理」（那是**判定标准**，不是**动手许可**）
- ❌ 「顺手」「反正就一行」「不改就跑不通」
- ❌ 「主人上次点过头」 → **上一次点过头 ≠ 这一次可以自己建**，每次都要先问

### 2.4 唯一正确做法

1. 主人**点名**（「把 X 改成 Y」「建 Z」）；
2. **只改那一处**，别的一律不碰；
3. 回话只写：**改了哪几处 + 实测结果**；
4. **不夹带**「要不要我再做 XX」，**不给自己派活**，不列"要不要"选项清单；
5. 拿不准 → **只问一句** → 主人不回 → **不动**。
