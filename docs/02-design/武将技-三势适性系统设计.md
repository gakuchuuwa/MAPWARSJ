# 武将技·双维策略系统（设计方向 · 待实现）

> **状态**：设计方向已定，**尚未实现**。本文件是唯一蓝图，实现前以此为准。
> **提出 / 定稿**：项目主人 2026-07-07。
> **目标**：① 战斗播报不再单调（不要每局都"岳飞·直捣黄龙"）② 武将性格立体（顺风/逆风打法不同）③ 强化慢直播观赏性。
> **铁律**：**每次战斗武将仍只释放 1 个战术技**——本系统不改这个核心，只加"按局势选技 + 势局适性加成"两层薄逻辑。风险可控，非推倒重来。

---

## 一、核心框架：双维矩阵

整套系统建立在**两个正交维度**上，三十六计六套 = 这两维的二维矩阵。

### 1.1 维度一 · 局（敌我实力）—— 用于【技能】

按战斗开局的敌我强弱，技能分三"局"：

| 局 | 战场态势 | 精髓 |
|----|----------|------|
| **碾压计** | 我强敌弱（优势） | 低成本扫除，求全胜/速胜，不给翻盘机会 |
| **破局计** | 旗鼓相当（均势） | 创造不平衡——制造信息差/假象，动摇对手露破绽 |
| **翻盘计** | 敌强我弱（劣势） | 奇正相生，绝不硬拼，用奇招险招以巧取胜 |

### 1.2 维度二 · 势（策略本质）—— 用于【武将】

按武将一生用兵的策略内核，武将分三"势"：

| 势 | 核心 | 精髓 | 代表 |
|----|------|------|------|
| **造势** | 主动性 | 主动创造、放大本不存在的力量/机会，用虚构的"势"影响敌人判断 | 无中生有、声东击西 |
| **借势** | 杠杆性 | 利用/转化/劫持第三方力量为己所用，善用矛盾让别人的力量为自己服务 | 借刀杀人、假道伐虢 |
| **逆势** | 逆转性 | 极端被动中利用对方思维定势，牺牲表面利益换战略主动，劣势瞬间转化为武器 | 苦肉计、空城计 |

### 1.3 六套 = 局 × 势 矩阵（本系统的基石）

三十六计六套，正好是"局"和"势"两根轴的交点。**六套 = 坐标；局 = 横坐标；势 = 纵坐标。**

| 局 ＼ 势 | 造势(主动创造) | 借势(借力用巧) | 逆势(绝境逆转) |
|:--------:|:---:|:---:|:---:|
| **碾压**(优势) | 胜战计 | 攻战计 | — |
| **破局**(均势) | 敌战计 | — | 混战计 |
| **翻盘**(劣势) | — | 并战计 | 败战计 |

自洽验证：
- 视角一（局）：胜+攻=碾压、敌+混=破局、并+败=翻盘 ✓
- 视角二（势）：胜+敌=造势、攻+并=借势、混+败=逆势 ✓

**关键红利**：只要把一个技能定位到"六套里的哪一套"，它的"局"和"势"两个标签就**同时确定**了，不必分别判两次。

> ⚠️ **局与势正交，不能互相倒推**：一个碾压技可能是胜战(造势)、也可能是攻战(借势)。所以**绝不能**"用技能的局推武将的势"（2026-07-07 曾犯此错，作废）。武将的势必须独立按战史判。

## 二、技能分类：定位六套（一次得到局+势双标签）

每个战术技定位到六套之一 → 局、势两个标签同时确定。

**两步定位**：
1. **先定局**（已完成）：按"战术手法本质"分碾压/破局/翻盘。见附录 A.1。当前 383 技分布：碾压 233 / 破局 66 / 翻盘 84。
2. **再各局二分到六套**（待做）：
   - 碾压 → 胜战计(造势) / 攻战计(借势)
   - 破局 → 敌战计(造势) / 混战计(逆势)
   - 翻盘 → 并战计(借势) / 败战计(逆势)
   - 二分判据见附录 A.3。

## 三、武将分类：按策略本质分势

713 登场武将（308 名将 + 405 普将）各标一个"势"。判据 = **一生主要用兵风格**（附录 A.2）：

- 主动强攻、正面歼灭、以势压人、主动造虚势 → **造势**
- 用计、火攻水攻、借地形天时、借矛盾离间、借第三方 → **借势**
- 以少胜多、背水、坚守孤城、诈降、绝境反转 → **逆势**

> 名将（308）须人工看战史逐个定；普将（405）可按规则批量。

## 四、核心机制：一将一技 + 按局选技 + 势局适性

### 4.1 一将一技释放（不变）
每场战斗武将**只释放 1 个战术技**。改的只是"放哪一个"和"效果多强"。

### 4.2 开局判局势（零新参数）
开局 `pickPredictedSides()` 已算出双方强弱 → 判"优势局 / 均势局 / 劣势局"。阈值复用现有 `ratio_underdog` 等语义。

### 4.3 按局选技（实现"播报多样"）
武将会多类技，开局判出局势后，释放**对应当前局势**的技（优势局→碾压技、均势局→破局技、劣势局→翻盘技）。同一武将顺风/逆风放不同技，**播报随战局变化，不再单调**。

### 4.4 势-局适性加成（双维矩阵驱动，核心）

由矩阵天然导出：**每个"势"覆盖两个局（矩阵每列两格），缺一个局**。

| 武将势 | 擅长的局（有专属六套技 → 加成） | 不擅长的局（只有通用技 → 减成） |
|--------|--------------------------------|--------------------------------|
| **造势** | 优势(胜战计) · 均势(敌战计) | **劣势** |
| **借势** | 优势(攻战计) · 劣势(并战计) | **均势** |
| **逆势** | 均势(混战计) · 劣势(败战计) | **优势** |

- **武将在擅长的局** → 能放出对应六套的**专属技**，效果**加成**（性格拉满）。
- **武将在不擅长的局**（矩阵空格）→ 只能放通用技，效果**减成**。

主人原话例证完全吻合：
- "造势武将在优势局放优势技 → 翻倍" ✓（造势擅长优势/胜战计）
- "逆势武将在优势局 → 减倍" ✓（逆势缺优势局，是它的短板）

> **加成幅度不取字面"翻倍/减半"**：胜负在 t=0 锁定，过猛倍率会把强弱悬殊放大成毫无悬念。实拟 匹配 ×1.4 / 错配 ×0.75，须用 `mapwar-skill-balance` 模拟器验证。

### 4.5 语音播报
携带局 + 技名（可选带势），如「**逆势·翻盘计——空城退敌！**」。风格须**沉稳历史解说**，不浮夸。

## 七、与现状的关系

- **当前**：战术技分五系（强化/命运/兵力/战损/克制，按引擎效果分），武将死挂 1 个 `tacticalSkillId`。
- **本设计**：分类维度换成**双维矩阵**（局×势=六套），技能定位六套、武将按势分、按局选技、势局匹配加成。
- **引擎效果层不变**：底层仍是那 5 种效果（增己战力 / 削敌兵 / 改运翻盘 / 战损 / 克制），本系统只换"分类框 + 选技逻辑 + 适性倍率"，**不新增引擎效果种类**。

## 附录A · 判定尺子

### A.1 局尺子（技能，按【战术手法本质】）— 已完成 383 技

判定优先级（自上而下，命中即定）：

1. **翻盘计(劣势)** ← condition ∈ {ratio_underdog, side_comeback, self_troops_below_enemy_pct, lose_as_underdog, battle_siege_defender}，或 effect ∈ {recompute_comeback, lose_enemy_casualty_boost, lose_zero_enemy_recovery, ally_add_troops_comeback}
2. **破局计(均势)** ← effect ∈ 削敌/扰敌/偷技类 {enemy_sub_troops_opening, dual_sub_troops_opening, luck_variance_enemy, steal/negate/partial_negate_enemy_skill, reflect/nullify_enemy_opening_cut, cancel/halve_terrain_buff}
3. **碾压计(优势)** ← 其余（主要是增己战力 ally_power_mult / first_sortie_power_mult / win_casualty_reduction 等，**不管 condition**）

**要点**：增己战力（220个）一律归碾压（硬实力），破局只装"对敌方动手脚"（削敌/扰敌/偷技）。曾试"按触发局势 + always→破局"，会把「摧枯拉朽」等错归破局，已废弃。

实测分布：**碾压 233 / 破局 66 / 翻盘 84**。碾压偏大是数据现实（增己战力占 57%）。完整清单见《武将技-三局分类清单.md》。

### A.2 势尺子（武将，按【策略本质 / 一生用兵内核】）

**判定方法**：只看武将**一生打仗的内核**，不看单场。现挂技名/战史注释作**辅助参考、不唯一**（现挂技只反映一个战例）。**局≠势正交，绝不能用技能的局倒推武将的势。**

| 势 | 核心 | 判据（一生主要打法） | 典型 |
|----|------|------|------|
| **造势** | 主动性 | 主动强攻、奔袭、正面歼灭、拓土扩张、以势压人、主动造虚势影响敌人 | 白起、王翦、霍去病、卫青、吴起 |
| **借势** | 杠杆性 | 用计、设伏诱歼、火攻水攻、借地形/天时/矛盾/第三方、运筹庙算、屯田持久 | 孙膑、先轸、李牧、赵充国、邓禹 |
| **逆势** | 逆转性 | 以少胜多、背水死战、坚守孤城、诈降、卧薪、后发制人、绝境反转 | 韩信、田单、勾践、廉颇、刘秀 |

**边界原则**：名将多面，**取其最标志性、最著名战役体现的那一面**；两面难分标 **△** 供主人复核。例：
- 韩信虽多面手，招牌"背水一战"→逆势；
- 乐毅伐齐横扫→造势，但合纵五国借力→沾借势，标△；
- 周亚夫深壁扼粮借粮道命脉→借势，但坚守不出→近逆势，标△。

**普将（405）批量规则**（多无战役级战绩，按角色定势，不逐个考据）：
- 守土君长 / 笼城死守 → **逆势**
- 骑射游牧 / 主动劫掠 → **造势**
- 水军 / 用计 / 借地形 → **借势**
- 拿不准 → 默认 **借势**（均势通用，最不突兀）

**名将（308）必须人工按战史逐个判**，边界标△；判定结果见《武将分势清单.md》。

### A.3 六套二分尺子（局 → 六套，待做）

在已定的"局"内，按"势"再二分：

| 母局 | 子套(势=造势) | 子套(势=借势/逆势) | 二分判据 |
|------|------|------|------|
| 碾压 | **胜战计**(造势)：以势压人、正面强攻扩大优势、主动造势 | **攻战计**(借势)：主动进攻捕捉战机、借力/借地形擒首 | 靠自身硬实力/造势 → 胜战；借机借力擒首 → 攻战 |
| 破局 | **敌战计**(造势)：主动制造假象/虚势削敌欺敌 | **混战计**(逆势)：乱中取利、以乱为掩护 | 主动欺敌 → 敌战；被动利用混乱 → 混战 |
| 翻盘 | —（造势不覆盖劣势） | **并战计**(借势)：借力反噬、多方借势；**败战计**(逆势)：绝境险招纯自身逆转 | 借第三方/外力 → 并战；纯绝境自救 → 败战 |

### A.6 补充规则（2026-07-07）

- **劣势 condition 优先**：技的 condition ∈ {ratio_underdog, self_troops_below_enemy_pct, side_comeback, lose_as_underdog, battle_siege_defender} → 一律归 **劣势** 局（覆盖 A.5 的 effect 判定）。因为"劣势下的增战力/博运/守城"(背水一战、破釜沉舟、守城死战)本质是劣势技。此规则使劣势池 **49→110**，撞车问题靠归位解决，无需硬造劣势技。
- **战斗判局阈值（引擎 assignSituationalSkills）**：`我方兵力 / 敌方 > 1.5 → 优势`、`< 0.67 → 劣势`、中间 → 均势。离散档，简单可预期，适合慢直播。
- **已改 condition 回劣势主场的招牌**：背水一战 ts_013(always→ratio_underdog)、诱敌疲歼 ts_173(battle_field→ratio_underdog)。其余 6 个错位招牌(破釜沉舟等)因 condition 本就是劣势，A.6 规则自动归位。
