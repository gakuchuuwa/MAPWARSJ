## 统计

- 62 个文明全部用英雄，共用到 84 种英雄兵模（含三位御驾战象）。
- 其中自己文明有英雄的 44 个，借邻近文化里样子相近的英雄补的 18 个：河西、鲜卑漠南、高丽、日本、维京、马扎尔、意大利、罗马、西班牙、葡萄牙、萨拉森、西域、印度斯坦、孟加拉、高棉、玛雅、阿兹特克、青藏。
- 借用的依据都是素材样貌（我看过英雄的待机图）：中式甲胄骑兵 → 东亚各国；具装骑 / 弓骑 → 草原各部；披风长发步战 → 维京；圆盾长矛重步 → 罗马；披羽毛的 → 美洲各部。
