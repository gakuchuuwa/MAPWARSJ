# 248 类 · 主将兵模归类（英雄 + 战车战象，按文化与样子，草稿，待主人过目）

> 🔴 [2026-10-05 主人令] 62 个二级文明用**英雄兵模**；**战车、战象也当英雄兵模用，高级的都用上**（高丽战车精锐、孟加拉拉塔战车高级、波斯战象精锐、桑纳亚战象高级、战斗象高级、象弓骑兵高级、弩炮战象精锐）；**有英雄就不分时代**（4 个时代用同一批）。
> 🔴 吕布与孙权的攻击都是弩，**不放进同一个文明**；日本不用马上刀（关羽），用马上枪（孙策）。
> 🔴 各文明**原有的英雄兵模保留**；借用的可以重复使用。
> 🔴 数据不合理的英雄已套用合理属性：雅德维加、塔玛尔（原攻击 0，补 10）、诸葛亮（hp220 atk8）、皇帝巴西琉斯（hp300 atk14）、瓜科尔达（hp190 atk12）、奥尔良少女贞德（hp200 atk12），所以都放回表里。
> 🔴 战车、战象只用冷兵器的；胡斯战车带火器，不用。我判断太弱的战车也不用：双轮战车高级（hp125 atk10）、孟加拉拉塔弓战车精锐（hp115 atk6）。
> 🔴 [2026-10-05 主人令] 游戏里有同名英雄的武将，直接用同名英雄（例：曹操用曹操，共 73 位已对应）；没有的，才用下表这个文明的随机池，**每局重新随机**（同一局内同一武将的形象不变）。
> 分配依据：文化挨着、样子像（看素材样貌，不看人名）。
> 排除：4 个英雄战船、战马「布塞法洛斯」，以及「装甲攻城战象高级」（它是攻城器械）。

## 统计

- 62 个文明全部有兵模。原有英雄的文明保留原有英雄（人数偏少的补了邻近文化里样子相近的）；自己没有英雄、借用的 18 个：河西、鲜卑漠南、高丽、日本、维京、马扎尔、意大利、罗马、西班牙、葡萄牙、萨拉森、西域、印度斯坦、孟加拉、高棉、玛雅、阿兹特克、青藏。
- 借用依据都是素材样貌：中式甲胄骑兵 → 东亚各国；具装骑 / 弓骑 → 草原各部；披风长发步战 → 维京；圆盾长矛重步 → 罗马；披羽毛的 → 美洲各部。
- 待你确认：孙坚是否持枪（日本用了孙策、孙坚，我没逐帧看孙坚的武器）。
