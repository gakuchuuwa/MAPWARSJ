## 一、四币分类（每个战术技效果只属于一种货币）

| 货币 | 家族（baseEffect） | 管什么 | 铁律 |
|---|---|---|---|
| ① 运气币 | luck_variance_self / luck_variance_enemy / luck_lock_self | 结果的方差 | **luckMin + luckMax = 2（均值恒 1）**；锁运锁 1.0；luck 字段挂在其他效果上 = 死字段 |
| ② 对抗币 | negate / partial_negate / steal_enemy_skill | 吃掉对面的技 | 通用否决/概率否决 = **0.25**；夺技封顶 **0.5**；100%/0.7 档必须一人一张 |
| ③ 胜率币 | ally_power_mult / first_sortie_power_mult / enemy_sub / ally_add / dual_sub | 谁赢 | 三档网格（见二） |
| ④ 战损币 | win_casualty_reduction / elite_casualty_reduction / lose_enemy_casualty_boost / post_recovery_rate / lose_zero_enemy_recovery | 赢得多惨、输得多疼 | 两档 + 锁定值（见三），不影响胜负 |

**核心原则：强度跟稀缺度走。** 谁都能拿的技 = 低档；高档必须真正一人一张（专属/精锐段）。

## 二、胜率币三档（解析标定：luck [0.8,1.2] 下等兵力胜率）

| 档 | 加攻乘区 | 削敌/加兵（换算 1/(1−x)） | 等兵力胜率 |
|---|---|---|---|
| 通用·无条件 | ×1.05 | 5% | ≈62% |
| 通用·真条件 / 专属 | ×1.10 | 9% | ≈70% |
| 绝品（个位数，如据水断桥） | ×1.15 | 13% | ≈79% |

**条件分级**（溢价补偿触发概率，不是名字帅）：
- **不算限制（低档）**：always、battle_field、terrain_plain
- **真限制（高档）**：攻城/守城限定、山地/水战、ratio_underdog 系、敌有名将、异文化、首战、带精锐、兵力阈值类

**运气币阶梯**：通用 [0.7,1.3] ／ 守城条件技 [0.6,1.4]（方差溢价一档）／ 专属 [0.5,1.5]。

**战损币档位**：减损 通用 0.3 / 专属 0.5 / 绝品 0.6（兵不血刃，锁定）；咬人 通用 1.25 / 专属 1.5（= 逆势败不垒保底）；恢复 0.5。

**锁定值（勿动）**：ts_026 百折不挠 0.12、ts_032 兵不血刃 0.6、str_07=0.02、地图技 hiddenPostBattlePct=0.01、固若金汤系数 1.3 教训（任何单侧乘区顶到 1.5 = 越过 luck 帽 = 等兵力必胜，禁止）。

## 三、势 × 局（三势适性，与实现一致的对角表）

| 势 \ 局 | 优势 (r>1.5) | 均势 | 劣势 (r<0.67) |
|---|---|---|---|
| 造势 | **1.35** | 1.15 | 0.75 |
| 借势 | 0.9 | **1.35** | 1.15 |
| 逆势 | 0.9 | 1.15 | **1.3** |

- 优势格错配只降 0.9 不降 0.75：0.75 会在 r=1.5 两侧造成"兵多反而必败"倒挂断崖。
- 逆势另有败不垒保底：劣势战败时敌方战损 ×1.5 起。
- **势的唯一权威 = docs/02-design/武将分势清单.md**（造势 195 / 借势 59 / 逆势 46）；profiles.ts 曾批量写错已修复（2026-07-14，197 条）。

## 五、重铺（命令二，进行中）与验收门

分配规则：专属格保护 → 候选池（三势标签对格 ∧ 攻防标签兼容 ∧ 条件面向兼容：守城技只进守槽、underdog 条件只进劣势格）→ 势的六计家族优先（造势:胜/攻战+敌战；借势:混战+并战；逆势:败战+敌战）→ generalId 哈希去同质化。

**落盘前六项验收门**：三势错位 0 ｜ 攻防冲突 0 ｜ 哑技 0 ｜ 六件套同款 0 ｜ 单技单槽持有 ≤40 ｜ 专属格保留率 100%。外加：**攻守区分度 ≥80%**（攻槽含攻向真条件技 且 守槽含守向真条件技的武将占比）。

**名计专属副本原则**：典故对人、一人一张、找不到正主宁留通用（宁缺毋滥）。
