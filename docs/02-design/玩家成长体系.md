# 玩家成长体系（九阶段）

> 玩家 = 乱入者，开局平民，逐级成长到皇帝。

## 权与力分离（核心设计）

- **管「权」**：`control`（指挥范围）+ `authority`（职权）——决定「指挥什么、决定谁出兵」。
  - `none` 只管自己 → `one` 前排 1 队 → `front` 整个前排 → `all` 三排全军。
- **管「力」**：`powerMult`（第九环玩家官阶战力乘数 1.1~1.9）——决定「打多狠」，复用九环战力体系第九环。

## 玩家初始状态

- 开局玩家是 **平民**（白身一人）。
- 陆军模型套用 **民兵**（militia）；水上模型套用 **独木舟**（canoe）。

## 晋升触发方式

- 功勋（`merit`）只增不减，官阶由功勋自动推导（`rankForMerit(merit)`）。
- 功勋来源：玩家本人 + 玩家指挥编队的击杀精灵数（1 精灵 = 20 兵），以及战略大捷战功分成（按当前官阶 `meritShare` 比例）。
