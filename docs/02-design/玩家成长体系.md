# 玩家成长体系（九阶段）

> 玩家 = 乱入者，开局平民，逐级成长到皇帝。

## 九阶段

| 阶段 | 身份 | 能力 |
|------|------|------|
| 1 平民 | 白身一人 | 游历名胜 |
| 2 斥候 | 入伍从戎 | 单骑行军 |
| 3 探马 | 十夫之长 | 指挥前排一个精锐编队 |
| 4 先锋 | 先锋大将 | 统领前排近战突击群 |
| 5 将军 | 统军中坚 | 全方阵前中后全军微操 |
| 6 元帅 | 位极人臣 | 可调动本国已出征的军团加入本军团，兵力合并 |
| 7 诸侯 | 拥有自己的第一座城池 | 可决定出兵权 |
| 8 国王 | 正式自立立国 | 可决定本势力所有据点的出兵权 |
| 9 皇帝 | 天下共主 | 可决定臣服势力的出兵权（后期加臣服外交） |

## 玩家初始状态

- 开局玩家是 **平民**（白身一人）。
- 陆军模型套用 **民兵**（militia）；水上模型套用 **独木舟**（canoe）。

## 待定事项

- 九阶段的**升级条件**（功勋门槛 / 触发方式）未定。
- 与现有「官阶」（第九环战力 ×1.10–1.50，5 档：风行斥候/探马蓝旗/陷阵先锋/百战将军/兵马元帅）的映射关系未定——九阶段管「权」，战力环管「力」，两者如何对应需定。
