## 建议的实现方案

### 1. 保住现有正确行为

继续存经纬度和稳定种子；屏幕坐标只在绘制时计算。保留水域排除、城市留白、绘制顺序、四季对应、季末两秒换季、缺瓦片时保留旧树以及重试机制。地理位置不随换季重新洗牌。

森林掩膜仍由 `StrategicForestMask.ts` 读取，其中当前查询将 R 通道作为 biome、G 通道作为 canopy。它约束“能不能长林、总体有多密”；美术噪声只塑造掩膜内部的布局，不能用好看的噪声凭空在荒漠或水面种林。

### 2. 从椭圆林团改为不规则连片林地

用世界坐标上的低频连续场决定大轮廓，中频扰动制造凹凸、林隙和窄连接，再用细粒度稳定采样摆树。相邻分块读取同一坐标函数，避免接缝；禁止每次移动相机重掷随机数。

保留大片空地与少量大林地，避免回到“满屏密麻麻的小林团”。疏密由真实 canopy 和地表适宜性调制，轮廓不要再固定圆形、椭圆形或均匀棋盘格。林缘树密度逐渐下降；疏林应以少量独立树冠表现，不能靠整片半透明的绿色雾团表达。

### 3. 树木贴地与地形适配

候选点读取自身高程与水域状态，缓存采样结果。若利用坡向或坡度塑造林地，先确认现有高程数据分辨率和噪声，禁止拿粗栅格推导精细山脊后硬切树林。山脊并非一律无树、河谷也并非一律密林，不新增这类绝对地理规则。

按素材锚点定位树根，阴影贴近树根并保持轻微。叶冠、原素材阴影与新增接地阴影不能叠成黑污点。必要时在同一林地覆盖掩膜内加入低对比的林下底色，保留山体明暗；不能重新铺圆形渐变斑点遮住地形。

### 4. Z9/Z10 两级层次

Z9 看林地整体形状和方向：减少树冠碎纹、保持主要林缘；Z10 增加单树可辨识度。两级从同一组稳定候选点选取，切换不能随机跳位。先用现有分层范围，不擅自扩展到 Z11–13。

第一轮美术试验可将 Z9 树高从现有 26px 比较至 20–24px，冠层局部对比降低约 10%–20%；这些是待比较的美术候选值，不是史实数值或已验收标准。最终以相同镜头前后图决定，不盲目固定参数。

不要全屏实时 blur，不在每株每帧使用滤镜，也不每次 paint 都读取像素。若需调色或生成变体小图，加载时处理并缓存；确认每种素材原本的透明通道，不重复抠色。

## 验收条件

- 同一机位可明显看出：椭圆盖章感减弱，林缘有凹凸与疏密，城池/旗号/军团更清楚；不能只是把树减少到“看不见”。
- 相机平移、跟随、Z9↔Z10 往返时树不滑动、不重排、不出现分块直线接缝。
- 地表数据加载中、换季前后，已有植被不得整层归零；树根位置保持，健康林不能闪成倒树/树桩。
- 海面与已有水域判定为水的点无陆生树；城市原有留白继续有效；高程检测使用候选点而非林团中心。
- 在同一设备、相同视口及树量条件下测至少 30 秒。记录 render/paint 的 p50、p95、长任务和贴图缓存；目标是不劣于原版，任何明显退步必须定位后处理。不要用隐藏页或 0×0 视口采集性能结论。
- 不运行 `npm run build`。运行 `npx tsc --noEmit --pretty false`；用真实浏览器验证布局。
- 若实际改到气候、树种归属或四季映射，按变更范围运行现有 `scratch/verify_tree_four_seasons.mts`、`scratch/verify_tree_dominance.mts`、`scratch/verify_eastasia_trees.mts`、`scratch/verify_theme_regions.mts` 等相关脚本；先读取其运行入口和依赖，不把脚本存在当作已经通过。未触及 Z13 不扩大修改范围。
