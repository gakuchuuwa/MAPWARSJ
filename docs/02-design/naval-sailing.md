# 海上行船（战略地图舰队航行）设计规范

> 🔴 [2026-09-11 主人「我不懂，请你用游戏海上行船的专业，帮我设计游戏」]
> 本文是**战略地图上舰队怎么走、怎么摆、怎么转**的唯一设计依据。代码在
> `src/map/legion/LegionPhalanxDrawer.ts` 的 `drawNaval()`（舰队编队绘制）。

---

## 一、两条设计标准（与项目总纲一致）

| 标准 | 本块的具体判据 |
|---|---|
| **游戏合理** | 手感对齐 AoE2 海战：舰队是"一支队伍在走"，不是"一列船被拖"；转向看得见地转过来（0.6~1.0 秒量级），不是原地拧头、也不是跳 22.5° 一格。 |
| **符合历史** | 桨帆船（galley）靠划桨+尾舵，满舵回转是**秒级**、有回转半径；帆船更大更慢。所以"整队划一道弧"才是正确形态，"瞬间换向"在任何船种上都错。 |

---

## 二、三条铁律

### 铁律 1 —— **逻辑航向**与**视觉航向**分开，谁也不许顶替谁

| 名称 | 来源 | 用途 | 特性 |
|---|---|---|---|
| **逻辑航向** `logicalDeg` | 军团路径（`headingDeg`，北=0 顺时针） | 位置推进、航迹采样、战斗判定 | 拐点上**瞬间换向**（路径是折线）——这是对的，别去平滑它 |
| **视觉航向** `courseDeg` | `stepNavalCourse()` 按**回转率上限**平滑逼近逻辑航向 | **只**决定贴图朝向 | 限速回转，拐点处划弧 |

- 视觉航向**只影响画出来的朝向**，绝不回写逻辑；寻路/战斗照旧读逻辑航向。
- 每支舰队各自记（key = `unitId`）；同 `tick` 重复调用步长为 0（同一帧多个 pane 各画一次不会重复推进）。

### 铁律 2 —— **全队共用同一条视觉航向**（这是"船头各指一边"的根治）

- 每艘船的贴图朝向一律取 `faceAng = flagAng`（由 `courseDeg` 得来），**不再取"自己所在那段航迹的切线"**。
  - 旧实现（2026-08-27 §A「蛇形跟随」）就是取当地切线：拐点那一帧旗舰朝新向、压在旧航段上的僚舰朝旧向，
    主人实机看到「旗舰已调头向北、二舰船头却朝西，然后船才向北」。
  - 航迹切线在**转弯过半时**才更到新方向，所以旧写法必然出现一段"船头朝旧向、人往新向走"。
- **站位仍按当地法线**（`localAng` 只留给横向偏移用）：这两件事必须分开，别再合并。

### 铁律 3 —— **站位沿旗舰真实航迹**（纵队），不许抄近道切弯

- 后随船沿 `navalFieldPose.trail` 回溯定位（弧长等距），无航迹才退化成直线纵队。
- 为什么不能改成"直接插到编队槽位"：我军舰队走河道/海峡，直插会**切弯上岸**（2026-08-27 的原始动机）。
- 所以转弯时看到"队首已过弯、队尾还在旧航段上"是**正确的纵队形态**，不是 bug；
  只要朝向统一（铁律 2），整列读起来就是一道流畅的弧。

## 三、参数表（现值 + 依据 + 上限）

| 参数 | 现值 | 依据 / 上限 |
|---|---|---|
| **回转率** `NAVAL_TURN_RATE_DEG_PER_SEC` | **120 °/s** | 满舵 90° ≈ **0.75s**。真实桨帆船满舵是秒级，RTS 里取 0.6~1.0s 一档手感。**上限**：>200°/s 就退化成瞬间换向，弧线感消失。 |
| 编队纵向间距 | `flagshipLength × 1.15` | = 1.15 个船长，艏艉不叠。**基准必须与朝向无关**（取 16 向最长边 `refLen`），否则转弯时船距跟着变、看着一卡一卡（2026-09-02 修）。 |
| 编队横向间距 | `flagshipW`（一船宽） | 两列中心隔一个船宽，刚好不叠。 |
| 站位误差（纵向） | `LONG_AMP = 0.07` | **硬上限 0.072**：相邻相舰位差 2.3 rad → 相对摆幅 1.82 倍；`LONG_AMP × 1.82 × 1.15 < 0.15` 才不叠。要更明显得先拉开 `shipDepth`。 |
| 站位误差（横向） | `LAT_AMP = 0.12` | 与纵向不同频（0.00061 vs 0.00082），避免两轴同相变成整齐画圈。 |
| 浮沉/横摇 | `NAVAL_MICRO.STATIC` / `.OARED` 两档 | 帆船（静态）幅度大、划桨船小；行军 MOVE 档比停泊 IDLE 档大。逐舰错相（`unitPhase + i×1.7`）防同频共振。 |
| 船体缩放 | `baseHeight 72 × scale × getNavalShipDrawScale(船型)` | 海军船略小，避免靠港/围城时遮挡过重。 |
| 朝向精度 | 16 向帧 + **残余角 `ctx.rotate` 补回** | 量化丢掉的 ±11.25° 必须补回去，否则转向是"一格一格跳"。 |
| 划桨频率 | `speedFactor` 驱动 | 快船快桨、停船收桨；缺省 1 = 旧的 150ms 固定步。 |

## 四、验收

**数值**（`scratch/_verify_naval_course.mjs`，可复跑）：

| 检查 | 期望 | 实测 |
|---|---|---|
| 每步角速度 | ≤ 120 °/s | **120** ✅ |
| 0°→90° 用时 | ≈0.75s | **0.750s** ✅ |
| 180° 转向 | 走最短一侧 | 0 → 358（−2°/步）✅ |
| 两支舰队互不串味 | 各自独立 | fleetA 85.2° / fleetC 270° 互不影响 ✅ |
| 同 tick 重复调用 | 不推进 | 90 / 90 / 90 ✅ |

**目视**（游戏内，必须人来确认）：开一支舰队沿河道北行 → 拐弯时应看到
①队首先转、队尾依次拉过弯（纵队）；②**全队船头同向**；③转向约 0.7 秒完成，是一条弧不是一格跳。

> ⚠️ 诚实交代：无头浏览器里 `window.game` 摸不到军团渲染器（`map` 上只有 `cityCaptureRenderer`），
> 把玩家军队挪到海上后 `renderer.isOnSea` 仍为 false —— **截图级验证没做成**，只有上面的数值验收 + 代码路径。

## 五、调参与禁区

**可以调**：回转率（60~140 一档）、编队间距系数（1.05~1.35）、站位误差幅度（守 0.072 上限）、微动两档幅度。

**禁止**：
1. 把贴图朝向钉回逻辑航向（等于删掉回转率，拐点必出"船头各指一边"）。
2. 把贴图朝向取回**当地航迹切线**（旧实现，同样是上面那个 bug）。
3. 丢掉 16 向量化残余角的 `ctx.rotate` 补正（转向会一格一格跳）。
4. 让编队间距基准随朝向变（船长是常量，间距就该是常量）。
5. 把逻辑航向也平滑掉（寻路/战斗判定跟着漂，会出卡顿与撞岸）。
