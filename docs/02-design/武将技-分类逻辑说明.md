# 武将技·分类逻辑说明（三类 / 六种）— 供检查

> 一个技**同时**贴两个标签:一个"六种"、一个"三类"。分类**只看 `baseEffect`（战斗效果）**,不看典故、不看技名。

---

## 一、两把独立的尺子

| 尺子 | 名称 | 含义 |
|------|------|------|
| **六种**（六套） | 攻战 / 胜战 / 敌战 / 混战 / 并战 / 败战 | 技的"手法家族"（借三十六计六套之名） |
| **三类**（三局） | 优势技 / 均势技 / 劣势技 | 技在什么战局放（碾压计 / 破局计 / 翻盘计） |

---

## 二、判据全链：effect → 六种 → 三类

### 第 1 步:effect → 六种

| 效果 | baseEffect | 六种 |
|------|-----------|------|
| **加己攻** | ally_power_mult / first_sortie_power_mult / ally_add_troops_opening | **攻战·机** |
| **减敌兵** | enemy_sub_troops_opening / dual_sub_troops_opening | **胜战·全** |
| **更随机** | luck_variance_self / luck_variance_enemy / luck_lock_self | **敌战·衡** |
| **克夺反** | steal / negate / partial_negate / reflect / nullify / cancel·halve_terrain | **混战·乱** |
| **减己损** | win_casualty_reduction / elite_casualty_reduction / post_recovery_rate | **并战·借** |
| **败不垒** | lose_enemy_casualty_boost / recompute_comeback / lose_zero_enemy_recovery / ally_add_troops_comeback | **败战·险** |

### 第 2 步:六种 → 三类

| 六种 | 三类 | 战局含义 |
|------|------|---------|
| 攻战 · 胜战 | **优势技**（碾压计） | 顺风加己攻 / 减敌兵,扩大优势 |
| 敌战 · 混战 | **均势技**（破局计） | 搅乱 / 克夺反,打破平衡 |
| 并战 · 败战 | **劣势技**（翻盘计） | 减己损 / 败不垒,绝境求生 |

### 第 3 步:劣势 condition 优先（唯一覆盖规则）

技的触发条件 `condition` ∈ 下列"劣势才触发"集 → **强制归劣势**,覆盖前两步:
`ratio_underdog`（我方兵少）、`self_troops_below_enemy_pct`（兵不到敌某比例）、`side_comeback`（逆境反打）、`lose_as_underdog`（以弱败）、`battle_siege_defender`（守城方）

**为什么**:像"背水一战/破釜沉舟",effect 是"更随机"(本该均势),但只在兵少绝境才放——本质是劣势翻盘技。此规则把它们归回劣势。**当前 63 个技因此改判。**

## 三、实例（4 个）

| 技 | baseEffect | condition | 六种 | 三类 | 说明 |
|----|-----------|-----------|------|------|------|
| 痛饮黄龙 | ally_power_mult | battle_field | 攻战 | **优势** | 加己攻 → 碾压 |
| 叠砦疲敌 | negate_enemy_skill | always | 混战 | **均势** | 克夺反 → 破局 |
| 空寨掩击 | lose_enemy_casualty_boost | always | 败战 | **劣势** | 败不垒 → 翻盘 |
| 破釜沉舟 | luck_variance_self | self_troops_below_enemy_pct | 敌战 | **劣势** | effect 算均势,但兵少才放 → 第3步改判劣势 |

| 六种 | 攻战 | 胜战 | 敌战 | 混战 | 并战 | 败战 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|

## 五、重要区分:技的"三类" ≠ 武将的"三势"

**这是最容易混的一点:**

| 对象 | 标签 | 是什么 |
|------|------|-------|
| **技** | 三类（优/均/劣局） | 技在什么战局用 |
| **武将** | 三势（造势 create / 借势 leverage / 逆势 reverse） | 武将的天赋性格 |

**运行流程**:武将登场 → 按双方兵力比判"当前是什么局"（优/均/劣）→ 放该局对应"三类"的技；武将的"势"则决定**势×局匹配时的战力加成**（3×3 系数表,见 A.7）。

两套标签在整合层（③）相乘,但**概念完全独立**——技分"六种×三类",武将分"三势"。
