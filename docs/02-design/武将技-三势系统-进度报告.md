# 武将技·三势适性系统 — 进度报告（2026-07-07，待主人检查）

## 一、目标（本系统要解决什么）

1. **播报不单调**：武将从"死挂 1 个技、每局都放同一个"→ 会 3 个技、开局按兵力局势(优/均/劣)换着放。
2. **武将立体**：顺风/逆风打法不同（如成吉思汗优势碾压少损、张巡劣势死战让敌惨胜）。
3. **慢直播观赏性**：远征跟拍军团的战斗有看点、有预期、符合史实。

---

## 二、核心判据（已定案，单一真理）

**一个技属哪套、哪局，只看它的 `baseEffect`**（不看 condition、不看典故）：

| 战斗效果 baseEffect | 六套 | 三局 |
|------|------|------|
| 加己攻 ally_power_mult / first_sortie / ally_add_opening | 攻战·机 | **优势** |
| 减敌兵 enemy_sub_troops / dual_sub | 胜战·全 | **优势** |
| 更随机 luck_variance_self/enemy / luck_lock | 敌战·衡 | **均势** |
| 克夺反 steal/negate/reflect/nullify/partial/terrain | 混战·乱 | **均势** |
| 减己损 win_casualty_reduction / elite_casualty / post_recovery | 并战·借 | **劣势** |
| 败不垒 lose_enemy_casualty / recompute / lose_zero / add_comeback | 败战·险 | **劣势** |

- **武将**：贴 1 个"势"(造势/借势/逆势) + 全局 1 张 3×3 适性系数表(势×局，二期用)。
- **一将一技释放不变**：每场只放 1 个技，开局按局势从 3 技里选 1 个。

## 四、引擎集成（已就位，**但未激活**）

- `GeneralProfile` 加 3 个可选字段：`advantageSkillId` / `balanceSkillId` / `disadvantageSkillId`（优/均/劣局技）。
- 新函数 `resolveSituationalSkillId(unit, situation)`：按局返回武将对应局技；**未配则返回 null**。
- `BattleField` 开局 `pickPredictedSides()` 后调 `assignSituationalSkills()`：判每个带将单位的局(兵力比<1.3均势/否则强方优势弱方劣势)→写入 `battleOverriddenSkillId`。
- `getActiveTacticalSkillId` **一行没改**——复用它现成的 `battleOverriddenSkillId` 覆盖钩子(原 counter 系用的)。counter 战斗中再覆盖，顺序不冲突。

> **关键：现在现役零影响。** 因为**还没有任何武将配 3 技**，`resolveSituationalSkillId` 全返回 null，所有武将仍走招牌单技，游戏行为和改动前**完全一样，不会崩**。引擎逻辑就位但处于"待激活"状态。
