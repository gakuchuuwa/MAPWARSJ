## 〇、体系速记

- **名将 = 1 战略技 + 1 战术技；普将 = 仅 1 战术技；无将 = 无技能。** 层级 **名将 > 普将 > 无将** 由技能数量自然拉开。
- **战术技 ①–⑩**：①–⑤ 开战即放（opening）；⑥–⑩ 己方兵力掉到 ≤80% 触发（comeback）。名将/普将通用。
- **战略技 S①–S⑧**：仅名将，条件生效（进攻/防守/地形），战力系倍数 ×1.5。
- **平衡目标**（模拟器实测，等兵力无其他加成）：
  - 同级对同级对称 → **50%**；
  - 每个战术技单发 ≈ **85%**（≈ ×1.2 效力），彼此平衡；
  - 战略技条件命中 → ×1.5 ≈ **100%**（名将在对口战场稳胜，符合"军团打据点少换跟随"的直播需求）。

**逆局触发**：`COMEBACK_TROOP_THRESHOLD = 0.80`（`GeneralSkillCombat.ts`）——己方兵力 ≤ 开战 80% 时触发；触发时**重算掷一次 luck**（每侧），使翻盘概率化、与开局技同档。

**① 与 ⑥ 的区别**（同为加兵，机制不同）：
- ①开局：以当前兵力为基数 +20%，**不封顶**（满编军团开战 troops==maxTroops，若封顶则 +20% 被吃掉 = 无效，故突破上限）。
- ⑥逆局：以 maxTroops 为基数 +20%，**封顶到 maxTroops**（恢复到接近满编，而非超编）。

## 三、系统技 / 全局加成（非武将技格）

| 项 | 常量（文件） | 值 | 说明 |
|:--|:--|:--:|:--|
| 有效战力随机 luck | `LUCK_MIN`~`LUCK_MAX`（GameConfig） | **0.8 ~ 1.2** | 开战每侧掷一次；援军编入再掷一次 |
| 精锐 tier 乘数 | `ELITE_TIER_MULT`（GameConfig） | T0 **1.5** / T1 **1.4** / T2 **1.3** / T3 **1.2** / T4 **1.1** | 与文化系数相乘 |

| 关隘守军（拒险而战） | `PASS_GARRISON_MULT`（GameConfig） | **1.2** | `type==='pass'` 守军；与文化系数相乘 |
| 远征军因粮于敌 | `EXPEDITION_FORAGE_SKILL`（GeneralSkills） | 补兵 **0.09** | 远征军系统技，独立于战略 S⑦ |
| 援军编入（合兵一处） | `REINFORCEMENT_JOIN_SKILL`（GeneralSkills） | luck **0.8 ~ 1.2** | `waveIndex≥1` 编入时掷定 |
| 逆局触发阈值 | `COMEBACK_TROOP_THRESHOLD`（GeneralSkillCombat） | **0.80** | 见 §一 |

### 文化区系数 `TIER_TABLE`（region → [野战, 守城]，GameConfig）

| 类型 | 区域 | 野战 | 守城 |
|:--|:--|:--:|:--:|
| 骑射（高攻） | STEPPE / TIBET / CENTRAL_ASIA | **1.2** | 0.8 |
| 机动（偏攻） | NORTHEAST / HEXI / NORTH | **1.1** | 0.9 |
| 中性 | CENTRAL / WESTERN | 1.0 | 1.0 |
| 善守（偏防） | JAPAN / KOREA / JIANGNAN | 0.9 | **1.1** |
| 高防 | LINGNAN / DIANQIAN / BASHU | 0.8 | **1.2** |

**相乘关系**：一侧有效战力 = Σ(单位兵力 × 文化系数 × 精锐/远征系数) × luck × 战术乘区 × 战略乘区。
例：岭南关隘守军 = 1.2（文化守城）× 1.2（关隘）= **1.44**（不叠成 1.2³）。

## 四、模拟器实测胜率（等兵力 10000，A 带技 vs B 裸）

> 工具：`scripts/skill-balance-sim.ts`。命令：`npm run sim:skill`；阈值扫描 `npx tsx scripts/skill-balance-sim.ts --sweep-comeback`。

| 效力（等效倍数） | A 胜率 |
|:--|:--:|
| ×1.00（裸 vs 裸，校验） | ≈ 50% |
| ×1.10 | ≈ 71% |
| ×1.20（① ② ③ ④ ⑤、T3、远征、文化偏区） | ≈ 85% |
| ×1.30（T2） | ≈ 94% |
| ×1.40（T1） | ≈ 98.5% |
| ×1.50（T0、战略技条件命中） | ≈ 100%（达 luck 上限比 1.2/0.8=1.5，几乎必胜） |

- **开局战术 ①–⑤**：均 ≈ 85%，彼此平衡；③ vs ④ 对撞 ≈ 50%。
- **逆局战术 ⑥–⑩**：等兵力时 ≈ 82–87%（与开局技同档）；带劣势时的翻盘力：
  - −5% 兵：裸 ≈ 38% → ⑥ ≈ 77% / ⑦⑧⑨⑩ ≈ 70%
  - −13% 兵：裸 ≈ 21% → ⑥ ≈ 52% / ⑦⑧⑨⑩ ≈ 44%

## 六、平衡变更记录

| 日期 | 变更 | 原因 |
|:--|:--|:--|
| 2026-07-03 | ①以逸待劳加兵**突破 maxTroops 上限** | 满编军团开战 troops==maxTroops，原封顶使 +20% 无效（=空技能）；修复后 ≈85%，与 ②③④⑤ 同档 |
