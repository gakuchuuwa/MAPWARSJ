# 武将技参数速查

> 旧 `tac_*` 参数表已退役。现行技能数量和参数持续变化，不在文档复制整张目录，避免与代码漂移。

## 现行单一真理

- 战术技定义与 `magnitude`：`src/data/TacticalSkillCatalog.ts`
- 战略技定义与 `magnitude`：`src/data/general-skills/catalogs.ts`
- 武将攻防六槽：`src/data/general-skills/profiles.ts`
- 三势系数：`src/combat/TacticalConstants.ts`
- 战术技执行：`src/combat/GeneralSkillCombat.ts`
- 战斗时长、胜负与战损：`src/combat/BattleField.ts`
- 文化、精锐、关隘等全局乘区：`src/config/GameConfig.ts`

## 装配口径

- 普将：攻方三槽 + 守方三槽
- 名将：攻方三槽 + 守方三槽 + 一个战略技
- 每场战斗按攻守侧和优/均/劣局势，从六槽中选一个战术技释放
- `aptitude` 与 `attackStyle` 均为武将标签，不计入技能数量
- `tacticalSkillId` 是招牌/回退索引，不计入六槽之外
