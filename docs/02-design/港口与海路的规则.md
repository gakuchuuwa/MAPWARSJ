# 港口与海路的规则（唯一口径）

> 🔴 **本文件是「港口认定、海路连接、码头摆放与验收标准」的唯一口径**（2026-11-14 主人定案「总之一律按真实历史来」）。

## 一、核心原则（历史第一 · 与城型解耦 · 唯一真源）

1. 🔴 **历史第一，不凑数**：是否是港口、连往何处、留几条线，一律以真实历史地理、航海史与史料记载为准。
2. **港口判定与城池大小解耦**：
   - 大城（`big_city`）、中城（`medium_city`）、小城（`small_city`）、险要（`pass`）、城寨（`stockade`）**五种城型均可成为港口，也均可是非港口**。
   - 不得因城池是「大中小城」且靠海就强行当港口，也不得因据点是「城寨 / 险要」就剥夺真实历史海港/水寨资格。
3. **唯一真源（Single Source of Truth）**：
   - 全部合法港口以 [cities_v2.ts](../../src/data/cities_v2.ts) 中 `CityDataV2.isPort: true` 为唯一真源（**必须写在 `type: '...',` 字段之后**，以兼容现有脚本正则解析）。
   - `VectorSeaRouteData.ts` 海路网端点集合、`SeaRouteEditor.ts` 编辑器选点与审查、[CityLifeAmbientLayer.ts](../../src/map/CityLifeAmbientLayer.ts) 码头/船坞贴图生成，**100% 绑定 `city.isPort === true`**。

## 二、港口准入与排除标准（三要素同时满足）

一座据点能否标为 `isPort: true`，必须同时满足以下三条：

### 1. 水体标准：只认通外洋真海
- **合法海域**：大洋及与外洋天然连通的真实海域、海湾与海峡（含地中海、黑海、亚速海、波罗的海、红海、波斯湾、濑户内海等）。
- **排除水域**：里海、咸海、死海、拉多加湖等**封闭内陆湖泊**，以及海船无法直达的**纯内河中上游据点**。

### 2. 距离标准：海岸 ≤ 25km（感潮河口大港特许 ≤ 80km）
- **常规海岸线**：据点坐标距开放真实海岸线 **≤ 25 km**。
- **感潮河口大港特许（≤ 80 km）**：必须同时满足——
  1. 历史上确有海船可乘潮直抵城下或外港联动；
  2. 史载设市舶司、海贸商馆、皇家船坞或远洋水师母港（如伦敦、番禺、冶城、汉堡、波尔多、南特、什切青、巴士拉、巨港等）。
- **排除对象**：距海过远，或海路接驳线必须大段横穿内陆掩膜的非海港城市（如佩拉、底比斯、佩特拉、诺夫哥罗德等）。

### 3. 史实功能标准
- **准入两类**：
  1. **海岛与单陆路刚需港**：海岛据点（`陆 = 0`）或只有 1 条陆路的滨海据点（`陆 = 1`），海路是其维持全图最小度数 ≥ 2 的生命线，按史实就近接入海网；
  2. **史实海港要地**：大陆沿岸虽已有 ≥ 2 条陆路，但历史上明确具备**海港商埠、市舶司、远洋中转补给站、水师水寨或控扼海峡水道的港口要塞**功能者（不论大中小城或城寨/险要，如比萨、丹吉尔、达米埃塔、苏伊士、阿奎莱亚、阿夫勒尔、圣瓦莱里、纳博讷、巴约讷、永嘉、长崎、澳门、澎湖、赤间关、尖竹汶、塔纳伊斯、海瑟比等）。
- **明确排除**：虽紧邻海岸线，但历史上纯属**陆道关城、内陆平原/山地城郭或纯农牧防戍**的据点（如山海关、宁远城、姬路城、浜松城、熊本、金泽、邓纳德、佩鲁西姆等），**不标 `isPort`、不连海路、不放码头贴图**。

## 三、海路连接规则

### 1. 端点合法性与双向一致
- `VectorSeaRouteData.ts` 每条海路的 `startConnection` 与 `endConnection` 必须均为 `cities_v2.ts` 中标有 `isPort: true` 的据点。
- 全库 `isPort: true` 集合与 `SEA_ROUTE_DATA` 海路端点集合必须 **100% 双向相等**：**0 条非港口连线、0 座未连线孤港**。

### 2. 按城型分级海路条数（硬上下限）

| 据点城型 (`type`) | 中文类别 | 允许海路数（双向连线总条数） | 连接分工与优先级 |
|---|---|---|---|
| `big_city` | 大城 | **6 – 9 条** | 核心海港枢纽，优先连接其他大城，辐射重要中城 |
| `medium_city` | 中城 | **3 – 6 条** | 区域中心港，优先连接中城并衔接区域大城 |
| `small_city` | 小城 | **2 – 6 条** | 常规沿岸港/岛港，优先连接同区小城及邻近大中港 |
| `pass` | 险要 | **2 – 6 条** | 海峡要塞/海防关隘（限真港），连接扼守水道的两岸/邻港 |
| `stockade` | 城寨 | **2 – 4 条** | 水寨/离岛/补给驿站，严格控度，避免城寨充当大枢纽 |

- 同一对港口之间最多只允许存在 **1 条**海路边（禁重边、禁自环）。
- 任意据点（含所有港口与非港口）全图总度数必须满足 **`陆 + 海 ≥ 2`**（不得因退港/删线制造 0 连或 1 连孤立据点）。

### 3. 严禁陆海重复
- 凡 `VectorRoadData.ts` 中已有直连陆路边的一对据点，**严禁再连直达海路**（全库陆海重复数必须为 **0**）。

### 4. 沿岸航行优先与史实跨洋商道保留
- **普通航线**：古代航海以沿岸航行为主，寻路核心按 `public/data/sea_routes_combined.geojson` 加 **`OPEN_SEA_PENALTY = 1.5`**（仅惩罚远洋干线 `marnet`，沿岸 `coastal` 与接驳 `stitch` 不罚），优先就近沿海岸连接；显示航程按实际折线公里数计算（`calculatePathLength`，不含选路惩罚）。
- **跨洋与史实特长线**：必须完整保留史有明载的跨洋商道与洲际大航海航线（马尼拉大帆船、哥伦布与西属宝藏船队、葡属巴西/佛得角/亚速尔/好望角印度航线、荷属大西洋线、西属南太平洋银船线、麦哲伦海峡线、海上丝绸之路与印度洋季风航线等），**禁止无史料支撑的跨洋乱连**。
- **知名商路链路保护**：必须保证 [TourRoutes.ts](../../src/player/TourRoutes.ts) 中的 `GLOBE_CHAIN`、`SAIL_CHAIN`、`TOUR_CHAIN` 全部 `sea` 跳段均为一跳直连海路（`seaMissing = 0`）。

### 5. 单连通与古代地理禁区（运河禁令）
- 全库所有港口须经真实开放海域构成 **1 个单连通分量**（现行规模：**270 座港口 / 481 条海路 / [270] 单连通**）。
- 🔴 **严禁画穿现代运河**（与游戏历史时代不符）：
  - **禁止穿行苏伊士运河**（1869 年通航）——地中海与红海之间无直接连线，须绕行非洲好望角联通；
  - **禁止穿行巴拿马运河**（1914 年通航）——加勒比海与东太平洋之间无直接连线，须经南美麦哲伦海峡联通。

### 6. 严禁假穿陆（贴水走线）
- 海路折线必须基于 `public/world/land-mask-ne10m.png` 精细海陆掩膜生成，避免「船开上陆地」。
- 跨 `±180°` 国际日期变更线的航线必须做经度连续展开接合（太平洋直通，不绕地球背面）。
- 若合并底图存在局部缺口或极窄海峡（如底图裁除运河后缺失顶点的**苏伊士湾北段**、博斯普鲁斯/麦哲伦海峡），必须人工或脚本沿**纯水路中心线**补足折线顶点，不得取直线横穿陆地沙漠。

## 四、行军海陆形态切换规则

- 海路在路网层显式标记 `isSea = true`，并传递至行军路径路点 `sea: true`。
- **登船与上岸只发生在港口据点**，整段航行期间军团/舰队保持海船形态不变；单条航线路径的陆/海形态切换次数必须 **≤ 2 次**（登船 + 上岸），且海路边不得被同对城的跨海陆路边抢走最短路。

## 五、战略地图码头与船坞贴图规则（`CityLifeAmbientLayer.ts`）

1. 🔴 **唯一准入条件**：只有 **`city.isPort === true`** 的港口据点才允许生成海边港口码头（`getOrCreateCityPortDock`）与近海渔港船坞建筑（`maritime_fishing` 的 `wantsDock`），全城型统一；未标 `isPort` 的非港海边城一律只保留近岸渔船或空白海岸，**不出任何码头/船坞建筑**。
2. **文化例外保留**：`city.buildingStyle === 'MONGOL'` 的游牧风格据点不出固定建筑码头。
3. **选址硬约束（仅限开放海边）**：
   - 码头位置必须紧邻开放深海（`isDeepEnoughSea` 判定连通外洋水域且非内河/内湖），岸线落点距城中心 **`coastPos <= 0.12°`**；
   - **每座港口最多 1 座码头/船坞**：若渔业组合已生成渔港船坞，则不再重复生成城市专属港口码头；
   - **美术样式**：按据点 `buildingStyle` 映射为对应 DE 文化的 `*_DOCK_AGE2`（`GREEK`、`THRACIAN` 含 `*_SHIPYARD_AGE2`）。

## 六、编辑器门禁与增/退港操作流程

### 1. 海路编辑器约束（[SeaRouteEditor.ts](../../src/sea/SeaRouteEditor.ts)）
- 点击据点连海路时，拦截 `!cityData.isPort` 的非港口据点并在编辑器状态栏提示原因。
- `🔍 海路审查` 面板全量检查三项：
  1. **非港口连线**（海路端点未标 `isPort: true`）；
  2. **陆海重复**（两城已有陆路）；
  3. **全部 `isPort: true` 港口的分级条数**（包含连线数为 `0` 的孤港）。

### 2. 增开或清退港口的标准 3 步流程
1. **史实与底线审查**：
   - 退港前先确认该城 `陆路度数 ≥ 2`（否则会变成单连/零连孤城），且未被 `TourRoutes.ts` 征用为 `sea` 跳点；
   - 开港前先核实「外洋真海＋海岸 ≤ 25km（感潮大港 ≤ 80km）＋史实港埠依据」。
2. **更新真源与海路**：
   - 在 `src/data/cities_v2.ts` 对应据点的 `type: '...',` **之后**增删 `isPort: true,`；
   - 在 `src/data/VectorSeaRouteData.ts` 增删对应航线，使用 `SeaGraph`（或纯水路中心线）生成水路折线，避开已有陆路并保证本港与所有邻港度数落在分级区间内。
3. **跑齐第七节全套验收**，通过后方算定稿。

## 八、已作废的旧口径（切勿再引用）

| 旧口径 | 为什么作废 |
|---|---|
| **所有港口一律连 9 条海路** | 小城/城寨与沿海区域港口密集互连会造成大量冗余与跨越陆地；已于 2026-11-14 改按城型分级（大 6–9 / 中 3–6 / 小·险要 2–6 / 城寨 2–4） |
| **每个港口一律只连 2–3 条海路**（2026-10-24 旧稿） | 无法区分伦敦/君士坦丁堡/亚历山大等世界级航运枢纽与普通哨所小寨，2026-11-14 已被分级表替代 |
| **港口「不存字段、由海路端点反向派生」** | 无法约束编辑器禁止给纯陆城拉海路，也无法发现 0 连线的遗漏真港；2026-11-14 起改为 `cities_v2.ts` 的 `isPort: true` 作唯一真源 |
| **只有大中小城放码头，城寨与险要一律不放**（2026-11-10 旧令） | 会导致 长崎/尖竹汶/圣瓦莱里/澳门/澎湖 等历史名港城寨没有码头，而 姬路/浜松/山海关 等临海非港却冒出码头；2026-11-14 起统一跟 `isPort: true` 走 |
| **红海—亚丁湾或里海独立成块（188/5 / 198 港）** | 亚丁已接入印度洋，现全库海路为外洋真海港口单连通（270 港 / 481 条），里海湖港已排除出外洋海路系统 |
