> # 🔴 铁律 · 兵种只认素材样貌，不认兵名
>
> 判断一个兵种能不能进某支军团，**只看 `public/SUCAI/` 里的素材长什么样**——甲胄形制、武器、马匹、旗号。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**全都不算数**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> 反面教材（都被主人当场抓过）：
> - 「契丹军团用女真铁浮屠精锐 = 乱炖」→ **错**。契丹有铁林军重甲骑兵，那副具装甲骑的样貌本来就对。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。那个素材的样貌和东北人本来就像。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**。胡斯军本来就用连枷 / 战锤。
>
> **没裁图看过素材，就不许下「不符合历史 / 跨国乱炖 / 时代不对」的结论。**
> 裁图工具：`scratch/tools_sprite_sheet.py`。判据优先级：**样貌 → 兵种类型 → 时代 → 名字**。

# 历史大乱斗 — 武将技现行口径

> 本文只描述现行体系。旧 `tac_*` 模板已经退役，不再作为设计、配将或审计依据。

## 一、技能分层

- **战术技**：发生在具体战斗中，数据唯一来源为 `src/data/TacticalSkillCatalog.ts` 的 `ts_*` 条目。
- **战略技**：作用于行军、补给、据点、防务等大地图规则；仅名将可配置一个。
- **系统加成**：文化、精锐、关隘、援军等，不属于武将技。

## 二、战术技装配

每名武将配置攻防六槽：

1. 攻·优势
2. 攻·均势
3. 攻·劣势
4. 守·优势
5. 守·均势
6. 守·劣势

开战后按武将所在攻守侧与双方兵力比选中一个槽；**每场战斗仍只释放一个战术技**。

局势阈值：

- 我方 / 敌方 `> 1.5`：优势
- 我方 / 敌方 `< 0.67`：劣势
- 其余：均势

`tacticalSkillId` 仅为招牌/回退兼容索引，不是额外技能槽。旧
`advantageSkillId` / `balanceSkillId` / `disadvantageSkillId` 仅供尚未迁完的数据回退。

## 三、六种与三类

战术技按 `baseEffect` 归入六种：

- 攻战：加己攻
- 胜战：减敌兵
- 敌战：改变随机
- 混战：克制、夺取、反制
- 并战：减少己方战损
- 败战：败方反咬或翻盘

六种再归入三类：

- 攻战、胜战 → 优势技
- 敌战、混战 → 均势技
- 并战、败战 → 劣势技

劣势触发条件可覆盖上述常规归类。详细判据见
`docs/02-design/武将技-分类逻辑说明.md`。

## 四、武将标签

- `aptitude`：造势 / 借势 / 逆势，决定势×局战力系数；不是技能。
- `attackStyle`：善攻 / 善防 / 双行标签；不是技能。
- `tier`：名将 / 普将。名将可额外配置一个战略技。
