> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>
> 另一条同级铁律：**别人（主人 / 其他 AI）已经做好的编制，不许擅自改。**
> 只有改动前就是红的（格位不符阵型 / 兵种不存在 / 象攻城违规 / 战力离群）才准动，其余一律先问。

# 历史大乱斗 — 武将技现行口径

> 本文只描述现行体系。旧 `tac_*` 模板已经退役，不再作为设计、配将或审计依据。

## 一、技能分层

- **战术技**：发生在具体战斗中，数据唯一来源为 `src/data/TacticalSkillCatalog.ts` 的 `ts_*` 条目。
- **战略技**：作用于行军、补给、据点、防务等大地图规则；仅名将可配置一个。
- **系统加成**：文化、精锐、关隘、援军等，不属于武将技。

## 二、战术技装配

每名武将配置攻防六槽：

1. 攻·优势
2. 攻·均势
3. 攻·劣势
4. 守·优势
5. 守·均势
6. 守·劣势

开战后按武将所在攻守侧与双方兵力比选中一个槽；**每场战斗仍只释放一个战术技**。

局势阈值：

- 我方 / 敌方 `> 1.5`：优势
- 我方 / 敌方 `< 0.67`：劣势
- 其余：均势

`tacticalSkillId` 仅为招牌/回退兼容索引，不是额外技能槽。旧
`advantageSkillId` / `balanceSkillId` / `disadvantageSkillId` 仅供尚未迁完的数据回退。

## 三、六种与三类

战术技按 `baseEffect` 归入六种：

- 攻战：加己攻
- 胜战：减敌兵
- 敌战：改变随机
- 混战：克制、夺取、反制
- 并战：减少己方战损
- 败战：败方反咬或翻盘

六种再归入三类：

- 攻战、胜战 → 优势技
- 敌战、混战 → 均势技
- 并战、败战 → 劣势技

劣势触发条件可覆盖上述常规归类。详细判据见
`docs/02-design/武将技-分类逻辑说明.md`。

## 四、武将标签

- `aptitude`：造势 / 借势 / 逆势，决定势×局战力系数；不是技能。
- `attackStyle`：善攻 / 善防 / 双行标签；不是技能。
- `tier`：名将 / 普将。名将可额外配置一个战略技。
