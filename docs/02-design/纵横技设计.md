> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>
> 另一条同级铁律：**别人（主人 / 其他 AI）已经做好的编制，不许擅自改。**
> 只有改动前就是红的（格位不符阵型 / 兵种不存在 / 象攻城违规 / 战力离群）才准动，其余一律先问。
> 自动闸门：`npm run legion:no-unjustified-edits`（已挂 PostToolUse 钩子，改完自动拦）。

## 一、涉及的现有游戏机制

### 1.1 据点将/精挂载

- `CitySpawnTierState.spawnGeneralUsed: boolean` — 该据点武将已出场过，不再刷
- `CitySpawnTierState.spawnEliteUsed: boolean` — 该据点精锐已出场过，不再刷
- 位置：`src/legion/LegionSpawnTier.ts:14-17`

### 1.2 征兵出军团

- `RecruitmentSystem.trySpawnLegions()` — 每季最多出 1 支军团
- `cityHasActiveLegion(cityId)` — 一据点一军（`src/ai/RecruitmentSystem.ts:341-366`）
- `LegionManager.createArmy()` — 创建军团、扣除城防兵（`src/legion/LegionManager.ts:811-869`）
- `attachFactionGeneralToArmy(army)` — 挂据点锚定武将（`src/legion/LegionSpawnTier.ts:77-86`）
- `makeArmyElite(army, eliteName, withGeneral)` — 升精锐+挂将（`src/legion/LegionSpawnTier.ts:89-104`）
- `markSpawnTierConsumed(state, {general, elite})` — 标记将/精已消耗（`src/legion/LegionSpawnTier.ts:58-64`）

### 1.3 战败再现

- `lockGeneralAfterDefeat(cityId)` / `lockEliteAfterDefeat(cityId)` — 战败后锁 N 季（`src/legion/DefeatCooldown.ts:17-23`）
- `tickAndApplyDefeatCooldowns(cities)` — 每季递减并 override `spawnXxxUsed=true`（`src/legion/DefeatCooldown.ts:34-58`）
- `clearCooldownsForCity(cityId)` — 占城换旗号时重置冷却（`src/legion/DefeatCooldown.ts:61-64`）
- 冷却季数：`DEFEAT_COOLDOWN_SEASONS = 1`（约 15–30 游戏秒）
- 战败 → lock → 冷却期间 `spawnUsed=true` → 冷却结束 → `spawnUsed` 恢复 false → 可再出场

### 1.4 城防留兵

- 征兵时 `city.troops -= newLegion.getTroops()`（扣城防兵，`RecruitmentSystem.ts:329`）
- 战后城防重置为 1000（`SiegeManager.ts:844`）
- 城防与守城将是两套系统：城防 = city.troops（兵力数字），守将 = 战斗中的 generalId

### 1.5 AI 目标选择

- `TargetEvaluator.pickTarget(factionId, anchorCityId, cities)` — 基于推进锚点选近敌城（`src/ai/TargetEvaluator.ts:48-55`）
- 路网可达敌城按方向池均匀随机抽签

## 二、纵横三技设计

### 2.1 釜底抽薪（最简单，先做）

> 攻城前，让被攻击据点变为无将+无精。

**实现**：
```typescript
// SiegeManager.ts，先声夺人之后、startRegionalBattle 之前
if (generalHasStrategicEffect(army, '釜底抽薪')) {
    // 消耗据点的将/精出场配额（等同一场败战，走冷却恢复）
    const tierState = this.cityManager.getCitySpawnTierState(targetCity.id);
    if (tierState) {
        tierState.spawnGeneralUsed = true;
        tierState.spawnEliteUsed = true;
    }
}
```

**效果**：
- 城还在，兵还在，但本场战斗守城方=无将无精
- 战后将/精走冷却 → DEFEAT_COOLDOWN_SEASONS 季后恢复
- 零新代码，改两个布尔值

### 2.2 调虎离山（二期）

> 攻城前，守城将+精立刻组军团出征。

**实现思路**：
1. 取 `getCityAnchoredGeneral(targetCity.id)` 得将
2. 取 `getLegionEliteLegionName(targetCity.id)` 得番号
3. `LegionManager.createArmy()` 新城防兵力组建军团
4. `attachFactionGeneralToArmy(army)` + `makeArmyElite()` 挂将挂精
5. `markSpawnTierConsumed(state, {general:true, elite:true})`
6. `TargetEvaluator.pickTarget()` 选目标
7. `LegionManager.moveLegionToCity(army, targetId)` 行军

**需厘清**：远征系统交互、战后是否回城、出兵兵力比例。

### 2.3 坐收渔翁（三期，待基础验证后）

> 找附近据点，让它出兵先打目标城。

**核心难点**：跨势力借兵。需要全新子系统。
