## 一、目标与边界

- **目标**：战术模式的战场地图与 DE 一致（山川、地貌、植被、细节），大形状用战斗地点的真实地理，看上去是战略地图的放大版。
- **边界**：玩法不复刻 DE；一场 10 队、每队 6×6、打完为止不变；只做陆地战场（纯陆地、河流、沿海、湖泊），不做海战；战略模式外观不许变。
- **硬约束**：旧 13 战术模式已存档（git 标签 `定档-20261009-13战术模式`），新模式验证通过之前旧 13 始终保留、可一键退回。

## 五、M3 实施要点（开工前由 CC 细化成任务书）

- **复用**既有的“战术战场真实地理试验”（`src/ui/Scene13WarLayer.ts` 的开关 `mapwar.realGeography`、`src/ui/scene13/Scene13RealGeography.ts`），**只保留这一个开关**，默认关。
- **数据管线**（DD）：把 `tools/rms/` 的骨架采样、主题选择、引擎生成搬成游戏可用的模块，生成放后台线程，同一地点同一种子可缓存；高程级别由战术侧单独传，**不动全局 `DEM_ZOOM`**。
- **地面层**（AA）：WebGL 地面层画在士兵下面；士兵、特效、界面仍用 Canvas 2D。
- **退回**：瓦片缺失、生成超时、WebGL 出错 → 自动退回旧 13 地面，控制台记原因。
- **动手规矩**：每次改 `src/` 前先交改动清单（文件:行 + 为什么），CC 审过才改；改完逐行 diff。
- **验收**：开关关时与改前逐像素一致；开关开时维也纳、武汉各一场战斗显示新地图、士兵照常打；帧率不低于旧 13；`npx tsc --noEmit` 零错误。
- **画面验收只由主人判（2026-10-10 主人令）**：新地面的美术由 AA 主导；每次交同一场战斗新旧并排图给主人，主人点头才算过；CC 只检查技术面，不宣布“画面通过”。首版新地面（岸线锯齿、草地单色、死板蓝水）主人已否决，AA 重做中。

## 六、质量门禁（每轮都要过）

1. 引擎回归：`node tools/rms/parseAll.mjs 3` → 180/180；`node tools/rms/genMap.mjs Arabia.rms 2 144` → 物件 5961（自然 3450）／森林 9.5%／有高度 14.0%；改引擎时 `scratch/_digest_all.mjs` 180 脚本与基线逐字节一致。
2. **改了哪条路径，就要另跑一条走到这条路径的用例**，给出“跑过”的证据（回归全绿 ≠ 功能生效）。
3. 改 `src/` 后：`npx tsc --noEmit` 零错误；战略地图外观不变（按方案里的比对办法）。
4. 不运行 `npm run build`；不执行 `git checkout/reset`；测试服务用完就停。
5. 回报写进 `docs/02-design/RMS给CC的审阅单.md`：改了什么（文件:行）、依据、实测数字、截图、未做项；做不到写“未做/未查清”，不许写成已完成。
