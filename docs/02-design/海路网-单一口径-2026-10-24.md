## 一、口径

1. **每个港口只连 2–3 个其他港口**（主人定）。普通线按「海路真实航程」就近取，即沿岸航行，不再出现 5–8 条的枢纽。
2. **特长线只留史有明载的**，见第三节；没有史料支撑的长线（智利内陆图卡佩尔通巴西等）一律删。
3. **没有史实海路的城不当港口**；**史实是海港/河海港却没海路的，补开港**（见第五节）。退港/补港都不删据点。
4. **全库不许出现「船开在陆地上」的假线**：每条折线按 `sea_route_core` 重算，穿陆超限的候选弃用。
5. **连通按海区分块**：
   - **大西洋—地中海—黑海—波罗的海—美洲两岸 与 印度洋—太平洋**：经**麦哲伦海峡线（圣胡安港—利马，1520）**连成一块（188 港）；
   - 红海—亚丁湾：独立一块（城库无亚丁港，史实航线是泽拉—亚丁—印度，缺中间港）；
   - 里海：独立一块（湖）；
   - 巴拿马运河不画（1914 年才通）；**好望角段暂不画**，原因见第六节。

## 六、环球（2026-10-24 主人问「能环球吗」→ 已能闭环）

**结论：能。** 非洲沿岸补了 7 座史实港口（罗安达、开普敦、莫桑比克、基尔瓦、蒙巴萨、摩加迪沙、亚丁），把原来
「佛得角—果阿 19540km 直航」拆成沿岸接力段；红海—亚丁湾也经「亚丁—泽拉」并入印度洋。现在全图只剩里海一块独立。

实测两条互不共用好望角段的路径并存 ⇒ **闭环成立**：

- **西行**（好望角沿岸接力，24501km）：里斯本 → 里贝拉 → 罗安达 → 开普敦 → 莫桑比克 → 基尔瓦 → 蒙巴萨 → 摩加迪沙 → 亚丁 → 果阿
- **东行**（禁好望角链，62522km）：果阿 → 马杜赖 → 普里 → 阿努拉德 → 马六甲 → 阿瑜陀耶 → 淡马锡 → 巴达维亚 → 帕加鲁荣 → 卡拉桑 → 德尔纳特 → 霍洛 → 马尼拉 → 阿加尼亚 → 阿卡普尔科 → 利马 → 圣胡利安港 → 瓜纳巴拉 → 萨尔瓦多 → 里贝拉 → 里斯本
- **环球一圈 ≈ 87000km**

注意：新港之间没有陆路，每一段都只能走海，所以军团会真的沿岸南下；但若直接下「里斯本→果阿」的长指令，
寻路仍会挑更短的欧亚陆路（约 1.4 万公里）——环球要按港口分段航行（这也符合史实：达伽马是一站站沿岸走的）。

**「同文化 + 镇守将」核法**（2026-10-24 主人令「据点武将一定要和据点文化相同，要镇守武将」）：
- **文化**：据点 `buildingStyle` ＝ 武将 `GENERAL_CULTURE`，逐条对齐（文化链审计硬伤 0）。
- 🔴 **66 文化里非洲只有三支，没有「非洲」这个文化名**（2026-09-16 主人定 62 二级＋4 三级）：`BERBER` 柏柏尔（北非·卡斯巴土堡）、`AFRICA` 马里（西非·生土要塞）、`ETHIOPIANS` 埃塞俄比亚（东非·法西尔盖比石堡）。东非斯瓦希里三港原先误挂 `AFRICA`（＝马里·西非），2026-10-24 已改为 `ETHIOPIANS`（66 无斯瓦希里分支，note 标「代理，非精确」）。
- **镇守**：每位武将都是该城的**守将/城主/苏丹/总督**（镇守、居住、守城防御战），不是出生地、不是路过、不是攻城者。
- **三座殖民城的口径**：莫桑比克（1507–1898 葡属东非首府）、罗安达（1576 葡建、葡属安哥拉首府）、开普敦（1652 荷建、荷属开普殖民地首府）——
  这几座在殖民者到来前**没有城**（罗安达 1576 年前只有姆本杜渔村、开普敦 1652 年前只有科伊科伊苇席营），城的建成层与守将都是葡/荷人，
  所以按「本地政权＝实际统治该城的政权」取 PORTUGUESE / GERMANIC，守将＝该城葡/荷镇守将。**这是与马尼拉（本地城在先，判 MALAY）不同的情形**。
