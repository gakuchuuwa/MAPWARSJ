## 三、分场卡

### 场 1｜1449 · 土木堡之战（野战）
- **片/段**：一 · 土木之变 / 段一 土木堡
- **① 入镜**：大同 → 彰国军城 → 宣府方向 → 土木堡。
- **势力/地点**：攻 瓦剌｜守 明（库里明系势力，做事件时查）。地点 土木堡（野战）。
- **② 人物**：攻 瓦剌太师**也先**（库里有）｜守 **明英宗朱祁镇**（库里没有）、宦官**王振**（库里没有）、英国公**张辅**（库里没有）。主将队：帝国/城堡时代草原英雄兵模（1449 年属城堡段，按 §二.5 看样貌选）；明军火铳可用。
- **③ 起因**：瓦剌以明朝削减马市赏赐为由，分道入寇；王振怂恿英宗亲征（史实）。
- **④ 经过**：明军至大同，闻前军覆没，王振慌忙退兵，又为护自家田产绕道，行动迟缓（通行说法）；退至土木堡，距怀来城仅二十里，王振以辎重未到不肯入城（史实，数字不进文案）；土木堡地高无水，掘井二丈不得水（史实，数字不进文案）；也先佯退议和，明军移营就水，阵乱，瓦剌骑兵四面冲杀（史实）。
- **⑤ 结局**：明军溃败，英国公张辅等五十余名大臣战死，王振被护卫将军樊忠以铁锤击杀，明英宗被俘（史实，数字不进文案）。不易主。
- **⑥ 出镜**：挟英宗叩关要挟，南下北京。
- **⑦ 出处**：英文维基 *Tumu Crisis*。
- **文案三件**：
  - **briefing**：公元一四四九年秋，瓦剌太师也先率军南下，明英宗在宦官王振的怂恿下御驾亲征。明军走到大同又仓皇退兵，一路拖拖拉拉，在土木堡停了下来，据说那里连一口能打出水的井都没有。
  - **inviteText**：「兄弟们，明朝的皇帝就在那座土堡里，他们渴了好几天了。先假装议和，等他们去找水，再冲上去。」
  - **description**：瓦剌军佯装后退议和，明军急着移营取水，队伍刚一动就乱成一团。也先的骑兵四面杀来，明军全线崩溃，大批文武大臣战死，王振被自家将领一锤打死，明英宗成了瓦剌的俘虏。

### 场 2｜1449 · 北京保卫战（攻城，剧终）
- **片/段**：一 / 段二 北京
- **① 入镜**：居庸关 → 大同 → 紫荆关 → 北京。
- **势力/地点**：攻 瓦剌｜守 明。据点 **北京** `city_beijing`（战后不易主）。
- **② 人物**：攻 **也先**（挟明英宗）｜守 兵部尚书**于谦**（库里有 `yi_yuqian`）、**石亨**（库里没有）；郕王朱祁钰即位为景泰帝（史实）。
- **③ 起因**：土木之变后，朝中有人主张南迁，于谦力主坚守（史实）。
- **④ 经过**：于谦列阵九门之外，亲自督战德胜门，下令临阵将不顾军先退者斩其将、军不顾将先退者后队斩前队（史实，数字不进文案）；德胜门外设伏，以火器大败瓦剌军，也先之弟孛罗卯那孩战死（史实）。
- **⑤ 结局**：也先攻城五日不下，闻明勤王援军将至，挟英宗北撤（史实，数字不进文案）。**不易主**。
- **⑥ 出镜**：剧终。1450 年也先无条件送还英宗（B 档）；1453 年也先自立为大元天圣大可汗，1454 年被部下所杀（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Tumu Crisis*；*Defense of Beijing*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一四四九年冬，也先挟持着被俘的明英宗，一路打到了北京城下。他满以为明朝群龙无首，城门很快就会打开。可城里的兵部尚书于谦，已经拥立了新的皇帝。
  - **inviteText**：「兄弟们，明朝的皇帝在我们手里，北京的城门迟早要开。攻德胜门，让于谦出来跟他的旧主说话。」
  - **description**：瓦剌军猛攻德胜门，于谦早已在城外设下伏兵，火铳火炮齐发，瓦剌军大败，也先的弟弟也战死了。一连几天攻不下城池，又听说明朝的援军快到了，也先只得带着明英宗北撤。
