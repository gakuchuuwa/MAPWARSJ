## 三、分场卡

### 场 1｜前99 · 浚稽山之战（野战，主角守，剧终）
- **片/段**：一 · 浚稽山 / 段一
- **① 入镜**：遮虏障 → 浚稽山。
- **势力/地点**：攻 匈奴（库里匈奴系势力，做事件时查）｜守 西汉。地点 浚稽山（野战）。
- **② 人物**：攻 匈奴**且鞮侯单于**（库里没有）｜守 骑都尉**李陵**（库里有）、校尉**韩延年**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：汉武帝派李广利击匈奴，李陵请以步卒五千独当一面，北出居延（史实，数字不进文案）。
- **④ 经过**：李陵军至浚稽山，被单于三万骑包围；李陵以大车为营，前列持戟盾、后列弓弩，千弩俱发，匈奴应弦而倒（史实，数字不进文案）；单于又召八万骑来攻，李陵且战且退，转战八日（史实，数字不进文案）；箭尽粮绝，军候管敢降匈奴、泄露汉军无援（史实）。
- **⑤ 结局**：李陵在距汉塞百余里处被围，韩延年战死，李陵投降（史实，数字不进文案）。不易主。
- **⑥ 出镜**：剧终。汉武帝误信李陵为匈奴练兵，族灭其家；司马迁为之辩护而受宫刑（史实）；李陵留匈奴二十余年，前74 年卒（史实，数字不进文案；B 档尾声）。
- **⑦ 出处**：英文维基 *Li Ling (Han dynasty)*（浚稽山之战独立条目待核）；《汉书·李陵传》。
- **文案三件**：
  - **briefing**：公元前九九年秋，李广之孙李陵主动请缨，只带着一支步兵从居延北出，深入匈奴腹地。在浚稽山下，匈奴单于的骑兵从四面八方围了上来，据说漫山遍野都是。
  - **inviteText**：「诸位，我们是步兵，跑不过他们的马。把大车围成营垒，前排举盾，后排放弩，一步也不许乱。」
  - **description**：汉军以大车结营，弩箭齐发，匈奴骑兵成排倒下。单于又调来更多的骑兵，李陵且战且退，一连苦战了好些天，箭射完了，粮也吃光了。一名军官叛逃泄露了汉军无援的消息，李陵在离汉塞不远的地方被团团围住，最终力竭投降。
