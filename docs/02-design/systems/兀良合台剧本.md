## 三、分场卡

### 场 1｜1254 · 押赤（攻城）
- **片/段**：一 · 平大理 / 段一
- **① 入镜**：羊苴咩 → 滇池。
- **势力/地点**：攻 蒙古｜守 大理（库里 `dali`）。据点 **滇池** `city_tuodongcheng`（战后 `cityUpdates` 归 `menggu_d`）。
- **② 人物**：攻 **兀良合台**（阿术随军）｜守 大理末代国王**段兴智**（库里没有）。主将队：城堡时代草原英雄兵模（按 §二.5 看样貌）；对手城堡时代西南系英雄兵模（按年代与样貌选）。
- **③ 起因**：大理城破后，段兴智逃往东方重镇押赤城（鄯阐）。
- **④ 经过**：押赤城三面临滇池，兀良合台架砲轰城，阿术率先登城（《元史》，通行说法）。
- **⑤ 结局**：**滇池归蒙古**（史实），段兴智被俘，后受封大理总管、领兵助蒙古平定云南各部。
- **⑥ 出镜**：南下安南。
- **⑦ 出处**：英文维基 *Uriyangkhadai*；*Mongol conquest of the Dali Kingdom*。
- **文案三件**：
  - **briefing**：公元一二五四年，大理国都陷落之后，国王段兴智逃到了滇池边的押赤城。兀良合台领着蒙古军一路追来，他的儿子阿术也在军中。
  - **inviteText**：「朋友，大理王以为湖水能护住他。我们把砲架在岸上，让阿术先上城头。」
  - **description**：押赤城三面环水，蒙古军在岸边架起砲石轰击，阿术率先登上城头。段兴智被俘，后来反倒领着自己的旧部，替蒙古人去平定云南各地。

### 场 2｜1258 春 · 平厉源之战（野战）
- **片/段**：二 · 征安南 / 段二 红河
- **① 入镜**：滇池 → 通海城 → 沿红河而下 → 平厉源。
- **势力/地点**：攻 蒙古｜守 陈朝大越（库里有陈朝系势力，做事件时查）。地点 平厉源（野战）。战后昇龙一度被占，但蒙古军旋即撤出——按历史 `cityUpdates` 不写永久易主（见疑点 2）。
- **② 人物**：攻 **兀良合台**｜守 陈朝**陈太宗**（陈日煚）、**黎辅陈**（库里没有）。
- **③ 起因**：蒙古遣使要安南借道攻宋，安南扣押使者（史实）。
- **④ 经过**：陈太宗亲率象兵在红河北岸列阵迎战；蒙古军用弓箭射象，战象受惊回奔，冲乱了陈军（通行说法）。
- **⑤ 结局**：陈军败退，放弃都城昇龙（史实）；蒙古军入城后因水土不服、粮尽，不久撤回云南（史实）。
- **⑥ 出镜**：撤回云南，北上。
- **⑦ 出处**：英文维基 *First Mongol invasion of Vietnam*（平厉源独立条目待核）；越南语维基未查。
- **文案三件**：
  - **briefing**：公元一二五八年正月，兀良合台顺着红河南下，陈朝国王陈太宗亲自带着象兵在河岸列阵。据说那些战象身披皮甲，是陈军最倚重的力量。
  - **inviteText**：「朋友，他们的大象很吓人，可大象也会怕。箭射在它们脸上，它们就会掉头。」
  - **description**：蒙古弓手集中射击战象，受惊的大象掉头冲进本阵，陈军阵脚大乱。陈太宗弃城撤走，蒙古军进了昇龙城，却因水土不服、粮草不继，没多久便退回了云南。

### 场 3｜1259 冬 · 潭州（攻城，剧终）
- **片/段**：三 · 北上会师 / 段三 湖南
- **① 入镜**：昇龙 → 撤回云南 → 广西 → 长沙。
- **势力/地点**：攻 蒙古｜守 南宋。据点 **长沙** `city_changsha`（潭州；战后不易主）。
- **② 人物**：攻 **兀良合台**、阿术｜守 南宋潭州守将**向士璧**（库里没有）。
- **③ 起因**：蒙哥三路伐宋，兀良合台奉命自云南北上，与忽必烈会师于鄂州。
- **④ 经过**：蒙古军穿越广西，围潭州，城中军民坚守（史实）。
- **⑤ 结局**：蒙哥死讯传来，忽必烈与宋议和，派兵接应；兀良合台撤围北渡长江，与忽必烈会合（史实）。**不易主**。
- **⑥ 出镜**：剧终。北返后参与平定阿里不哥（B 档），1272 年卒。
- **⑦ 出处**：英文维基 *Uriyangkhadai*；《元史》。
- **文案三件**：
  - **briefing**：公元一二五九年冬，兀良合台从云南出发，穿过广西的崇山峻岭，一路打到了潭州城下。他要去长江边与忽必烈会师，可潭州挡住了他的路。
  - **inviteText**：「朋友，我们从大理一路走到这里，脚底都磨破了。忽必烈在江北等我们，潭州只是路上的一道门槛。」
  - **description**：潭州军民顽强守城，蒙古军久攻不下。这时蒙哥汗的死讯传来，忽必烈派兵接应，兀良合台撤围北渡长江，与忽必烈会合北归。
