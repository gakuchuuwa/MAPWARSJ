## 三、分场卡

**1｜756 · 嘉山之战**　①晋阳 → 井陉 → 常山 → 嘉山。②攻 郭子仪、**李光弼**（库里有）｜守 安禄山大将**史思明**（库里没有）。主将队：待看素材定。③安禄山叛乱，李光弼东出井陉收复常山。④唐军在嘉山大破史思明，斩首四万（通行说法），史思明坠马、光着脚逃走（史实）。⑤河北十余郡响应唐朝（史实）。**真定归唐**。⑥潼关失守，唐玄宗入蜀，李光弼退守太原（B 档）。⑦英文维基 *Li Guangbi*；*An Lushan Rebellion*。

**2｜757 · 太原保卫战（主角守城）**　①→ 井陉 → 太原。②攻 **史思明**、蔡希德等（号称十万）｜守 **李光弼**（不满一万）。③叛军想夺太原、再取河陇。④李光弼挖壕沟、造数十万块土坯修补城墙；在城下挖地道，敌军走过就陷下去；用大型抛石车一次击杀敌军数十人；又假装约降，挖空敌营地下，约降当日敌营塌陷（史实）。⑤坚守五十余日，击退叛军（史实）。⑥⑦同上。

**3｜759–760 · 河阳保卫战（剧终，主角守）**　①太原 → 洛阳 → 河阳。②攻 **史思明**｜守 **李光弼**。③九节度相州溃败后，李光弼接任天下兵马副元帅，放弃洛阳、据守河阳三城牵制叛军。④史思明用数百匹战马在河边炫耀，李光弼把军中母马牵到河边、把小马驹拴在城里，母马嘶鸣，叛军的马全部游过河来（史实）；又用长竿顶住火船、用叉竿钩住巨船，击退水攻（通行说法）。⑤叛军久攻不下（史实）。⑥剧终：761 年邙山之战失利，764 年卒（B 档）。⑦同上。
