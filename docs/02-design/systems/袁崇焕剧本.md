## 三、分场卡

### 场 1｜1626 · 宁远之战（攻城，主角守）
- 同 [`努尔哈赤剧本.md`](努尔哈赤剧本.md) 场 4（数据以那边为准）。
- **② 人物**：主将队按 §二.5 看样貌选帝国时代华夏英雄兵模；红夷大炮可用。
- **inviteText**（袁崇焕线专用）：「诸位，关外的兵都撤走了，只剩我们。我刺血写下这封书，宁远在，我在；宁远亡，我亡。」
- **description**（袁崇焕线专用）：袁崇焕坚壁清野，把城外的百姓和粮草都迁进城里，又在城头架起红夷大炮。后金军一次次攻到城下，都被炮火打退，努尔哈赤只得撤围而去。

### 场 2｜1627 · 宁锦之战（攻城，主角守）
- 同 [`皇太极剧本.md`](皇太极剧本.md) 场 1（数据以那边为准）。
- **inviteText**（袁崇焕线专用）：「诸位，新汗要替他父亲报仇了。满桂将军出城迎战，我在城头给你们开炮。」

### 场 3｜1629 · 广渠门之战（野战，主角守，剧终）
- **片/段**：二 · 京师 / 段三 广渠门
- **① 入镜**：宁远城 → 山海关 → 无终 → 北京 → 广渠门。
- **势力/地点**：攻 后金｜守 明。地点 北京广渠门外（野战）。
- **② 人物**：攻 **皇太极**（库里有）、**莽古尔泰**、**多尔衮**（库里有）｜守 督师**袁崇焕**、总兵**祖大寿**（库里没有）。
- **③ 起因**：皇太极避开宁锦防线，绕道蒙古从喜峰口破长城入塞，直逼北京，史称「己巳之变」（史实）。
- **④ 经过**：袁崇焕率关宁铁骑昼夜兼程赶到，在广渠门外列阵；后金军三面围攻，袁崇焕披甲亲战，两肋中箭如猬（史实，据说如此），关宁军死战击退后金（史实）。
- **⑤ 结局**：后金军退走（史实）。**不易主**。
- **⑥ 出镜**：剧终。崇祯帝中后金反间计（通行说法），又疑袁崇焕擅杀毛文龙、纵敌入塞，将其下狱；1630 年袁崇焕被凌迟处死于北京西市（史实，文案不渲染；B 档尾声）。
- **⑦ 出处**：英文维基 *Yuan Chonghuan*；*Jisi Incident*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一六二九年冬，皇太极绕开了宁锦防线，从蒙古草原破长城入塞，大军直逼北京。袁崇焕接到消息，据说带着关宁铁骑日夜兼程，连饭都顾不上吃。
  - **inviteText**：「诸位，敌人就在京城脚下，皇上在城里看着我们。今天，关宁铁骑一步也不许退。」
  - **description**：后金军从几面扑来，袁崇焕披甲上阵，身上中了好几箭仍在督战，关宁铁骑死战不退，终于把后金军打了回去。可京城里流言四起，崇祯皇帝疑心大起，不久就把这位守住京城的督师下了大狱。
