## 三、分场卡

### 场 1｜1381 · 白石江之战（野战）
- **片/段**：一 · 平云南 / 段一 曲靖
- **① 入镜**：金陵 → 武昌 → 长沙 → 胜境关 → 曲靖 → 白石江。
- **势力/地点**：攻 明｜守 元梁王（库里元系势力，做事件时查）。地点 白石江（野战），战后按历史 `cityUpdates` 写 **曲靖** 归明。
- **② 人物**：攻 征南将军**傅友德**（库里没有）、左副将军**蓝玉**（库里有）、右副将军**沐英**（库里有）｜守 元梁王部将**达里麻**（库里没有）。主将队：城堡时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：云南元梁王把匝剌瓦尔密拒不降明。
- **④ 经过**：大雾中明军突至白石江，达里麻隔江列阵；沐英献计：大军在正面佯作渡江，另遣奇兵从下游渡江，绕出元军阵后，张疑兵于山谷，鸣金鼓；元军惊乱，沐英率大军乘势渡江（史实）。
- **⑤ 结局**：元军大败，擒达里麻，俘两万余人（史实，数字不进文案）。**曲靖归明**。梁王闻讯自杀，昆明降（B 档）。
- **⑥ 出镜**：西取大理。
- **⑦ 出处**：《明史·沐英传》；英文维基 *Ming conquest of Yunnan*。
- **文案三件**：
  - **briefing**：公元一三八一年冬，明军翻山越岭进入云南，大雾之中突然出现在白石江边。元梁王的大将达里麻隔着江摆开了阵势，据说以为明军根本过不了这条江。
  - **inviteText**：「诸位，大军在正面做出渡江的样子，吸住他们的眼睛。我另派一支人马从下游悄悄过江，绕到他们背后去。」
  - **description**：明军在正面虚张声势，奇兵却从下游渡过江去，绕到元军阵后，在山谷里擂鼓鸣金。元军以为被包围了，阵脚大乱，沐英率大军乘势渡江猛攻，大破元军，生擒达里麻。

### 场 2｜1382 · 大理（攻城）
- **片/段**：一 / 段二 大理
- **① 入镜**：曲靖 → 滇池 → 羊苴咩。
- **势力/地点**：攻 明｜守 大理总管段氏（库里 `dali`）。据点 **羊苴咩** `city_dali_city`（大理；战后 `cityUpdates` 归明）。
- **② 人物**：攻 **沐英**、**蓝玉**｜守 大理总管**段世**（库里没有）。
- **③ 起因**：昆明降后，大理段氏据守下关、龙尾关不降。
- **④ 经过**：段氏据下关天险；沐英派王弼从洱水东趋上关，胡海洋夜绕点苍山后，立旗帜于山巅；沐英率大军抢渡，攻破下关（史实）。
- **⑤ 结局**：擒段世，**大理归明**（史实）。
- **⑥ 出镜**：留镇云南，屯田、兴学（B 档）。
- **⑦ 出处**：《明史·沐英传》；英文维基 *Ming conquest of Yunnan*。
- **文案三件**：
  - **briefing**：公元一三八二年春，昆明已经投降，大理的段氏却仍然据守着下关天险。下关背靠点苍山、面临洱海，据说只有一条窄路能过。
  - **inviteText**：「诸位，关口只有一条路，那就不走路。胡海洋翻过点苍山，在山顶插上我们的旗。」
  - **description**：夜里，明军一支人马翻越点苍山，天亮时山顶上插满了明军的旗帜。守关的段氏军队抬头一看，以为后路已断，军心大乱，沐英趁势率军抢渡，攻破下关，擒获段世，大理归明。

### 场 3｜1388 · 定边之战（野战，主角守，剧终）
- **片/段**：二 · 麓川 / 段三 定边
- **① 入镜**：羊苴咩 → 蒙舍城 → 定边。
- **势力/地点**：攻 麓川（思氏，库里没有）｜守 明。地点 定边（野战）。
- **② 人物**：攻 麓川宣慰使**思伦发**（库里没有）、象兵百余头（史实，数字不进文案）｜守 **沐英**。
- **③ 起因**：麓川思伦发反明，率众围定边。
- **④ 经过**：沐英选骁骑三万，昼夜兼程赶到定边；他将火铳、神机箭手分为三行，前行发射，若象不退，次行继之，再不退，三行继之（《明史》，史实——这是史料可见最早的火铳轮射战法之一）；麓川战象中箭中铳，返身奔溃（史实）。
- **⑤ 结局**：麓川大败，斩首三万余，擒象三十七（史实，数字不进文案）。不易主。
- **⑥ 出镜**：剧终。1392 年太子朱标死，沐英哀痛成疾，卒于云南，追封黔宁王，子孙世镇云南（史实，B 档尾声）。
- **⑦ 出处**：《明史·沐英传》；英文维基 *Mu Ying*（定边之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元一三八八年春，麓川的思伦发率领大军和成群的战象围攻定边。沐英挑选精锐骑兵，昼夜兼程赶去救援，据说麓川的大象披着皮甲，背上还驮着战楼。
  - **inviteText**：「诸位，大象不怕刀枪，可怕火和响声。火铳手分成几行，一行放完，下一行接上，不要停。」
  - **description**：明军的火铳手分行轮番射击，铳声不绝，火光一片，麓川的战象受惊掉头，反把自己的军阵踩得大乱。明军乘势冲杀，大破麓川军，擒获了大批战象。
