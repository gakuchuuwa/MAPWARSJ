## 三、分场卡

### 场 1｜1002 · 灵州（攻城）
- **片/段**：一 · 西取河西 / 段一 灵州
- **① 入镜**：靖边堡 → 统万城 → 回乐。
- **势力/地点**：攻 党项｜守 北宋（库里 `song`）。据点 **回乐** `city_lingzhou`（灵州；战后 `cityUpdates` 归 `xiazhou`）。
- **② 人物**：攻 **李继迁**（库里有）｜守 宋灵州知州**裴济**（库里没有）。主将队：封建时代党项/西北英雄兵模（1002 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：李继迁反宋多年，屡断宋灵州粮道，灵州孤悬塞外（史实）。
- **④ 经过**：李继迁率众围攻灵州，裴济刺指血写书求援，援军不至（史实）。
- **⑤ 结局**：灵州陷落，裴济战死（史实）。**灵州归党项**，李继迁改名西平府，自夏州迁都于此。
- **⑥ 出镜**：西攻河西吐蕃。
- **⑦ 出处**：英文维基 *Li Jiqian*；《宋史·夏国传》。
- **文案三件**：
  - **briefing**：公元一〇〇二年春，党项首领李继迁率军围住了宋朝的灵州。这座城孤零零地立在塞外，粮道早被截断，据说守城的裴济刺破手指，用血写信向朝廷求援。
  - **inviteText**：「兄弟们，灵州是西北的咽喉，拿下它，我们就有了自己的都城。宋朝的援兵不会来了。」
  - **description**：灵州的守军苦苦支撑，援兵却迟迟不到。党项军攻破城池，裴济战死。李继迁把灵州改名为西平府，从此在这里定都，党项人的国家有了雏形。

### 场 2｜1003–1004 · 西凉府（攻城，剧终）
- **片/段**：一 / 段二 西凉
- **① 入镜**：回乐 → 赤乌堡 → 姑臧。
- **势力/地点**：攻 党项｜守 吐蕃六谷部（库里吐蕃系势力，做事件时查）。据点 **姑臧** `city_wuwei`（西凉府；战后不易主）。
- **② 人物**：攻 **李继迁**｜守 六谷部首领**潘罗支**（库里没有）。
- **③ 起因**：李继迁西攻河西走廊，欲取西凉府。
- **④ 经过**：李继迁攻下西凉府，潘罗支诈降；李继迁受降时，潘罗支集结六谷部众突然袭击（史实）。
- **⑤ 结局**：李继迁中流矢重伤，退走灵州，不久伤重而死（史实）。按历史写 **姑臧归党项**（攻下之时），随后被六谷部夺回（见疑点 2）。
- **⑥ 出镜**：剧终。其子李德明继位，孙李元昊建立西夏（见 [`李元昊剧本.md`](李元昊剧本.md)）。
- **⑦ 出处**：英文维基 *Li Jiqian*；*Pan Luozhi*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一〇〇三年冬，李继迁挥师西进，攻下了河西重镇西凉府。吐蕃六谷部的首领潘罗支前来请降，据说他的部众正在城外悄悄集结。
  - **inviteText**：「兄弟们，潘罗支来投降了。河西的吐蕃人都归了我们，往西的路就通了。」
  - **description**：受降的时候，潘罗支的部众突然发难，四面杀来。李继迁身中流矢，拼死突围退回灵州，没过多久就伤重去世了，西凉府又落回了吐蕃人的手中。
