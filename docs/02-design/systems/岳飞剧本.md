## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜1130 夏 · 收复建康（攻城）**　①宜兴 → 牛头山 → 建康。②攻 **岳飞**（库里有）｜守 金将**完颜宗弼（金兀术）**部（库里没有）。主将队：待看素材定（城堡时代华夏英雄兵模以素材样貌为准）。③金兵南下渡江，宋高宗逃往海上；金兀术北撤时屯兵建康。④岳飞在牛头山设伏，夜里派百人穿黑衣混入金营扰乱；再在清水亭大破金兵，据说斩首一百七十五级（出自《金佗稡编》，据说如此）。⑤金兵弃建康北撤，**金陵（建康）归宋**（`city_nanjing` → `song`）。⑥驻防江南，后移驻鄂州。⑦英文维基 *Yue Fei* <https://en.wikipedia.org/wiki/Yue_Fei>（建康之战独立条目**待核**）。

**2｜1134 夏 · 收复襄阳（攻城）**　①金陵 → 武昌 → 郢州 → 襄阳。②攻 岳飞｜守 伪齐将**李成**（库里没有）。③伪齐刘豫与金联兵南下，占襄阳六郡，威胁长江中游。④岳飞先克郢州，再进逼襄阳；李成背靠汉水列阵，岳飞说「步兵利在险阻，骑兵利在平旷」，李成却把骑兵摆在江岸、步兵摆在平地，岳飞以长枪步兵攻其骑、以骑兵攻其步（出自《宋史》）。⑤李成弃城逃走，**襄阳归宋**（`city_xiangyang` → `song`）；随后收复随州等六郡，**汉东**（`city_suizhou`）归宋。⑥驻鄂州。⑦英文维基 *Yue Fei*（1134 收复襄阳独立条目**待核**）。

**3｜1140 秋 · 郾城之战（剧终）**　①襄阳 → 随州 → 鄂州 → 北伐 → 郾城。②攻 **金兀术**（号称十万，信息框现代估计二至三万）｜守 **岳飞**（信息框 8000–15000）。③金毁约南侵，岳飞奉命北伐，连克中原诸城，驻郾城。④金兀术以精锐骑兵「拐子马」「铁浮屠」来攻；岳飞令步兵手持麻扎刀、大斧，专砍马腿，岳云率骑兵冲阵，从午后战至黄昏。⑤金兵大败（史实）；岳家军随后又胜于颍昌，推进至朱仙镇（B 档）。⑥剧终：宋高宗、秦桧一日十二道金牌召回，1142 年岳飞被以「莫须有」罪名杀害（B 档尾声）。⑦*Battle of Yancheng* <https://en.wikipedia.org/wiki/Battle_of_Yancheng>。
