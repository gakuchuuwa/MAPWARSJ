## 三、分场卡

### 场 1｜1355 · 采石之战（野战·渡江登岸）
- **片/段**：一 · 渡江 / 段一 采石
- **① 入镜**：濡须口（和州）→ 牛渚 → 采石。
- **势力/地点**：攻 朱元璋（库里明系势力）｜守 元（库里元系势力）。地点 采石矶（野战），战后按历史 `cityUpdates` 写 **姑孰**（太平路）归朱元璋（随即攻克太平；史实）。
- **② 人物**：攻 **朱元璋**（库里有）、先锋**常遇春**（库里有）｜守 元军采石守将（史书未载名）。主将队：城堡时代华夏英雄兵模（1355 年属城堡段，按 §二.5 看样貌选）；火铳类兵种可用。
- **③ 起因**：朱元璋据和州粮尽，决意渡江取太平。
- **④ 经过**：元军列阵矶上，船距岸三丈许不能靠近；常遇春驾小舟冲来，朱元璋麾之前进，常遇春应声挺戈跃上岸，元军披靡，诸军随之登岸（史实，数字不进文案）。
- **⑤ 结局**：采石攻克，随即取太平（史实）。**姑孰归朱元璋**。
- **⑥ 出镜**：进取集庆（B 档）。
- **⑦ 出处**：《明史·常遇春传》；英文维基 *Chang Yuchun*（采石之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元一三五五年夏，朱元璋在和州缺粮，决定渡江南下。元军在采石矶上列好了阵，船还离岸很远就靠不上去。一个刚刚投军不久的年轻人常遇春，驾着小船冲到了最前面。
  - **inviteText**：「主公，岸上的元兵并不多，只是站得高。我先跳上去，大家跟着我。」
  - **description**：常遇春的小船刚一靠近，他便手持长戈纵身跃上了岸，砍倒了面前的元兵。元军阵脚大乱，后面的船纷纷靠岸，将士们一拥而上，采石矶就这样被攻了下来，太平城随即也落入朱元璋手中。

### 场 2｜1363 · 鄱阳湖之战（野战·水战）
- 同 [`朱元璋剧本.md`](朱元璋剧本.md) 场 3（数据以那边为准）。
- **② 人物补**：陈友谅骁将张定边直冲朱元璋座舟，常遇春一箭射中张定边，救出朱元璋（《明史》，史实）。
- **inviteText**（常遇春线专用）：「主公的船被围住了！弓来——我射那个领头的。」
- **description**（常遇春线专用）：陈军骁将张定边驾船直冲朱元璋的座舟，眼看就要得手。常遇春从旁边张弓一箭，正中张定边，陈军的攻势顿时一挫，朱元璋脱离了险境。

### 场 3｜1368 · 太原（攻城）
- 同 [`徐达剧本.md`](徐达剧本.md) 场 3（数据以那边为准）。
- **④ 经过（常遇春视角）**：扩廓帖木儿回援太原，常遇春说我骑兵虽集、步卒未至，骤与战必多杀伤，不如夜袭；遂以精骑夜劫扩廓营，扩廓仓促以十八骑北走（史实，数字不进文案）。
- **inviteText**（常遇春线专用）：「徐将军，扩廓的营寨扎得很松，步兵还没到，骑兵先去劫营。今夜就让他睡不成觉。」

### 场 4｜1369 · 上都（攻城，剧终）
- **片/段**：三 · 北伐 / 段四 上都
- **① 入镜**：晋阳 → 大同 → 上都。
- **势力/地点**：攻 明｜守 北元。据点 **上都** `city_shangdu`（开平；战后 `cityUpdates` 归明）。
- **② 人物**：攻 副将军**常遇春**、**李文忠**（库里没有）｜守 北元**元顺帝**（已北走应昌，库里没有）。
- **③ 起因**：徐达、常遇春取大都后，常遇春奉命北追元顺帝。
- **④ 经过**：常遇春率步骑自北平出发，经三河、锦州、全宁，攻克上都，元顺帝北走（史实）。
- **⑤ 结局**：**上都归明**，获元宗王、将校、牲畜无数（史实，数字不进文案）。
- **⑥ 出镜**：剧终。常遇春班师途中暴病卒于柳河川，年四十（史实，年岁不进文案；B 档尾声）。朱元璋闻讯大恸。
- **⑦ 出处**：《明史·常遇春传》；英文维基 *Chang Yuchun*。
- **文案三件**：
  - **briefing**：公元一三六九年夏，明军攻下大都后，副将军常遇春率骑兵北上，直扑元朝的上都开平。元顺帝据说听到消息，又一次仓皇北逃。
  - **inviteText**：「诸位，元朝的皇帝跑到哪里，我们就追到哪里。上都，今天就要拿下来。」
  - **description**：明军长驱直入，攻克上都，俘获了大批元朝宗王和将校。可就在班师南归的路上，常遇春突然病倒，死在了柳河川，年纪还很轻，朱元璋听说后放声痛哭。
