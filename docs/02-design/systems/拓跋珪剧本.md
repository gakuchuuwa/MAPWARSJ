## 三、分场卡

**1｜395 · 参合陂之战**　①盛乐 → 河套 → 参合陂。②攻 **拓跋珪**（库里有）｜守 后燕太子**慕容宝**（库里没有）。主将队：待看素材定。③后燕伐魏，拓跋珪西渡黄河避其锋芒。④拓跋珪截住后燕的使者，散布「慕容垂已死」的谣言，燕军军心动摇、烧船夜退；魏军轻骑追击，在参合陂追上正在休息的燕军（史实）。⑤燕军几乎全灭，四五万降卒被坑杀（史实）。⑥⑦英文维基 *Battle of Canhe Slope*。

**2｜397 · 中山（攻城）**　①参合陂 → 晋阳 → 井陉 → 中山。②攻 拓跋珪｜守 后燕赵王**慕容麟**等（慕容宝已北逃龙城）。③慕容垂死后后燕内乱。④围攻中山半年多，城中内讧（史实）。⑤中山陷落，后燕退回辽西（史实）。**中山归北魏**。⑥⑦同上。

**3｜402 · 柴壁之战（剧终）**　①中山 → 平城 → 晋阳 → 柴壁。②攻 拓跋珪｜守 后秦将**姚平**（被围于柴壁，库里没有），后秦皇帝姚兴率大军来救。③后秦与北魏争河东。④拓跋珪把姚平围在柴壁，同时在汾水上结浮桥、筑长围阻姚兴援军（史实）。⑤姚平突围不成，率众投汾水而死，三万余人被俘，姚兴隔岸眼看不能救（史实）。⑥剧终：409 年拓跋珪被儿子拓跋绍所杀（B 档）。⑦英文维基 *Battle of Chaibi*。

## 四、B 档背景
386 即代王位、改国号魏 · 398 迁都平城、称帝 · 409 被杀。
