> 🔴 **这份是「路」的唯一口径**：起点、终点、什么是一条路、怎么编号、怎么验收，**只写这里**。

> 「句」（一路一句、字数、挂点、文案）见 `剧本工序-单一口径.md` 第三节；「据点显示」见其第四之二节。本文件不管它们。

> **1. 终点必须是战场，或者是一段故事的结束。**

## 一、核心原则（2026-10-02 主人重新设计定案）

1. 🔴 **终点必须是战场，或者是一段故事的结束**：
   - 行军的终极目标是奔赴战场或完成一个战略故事阶段。
   - 战斗事件的终点一律是**战场**（野战战场或攻城战被攻据点）。
   - **一段故事的结束**亦可作为终点（例：底比斯平定后班师佩拉过冬完成希腊整合、远征军彻底收官之地）。
2. 🔴 **超过 500KM 必须设断点**：
   - 如果从起点到终点（战场/故事结束地）的行军距离超过 500KM，必须在中间设立一个断点作为阶段终点。
   - 距离 ≤ 500KM 时，一路直达战场/终点，中途不断开！
3. 🔴 **断点优先历史上真实驻军停留的地方**：
   - 中间断点必须优先选择历史上大军明确驻扎、休整、过冬、建城、受降的地方。
   - 若途中无史实驻军点，才退选行军路线上的既有城池。
4. **150KM 下限取消**：
   - 只要是奔赴战场、故事终点或史实断点，哪怕只有几十公里也是一条路，绝不为机械凑公里数而破坏历史真实连贯性。

## 二、什么是一条路

**一条路 ＝ 相邻两个「终点」之间的一段连贯行军。**

- **常规情况（≤ 500KM）**：从上一处落点直奔本场战场（或故事结束点），中间不断开，这整段行军就是一条路。
- **超距情况（> 500KM）**：路程过长（游戏行军超 23 秒，观众观看节奏过长），中间按史实驻军点设立断点，拆分成两条（或多条）路，每条路的终点即为该断点或最终战场。
- 路表 `SCRIPT_ROAD_SEGMENTS` 是这批路的**标准展示**，路必须首尾相接、可严密复算。

## 三、起点【沿用】

- **起点 ＝ 上一条路的终点**（攻城战＝那座城，野战＝那处战场，进占／过冬＝进驻的城；全剧第一条路从佩拉起）。
- 事件里写死的「出发据点」优先（那是「军团此刻在哪」，不是记账栏）；史料里他中途经过的地方一律写成路标，不许写成出发据点。
- **路必须首尾相接**：每条路的起点 ＝ 上一条路的终点，断了就是错。
- 验收：`npx tsx --import ./tools/sim-preload.mjs scratch/_audit_departure_city.mts`（须全部 0 公里）。

## 四、终点标准与断点选取

### 1. 终点的两类形态【主人 2026-10-02 定】
1. **战场必须是终点**：
   - **野战**：终点为真实旷野战场坐标（`bf_*` 节点）。
   - **攻城战**：终点为被攻打的敌方据点。
2. **一段故事的结束是终点**：
   - 一个战略区域或阶段闭环之处（例：巴尔干平叛与希腊整合结束，班师佩拉过冬；全剧主角大军最终归宿）。

### 2. 超 500KM 的断点标准【主人 2026-10-02 定】
当从起点到战场（或故事结束点）的真实路网距离超过 500KM 时，必须在路线上选择断点作为该路的终点：
1. **第一优先：历史上真实驻军停留的地方**
   - 史料（以阿里安《远征记》等为准）明载大军在此驻扎、大休整、集结、过冬、建城、受降的大营。
   - 不设机械的“停留天数”门槛，只要史实明确在此扎营驻军，即为第一候选断点。
2. **第二优先：行军路线上的既有城池**
   - 若途中查无史实驻军点，或驻军点位置不均仍导致单路 > 500KM，则选取真实行军大方向上、库中已有且当年存在的城市作为扎营断点（大军过城即视为扎营）。
3. 🔴 **严禁非据点断路**：
   - 断点必须是已有据点（库里存在且当年存在）。山口、河滩、绿洲、荒野等无名地一律不许当断点终点。
   - 两个点相距不到 50 公里视为同一个点，取历史上名气大的那一个。

## 五、只写主角，一镜到底【主人 2026-09-30 定】

- **路只写主角本人（如亚历山大）。** 全剧镜头只有一个，紧随主角行军，一镜到底，中间不切偏师、不切后方。
- 史书里其他人另走的路、另打的仗一律不写、不画、不当终点；他们与主角大军会合的地方，才算汇合落点。
- 终点、断点、路上的城，均以主角本人亲率大军走过、停过、扎过营的地方为准。

## 六、路网实测四闸【沿用】

针对相邻路标之间的每一腿行军：
1. 直线距离 ≤ 400 km；
2. 绕远倍数 ≤ 1.6 倍；
3. 末段离路 ≤ 40 km；
4. **无折返跑**；
5. 渡海必须坐船。
超出的必须加路标；路网缺边属道路问题，归主人在编辑器修，AI 只报告不擅自补路。

## 七、编号与路表生成【沿用】

- **全剧「第 N 路」只有一份口径**：路表 `SCRIPT_ROAD_SEGMENTS` 的累计编号，从第 1 路数到最后一路。
- 仗是某条路终点上的战斗事件；若该仗行军 ≤ 500KM 则该仗仅占 1 路；若行军 > 500KM 断开，则该仗涵盖前置断点路与最终冲锋路。
- 改路必须通过调整事件大营/路标数据后重生成路表，**严禁手改路表，严禁另立一套编号**。
