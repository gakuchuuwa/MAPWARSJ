# 路的规则（唯一口径）

> 🔴 **这份是「路」的唯一口径**：起点、终点、什么是一条路、怎么编号、怎么验收，**只写这里**。
> 别的文件要用，只许写链接，**不许复述**（复述就会长出第二个版本，「两个第 50 路」就是这么来的）。
> 「句」（一路一句、字数、挂点、文案）见 `剧本工序-单一口径.md` 第三节；「据点显示」见其第四之二节。本文件不管它们。
>
> 状态：2026-09-30 建立；**同日主人两轮补定**（第三、七节）：必须是终点的只有「战场」和「一个故事结束的地方」两类，驻扎点只是首选参考；150 公里下限取消；超 500 公里要断开，优先驻扎点、没有就用路上的城。标 **【沿用】** 的来自主人已定的原话或已落盘规则。

## 一、什么是一条路

**一条路 ＝ 相邻两个「终点」之间的一段行军。** 终点怎么定，见第三、七节。

- 路的划法**写成可重复的规则**（第七节），不是每个人各切各的：同一份事件数据，任何人、任何脚本切出来必须是同一批路、同一个总数。
- 路表 `SCRIPT_ROAD_SEGMENTS` 是这批路的**展示**；改路 ＝ 改事件路标／驻扎点清单后按第七节重切，**不许手改路表，也不许另立一套数**。
- 为什么要写成规则：旧规则只说「终点必须是大营」，没说怎么切，所以路账脚本 78 路、路表 72 路，各自都自称合规。

## 二、起点【沿用】

- **起点 ＝ 上一条路的终点**（攻城的仗＝那座城，野战＝那处战场，进占／过冬＝进驻的城；第一条路从佩拉起）。
- 事件里写死的「出发据点」优先（那是「军团此刻在哪」，不是记账栏）；史料里他**中途**去过的地方一律写成路标，不许写成出发据点。
- 路必须**首尾相接**：每条路的起点 ＝ 上一条路的终点，断了就是错。
- 出处：AGENTS.md「历史剧本事件标准·三、行军路线」§1；`剧本工序-单一口径.md` 第一、二节。
- 验收：`npx tsx --import ./tools/sim-preload.mjs scratch/_audit_departure_city.mts`（须全部 0 公里）。

## 三、终点

**必须是终点的，只有两类**（主人 2026-09-30 定）【沿用】：

1. **战场必须是终点。** 有战场记录（`bf_*`）的那一仗，它的战场一律是一条路的终点，路到战场就止，绝不许出现在半路把路切断；攻城战的终点是被攻据点（没有战场记录）。
2. **一个故事结束的地方是终点。** 例：底比斯平定后班师佩拉过冬。

**首选参考的终点：史实驻扎点**（主人 2026-09-30 定：「把驻扎点作为优先参考的终点」）【沿用】：
- 史料明载大军在此驻扎、休整、过冬、建城、受降、围城的地方。**不设「驻多久」的门槛**（主人：「我也不知道是多久」）。
- 需要断开路的时候，**先从驻扎点里选**；驻扎点不够用，才用第七节的「路上的城」。

**其他地方**（山口、河滩、绿洲、渡口、无名地）**一律不许当终点**，只能是途经点。

- **终点必须是已有据点**：库里已存在、且那一年判「存在」的据点（`cities_v2` ＋ `cityInYear`）；不许为凑终点新建据点。【沿用】
- 主人原话（2026-09-30）：「终点必须是历史上大军明确扎营，驻军的地方，必须是已有据点，你不要乱弄好吗。」【沿用】
- 路过**战场节点**不断路（挂点只认据点）。【沿用】
- **掉头**（原路往回走）的转折点：当场收成一条路（史实上必是营地，例：锡瓦绿洲）。【沿用】
- **班师回都算一路**（例：底比斯 → 佩拉）。【沿用】

**40 公里内视为一个点**（主人 2026-09-30 定）：两个点（据点与据点、据点与战场都算）相距不到 40 公里，视为同一个点，取历史上名气大的那一个当终点／路标；另一个不再单列一路。例：白沙瓦与佩乌凯拉奥提斯（恰尔萨达）相距约 27 公里，取白沙瓦；蒙格与海达斯佩斯河战场相距约 23 公里，取战场。

## 四、只写亚历山大，镜头一镜到底【主人 2026-09-30 定】

- **路只写亚历山大本人。** 全剧镜头只有一个，从佩拉出发跟着亚历山大，一镜到底，中间不换镜头、不切别人。
- 史书里其他人（帕曼纽、克拉特鲁斯、埃里吉乌斯、留守将领）另走的路、另打的仗，**一律不写、不画、不当终点**；他们与亚历山大会合的地方，才算这一路的落点。
- 史书写他率轻装先锋、大军另走一路时，取**他本人**走的那一路（例：波斯门走山路；赫卡尼亚走「最近也最难」的山路，不走克拉特鲁斯、埃里吉乌斯那两路）。
- 终点、驻扎点、路上的城，都只看**亚历山大本人**到过、停过、扎过营的地方。

## 五、「明确」的证据标准（驻扎点用）【修订·待主人过目·新增】

- 每个大营必须在该事件「史料依据·行军路线」里写出**出处**：英文维基条目正文（当地语种为辅）＋古典作家原文（亚历山大剧本以阿里安《远征记》为准，写到卷、章）。
- 一个地方要算**驻扎点**，出处里要有**停留的明文**（天数、过冬、受降、建城、献祭赛会等）；只写「经过」「抵达」的不算驻扎点。
- **「路上的城」不需要驻扎证据**（第七节：大军过城即扎营），只要它在真实行军路线上、库里有据点、当年存在。
- 例：兹拉卡塔（赫卡尼亚首府）—— 阿里安 III.25「在此停留十五日，献祭、办竞技」→ 是大营。诺塔卡 —— 329 年阿里安只写贝苏斯**退往**诺塔卡，亚历山大 328/327 年冬才在此扎营（IV.18）→ 329 年不是大营。

## 六、史实大营库里没有据点时【修订·待主人过目·新增】

- **不新建据点**（新建据点唯一入口：攻城战缺被攻据点，见 AGENTS §二之二）。
- 该营地**不能当终点**；改用路上的城（第七节）。
- **报告一次**：「XX 是史实大营，库里没有据点」。只报与史料冲突的事，同一件事只报一次。
- 当前已知库里没有据点的史实营地：塔尔苏斯、西顿、比布鲁斯、兹拉卡塔（赫卡尼亚首府）、苏西亚（阿里亚省城）。

## 七、路的长度与切法

**150 公里下限取消**（主人 2026-09-30：「150 不要了」）。营地离得再近也是一条路（例：米利都 → 哈利卡纳苏斯 85 公里）。【沿用】

**为什么有 500 这个上限（主人 2026-09-30）：** 这是历史模拟器 —— **一切以符合历史为先，但一条路不能走得太久，太久观众会觉得没意思。** 游戏里行军约 22 公里／秒，500 公里 ≈ 23 秒。所以：**上限管的是「一条路看多久」，端点仍由史实定**；断点要选真实的驻扎点／路上的城，**不许为了压长度把路切在山口、河滩这类根本没有据点的地方**。

**超过 500 公里的路，必须断开**（主人 2026-09-30）。【沿用】断在哪，按下面的顺序找：

1. **先找史实驻扎点**（第三节）：路线上、库里有据点的驻扎点。例：孟菲斯 → 推罗 641 公里 → 佩鲁西姆（阿里安 III.1：大军与舰队在此会合、留守军）→ 拆成 223 ＋ 418。
2. **没有驻扎点，就找路上的城**（主人 2026-09-30：「找城，大军过城，要扎营吧」）：真实行军路线上经过的、库里已有据点、且当年存在的城，一律视为大军在此扎营，可当终点。
3. **山口、河滩、绿洲、无名地不行**（必须是据点，第三节）。

**切法（让结果唯一）【待主人确认】**：两个「必须的终点」之间（例：从佩拉走到海姆斯山战场），路线上依次有若干候选站（驻扎点、路上的城）。
- 两个必须终点之间总长 ≤ 500 公里 → 一条路直达；
- 总长 > 500 公里 → 选一组断点，使**每条路都 ≤ 500**，并按这个顺序比：**①路数最少 ②用「路上的城」（非驻扎点）断的次数最少 ③最长那条路最短**；仍相同取靠前的。

一句话的字数由公式按路长自动算（见 `剧本工序` 第三节），路长不影响句子能不能写。

## 八、路网实测四闸【沿用】

针对**相邻路标之间的每一腿**（不是整条路）：直线 ≤ 400 km；绕远 ≤ 1.6 倍；末段离路 ≤ 40 km；无折返跑；渡海必须坐船。
超出的，**加路标**（用附近已有据点，按史料途经地设）。路网缺边、绕远是**道路问题，归主人**，AI 只报告、不补路。
出处：AGENTS.md「历史剧本事件标准·三、行军路线」§2–3；`src/events/scriptMarchPath.ts`（游戏与编辑器共用）。

## 九、编号【沿用，2026-09-30 主人令「必须避免下次又数出两个第 50 路」】

- **全剧「第 N 路」只有一份口径：路表（代码里叫 `SCRIPT_ROAD_SEGMENTS`）的全程编号，从第 1 路数到最后一路。没有「第几场」「第几段」，只有路；仗只是某条路终点上的标记。** 任何脚本、汇报、口头说「第 N 路」都以此为准。
- 现状（2026-09-30，**全剧第 1–76 路已按本文件逐路重排并写好备注**，见 `亚历山大东征-逐路备注.md`）：共 76 路。**之后再改，总数会变，以路表为准，别在别处写死总数。**
- 重排用的驻扎点清单在 `scratch/_sync_editor_segments.mts` 的 `CAMPS`，**只收阿里安原文写明停留／建城／受降／过冬的地方**（阿达纳＝塔尔苏斯的替身）。断路时优先断在路标城（史料点名的途经地），其次才是路网碰巧经过的城。没有据点、只能报告的：塔尔苏斯、西顿、比布鲁斯、苏西亚。
- 已知遗留（路网与据点问题，归主人）：汇总在 `亚历山大东征-逐路备注.md` 文末「待主人处理」。
- **逐路备注（终点理由、播报要说清的地方）**：`亚历山大东征-逐路备注.md`，每核完一路就补一行。
- 路账脚本 `scratch/_gen_road_ledger.mts` 只读路表、按全剧累计编号打印；它自带的机械切路只留给站点表 `_ledger_stations.json`。
- 要改路：改事件的大营清单／路标 → 跑 `scratch/_sync_editor_segments.mts` 重生成路表 → 跑路账核对。**不许手改路表，也不许另立一套数。**
