## 三、分场卡

### 场 1｜887 · 汴州城北之战（野战，主角守）
- **片/段**：一 · 宣武称雄 / 段一 汴州
- **① 入镜**：虞城 → 汴州城北。
- **势力/地点**：攻 秦宗权（蔡州，库里没有）｜守 宣武军。地点 汴州北郊（野战）。
- **② 人物**：攻 自称皇帝的**秦宗权**、**张晊**（库里没有）｜守 **朱温**（库里有）、**朱珍**、**庞师古**（库里没有）；兖、郓二镇朱瑄、朱瑾来援（史实）。主将队：封建时代华夏英雄兵模（887 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：黄巢死后，秦宗权据蔡州称帝，四出掳掠，围攻汴州。
- **④ 经过**：朱温联合朱瑄、朱瑾，以朱珍从淄青募兵归来，四镇兵合击，连破秦宗权营寨（史实）。
- **⑤ 结局**：秦宗权大败，从此一蹶不振，次年被部下擒献（史实）。不易主。
- **⑥ 出镜**：转而吞并曾经的盟友兖、郓二镇。
- **⑦ 出处**：《旧五代史·梁太祖纪》；英文维基 *Zhu Wen*。
- **文案三件**：
  - **briefing**：公元八八七年夏，蔡州的秦宗权自称皇帝，大军压到了汴州城北，营寨连绵不绝。宣武节度使朱温据说此时兵力远不如对方，他派人向东边的兖州、郓州求援。
  - **inviteText**：「诸位，秦宗权纵兵掳掠，天下人都恨他。朱瑄、朱瑾兄弟已经来了，我们一起把他赶回蔡州。」
  - **description**：几路援军赶到，与宣武军里应外合，接连攻破秦宗权的营寨。秦宗权大败而逃，从此一蹶不振。可打完这一仗，朱温转过身来，就把刀口对准了刚刚帮过他的朱瑄、朱瑾。

### 场 2｜897 · 郓州（攻城）
- **片/段**：一 / 段二 郓州
- **① 入镜**：雍丘 → 虞城 → 聊城方向 → 郓州。
- **势力/地点**：攻 宣武军｜守 天平军（库里没有）。据点 郓州（库里没有；§二之二 可添加，离聊城 67 km，按间距能过，添加前须 `--probe` 实测）。
- **② 人物**：攻 **朱温**、**庞师古**、**葛从周**（库里没有）｜守 天平节度使**朱瑄**（库里没有）。
- **③ 起因**：朱温与朱瑄、朱瑾兄弟反目，连年攻战。
- **④ 经过**：梁军乘夜渡濠攻城，朱瑄弃城出逃，被擒（史实）。
- **⑤ 结局**：郓州归朱温，朱瑄被杀；随即取兖州，朱瑾南奔杨行密（史实）。
- **⑥ 出镜**：北上争河东。
- **⑦ 出处**：《旧五代史·梁太祖纪》；英文维基 *Zhu Xuan*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元八九七年正月，朱温与当年的盟友朱瑄已经打了好些年。梁军趁着夜色来到郓州城下，据说城外的护城河已经冻住了。
  - **inviteText**：「诸位，当年是他们帮过我，可天下只能有一个主人。趁夜过濠，拿下郓州。」
  - **description**：梁军连夜渡过护城河攻城，朱瑄弃城出逃，不久被擒杀。朱温又乘势夺下兖州，朱瑾只身南逃，投奔了淮南的杨行密，中原东部尽归朱温所有。

### 场 3｜902 · 晋阳（攻城，剧终）
- **片/段**：二 · 争河东 / 段三 晋阳
- **① 入镜**：郓州 → 虎牢关 → 天井关 → 长子 → 晋阳。
- **势力/地点**：攻 宣武军｜守 河东（李克用，库里沙陀系势力，做事件时查）。据点 **晋阳** `city_taiyuan`（战后不易主）。
- **② 人物**：攻 **朱温**（遣大将**氏叔琮**，库里没有）｜守 河东节度使**李克用**（库里有，做事件时查）、**周德威**、**李嗣昭**（库里没有）。
- **③ 起因**：朱温控制唐昭宗后，出兵攻李克用，意欲灭河东。
- **④ 经过**：梁军围晋阳，李克用登城督战，一度想弃城北奔，被刘夫人劝止（史实）；城中出奇兵袭扰，时值大雨，梁军多疫（史实）。
- **⑤ 结局**：梁军撤围（史实）。**不易主**。
- **⑥ 出镜**：剧终。朱温挟持唐昭宗迁都洛阳，904 年弑昭宗，907 年篡唐称帝建后梁（B 档）；912 年被其子朱友珪所杀（史实，B 档尾声）。
- **⑦ 出处**：《旧五代史·梁太祖纪》；英文维基 *Zhu Wen*。
- **文案三件**：
  - **briefing**：公元九〇二年春，朱温派大将氏叔琮率领大军围攻晋阳，要一举消灭宿敌李克用。晋阳城里人心惶惶，据说李克用都一度想要弃城北逃。
  - **inviteText**：「诸位，李克用是我最大的对头。拿下晋阳，天下就再也没有人能挡住我。」
  - **description**：李克用的夫人劝住了想要出逃的丈夫，城中军民坚守不退，还不时出城偷袭梁军。偏偏那时大雨连绵，梁军营中疫病流行，只得撤围而去，朱温吞并河东的打算落了空。
