## 三、分场卡

### 场 1｜956 · 清流关（攻城·关隘）
- **片/段**：一 · 后周名将 / 段一 淮南
- **① 入镜**：寿春 → 钟离 → 清流关。
- **势力/地点**：攻 后周（库里后周系势力，做事件时查）｜守 南唐（库里南唐系势力）。据点 **清流关** `city_qingliuguan`（战后 `cityUpdates` 归后周）。
- **② 人物**：攻 殿前都虞候**赵匡胤**（库里有）｜守 南唐奉化节度使**皇甫晖**、团练使**姚凤**（库里没有）。主将队：封建时代华夏英雄兵模（956 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：柴荣亲征淮南，南唐皇甫晖屯兵清流关，扼滁州之险。
- **④ 经过**：赵匡胤引兵绕到山后，从关背出击，南唐军溃退入滁州；赵匡胤追至城下，皇甫晖说各为其主，请列阵决战；赵匡胤笑而许之，列阵后单骑冲入，挥剑击中皇甫晖脑后，生擒之（《宋史》，史实）。
- **⑤ 结局**：**清流关归后周**，滁州亦下（史实）。
- **⑥ 出镜**：继续淮南之战；960 年陈桥兵变，黄袍加身（B 档）。
- **⑦ 出处**：《宋史·太祖本纪》；英文维基 *Emperor Taizu of Song*（清流关之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元九五六年春，后周世宗柴荣亲征南唐。南唐名将皇甫晖屯兵清流关，据守着通往滁州的险道。年轻的殿前都虞候赵匡胤领着一支人马，悄悄绕进了关后的山路。
  - **inviteText**：「诸位，关前守得再严，关后总有空当。翻过这座山，从背后给他们一击。」
  - **description**：周军从山后杀出，南唐军溃退进滁州城。皇甫晖在城下对赵匡胤说，各为其主，请你列好阵再打。赵匡胤笑着答应，阵形刚一排好，他便单骑冲入敌阵，一剑击中皇甫晖，将他生擒。

### 场 2｜960 · 泽州（攻城）
- **片/段**：二 · 宋太祖亲征 / 段二 泽潞
- **① 入镜**：清流关 → 寿春 → 开封 → 天井关 → 泽州。
- **势力/地点**：攻 北宋｜守 李筠（后周昭义节度使，起兵反宋，库里没有）。据点 泽州（库里没有；§二之二 可添加，离天井关 27 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **赵匡胤**（亲征）、**石守信**、**高怀德**（库里没有）｜守 昭义节度使**李筠**（库里没有）。
- **③ 起因**：赵匡胤称帝后，后周旧臣李筠联合北汉起兵反宋。
- **④ 经过**：宋军在泽州城南大破李筠，李筠退守泽州；赵匡胤亲临督战，士卒冒矢石登城（史实）。
- **⑤ 结局**：城破，李筠投火自焚（史实）。泽州归宋。
- **⑥ 出镜**：回师开封。
- **⑦ 出处**：《宋史·太祖本纪》；英文维基 *Li Yun (Later Zhou)*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元九六〇年夏，赵匡胤刚刚在陈桥驿黄袍加身不久，后周的老将李筠便在潞州起兵，还联络了北汉。新登基的宋太祖决定亲自出征。
  - **inviteText**：「诸位，天下刚刚安定，有人就不服了。朕亲自来，看他服不服。」
  - **description**：宋军在泽州城南大破李筠，把他围在城里。赵匡胤亲临城下督战，将士们冒着箭雨攀上城头，城破之时，李筠纵身跳入火中自焚。

### 场 3｜960 · 扬州（攻城）
- **片/段**：二 / 段三 扬州
- **① 入镜**：泽州 → 天井关 → 开封 → 寿春 → 广陵。
- **势力/地点**：攻 北宋｜守 李重进（后周淮南节度使，库里没有）。据点 **广陵** `city_yangzhou`（战后 `cityUpdates` 归 `song`）。
- **② 人物**：攻 **赵匡胤**（亲征）、**石守信**｜守 淮南节度使**李重进**（后周太祖外甥，库里没有）。
- **③ 起因**：李重进在扬州起兵反宋。
- **④ 经过**：赵匡胤亲征，到扬州城下当日即破城（史实）。
- **⑤ 结局**：李重进举家自焚（史实）。**扬州归宋**。
- **⑥ 出镜**：回师开封；961 年杯酒释兵权（B 档）。
- **⑦ 出处**：《宋史·太祖本纪》；英文维基 *Li Chongjin*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元九六〇年冬，泽潞刚刚平定，后周太祖的外甥李重进又在扬州举兵。宋太祖赵匡胤没有片刻停歇，又亲率大军南下。
  - **inviteText**：「诸位，朕刚从泽州回来，没关系，再去扬州。扬州，今天就拿下来。」
  - **description**：宋军兵临扬州城下，当天就攻破了城池。李重进走投无路，带着全家自焚而死，宋朝初年的两场叛乱就这样平定了。

### 场 4｜969 · 太原（攻城，剧终）
- **片/段**：二 / 段四 太原
- **① 入镜**：广陵 → 开封 → 真定 → 晋阳。
- **势力/地点**：攻 北宋｜守 北汉（库里北汉系势力，做事件时查）。据点 **晋阳** `city_taiyuan`（太原；战后不易主）。
- **② 人物**：攻 **赵匡胤**（亲征）、**曹彬**、**党进**（库里没有）｜守 北汉主**刘继元**、名将**刘继业**（即杨业，库里有，见 [`杨业剧本.md`](杨业剧本.md)）。
- **③ 起因**：宋太祖先南后北，亲征北汉。
- **④ 经过**：宋军筑长围，引汾水、晋水灌太原城，城墙渗漏；辽军来援，宋军阻击（史实）；时值暑雨，宋军多病（史实）。
- **⑤ 结局**：赵匡胤采纳建议撤围，迁太原附近百姓南归（史实）。**不易主**。
- **⑥ 出镜**：剧终。975 年灭南唐（见 [`曹彬剧本.md`](曹彬剧本.md)），976 年「烛影斧声」中去世（B 档尾声）；979 年宋太宗灭北汉。
- **⑦ 出处**：《宋史·太祖本纪》；英文维基 *Northern Han*。
- **文案三件**：
  - **briefing**：公元九六九年春，宋太祖赵匡胤亲征北汉，大军把太原城团团围住。太原城坚，北汉又有契丹做后盾，守城的将领里据说还有一位人称「无敌」的刘继业。
  - **inviteText**：「诸位，太原城墙厚，那就用水来泡。把汾水引过来，灌进城去。」
  - **description**：宋军修起长堤，引汾水灌城，城墙被泡得四处渗漏。可夏天暑雨连绵，军中疫病流行，契丹的援军又虎视眈眈，赵匡胤只得撤围南返，北汉又多撑了好些年。
