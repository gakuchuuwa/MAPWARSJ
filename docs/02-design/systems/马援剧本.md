## 三、分场卡

### 场 1｜35 · 临洮之战（野战）
- **片/段**：一 · 陇西 / 段一 临洮
- **① 入镜**：襄武 → 临洮。
- **势力/地点**：攻 东汉｜守 先零羌（库里羌系势力，做事件时查）。地点 临洮（野战）。
- **② 人物**：攻 **马援**（库里有）｜守 先零羌诸部首领（史书未载名）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：先零羌侵扰陇西诸县。
- **④ 经过**：马援率步骑深入，羌人据山险，马援断其水草，羌人饥困（《后汉书》，通行说法）；马援在战斗中腿中流矢（史实）。
- **⑤ 结局**：羌人大败投降（史实）。不易主。
- **⑥ 出镜**：此后在陇西六年，安抚羌人（B 档）。
- **⑦ 出处**：《后汉书·马援列传》；英文维基 *Ma Yuan (Han dynasty)*。
- **文案三件**：
  - **briefing**：公元三五年，先零羌屡屡侵扰陇西。太守马援领兵出征，羌人退上了山险之处，居高临下。据说马援并不急着攻山，而是先去找他们的水源。
  - **inviteText**：「诸位，山高难攻，可山上没有水。守住他们的水草，羌人自己就会下来。」
  - **description**：汉军截断了羌人的水草，羌人又饥又渴，被迫下山决战。激战中马援的小腿中了一箭，他却照常指挥，羌人终于大败投降。

### 场 2｜42–43 · 浪泊之战（野战）
- **片/段**：二 · 南征交趾 / 段二 浪泊
- **① 入镜**：迭部 → 襄武 → 长安 → 宛城 → 长沙 → 海门 → 浪泊。
- **势力/地点**：攻 东汉｜守 征氏（交趾起义，库里没有）。地点 浪泊（野战）。
- **② 人物**：攻 **马援**、楼船将军**段志**（途中病死，库里没有）｜守 **征侧**、**征贰**姐妹（库里没有）。
- **③ 起因**：交趾太守苏定施政严苛，征侧、征贰姐妹起兵，岭南诸郡响应（史实）。
- **④ 经过**：马援缘海而进，随山开道千余里，至浪泊与征氏会战（史实）；南方湿热，瘴疫流行（史实）。
- **⑤ 结局**：征氏大败，退守禁溪；次年正月被汉军斩杀（史实）。不易主（交趾郡治龙编库里没有）。
- **⑥ 出镜**：平定九真余部，立铜柱为界（据说如此），44 年北返。
- **⑦ 出处**：英文维基 *Trưng sisters' rebellion*；*Ma Yuan (Han dynasty)*；越南语维基未查。
- **文案三件**：
  - **briefing**：公元四二年，交趾的征侧、征贰姐妹起兵反抗汉朝的太守，岭南一带纷纷响应。伏波将军马援奉命南征，他的大军沿着海岸开山辟路，一路南下。
  - **inviteText**：「诸位，这里湿热难当，瘴气伤人，可朝廷的命令不能不遵。打完这一仗，我们就回家。」
  - **description**：汉军在浪泊与征氏姐妹决战，征军大败，退往禁溪。第二年正月，马援攻破禁溪，征侧、征贰被斩，交趾重新归汉。

### 场 3｜48–49 · 壶头（攻城·关隘，剧终）
- **片/段**：三 · 五溪 / 段三 壶头
- **① 入镜**：浪泊 → 北返 → 长沙 → 沅陵 → 壶头山。
- **势力/地点**：攻 东汉｜守 五溪蛮（库里武陵 `wuling`）。据点 **壶头山** `city_wulingshan`（战后不易主）。
- **② 人物**：攻 **马援**（年过六旬请战，史实）、耿舒（库里没有）｜守 五溪蛮首领（史书未载名）。
- **③ 起因**：武陵五溪蛮反，前军覆没；马援主动请战，披甲上马以示可用（史实）。
- **④ 经过**：马援选择走近路攻壶头，蛮人据高守隘，水流湍急，船不能上；时值暑热，士卒多疫死（史实）。
- **⑤ 结局**：马援病死军中（史实）。壶头**不易主**；后监军宋均矫诏招降，五溪平定（B 档）。
- **⑥ 出镜**：剧终。马援死后遭梁松诬陷，追收印绶，家人草葬（史实，B 档尾声）。
- **⑦ 出处**：《后汉书·马援列传》；英文维基 *Ma Yuan (Han dynasty)*。
- **文案三件**：
  - **briefing**：公元四八年冬，五溪的蛮人又一次起兵反叛。年纪已老的马援主动请战，据说他当着光武帝的面披甲上马，左顾右盼，表示自己还能打仗。
  - **inviteText**：「诸位，男儿要死在边野，以马革裹尸还葬，怎么能躺在床上死在儿女手中？」
  - **description**：汉军从近路进攻壶头，蛮人占据高处死守，溪水湍急，船只无法逆流而上。时值盛暑，疫病在军中蔓延，马援也病倒了，最终死在了军营里，果然应了他自己的誓言。
