## 三、分场卡

**1｜1114 · 宁江州（攻城）**　①按出虎水 → 宁江州。②攻 **完颜阿骨打**（库里有）女真兵二千五百（史实）｜守 辽宁江州守军。主将队：待看素材定。③辽朝对女真横征暴敛，阿骨打誓师起兵。④在涞流水誓师，攻破宁江州（史实）。⑤宁江州归金。⑥随后在出河店以三千七百人破辽军十万（B 档）。⑦英文维基 *Wanyan Aguda*。

**3｜1115 秋 · 黄龙府（攻城）**　①→ 伯都 → 黄龙府。②攻 阿骨打（已称帝建金）｜守 辽黄龙府守军。③黄龙府是辽东北重镇。④围攻后攻破（史实）。⑤**黄龙府归金**（岳飞后来说「直抵黄龙府，与诸君痛饮」即指此地）。⑥辽天祚帝亲征。⑦同上。

**2｜1115 冬 · 护步达冈之战（主角守）**　①黄龙府 → 护步达冈。②攻 辽**天祚帝**亲征（号称七十万，按 §一.2 封顶；库里没有）｜守 阿骨打二万（史实）。③天祚帝亲率大军东征。④辽军内部耶律章奴叛乱，天祚帝急于回师；阿骨打率二万人追击，集中兵力冲击天祚帝中军（史实）。⑤辽军大溃（史实），辽国从此一蹶不振。⑥⑦同上。

**4｜1120 · 上京（攻城，剧终）**　①→ 会宁 → 黄龙府 → 上京。②攻 阿骨打｜守 辽上京留守**挞不野**（库里没有）。③宋金「海上之盟」约定共同攻辽。④阿骨打亲临城下，从早晨攻到中午就攻破外城（史实）。⑤挞不野出降。**临潢府（辽上京）归金**。⑥剧终：1122 年攻破燕京，1123 年阿骨打病逝，1125 年辽亡（B 档）。⑦同上。
