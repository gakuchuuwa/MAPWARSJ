## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜前229–228 · 邯郸（攻城）**　①关中 → 井陉 → 邯郸。②攻 **王翦**（库里有）｜守 赵将**李牧**（后换赵葱、颜聚）、赵王迁（库里查不到）。主将队：待看素材定。③秦欲灭赵。④王翦与李牧相持一年不下；秦用反间计买通赵王宠臣郭开，诬李牧谋反，赵王杀李牧；王翦随即大破赵军。⑤邯郸破，赵王迁被俘（史实）。**邯郸归秦**（`city_handan` → `qin`）。⑥北上攻燕。⑦英文维基 *Wang Jian (Qin)* <https://en.wikipedia.org/wiki/Wang_Jian_(Qin)>；*Qin's wars of unification*。

**2｜前226 · 蓟（攻城）**　①邯郸 → 易水 → 蓟。②攻 王翦｜守 燕太子丹与代王嘉联军（库里没有）。③前227 年荆轲刺秦王失败，秦王大怒攻燕。④王翦在易水之西击败燕代联军。⑤攻下燕都蓟，燕王喜逃往辽东（史实）。蓟归秦（库里没有，写不进）。⑥回关中。⑦同上。

**3｜前224 · 蕲南之战**　①→ 频阳（辞官）→ 秦王亲请 → 陈 → 蕲南。②攻 王翦 六十万（史实）｜守 楚将**项燕**（项羽祖父，库里没有；兵力推定）。③李信带二十万伐楚大败，秦王只好亲自去请王翦，王翦说「非六十万人不可」。④王翦到了楚地筑营坚守，每天让士兵休息洗浴、吃好喝好，只问士兵「投石超距」（掷石、跳远）的游戏玩得怎样；一年后楚军东撤，王翦全军追击。⑤在蕲南大破楚军，项燕战死（通行说法；一说自杀）。⑥追至寿春。⑦同上。

**4｜前223 · 寿春（攻城，剧终）**　①蕲南 → 寿春。②攻 王翦（与蒙武）｜守 楚王**负刍**。③楚主力已灭。④攻破楚都寿春，俘楚王负刍（史实）。⑤**寿春归秦**（`city_shouxian` → `qin`），楚亡。⑥剧终：王翦此后平定江南、百越（B 档），卒年不详。⑦同上。
