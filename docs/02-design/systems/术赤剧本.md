## 三、分场卡

### 场 1｜1219 · 伊尔吉兹河之战（野战，主角守）
- **片/段**：一 · 西征花剌子模 / 段一
- **① 入镜**：养吉干 → 伊尔吉兹河。
- **势力/地点**：攻 花剌子模（库里 `huarazim`，本城玉龙杰赤）｜守 蒙古。地点 伊尔吉兹河（野战）。
- **② 人物**：攻 花剌子模沙**摩诃末二世**、王子**札兰丁**（库里都没有）｜守 **术赤**（速不台同行，一说哲别）。主将队：城堡时代草原英雄兵模（按 §二.5 看样貌）；对手选城堡时代中亚/波斯系英雄兵模。
- **③ 起因**：术赤追讨蔑儿乞残部，在草原上与出兵北进的花剌子模主力相遇。蒙古使者说无意交战，摩诃末不听。
- **④ 经过**：蒙古左翼一度冲到摩诃末的中军，札兰丁率右翼力战救回（志费尼，通行说法）。
- **⑤ 结局**：两军相持到天黑，蒙古军燃起营火，连夜撤走（史实）；摩诃末从此畏惧蒙古军。不易主。
- **⑥ 出镜**：回师与成吉思汗主力会合。
- **⑦ 出处**：英文维基 *Jochi*；*Mongol invasion of the Khwarazmian Empire*（「伊尔吉兹河之战」独立条目待核）。
- **文案三件**：
  - **briefing**：公元一二一九年，术赤在草原上追赶逃散的蔑儿乞人，却迎面撞上了花剌子模的大军。据说他派人去说明来意，摩诃末却不肯罢休。
  - **inviteText**：「朋友，父亲只叫我们追蔑儿乞人，没叫我们和花剌子模打仗。可他们既然不让路，那就打一场给他们看看。」
  - **description**：蒙古骑兵一度冲到摩诃末的帐前，札兰丁率军死战才把局面扳回。天黑后蒙古军燃起满营篝火，悄悄退走，摩诃末却从此对蒙古人心存畏惧。

### 场 2｜1219 冬 · 毡的（攻城）
- **片/段**：一 / 段一
- **① 入镜**：养吉干 → 讹答剌分兵 → 沿锡尔河下行 → 毡的。
- **势力/地点**：攻 蒙古｜守 花剌子模。据点 **毡的** `city_zhande`（战后 `cityUpdates` 归 `menggu_d`）。
- **② 人物**：攻 **术赤**｜守 毡的守军（守将史书未载名；志费尼说守将弃城出逃）。
- **③ 起因**：成吉思汗在讹答剌分兵，命术赤沿锡尔河而下，攻取下游诸城（昔格纳黑、毡的等）。
- **④ 经过**：术赤先派使者劝降，昔格纳黑杀使者被屠；毡的守将弃城逃走，城中军民草草抵抗，蒙古军架梯登城（志费尼，通行说法）。
- **⑤ 结局**：**毡的归蒙古**（史实），术赤赦免了城中居民。
- **⑥ 出镜**：南下围玉龙杰赤。
- **⑦ 出处**：英文维基 *Jochi*；*Jend*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一二一九年冬，术赤沿着锡尔河一路向下。上游的昔格纳黑杀了他的使者，已经被夷为平地。毡的的守将听到消息，恐怕早已心惊胆战。
  - **inviteText**：「朋友，毡的的人若肯开门，我就饶了他们。昔格纳黑的下场，他们应该听说了。」
  - **description**：毡的守将连夜弃城出逃，城中军民仓促守城，蒙古军架起云梯登上城头。术赤没有屠城，只把居民赶出城外清点。

### 场 3｜1220–1221 · 玉龙杰赤（攻城，剧终）
- **片/段**：一 / 段二 花剌子模本土
- **① 入镜**：毡的 → 养吉干 → 咸海西岸 → 玉龙杰赤。
- **势力/地点**：攻 蒙古｜守 花剌子模。据点 **玉龙杰赤** `city_urgench`（战后 `cityUpdates` 归 `menggu_d`）。
- **② 人物**：攻 **术赤**、**察合台**（库里没有）、**窝阔台**（库里没有）｜守 花剌子模守将**忽马儿的斤**（库里没有）。
- **③ 起因**：花剌子模旧都玉龙杰赤是太后秃儿罕的根据地，摩诃末死后仍拒不投降。
- **④ 经过**：术赤想保全这座将来要封给自己的城，主张缓攻；察合台主张急攻，兄弟不和，围城数月不下；成吉思汗改命窝阔台统一指挥，蒙古军掘开阿姆河堤，逐街巷战（史实）。
- **⑤ 结局**：**玉龙杰赤归蒙古**（史实），城被洪水淹没。
- **⑥ 出镜**：剧终。术赤与父兄失和，留驻钦察草原，1227 年先于成吉思汗而卒（B 档）；他的封地后来由儿子拔都建成金帐汗国（见 [`拔都剧本.md`](拔都剧本.md)）。
- **⑦ 出处**：英文维基 *Siege of Gurganj*。
- **文案三件**：
  - **briefing**：公元一二二〇年冬，蒙古三位王子合围花剌子模的旧都玉龙杰赤。术赤想留下这座富庶的城，察合台却只想早日攻下。兄弟俩在城下争吵不休，围城迟迟没有进展。
  - **inviteText**：「朋友，这座城将来是我的封地，拆了它，我拿什么给百姓？可二弟不这么想，父亲也等得不耐烦了。」
  - **description**：兄弟不和让围城拖了几个月，成吉思汗改命窝阔台统一指挥。蒙古军掘开阿姆河的堤坝，河水灌进城里，守军逐街死战，玉龙杰赤最终在洪水中陷落。
