# 亚历山大东征 · 剧本底本（一部人物传记）

> 🔴 **主人 2026-09-24 定**：「剧本已经设定了，**亚历山大东征**，镜头跟随亚历山大军团。我们要**像写剧本一样**来设计这个剧本。」
>
> 本文件就是这部剧本的**底本**（screenplay）：**一幕一场地读下来，就是亚历山大这一生的这一段战争史**。
> 写事件时照它填；**它本身不改任何游戏数据**，也不新增任何字段——剧本的每一句都写在既有字段里（见 §一）。

**一部剧本 = 一部人物传记 = 一个人物一条线。** 主角：亚历山大大帝（`gen_alexander_great`）。
**镜头只有一路**：跟主角军团（`CameraFollowUI` 跟玩家所在军团）；其他军团不许有镜头、也不许自己移动。

## 一、剧本要素 → 现有字段对照（**不需要新字段**）

| 剧本要素 | 写在哪儿（现有字段） |
|---|---|
| **幕**（Act） | 不进数据——**只在本底本里分段**。游戏按 `year` / `season` 自动排场次先后 |
| **场次标题** | `title`（战役全名，带年份前缀）+ `year` / `season` / `type` |
| **场景地点** | 野战：`fieldBattleData.location` + `Battlefields.ts` 的 `bf_*` 战场记录；攻城战：`siegeData.defenderCityId`（被攻打的那座城） |
| **入镜**（这场从哪来） | `src/events/scriptEventStart.ts` 的出发地（没写 `startCityId` 就是**上一场落点**）+ `marchWaypoints` + 出兵据点 `attackerSourceCityId`（记账） |
| **出镜**（打完往哪去） | `cityUpdates`（战后据点归谁）+ 下一场的出发地（链体检逐场核） |
| **人物** | `attackerGeneralId` / `defenderGeneralId`（战场人物表 `src/data/BattlefieldCharacters.ts` 兜底）+ 主将队 `commanderUnit` / `foeCommanderUnit` |
| **起因 · 台词** | `inviteText`（邀约对白，**只显示文字不念**，称呼合人物时代与文化） |
| **旁白** | 野战：战场记录 `bf_*.briefing`（赶路播报）；攻城战：事件自身 `briefing` |
| **经过 · 转折** | `fieldBattleData.description` / `siegeData.description`（战术模式战斗面板）+ 13 项史料依据 |
| **结局 · 归宿** | `result` + `cityUpdates` |
| **镜头** | 全局一条：行军纵队 `Army.columnMarch` → 距战场 60 km 展开成阵；守方**本地生成**（野战在战场对阵位、攻城战在城里） |

### 十五场｜前327 年 · 春 · 索格狄亚那岩（攻城，40.4,69.4）

- **入镜**：军团此刻在**贵山城**（上一场落点锡尔河战场那一年最近且已存在的据点；忽毡在前327 过不了年代闸门）→ 路标 **撒马尔罕（马拉坎达）→ 阿母城（乌浒水渡口，巴克特里亚方向）→ 撒马尔罕 → 忽毡（居鲁士城）** → 索格狄亚那岩。
- **势力**：守方＝**索格狄亚那**（2026-09-24 主人批准新建：以索格狄亚那岩为首府，配武将阿里马泽斯＋精锐「岩堡守兵」——
  不这样做的话，这座岩不是任何势力的首府，「归属武将」推不出来，前327 的地图上就不画它）。
- **人物**：攻 亚历山大（信息框 strength1 = 300，即那支夜攀队）｜守 岩堡首领**阿里马泽斯**（strength2 = Unknown，按守≤攻×2 取 600，合理推定）。主将队：英雄·骑马亚历山大 ／ 英雄·塞乌特斯三世（照 §二.5「先保年代，再尽样子」；名册里没有粟特英雄兵模）。

- **入镜**：第一场，军团自他的本城**佩拉**起兵 → 路标 **安菲波利斯 → 菲利比 → 普罗夫迪夫（菲利波波利斯，前342 年腓力二世所建）** → 海姆斯山。实测：佩拉 → 安菲波利斯 沿路 120.7 公里；安菲波利斯 → 菲利比 沿路 51.6 公里（绕潘盖翁山北麓走廊）；菲利比 → 普罗夫迪夫 沿路 262.8 公里（渡内斯托斯河、将奥尔贝鲁斯山置于左侧、穿罗多彼山经帕扎尔吉克入马里查河谷）；普罗夫迪夫 → 塞乌托波利（卡赞勒克谷地）→ 战场 沿路 142.9 公里。全程 578 公里矢量道路全线闭环连通，红 0、提示 0。
- **人物**：攻 亚历山大 23000（英文维基 *Balkan campaign of Alexander the Great* 信息框）｜守 自治色雷斯人 8000（维基无守方兵数，据同一战役中格泰人一万四千、特里巴利人一役阵亡三千推定）。主将队：英雄·骑马亚历山大 ／ 守方照 §二.5「先保年代，再尽样子」。
- **起因**：前335 年春亚历山大北上平定色雷斯，自治的色雷斯人据海姆斯山脊、以大车连成营垒，要推车冲散登山的马其顿军。
- **经过**：亚历山大令步兵遇车则散开让路、来不及散开就伏地举盾，弓手射乱其阵，方阵一路登顶。
- **结局**：色雷斯人溃散，北上之路就此打通。本场为野战，不涉据点易主。
- **出镜**：战场落点 → 下一场自上一处战场开拔（承前）。
- **出处**：英文维基百科 *Balkan campaign of Alexander the Great*（13 项史料依据见数据）。

### 二场｜前335 年 · 夏 · 佩利昂（攻城，40.7306,20.8625）

- **入镜**：军团此刻在上一场落点（海姆斯山战场），出兵据点记**普罗夫迪夫**（那年离战场最近且已存在的据点；塞乌托波利前330 年才建）→ 路标**无**（沿途无那一年已存在的据点）→ 佩利昂。实测：海姆斯山战场 → 佩利昂 沿路 528 公里／直线 433 公里＝1.22 倍，**末段离路 0 公里**，走线经塞乌托波利 → 索非亚 → 丘斯滕迪尔 → 斯科普里 → 基切沃 → 奥赫里德 → 佩利昂（2026-09-25 补绘这条道之前，末段要离路直行 140 公里 ✗）。
- **势力**：守方＝伊利里亚（佩利昂为其要塞）。
- **人物**：攻 亚历山大 23000｜守 伊利里亚王**克莱图斯**（巴尔迪利斯之子）7000（英文维基 *Siege of Pelium* 信息框 strength2 = 7,000），另有陶兰提王格劳基亚斯引兵来援。主将队：英雄·骑马亚历山大 ／ 守方照 §二.5。
- **起因**：亚历山大在多瑙河征战时闻伊利里亚人叛，克莱图斯据佩利昂要塞，格劳基亚斯引兵来会。
- **经过**：格劳基亚斯的援军占据四周高地，一度把马其顿军逼退到河对岸；三日后亚历山大趁夜突袭，伊利里亚人猝不及防。
- **结局**：伊利里亚人大败，克莱图斯焚城逃往格劳基亚斯境内；**佩利昂归马其顿**。
- **出镜**：佩利昂落点 → 下一场自佩利昂开拔（承前）。

### 三场｜前335 年 · 秋 · 底比斯（攻城，38.32,23.31）

- **入镜**：军团此刻在上一场落点**佩利昂** → 路标**无** → 底比斯。实测：佩利昂 → 底比斯 沿路 486 公里／直线 340 公里＝1.43 倍，走线 佩利昂 → 雷森 → 比托拉 → 弗洛里纳 → 埃泽萨 → 佩拉 → 坦佩谷 → 拉里萨 → 温泉关 → 底比斯（即史载那条南北干道），红 0、提示 0。
- **势力**：守方＝底比斯（守将菲尼克斯）。
- **人物**：攻 亚历山大 33000（英文维基 *Battle of Thebes* 信息框）｜守 底比斯军 15000。主将队：英雄·骑马亚历山大 ／ 守方照 §二.5。
- **起因**：亚历山大北上色雷斯、伊利里亚期间，底比斯趁势举兵反抗马其顿霸权。
- **经过**：亚历山大自佩利昂十三日急行军南下，经色萨利、温泉关入维奥蒂亚，围城强攻。
- **结局**：底比斯陷落、被夷为平地，幸存者尽卖为奴；**底比斯归马其顿**。
- **出镜**：底比斯落点 → 下一场自底比斯开拔（下一场＝格拉尼库斯河）。

### 四场｜前334 年 · 春 · 格拉尼库斯河（野战，40.3167,27.2811）

- **入镜**：他的第一场，自本城佩拉起兵 → 安菲波利斯 → 羊河（塞斯托斯）→ **坐船渡赫勒斯滂** → 特洛伊（伊利昂）→ 沿海岸东进 → 战场。那年还不存在的「鲁西翁」（中世纪地名）与「格拉尼库斯」城寨不上图，路照走。
- **人物**：攻 亚历山大（马其顿军，18100）｜守 波斯小亚细亚诸总督联军（27000，主帅按现代学者为赫勒斯滂弗里吉亚总督阿尔西提斯）。主将队：英雄·骑马亚历山大 ／ 英雄·阿尔塔弗涅斯。
- **起因**：以报复波斯当年焚毁雅典神庙为名渡海东征（阿里安《亚历山大远征记》II.14）。
- **经过**：波斯骑兵沿东岸列阵、希腊雇佣兵列于其后高地；亚历山大亲率伙伴骑兵强渡河流进攻。
- **结局**：马其顿胜，小亚细亚半壁入手；**达斯基利翁**（阿尔西提斯治所）归马其顿。
- **出镜**：战场 → 下一场自羊河开拔（58 km，规则：取离战场最近、那一年已存在的据点）。

### 五场｜前334 年 · 夏 · 米利都（攻城，37.5303,27.2783）

- **入镜**：上一场战场打完 → 路标 **斯法尔德（萨第斯）→ 以弗所** → 米利都。
- **人物**：攻 亚历山大（18000）｜守 米利都守将赫格西斯特（3000）。主将队：英雄·骑马亚历山大 ／ 英雄·阿里斯塔哥拉斯。
- **起因**：守将本已答应献城，因附近波斯军未远走、波斯舰队许诺来援而反悔，只肯让米利都中立、对双方开放港口。
- **经过**：尼卡诺尔先占莱德岛，把波斯舰队逼在港外；陆军以投石机轰塌城墙、自缺口突入；退守小岛的希腊雇佣兵被亚历山大收编。
- **结局**：米利都归马其顿，伊奥尼亚全境臣服。**转折**：此战让亚历山大认清马其顿舰队敌不过波斯海军，遂解散海军，此后专以陆军逐座拔掉波斯的海军基地。
- **出镜**：自米利都沿新路南下 → 哈利卡纳苏斯（94 km）。

### 六场｜前334 年 · 秋 · 哈利卡纳苏斯（攻城，37.03,27.43）

- **入镜**：上一场落点＝米利都（攻城战＝那座城），沿「米利都—哈利卡纳苏斯」道路南下直抵该城。
- **人物**：攻 亚历山大（18000）｜守 **门农**（罗得岛，新任波斯小亚细亚总指挥、兼统舰队）与卡里亚总督欧戎托巴提斯（3000）。主将队：英雄·骑马亚历山大 ／ 英雄·阿里斯提德。
- **起因**：米利都既下，波斯把兵力与希腊雇佣军一齐集中到卡里亚的哈利卡纳苏斯；门农受任总指挥、加固城防、舰队泊于港内。
- **经过**：先拿城旁要塞当跳板无功（内应被发觉、城门未开）→ 填平护城河、架投石机 → 佩尔狄卡斯营两名士兵莽撞逼近引发大战、城墙被撞开一段（泥瓦匠很快砌起新墙）→ 守军夜袭烧器械、连日居高反击。
- **结局**：门农与欧戎托巴提斯见伤兵日增，趁夜弃城并纵火，风大火烈全城化为火海；亚历山大急令追击扑火，最后只得到一座残城；卡里亚交前女王阿妲统领。
- **出镜**：自哈利卡纳苏斯北上 → 戈尔迪乌姆 → 伊苏斯。

### 七场｜前333 年 · 秋 · 伊苏斯（野战，36.7525,36.1923）

- **入镜**：上一场落点＝哈利卡纳苏斯城（军团此刻就在那座城，出兵据点也是它）→ 路标**戈尔迪乌姆**（前333 年春在此斩断戈尔迪之结）→ **安卡拉（古安库拉）→ 伊科尼乌姆 → 阿达纳（塔尔苏斯附近）** → 战场。阿达纳挂的「蛇堡」是中世纪亚美尼亚城堡，那一年不上图，路照走。
- **人物**：攻 亚历山大（37000）｜守 **大流士三世**（74000；信息框中值 75000 超出「守方 ≤ 攻方×2」，取区间内最近的 74000）。主将队：英雄·骑马亚历山大 ／ 英雄·阿尔塔弗涅斯（项目没有大流士本人的兵模，按**样貌与年代**取同时代的阿契美尼德总督）。
- **起因**：大流士在巴比伦集结大军；亚历山大越过托罗斯山进入奇里乞亚迎战。
- **经过**：海湾到群山之间仅两英里；两军在皮纳鲁斯河两岸会战，波斯骑兵率先渡河冲击；亚历山大亲率右翼伙伴骑兵渡河突破波斯左翼，直扑大流士御驾。大流士绕到马其顿军后方占了伊苏斯、砍去伤病员之手。
- **结局**：马其顿决定性胜利；大流士弃车逃离，母亲、妻子、两个女儿被俘。**伊苏斯是战场，没有据点易主。**
- **出镜**：战场 → 下一场自阿达纳开拔（82 km，规则）。

### 八场｜前332 年 · 春 · 推罗（攻城，33.2709,35.1962）

- **入镜**：上一场战场直接开拔，沿海岸大道南下抵推罗（**不写出发据点、不设路标**：阿卡在推罗以南、属反方向，不作航点；库里没有西顿、比布鲁斯，用已有据点连接，绝不新建）。
- **人物**：攻 亚历山大（37500）｜守 推罗末代国王阿泽米尔库斯（9000；另有避难军民 3–4 万，非战斗人员不计）。主将队：英雄·骑马亚历山大 ／ 英雄·巴西达斯。
- **起因**：推罗人拒绝亚历山大入城向城中的麦勒卡特（希腊称赫拉克勒斯）献祭。
- **经过**：推罗是距大陆近千米的海岛城邦，峭立海中；亚历山大伐尽黎巴嫩山雪松，在惊涛间强行构筑六十米宽的跨海长堤；推罗以火船冲撞、弩炮轰击与蛙人破障死守，马其顿调塞浦路斯巨舰与攻城石弩日夜推进。
- **结局**：围城约七个月城破，推罗易主归马其顿；跨海长堤淤积使海岛此后永久成为半岛。
- **出镜**：自推罗南下 → 加沙。

### 九场｜前332 年 · 秋 · 加沙（攻城，31.5017,34.4668）

- **入镜**：自上一场推罗南下；路网实测取道**阿音贾鲁特—耶路撒冷—加沙**。
- **人物**：攻 亚历山大（37500，推罗战后未获大补）｜守 要塞守将巴提斯（10000；史无守军确数，据城破阵亡约一万推定）。主将队：英雄·骑马亚历山大 ／ 英雄·阿里斯提德。
- **起因**：加沙踞高地、距海约五英里、城墙高逾十八米，扼叙利亚通往埃及的大道；巴提斯拒不投降。
- **经过**：把推罗用过的攻城器械一并运来、在城下筑土山；守军曾出城焚烧器械，亚历山大在反击中肩部受伤，仍三次强攻不止。
- **结局**：城破，男丁被杀、妇孺贩为奴，巴提斯按库尔提乌斯所记被拖于战车之后处死。**加沙归马其顿，通往埃及的门户打开**；亚历山大随即进军埃及，波斯埃及总督马扎克斯不战而降，**孟菲斯归马其顿**，他并在孟菲斯加冕为法老。
- **出镜**：自加沙南下埃及（佩鲁西姆—孟菲斯—亚历山大城），再回师北上——这一节是**下一场的路标**，军团走过去，不许瞬移。

### 十场｜前331 年 · 秋 · 高加米拉（野战，36.56,43.444）

- **入镜**：上一场落点＝加沙城 → 路标 **佩鲁西姆 → 孟菲斯 → 亚历山大城 → 佩鲁西姆 → 加沙 → 推罗 → 大马士革 → 阿勒颇 → 埃德萨 → 尼尼微** → 战场。
- **人物**：攻 亚历山大（47000）｜守 大流士三世（85000）。主将队：英雄·骑马亚历山大 ／ 英雄·阿尔塔弗涅斯。
- **起因**：大流士三次遣使求和（赎回眷属、割让哈吕斯河以西、乃至愿与亚历山大平起平坐），皆被拒；他为镰刀战车铲平战场植被，并布下十五头印度战象。
- **经过**：马其顿方阵居中双列推进、两翼后斜；帕曼纽率色萨利与色雷斯骑兵死守左翼；亚历山大率伙伴骑兵自右翼缺口直插大流士本阵。
- **结局**：大流士弃阵东逃，波斯半壁与美索不达米亚全境入亚历山大之手；**巴比伦**总督马扎欧斯献城、波斯冬都**苏萨**随后亦下，两城归马其顿。
- **出镜**：战场 → 下一场自尼尼微开拔（34 km，规则）。

### 十一场｜前331 年 · 冬 · 乌克西亚隘口（野战，32.0457,48.8506）

- **入镜**：上一场战场 → 尼尼微 → 亚述城 → 巴比伦 → 苏萨 → 隘口（本场未写路标，编辑器点出路网实测经过 **苏萨、波斯波利斯** 供核对）。
- **人物**：攻 亚历山大（8000）｜守 马达泰斯（乌克西亚部落联盟，5000；史无兵数，按「能向历代波斯大王索取过路贡、又能以险隘伏击马其顿全军」推定千计）。主将队：英雄·骑马亚历山大 ／ 英雄·阿尔塔弗涅斯。
- **起因**：乌克西亚人是扎格罗斯山中非伊朗裔半游牧部落联盟，向来向过境军队索买路钱，也要亚历山大照付。
- **经过**：亚历山大明许走大道、如约纳贡；克拉特鲁斯先据高地断其退路，他自率精锐走北路袭取部落村落，再以接连强行军夺下隘口。
- **结局**：部落退往高地，正撞上守候已久的方阵，被四面合围；通往波斯腹地的山道尽开，幸存者乞和。**战场不易主。**
- **出镜**：战场 → 下一场自苏萨开拔（58 km，规则）。

### 十二场｜前330 年 · 1月（游戏记春）· 波斯门（野战，30.7083,51.5986）

- **入镜**：上一场落点＝乌克西亚战场 → 沿**苏萨—波斯波利斯大道（经波斯门那条路）**东南行 → 波斯门（实测沿路 402 km、直线 300 km = 1.34 倍，末段离路 0 公里）。
- **日历口径**：本役在**前330年1月**，属该年**年初**（英文维基 Battle of the Persian Gate 信息框 date = 330 BC、正文记一月）；游戏一年四季按春夏秋冬排、冬在年末，若记冬会被算到前330年**年底**，故数据记**春**（season 0），使它落在前330年年初、紧接前331年冬的乌克西亚隘口之后 —— 与推罗（前332年1月起围城、同样记春）同一处理。文案按史实写「前330年1月」。
- **人物**：攻 亚历山大（17000）｜守 阿里奥巴赞斯（34000）。主将队：英雄·骑马亚历山大 ／ 英雄·阿尔塔弗涅斯。
- **起因**：隘口窄得只容数人并行，北坡是滚石、南坡是箭雨，守军已在隘口垒起石墙。
- **经过**：他先轻敌冒进、没派斥候，全军人马被压在窄道里，成队死在石头与箭下，连阵亡者尸体都没能带回；后得俘虏或当地牧羊人引路，亲率精兵趁夜翻山绕至守军背后，托勒密与佩尔狄卡斯分路合围、克拉特鲁斯在营中牵制。

## 四、怎么写下一场（工序七步 · 一次只做一场）

1. **定幕**：这一场属于哪一幕？没有就新起一幕（幕名照史料阶段起，不进数据）。
2. **查史料**：英文维基条目为准 + 当地语种维基补细节 → 定**场次标题**（年 / 季 / 地名 / 野战还是攻城）。
3. **写入镜**（先线后点）：从**上一场落点**出发，按史料途经地设 `marchWaypoints` → 跑编辑器「行军路线实测」（一段直线 ≤400 km、绕远 ≤1.6 倍、末段离路 ≤40 km、渡海坐船）。
4. **写人物**：双方主帅按史料指名；主将队与对手主将队选英雄兵模，**看样子和年代，不看名字**。
5. **写戏**：起因（`inviteText` 邀约对白，文案不写兵力确数）／经过（战斗面板 description）／旁白（`briefing`）。
6. **写结局与出镜**：`result` 写真胜负 + `cityUpdates` 按历史写据点归属；**给下一场留好出发点**（本场落点＝下一场出发地）。
7. **过校验**：编辑器全项无红才能存 → 跑链体检 → 回本底本**补一张分场卡**。

> 编辑器在 `/battlefield-editor.html`；链体检 `npx tsx --import ./tools/sim-preload.mjs scratch/_audit_script_chain_all.mts`。

## 五、镜头纪律（一条镜头）

- **只有一路镜头**：跟主角亚历山大军团（`CameraFollowUI` 跟玩家所在军团）。其他军团不许有镜头、不许自己移动。
- **入镜 = 行军**：剧本期主角军团沿实际走过的路排一条纵队（乱入者打头 → 将军 → 前排 → 中排 → 后排），距战场 60 km 展开成阵，逐帧走位不瞬移；海运段同样是长蛇阵，船朝向脚下航迹的切线。
- **守方本地生成**：野战直接生成在战场对阵位、攻城战直接生成在城里——**守方不走、不从任何据点开拔**。
- **出镜 = 班师与承前**：战毕双方史实军团撤场班师、主帅归城；主角军团留在原地，正是下一场的出发点。
- **其余军团**：剧本期不随机生军团、非剧本军团不寻敌、无减兵、无补兵、无战略技；据点一律先过年代闸门才上图。

## 七、行军路线逐场核对（主人令：从第一场起逐场分析、逐条记下，最后总结该怎么连路）
