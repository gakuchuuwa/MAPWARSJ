>
> 本文件就是这部剧本的**底本**（screenplay）：**一片一片、一场一场地读下来，就是亚历山大这一生的这一段战争史**。
> 写事件时照它填；**它本身不改任何游戏数据**，也不新增任何字段——剧本的每一句都写在既有字段里（见 §一）。

**一部剧本 = 一部人物传记 = 一个人物一条线。** 主角：亚历山大（gen_alexander_great）。

> 🔴 **主人 2026-09-28 定死工序最高准则**：
> - **「点没有做好，不要连线做路，做了也错的。」**
> - **「路没有做好不要写文案，写了以后错了还要改，做了也是错的。」**
>
> 🔴 **主人 2026-09-28 定死四大铁律**：
> 1. **道路划分铁律**：**150-500KM 算一条路**，全剧总长 25,641 km 精确划分为 **95 条路**。
> 2. **行军驻军铁律**：大军中途穿城全速行进不停歇；**只有在道路起点和终点，若播报未完才驻军**（展开常规阵型歇脚）。
> 3. **尊号称呼铁律**：绝对严禁出现「大帝」、「大帝阵亡」等后世称谓，**一律使用历史本名（如「亚历山大」、「亚历山大战死」）**。
> 4. **第一片终点铁律**：底比斯打完后亚历山大率大军**班师佩拉过冬**，第一片终点收官于【佩拉】（共 11 条路）；第二片开春在【佩拉】誓师东征（共 10 条路）。
**镜头只有一路**：跟主角军团（`CameraFollowUI` 跟玩家所在军团）；其他军团不许有镜头、也不许自己移动。

## 一、剧本要素 → 现有字段对照（**不需要新字段**）

| 剧本要素 | 写在哪儿（现有字段） |
|---|---|
| **片**（Part） | 不进数据——**只在本底本里分段**（战略区域，共 6 片）。游戏按 `year` / `season` 自动排场次先后 |
| **场次标题** | `title`（战役全名，带年份前缀）+ `year` / `season` / `type` |
| **场景地点** | 野战：`fieldBattleData.location` + `Battlefields.ts` 的 `bf_*` 战场记录；攻城战：`siegeData.defenderCityId`（被攻打的那座城） |
| **入镜**（这场从哪来） | `src/events/scriptEventStart.ts` 的出发地（没写 `startCityId` 就是**上一场落点**）+ `marchWaypoints` + 出兵据点 `attackerSourceCityId`（记账） |
| **出镜**（打完往哪去） | `cityUpdates`（战后据点归谁）+ 下一场的出发地（链体检逐场核） |
| **人物** | `attackerGeneralId` / `defenderGeneralId`（战场人物表 `src/data/BattlefieldCharacters.ts` 兜底）+ 主将队 `commanderUnit` / `foeCommanderUnit` |
| **起因 · 台词** | `inviteText`（邀约对白，**只显示文字不念**，称呼合人物时代与文化） |
| **旁白** | 野战：战场记录 `bf_*.briefing`（赶路播报）；攻城战：事件自身 `briefing` |
| **经过 · 转折** | `fieldBattleData.description` / `siegeData.description`（战术模式战斗面板）+ 13 项史料依据 |
| **结局 · 归宿** | `result` + `cityUpdates` |
| **镜头** | 全局一条：行军纵队 `Army.columnMarch` → 距战场 60 km 展开成阵；守方**本地生成**（野战在战场对阵位、攻城战在城里） |

## 四、怎么写下一场（工序七步 · 一次只做一场）

1. **定片**：这一场属于哪一片？没有就新起一片（片＝战略区域，照史料阶段起名，不进数据；现共 6 片）。
2. **查史料**：英文维基条目为准 + 当地语种维基补细节 → 定**场次标题**（年 / 季 / 地名 / 野战还是攻城）。
3. **写入镜**（先线后点）：从**上一场落点**出发，按史料途经地设 `marchWaypoints` → 跑编辑器「行军路线实测」（一段直线 ≤400 km、绕远 ≤1.6 倍、末段离路 ≤40 km、渡海坐船）。
4. **写人物**：双方主帅按史料指名；主将队与对手主将队选英雄兵模，**看样子和年代，不看名字**。
5. **写戏**：起因（`inviteText` 邀约对白，文案不写兵力确数）／经过（战斗面板 description）／旁白（`briefing`）。
6. **写结局与出镜**：`result` 写真胜负 + `cityUpdates` 按历史写据点归属；**给下一场留好出发点**（本场落点＝下一场出发地）。
7. **过校验**：编辑器全项无红才能存 → 跑链体检 → 回本底本**补一张分场卡**。

> 编辑器在 `/battlefield-editor.html`；链体检 `npx tsx --import ./tools/sim-preload.mjs scratch/_audit_script_chain_all.mts`。

## 五、镜头纪律（一条镜头）

- **只有一路镜头**：跟主角亚历山大军团（`CameraFollowUI` 跟玩家所在军团）。其他军团不许有镜头、不许自己移动。
- **入镜 = 行军**：剧本期主角军团沿实际走过的路排一条纵队（乱入者打头 → 将军 → 前排 → 中排 → 后排），距战场 60 km 展开成阵，逐帧走位不瞬移；海运段同样是长蛇阵，船朝向脚下航迹的切线。
- **守方本地生成**：野战直接生成在战场对阵位、攻城战直接生成在城里——**守方不走、不从任何据点开拔**。
- **出镜 = 班师与承前**：战毕双方史实军团撤场班师、主帅归城；主角军团留在原地，正是下一场的出发点。
- **其余军团**：剧本期不随机生军团、非剧本军团不寻敌、无减兵、无补兵、无战略技；据点一律先过年代闸门才上图。

## 七、行军路线逐场核对（主人令：从第一场起逐场分析、逐条记下，最后总结该怎么连路）

> ③ **判定**：✓ 对 ／ ✗ 不对（写明错在哪） ④ **待修**：属「城没接路」／「城际路缺」／「战场选点离路远」／「路形蜿蜒不算错」。
> 实测工具：`node scratch/_probe_route_adhoc.mjs <起点lat> <lng> <终点lat> <lng> [途经城id…]`（逐段＋沿途城）、
