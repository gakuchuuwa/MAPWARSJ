## 三、分场卡

**1｜前321 · 华氏城（攻城，剧终）**　①入镜：塔克西拉 → 恒河平原 → 华氏城。②人物：攻 **旃陀罗笈多**（库里有）与谋臣**考底利耶**（库里没有）｜守 难陀王朝末王**达那·难陀**（库里没有）。兵力史书无载（希腊史料说难陀有步兵二十万、战象数千，属夸大），全部推定。主将队：待看素材定（古典段南亚英雄兵模库里没有，照 §二.5 先保年代）。③起因：难陀王横征暴敛、民怨沸腾。④经过：据说第一次直攻都城失败，后改为先取边境村镇、步步蚕食，最后围攻华氏城（出自佛教、耆那教传说，据说如此）。⑤结局：达那·难陀被杀（一说被放逐），孔雀王朝建立（通行说法）。**华氏城归孔雀**（本来就是孔雀本城，不用改）。⑥出镜：剧终；此后收复旁遮普的希腊驻军、前305–303 与塞琉古一世交战后议和（见 [`塞琉古一世剧本.md`](塞琉古一世剧本.md) B 档），晚年据说皈依耆那教、绝食而终（B 档尾声）。⑦出处：英文维基 *Chandragupta Maurya*、*Nanda Empire* <https://en.wikipedia.org/wiki/Nanda_Empire>（灭难陀之战独立条目**待核**，若无，按判据 1 本线为 0 场，只能挂在别人的线里当背景）。
