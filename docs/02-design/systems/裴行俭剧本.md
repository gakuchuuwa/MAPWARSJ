## 三、分场卡

### 场 1｜680 · 黑山之战（野战，剧终）
- **片/段**：一 · 黑山大捷 / 段一
- **① 入镜**：碎叶 → 长安 → 晋阳 → 大同 → 黑山。
- **势力/地点**：攻 唐｜守 东突厥复国势力（库里突厥系势力，做事件时查）。地点 黑山（野战）。
- **② 人物**：攻 定襄道行军大总管**裴行俭**（库里有）、**程务挺**、**王方翼**（库里没有）｜守 自立为可汗的**阿史那泥熟匐**（库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：东突厥阿史德温傅、奉职二部反唐，立阿史那泥熟匐为可汗，单于府所属二十四州皆叛（史实，数字不进文案）。
- **④ 经过**：此前唐军粮车屡被突厥劫掠；裴行俭伪装运粮车三百辆，每车藏壮士五人，突厥来劫，壮士突出，尽歼之（史实，数字不进文案）；后在黑山与突厥主力大战，屡破之（史实）；又料定夜有风雨，令移营高冈，是夜营地果被大水淹没（史实）。
- **⑤ 结局**：突厥大败，阿史那泥熟匐被部下所杀，奉职被擒（史实）。不易主。
- **⑥ 出镜**：剧终。681 年再平阿史那伏念，裴行俭许其不死，宰相裴炎争功，杀伏念，裴行俭叹曰「浑、濬旧事，古今耻之」（史实）；682 年卒（B 档尾声）。
- **⑦ 出处**：英文维基 *Pei Xingjian*；《旧唐书·裴行俭传》。
- **文案三件**：
  - **briefing**：公元六八〇年春，东突厥诸部反唐，拥立阿史那泥熟匐为可汗。唐军的粮车屡屡被突厥人劫走，主帅裴行俭据说想出了一个主意：往粮车里藏人。
  - **inviteText**：「诸位，突厥人爱抢粮车，那就让他们抢。车里装的不是粮食，是你们。」
  - **description**：突厥骑兵果然又来劫粮，车里的唐军壮士一跃而出，把劫粮的突厥兵杀得干干净净。此后唐军在黑山与突厥主力大战，接连告捷；一天傍晚裴行俭突然下令移营到高处，夜里暴雨骤至，原来的营地被大水淹没，将士们这才佩服他的先见之明。
