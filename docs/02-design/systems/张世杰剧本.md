## 三、分场卡

### 场 1｜1275 秋 · 焦山之战（主角守）
- 同 [`阿术剧本.md`](阿术剧本.md) 场 2（数据以那边为准）。
- **② 人物**：主将队按 §二.5 看样貌选城堡时代华夏英雄兵模。
- **inviteText**（张世杰线专用）：「诸位，把船锁在一起！今天不进不退，就在这江心里和他们拼了。」
- **⑤ 结局补**：张世杰以铁索连舟示必死，反被火攻（史实）；后世多以此为他用兵之失。

### 场 2｜1277 · 泉州（攻城）
- **片/段**：一 / 段二 闽粤
- **① 入镜**：广陵 → 温州 → 冶城 → 刺桐。
- **势力/地点**：攻 南宋（`song`）｜守 蒲寿庚（降元，库里泉州 `quanzhou`）。据点 **刺桐** `city_qingjingsi`（战后不易主）。
- **② 人物**：攻 **张世杰**｜守 泉州市舶使**蒲寿庚**（阿拉伯裔海商，库里没有）。
- **③ 起因**：宋端宗行朝南下泉州，蒲寿庚闭城拒纳，还杀害城中宋宗室，降元（史实）。
- **④ 经过**：张世杰率军与畲族义军围城三月，蒲寿庚坚守待援（史实）。
- **⑤ 结局**：元将唆都率援军来到，张世杰撤围（史实）。**不易主**。
- **⑥ 出镜**：护行朝继续南走广东。
- **⑦ 出处**：英文维基 *Pu Shougeng*；*Zhang Shijie*（泉州之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元一二七七年，宋朝的小朝廷一路漂泊到了泉州，却被掌管海港的蒲寿庚关在了城外。据说蒲寿庚还杀了城里的宋朝宗室，转投了元朝。张世杰怒而攻城。
  - **inviteText**：「诸位，皇上的船就停在港外，泉州人却不肯开门。蒲寿庚忘了是谁让他发的财。」
  - **description**：张世杰联合当地的畲族义军把泉州围了起来，蒲寿庚闭城死守。围了几个月，城还没有攻下，元军援兵已经赶到，张世杰只得解围而去。

### 场 3｜1279 春 · 厓山海战（主角守，剧终）
- **片/段**：一 / 段三 厓山
- **① 入镜**：刺桐 → 广东沿海 → 海阳 → 厓山。
- **势力/地点**：攻 元（`yuan_d`）｜守 南宋。地点 厓山海面（战后 `cityUpdates` 按历史写 **厓山** 归 `yuan_d`；库里厓山是关隘型据点，本仗为海战，见疑点 2）。
- **② 人物**：攻 元将**张弘范**（库里没有）、**李恒**（库里没有）｜守 **张世杰**、丞相**陆秀夫**（库里没有）、少帝**赵昺**。
- **③ 起因**：宋行朝退到新会厓山，是最后的据点。
- **④ 经过**：张世杰把千余艘战船用大索连成一字阵，把少帝的船围在中间；元军断绝宋军汲水、砍柴之路，宋军口渴饮海水而病；张弘范南北两面夹攻，乘潮涨潮落两次进攻（史实）。
- **⑤ 结局**：宋军全线崩溃，陆秀夫背着少帝赵昺投海；**厓山归元**，南宋亡（史实）。
- **⑥ 出镜**：剧终。张世杰突围后想再图恢复，在海陵山遭遇飓风，舟覆溺死（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Yamen*。
- **文案三件**：
  - **briefing**：公元一二七九年春，南宋最后的朝廷停泊在厓山的海湾里。张世杰把战船用大索连成一道长墙，把年幼的皇帝赵昺护在中间，据说船上还有无数随行的百姓。
  - **inviteText**：「诸位，陆地已经没有我们的地方了，就在这海上守住大宋最后的旗帜。」
  - **description**：元军截断了宋军打水砍柴的去路，宋军只能喝海水，病倒了很多人。张弘范趁着涨潮落潮两面夹攻，宋军阵线崩溃，陆秀夫背着少帝投海而死，南宋就此灭亡。
