# 李世民 · 剧本底本（一部人物传记）

> 年代：617–645（隋末唐初，唐太宗亲征高句丽）。主角 **李世民**——**库里有**：武将 `tang_lishimin`，势力 `tang`（唐），本城 `city_changan` 长安。战后易主写 `tang`。
> 本底本不改数据、不新建任何东西。资料：网络搜索读英文维基摘要；**中文、韩文维基未能直接查**，细节依《旧唐书》《资治通鉴》通行说法；**路网未实测**。

> 🔴 **先说清楚**：AGENTS.md 血训（2026-09-19）——虎牢关战役**只有攻（唐）守（夏）两方**，主人当时令删掉擅自建的「郑」势力与王世充。本底本照此：虎牢之战只写唐对夏；洛阳围王世充**不单列**（B 档），**不提建郑**。

## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜617 秋 · 霍邑之战（攻城）**　①晋阳 → 贾胡堡 → 霍邑。②攻 **李渊**（主帅）、**李世民**、李建成｜守 隋将**宋老生**（库里查不到）。兵力史书未明，推定。主将队：待看素材定。③李渊起兵南下关中，宋老生守霍邑扼路。④大雨阻军多日，粮将尽，李渊一度想回师，李世民力谏；雨停后李渊、李建成在城东，李世民在城南，佯退诱宋老生出城，李世民率骑兵从南原冲下，横击其阵。⑤宋老生败退至城下被杀，霍邑破（史实）。⑥入关中。⑦英文维基 *Battle of Huoyi* <https://en.wikipedia.org/wiki/Battle_of_Huoyi>（主帅为李渊，见疑点 2）。

**2｜618 冬 · 浅水原之战**　①霍邑 → 渡河 → 长安 → 新平 → 浅水原。②攻 **李世民**｜守 西秦薛仁杲部将**宗罗睺** 十余万（史实）。③第一次浅水原唐军在李世民患病时失利；这一次李世民坚守不战六十余日，待其粮尽。④先派梁实在浅水原诱敌、宗罗睺猛攻数日；李世民见敌疲，自率精骑从背后突袭，宗罗睺大溃；李世民只带两千余骑穷追至折墌城下。⑤薛仁杲出降（史实）。陇右平定。⑥东向。⑦*Battle of Qianshuiyuan* <https://en.wikipedia.org/wiki/Battle_of_Qianshuiyuan>。

**3｜621 夏 · 虎牢之战**　①新平 → 长安 → 洛阳 → 虎牢。②攻 夏王**窦建德**（库里有：`xia` 势力 `doujiande`）十至十二万（史实，按 §一.2 封顶）｜守 **李世民** 不足一万（史实）。③李世民围洛阳王世充，窦建德率大军来救，李世民分兵据守虎牢关挡住。④相持月余，窦建德在汜水东岸列阵二十里，从早到午士卒饥疲；李世民率骑兵冲入敌阵，程知节、秦叔宝、宇文歆卷旗突阵，直透阵后张唐旗，夏军大溃。⑤窦建德负伤被俘（史实）；王世充见救兵已败，出洛阳投降。**洛阳归唐**（`city_luoyang` → `tang`）。⑥回长安献俘。⑦*Battle of Hulao* <https://en.wikipedia.org/wiki/Battle_of_Hulao>。

**4｜645 夏 · 辽东城之战（攻城）**　①虎牢 → 长安 → 洛阳 → 幽州 → 营州 → 辽东城。②攻 **唐太宗李世民**（李勣先锋）｜守 高句丽辽东城守军（守将名不详）。兵力推定。③唐太宗以高句丽渊盖苏文弑君为由亲征。④唐军以抛车飞石、撞车破城，乘南风放火烧城西南楼。⑤城破（史实），唐于其地置辽州。**襄平（辽东城）归唐**（`city_liaoyang` → `tang`）。⑥进逼安市。⑦英文维基 *Goguryeo–Tang War* 相关条目（辽东城有无独立条目**待核**）。

**5｜645 夏 · 驻跸山之战**　①→ 驻跸山。②攻 李世民 约三万（史实）｜守 高句丽**高延寿**、**高惠真**率十五万援军（史实，按 §一.2 封顶）。③高句丽大军来救安市。④唐太宗登山指挥，李勣列步骑一万五千于西岭，长孙无忌率一万一千人绕到敌后，太宗亲率四千骑藏在北山；鼓角齐鸣，四面夹攻；薛仁贵白袍持戟冲阵，因此成名。⑤高延寿、高惠真率三万六千余人投降（史实）。唐太宗把这座山命名为「驻跸山」。⑥回攻安市城。⑦*Battle of Mount Jupil* <https://en.wikipedia.org/wiki/Battle_of_Mount_Jupil>。

**6｜645 秋 · 安市城之战（攻城，剧终）**　①→ 安市城。②攻 李世民（信息框写不详，推定）｜守 **安市城主**（韩国史称杨万春，名字史书存疑）约 5000（史实）。③安市城扼唐军南下之路。④唐军日夜猛攻，又在城东南筑土山，六十日不下；土山崩塌压破城墙，反被守军夺去。⑤辽东天寒、粮草将尽，唐太宗九月班师（史实）。不易主。⑥剧终：649 年李世民卒（B 档）。⑦*Siege of Ansi* 英文维基（条目名以站内为准）。

## 六、疑点
1. 第一场出发地取晋阳而非规则算出的长安（理由见 §二）。
2. **霍邑之战主帅是李渊**，李世民是分兵统帅，与塞琉古底本加沙之战同类（主角在场、领一军）。
3. 北京建立年代写 1421、临汾写 581，途经地能否上图要核。
4. 安市城主「杨万春」之名只见于后世朝鲜文献，文案里写「安市城主」。
