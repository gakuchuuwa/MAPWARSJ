## 三、分场卡

### 场 1｜1659 · 南京之战（攻城）
- **片/段**：一 · 北伐南京 / 段一 南京
- **① 入镜**：刺桐（厦门）→ 坐船北上 → 长江 → 广陵 → 金陵。
- **势力/地点**：攻 明郑｜守 清（库里清系势力，做事件时查）。据点 **金陵** `city_nanjing`（战后不易主）。
- **② 人物**：攻 **郑成功**（库里有）、**甘辉**、**张煌言**（库里没有）｜守 清两江总督**郎廷佐**、崇明总兵**梁化凤**（库里没有）。主将队：帝国时代华夏英雄兵模（1659 年属帝国段，按 §二.5 看样貌选）；火炮、铁人军可用（史实）。
- **③ 起因**：郑成功联合张煌言北伐，意图恢复明朝。
- **④ 经过**：郑军连破瓜洲、镇江，兵临南京；郎廷佐诈降拖延，郑成功轻敌，屯兵城下不急攻，将士解甲宴饮（史实）；梁化凤率骑兵夜出神策门，突袭郑军营垒，郑军大乱（史实）。
- **⑤ 结局**：郑军大败，大将甘辉被俘不屈而死（史实）。**不易主**。
- **⑥ 出镜**：退回厦门，决意东取台湾为根据地。
- **⑦ 出处**：英文维基 *Siege of Nanjing (1659)*（条目名以站内为准）；*Koxinga*。
- **文案三件**：
  - **briefing**：公元一六五九年夏，郑成功率领大军乘船溯长江而上，连下瓜洲、镇江，兵临南京城下。江南各地据说纷纷响应，清朝的两江总督郎廷佐派人来说，只要再等些日子，他就开城投降。
  - **inviteText**：「诸位，南京城里的人已经心慌了，郎廷佐说要投降。那就等他几天，让将士们歇一歇。」
  - **description**：郑成功相信了清军的缓兵之计，大军在城外松懈下来。一天夜里，清将梁化凤率骑兵从神策门突然杀出，郑军营垒大乱，全线溃败，大将甘辉被俘遇害，北伐就此失败。

### 场 2｜1661–1662 · 热兰遮之围（攻城，剧终）
- **片/段**：二 · 收复台湾 / 段二 热兰遮
- **① 入镜**：金陵 → 刺桐 → 横渡海峡 → 澎湖 → 承天。
- **势力/地点**：攻 明郑｜守 荷兰东印度公司（库里荷兰系势力，做事件时查）。据点 **承天** `city_tainan`（大员；战后 `cityUpdates` 归 `ming_zheng`）。
- **② 人物**：攻 **郑成功**、**马信**（库里没有）｜守 荷兰大员长官**揆一**（Frederick Coyett，库里没有）。
- **③ 起因**：郑成功南京兵败后需要稳固的根据地；荷兰通事何斌献台湾地图，言鹿耳门水道可乘潮而入（史实）。
- **④ 经过**：郑军趁涨潮由鹿耳门驶入台江内海（史实）；先取普罗民遮城（赤嵌），再围热兰遮城；荷兰援军舰队被击退；围城九月，郑军以炮轰城（史实，数字不进文案）；荷军叛兵献策攻乌特勒支碉堡（史实）。
- **⑤ 结局**：揆一投降，荷兰人撤离台湾（史实）。**承天归明郑**，郑成功改赤嵌为承天府。
- **⑥ 出镜**：剧终。郑成功收复台湾数月后病逝（1662 年，年三十九，史实；年岁不进文案；B 档尾声）。
- **⑦ 出处**：英文维基 *Siege of Fort Zeelandia*。
- **文案三件**：
  - **briefing**：公元一六六一年春夏之交，郑成功率领舰队横渡台湾海峡。荷兰人以为鹿耳门的水道太浅，大船开不进来，据说郑成功却算准了涨潮的日子。
  - **inviteText**：「诸位，潮水来了，船就能过去。台湾本是我们先人经营的地方，今天要把它拿回来。」
  - **description**：郑军的船队趁着涨潮驶过鹿耳门，出现在荷兰人的眼前。郑军先拿下赤嵌城，再把热兰遮城团团围住，击退了荷兰的援军，又用火炮日夜轰城。围城很久之后，荷兰长官揆一终于投降，荷兰人离开了台湾。
