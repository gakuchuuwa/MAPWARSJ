## 三、分场卡

### 场 1｜1241 春 · 赫梅尔尼克之战（野战）
- **片/段**：一 · 波兰偏师 / 段一
- **① 入镜**：基辅 → 沃伦 → 桑多梅日 → 赫梅尔尼克。
- **势力/地点**：攻 蒙古｜守 小波兰（库里克拉科夫 `piyasite` 皮雅斯特）。地点 赫梅尔尼克（野战）。
- **② 人物**：攻 **拜答儿**、**合丹**（库里没有）｜守 克拉科夫督军**弗沃济米日**、桑多梅日督军**帕科斯瓦夫**（库里没有）。主将队：城堡时代草原英雄兵模；对手城堡时代西欧/斯拉夫骑士英雄兵模（按 §二.5 看样貌）。
- **③ 起因**：为防止波兰援助匈牙利，拔都派偏师北进波兰。
- **④ 经过**：波兰骑士冲击蒙古军，蒙古军佯退，把波兰骑兵引入射程后合围（通行说法）。
- **⑤ 结局**：小波兰贵族骑士几乎全军覆没，弗沃济米日战死（史实）。
- **⑥ 出镜**：西进克拉科夫；波兰大公波列斯瓦夫五世已经出逃，城被焚（B 档）。
- **⑦ 出处**：英文维基 *Battle of Chmielnik*。
- **文案三件**：
  - **briefing**：公元一二四一年三月，蒙古偏师闯进了小波兰。克拉科夫与桑多梅日的贵族骑士们集结起来，要在赫梅尔尼克挡住这些东方来的骑手。
  - **inviteText**：「朋友，拔都叫我们来这里，是不让波兰人去救匈牙利。他们的骑士冲得很猛，那就让他们冲。」
  - **description**：波兰骑士一冲，蒙古军便往后退，等骑士们冲进了箭雨之中，四面的蒙古骑兵才合拢过来。小波兰的贵族几乎都死在了这片田野上。

### 场 2｜1241 春 · 莱格尼察之战（野战，剧终）
- **片/段**：一 / 段一
- **① 入镜**：赫梅尔尼克 → 克拉科夫 → 奥得河 → 莱格尼察。
- **势力/地点**：攻 蒙古｜守 西里西亚（库里没有西里西亚公国；亨利二世库里在 `pelianci` 势力）。地点 莱格尼察（野战，瓦尔施塔特）。
- **② 人物**：攻 **拜答儿**、合丹、斡儿答（库里没有）｜守 西里西亚公**亨利二世·虔诚者**（库里有 `pelianci_hengli2`），条顿骑士、圣殿骑士分队、摩拉维亚矿工兵（史实）。
- **③ 起因**：亨利二世集结西里西亚、波兰残部与骑士团，等待波希米亚王瓦茨拉夫一世的援军。
- **④ 经过**：蒙古军抢在波希米亚援军到达之前开战；佯退诱骑士追击，放烟幕隔断骑兵与步兵，再以弓骑围射（通行说法）。
- **⑤ 结局**：联军大败，亨利二世战死、首级被挑在枪上示众（史实）。不易主。
- **⑥ 出镜**：剧终。拜答儿南下摩拉维亚，与拔都主力在匈牙利会合（B 档）；1242 年东撤。
- **⑦ 出处**：英文维基 *Battle of Legnica*。
- **文案三件**：
  - **briefing**：公元一二四一年四月，西里西亚公亨利二世在莱格尼察城外列阵，骑士团的旗帜在他身边飘扬。据说波希米亚国王的援军已经不远了，蒙古人不打算等他们。
  - **inviteText**：「朋友，他们在等援军。我们不能让他们等到。」
  - **description**：蒙古军佯退，骑士们追了上去，一阵浓烟升起，把骑兵和后面的步兵隔开了。蒙古弓骑在烟里四面放箭，联军溃败，亨利二世战死在乱军之中。
