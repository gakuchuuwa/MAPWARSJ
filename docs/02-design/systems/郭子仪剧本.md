## 三、分场卡

### 场 1｜757 · 香积寺之战（野战）
- **片/段**：一 · 收复两京 / 段一 长安
- **① 入镜**：岐山（凤翔）→ 奉天 → 沣水 → 香积寺。
- **势力/地点**：攻 唐（与回纥援军）｜守 安史燕军（库里燕系势力，做事件时查）。地点 香积寺北（野战），战后按历史 `cityUpdates` 写 **长安** 归唐。
- **② 人物**：攻 天下兵马元帅**广平王李俶**（后唐代宗，库里没有）、副元帅**郭子仪**（库里有）、前军**李嗣业**（库里没有）、回纥叶护（库里没有）｜守 燕将**安守忠**、**李归仁**（库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：安禄山死，其子安庆绪继立；唐肃宗借回纥兵收复长安。
- **④ 经过**：两军在香积寺北列阵；燕军先冲，唐前军阵乱，李嗣业袒身执长刀立于阵前，大呼奋击，所向披靡（史实）；燕军伏精骑于阵东，被回纥兵从后掩杀（史实）。
- **⑤ 结局**：燕军大败，斩首六万（史实，数字不进文案），安守忠等弃长安东逃。**长安归唐**。
- **⑥ 出镜**：东进追击。
- **⑦ 出处**：英文维基 *Battle of Xiangji Temple*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元七五七年秋，副元帅郭子仪与广平王李俶率领唐军与回纥援军，来到长安城南的香积寺北。长安已经沦陷了很久，城里的燕军据说早已准备好迎战。
  - **inviteText**：「诸位，长安就在眼前，陛下在凤翔等着我们的消息。今天拿不下长安，我们就没脸回去。」
  - **description**：燕军率先冲击，唐军前阵一度动摇，猛将李嗣业脱掉上衣、手持长刀冲在最前，硬生生把阵线顶了回去。燕军埋伏在东边的骑兵又被回纥兵从背后截杀，全军溃败，长安重回唐朝手中。

### 场 2｜757 · 新店之战（野战，剧终）
- **片/段**：一 / 段二 洛阳
- **① 入镜**：长安 → 潼关 → 函谷关 → 渑池 → 新店。
- **势力/地点**：攻 唐｜守 燕。地点 陕州新店（野战），战后按历史 `cityUpdates` 写 **洛阳** 归唐。
- **② 人物**：攻 **郭子仪**、回纥叶护｜守 燕御史大夫**严庄**、安庆绪所遣援军（库里没有）。
- **③ 起因**：安庆绪倾洛阳之兵西援陕州。
- **④ 经过**：燕军依山列阵，唐军初战不利；回纥兵从南山背后出击，扬起尘土，燕军回头惊呼「回纥至矣」，阵形崩溃（史实）。
- **⑤ 结局**：燕军大败，安庆绪弃洛阳北逃邺城（史实）。**洛阳归唐**。
- **⑥ 出镜**：剧终。唐肃宗对郭子仪说「吾之家国，由卿再造」（史实）；759 年邺城九节度之败，郭子仪背锅被夺兵权（B 档）；765 年单骑见回纥、退吐蕃（B 档）；781 年卒，享年八十五（年岁不进文案）。
- **⑦ 出处**：英文维基 *Guo Ziyi*；*An Lushan Rebellion*。
- **文案三件**：
  - **briefing**：公元七五七年冬，安庆绪把洛阳所有的兵力都派到了陕州，想把唐军挡在新店。燕军依山列阵，居高临下，唐军最初的冲锋被打了回来。
  - **inviteText**：「诸位，正面打不动不要紧，回纥的骑兵已经绕到南山后面去了。等山后扬起尘土，就是我们再冲的时候。」
  - **description**：南山背后突然尘土飞扬，回纥骑兵呼啸而出。燕军回头一看，惊呼回纥来了，阵形顿时崩溃。安庆绪丢下洛阳逃往邺城，两京收复，唐肃宗说，大唐是郭子仪再造的。
