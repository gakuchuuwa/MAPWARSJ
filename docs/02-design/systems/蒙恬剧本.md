## 三、分场卡

### 场 1｜前215 · 河南之战（野战）
- **片/段**：一 · 北逐匈奴 / 段一
- **① 入镜**：肤施 → 河南地。
- **势力/地点**：攻 秦｜守 匈奴（库里匈奴系势力，做事件时查）。地点 河南地（野战）。
- **② 人物**：攻 **蒙恬**（库里有）｜守 匈奴**头曼单于**（冒顿之父，库里没有）。主将队：古典时代华夏英雄兵模；对手古典草原英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：秦始皇巡游北边，据说方士献书言「亡秦者胡也」，遂命蒙恬北击匈奴（《史记》，据说如此）。
- **④ 经过**：蒙恬率大军渡河北上，击败匈奴，收复河南地（史实，细节史书简略）。
- **⑤ 结局**：匈奴北退七百余里（《史记》，数字不进文案）；秦在河南地设四十四县（史实）。不易主（河南地无据点；九原一带归秦见疑点 2）。
- **⑥ 出镜**：北渡黄河，取高阙、阴山。
- **⑦ 出处**：《史记·蒙恬列传》《匈奴列传》；英文维基 *Meng Tian*（「河南之战」独立条目待核）。
- **文案三件**：
  - **briefing**：公元前二一五年，秦始皇命大将蒙恬率领大军北上。黄河拐弯处那片水草丰美的河南地，已经被匈奴人占据了很久。据说头曼单于还不知道，秦人的铁骑正在逼近。
  - **inviteText**：「诸位，陛下要把匈奴人赶出河南地。黄河以南，以后不许再有他们的帐篷。」
  - **description**：秦军渡河北击，匈奴人抵挡不住，一路向北退去。河南地重新回到了秦的手中，蒙恬在这里设县置吏，迁来了中原的百姓。

### 场 2｜前214 · 高阙（攻城·关隘，剧终）
- **片/段**：一 / 段一
- **① 入镜**：河套 → 九原 → 高阙塞。
- **势力/地点**：攻 秦｜守 匈奴。据点 **高阙塞** `city_gaoque`（战后 `cityUpdates` 归秦）。
- **② 人物**：攻 **蒙恬**｜守 匈奴守军（主将史书未载名）。
- **③ 起因**：蒙恬渡河北上，要夺取阴山山口，把匈奴挡在阴山以北。
- **④ 经过**：秦军攻取高阙、阳山、北假一带（《史记》，细节简略）。
- **⑤ 结局**：**高阙塞归秦**（史实）。
- **⑥ 出镜**：剧终。蒙恬在此后十余年间修筑长城，西起临洮、东至辽东，又修直道自九原直通咸阳（B 档）；前210 年秦始皇死，赵高、李斯矫诏赐死扶苏，蒙恬被囚后服药自尽（史实，B 档尾声）。
- **⑦ 出处**：《史记·蒙恬列传》；英文维基 *Meng Tian*。
- **文案三件**：
  - **briefing**：公元前二一四年，蒙恬的大军渡过黄河，来到了阴山脚下。山口上的高阙，就像一扇打开的门，门的那一边是匈奴人的草原。
  - **inviteText**：「诸位，把高阙拿下来，阴山就是秦的城墙。以后匈奴人再想南下，得先问问这座山。」
  - **description**：秦军攻上山口，夺取了高阙，匈奴人退到了阴山以北。蒙恬随后沿着山脊修筑长城，据说此后很多年，匈奴人都不敢南下牧马。
