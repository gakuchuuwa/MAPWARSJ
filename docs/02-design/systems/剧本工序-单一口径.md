# 亚历山大东征 · 剧本工序（单一口径 · 一页纸）

> 🔴 **这页是剧本的唯一口径**：写剧本、检查剧本、改口径，**先改这一页**，再动数据。
> `AGENTS.md` 只作历史与血训存档（很长，我每轮看不全）；本页短，每轮整份读。
> 最后更新：2026-09-29（路数＝句数 20/20 对齐、全剧账 83 路／23687 公里／7949 字、补 3 处缺句、校验工具表）。
> 2026-09-28 主人定：「路要大于 150KM 小于 500KM，除非有战场」。

## 一、结构：以人物为核心

**片（战略区域）→ 段（＝一场）→ 点 ＋ 路（段由点和路构成）→ 句（一路一句）**

| 层 | 是什么 | 例（第 1 片） |
|---|---|---|
| 片 | 战略区域，共 **6 片** | 巴尔干平叛与希腊整合（前335） |
| 段 | **一段＝一场**，共 **20 段** | 段1｜第 1 场 海姆斯山战役 |
| 点 | **战役点**（这一场打在哪）＋ **影响地**（战后易主的据点） | 点＝海姆斯山；影响地＝战后 `cityUpdates` 里那些城 |
| 路 | **行军路线**：上一场落点到本场战斗点之间的一条路 | 佩拉 → 普罗夫迪夫（321 公里） |
| 句 | **一条路一句话**，走到哪讲到哪 | 这 321 公里那一句 |

**连线的铁律：路必须首尾相接。** 上一段末路的终点 ＝ 下一段首路的起点；断了就是错的。

## 二、路的尺子（唯一口径）

1. **一条路 150–500 公里。**
2. 🔴 **例外：通向战场／被攻据点的那一段，不受 150 公里下限**（战场可以更近）。
   例：塞乌托波利 → 海姆斯山战场 **17 公里**，照样算一条路 —— 剔掉它，路就断了。
3. **起点 ＝ 上一场最终落点**：攻城战＝那座城；野战＝那处战场；进占／过冬＝进驻的那座城。
   事件里写死的「出发据点」优先（那是「军团此刻在哪」，不是记账栏）。
4. 单腿超 500 公里的路网边（如 哈利卡纳苏斯→戈尔迪乌姆 854）无法再拆，**照原样算一条路**。
5. 路网实测四闸：一段直线 ≤400 km、绕远 ≤1.6 倍、末段离路 ≤40 km、**无折返跑**、渡海必坐船。
6. 🔴 **路数 ＝ 播报句数**，逐场一致（2026-09-29 实测 **20/20 对齐**）。全剧账：**6 片 / 20 段 / 83 路 / 23687 公里 / 7949 字**。
   - 路过**战场节点**不断路（挂点只认据点）；**掉头**（原路往回走）当场收成一条路。
   - **衔接腿**（本场战斗点 → **下一场写死的出发据点**，如 底比斯 → 佩拉「班师」）：军团**确实要走**（不然下一场从佩拉到不了、等于瞬移），
     但**它不写话**——那一腿的叙述写在下一次的起步句里（第 4 场起步句「底比斯既平，亚历山大班师佩拉过冬」），**不计入路数、不写挂点**。

## 三、句的尺子（唯一口径）

1. **一条路 ＝ 一句话**：这条路走完，这句念完。
2. **字数 ＝ 公里 ÷ 12.51 × 4.2**（每公里 0.336 字）。写法：**宁可略多，不许比它少**。
3. **挂点 ＝ 这条路起点的据点**（写**图上那一年的名字**，如「菲利波波利斯」而不是「普罗夫迪夫」）；
   每段第一句是**起步句，不写挂点**。挂点只许挂**真机走过的那条路上的站**。
4. **到了点这句没念完 → 军团就地驻足，听完再走**（每帧重按、1.5 秒自动松，不会钉死）；这几十秒里军团摆**常规阵型**，像在据点歇脚。
5. **一句话一屏字幕**（整句一次 `speak()`，不切片、不分屏）。

## 四、工序：点 ➜ 路 ➜ 文案（不许越级）

> 「点没有做好，不要连线做路，做了也错的。」「路没有做好不要写文案，写了以后错了还要改。」

**① 点（先做，一场一场做）**
- 性质与坐标：**野战**（真实旷野坐标）／**攻城战**（必须有一座真据点）；
- 双方主帅写明（攻／守各一位）；兵力取维基信息框、区间取中值，**守方 ≤ 攻方 ×2**；
- 双方**剧本军团**（整场战争不换）＋ 主将队英雄兵模（看年代与样貌选）；
- 胜负按史料；**战后易主的据点写进 `cityUpdates`**；
- 🔴 **打完军团停在哪（落点）** —— 这是下一段的起点，**没定死就不许连下一段的路**。

**② 路（点全定死之后才做）**
- 起点＝上一场落点；按史料写明途经地设 `marchWaypoints`；跑编辑器「行军路线实测」；
- 按 §二 的尺子切成「路」，并检查**首尾相接**（上一段末路终点＝本段首路起点）。

**③ 文案（路跑通、里程定死之后才写）**
- 一路一句，字数按 §三；挂点用图上那年的名字；
- **全篇 100% 第三人称传记体**：不许我／我们／你／你们，不许「朋友／壮士／诸位」这类搭话，**全剧 0 对话**；
- 不许第三人称代词（他／她／他们／其）→ 一律写名字或族名；
- 不许关系称谓（父王／大王／先王）、不许「大帝」尊号 → 一律直呼「亚历山大」；
- 不写量化词（兵力、人数、日程、里程、件数、次数），只有**纪年与地名坐标**例外；
- 人物写真名或史称；句子通顺、内容专业（军事史口径）。

## 四之二、据点显示：**只有两种方式**（2026-09-28 主人定，唯一口径）

> 主人原话：「**全部据点，只有全部显现，和只显示灰色名字这两种显示方式。**」

| 方式 | 长什么样 | 判据 |
|---|---|---|
| ① **全部显现** | 城样貌（含旗帜）＋ 名字（白字），**可点** | **过了年代闸门**：建立年代 ≤ 这一年的年份，**且**归属武将的时代不晚于这一年 |
| ② **只显示灰色名字** | **只画一个灰字 11px，不画城、不可点** | **没过闸门**：那年这座城还不存在（如 索非亚 1300 年才建、特尔诺沃是城堡时代的城） |

- **没有第三种**：不存在「白名但不画城」「灰名但可点」这类中间态。
- 🔴 **点名不等于免闸**：路标、段表途经点、被攻据点、影响地（战后易主）**统统要过闸门** ——
  过了就①，没过就②。血训（2026-09-28）：第 2 场的路标【特尔诺沃】是中世纪都城，却因为「点名」被无条件顶成白名。
- **「这一场不显示」（`absentCities`）优先于点名**：标了这一场的，直接②。
- **不显示 ≠ 不存在**：路照走、寻路／归属／补兵／战斗一概不受影响，只是那年地图上不画它；
  播报里也**不念**这类站的名字（改念那年的河、山、隘口、部族）。
- 实现：`src/events/scriptCityVisibility.ts` 的 `compute()` 是唯一判据（`cityInYear.ts` 的 `cityExistsInYear`）；
  渲染两路（`CityManager.setVisibilityFilter`、`TerritorySystem.setSpriteFilter`）都吃它。

## 六、不许自作主张

- 不新建／新建即报告：**据点**（只有攻城战缺城时可加，且要配齐 势力＋武将＋精锐）、**道路**（归主人）、人物；
- 已定稿的数据（地点坐标、行军路线、胜负、归属）**不问不改**；
- 编辑器里的「提示」不是待办；**只报「与史料冲突」的事，同一件事只报一次**；
- 口径与实测不一致时：**先报给主人定规则，不擅自改口径、也不擅自改数据**。
