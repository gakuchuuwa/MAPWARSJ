## 三、分场卡

### 场 1｜前225 · 水灌大梁（攻城）
- **片/段**：一 · 扫灭三国 / 段一 灭魏
- **① 入镜**：长安 → 函谷关 → 新郑 → 大梁。
- **势力/地点**：攻 秦｜守 魏（库里魏系势力，做事件时查）。据点 大梁 = 库里 **开封** `city_bianliang`（战后 `cityUpdates` 归秦）。
- **② 人物**：攻 **王贲**｜守 魏王**魏假**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 看样貌，先保年代）。
- **③ 起因**：秦王政命王贲攻魏，魏王据大梁坚守。
- **④ 经过**：大梁城坚，王贲引黄河、鸿沟之水灌城，三个月城坏（《史记》，史实）。
- **⑤ 结局**：魏王假出降，魏亡（史实）。**大梁归秦**。
- **⑥ 出镜**：北上辽东。
- **⑦ 出处**：《史记·秦始皇本纪》；英文维基 *Qin's wars of unification*（大梁之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元前二二五年，秦将王贲兵临魏国都城大梁。大梁城高池深，秦军一时攻不下来。据说王贲看着城外的黄河与鸿沟，想到了一个办法。
  - **inviteText**：「诸位，城墙挡得住刀枪，挡不住河水。把鸿沟挖开，让水替我们攻城。」
  - **description**：秦军掘开河渠，引水灌进大梁。城墙在水里泡了很久，终于崩坏，魏王魏假出城投降，魏国就此灭亡。

### 场 2｜前222 · 辽东（攻城）
- **片/段**：一 / 段二 北方
- **① 入镜**：开封 → 真定 → 渔阳方向 → 襄平。
- **势力/地点**：攻 秦｜守 燕（库里燕系势力，做事件时查）。据点 **襄平** `city_liaoyang`（战后 `cityUpdates` 归秦）。
- **② 人物**：攻 **王贲**｜守 燕王**姬喜**（库里没有）。
- **③ 起因**：前226 年王翦破燕都蓟，燕王喜杀太子丹求和，退保辽东。
- **④ 经过**：王贲远征辽东，攻下燕王所在（《史记》，史料简略）。
- **⑤ 结局**：虏燕王喜，燕亡（史实）。**襄平归秦**。
- **⑥ 出镜**：回师攻代。
- **⑦ 出处**：《史记·秦始皇本纪》；英文维基 *Qin's wars of unification*。
- **文案三件**：
  - **briefing**：公元前二二二年，燕王喜躲在遥远的辽东，他以为献上了儿子太子丹的人头，秦人就会放过他。王贲的大军却不顾山高路远，一路追了过来。
  - **inviteText**：「诸位，燕国的都城早就丢了，燕王还在辽东苟延残喘。去把他请回咸阳。」
  - **description**：秦军长驱直入辽东，燕王喜无处可逃，被秦军俘虏，燕国宣告灭亡。

### 场 3｜前222 · 代（攻城，剧终）
- **片/段**：一 / 段二
- **① 入镜**：襄平 → 回师西向 → 灵仙。
- **势力/地点**：攻 秦｜守 代（赵国余部，库里没有）。据点 代王城（库里没有；最近灵仙 `city_daixian` 18 km，过不了 40 km 间距硬闸，只能用灵仙，见疑点 3）。
- **② 人物**：攻 **王贲**｜守 代王**赵嘉**（赵国公子，库里没有）。
- **③ 起因**：前228 年赵亡后，公子嘉逃到代地自立为代王。
- **④ 经过**：王贲还师攻代（史料简略）。
- **⑤ 结局**：虏代王嘉，赵国余脉断绝（史实）。归秦。
- **⑥ 出镜**：剧终。前221 年王贲自燕地南下攻齐，齐王建不战而降，秦统一天下（B 档）；王贲受封通武侯。
- **⑦ 出处**：《史记·秦始皇本纪》。
- **文案三件**：
  - **briefing**：公元前二二二年，赵国虽然已经灭亡，公子嘉却逃到北方的代地，自立为代王。王贲从辽东回师，顺路来收拾这最后的赵人。
  - **inviteText**：「诸位，赵国的余火还在代地烧着。扑灭它，北方就干净了。」
  - **description**：秦军兵临代地，代王嘉兵少力弱，城破被俘，赵国最后的一脉就此断绝。
