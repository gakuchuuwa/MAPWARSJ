## 三、分场卡

### 场 1｜879 · 广州（攻城）
- **片/段**：一 · 南下岭南 / 段一
- **① 入镜**：仙霞关 → 冶城 → 海阳 → 番禺。
- **势力/地点**：攻 黄巢｜守 唐。据点 **番禺** `city_panyu`（战后 `cityUpdates` 归 `huangwang`）。
- **② 人物**：攻 **黄巢**（库里有）｜守 岭南东道节度使**李迢**（库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：黄巢向朝廷求任广州节度使不成（史实），转而攻广州。
- **④ 经过**：黄巢攻城一日而下，擒李迢（史实）；阿拉伯史料称城中外商遭屠戮（通行说法，数字存疑，文案不写）。
- **⑤ 结局**：**广州归黄巢**（史实）；岭南瘴疫流行，义军死者十之三四，部众劝他北还（史实，数字不进文案）。
- **⑥ 出镜**：北上，一路打到长江、淮河。
- **⑦ 出处**：英文维基 *Huang Chao*；*Guangzhou massacre*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元八七九年秋，黄巢向朝廷讨要广州节度使的官职，被一口回绝。他索性带着义军南下，兵临岭南最富庶的广州城下。
  - **inviteText**：「弟兄们，朝廷不给，我们就自己拿。广州有的是海外的商船和财宝。」
  - **description**：义军一天之内攻破广州，节度使李迢被擒。可岭南湿热，瘟疫在军中蔓延，病倒了许多人，部下纷纷劝黄巢北返，他终于掉头北上。

### 场 2｜880 · 潼关（攻城·关隘）
- **片/段**：二 · 北上入关 / 段二
- **① 入镜**：番禺 → 长沙 → 江陵 → 襄阳 → 寿春 → 洛阳 → 函谷关 → 潼关。
- **势力/地点**：攻 黄巢｜守 唐。据点 **潼关** `city_tongguan`（战后 `cityUpdates` 归 `huangwang`）。
- **② 人物**：攻 **黄巢**、**尚让**（库里没有）｜守 唐将**张承范**、**齐克让**（库里没有）。
- **③ 起因**：黄巢攻陷洛阳，西逼长安；唐廷仓促派兵守潼关，所派神策军多是富家子弟雇来的病弱之人（史实）。
- **④ 经过**：关外齐克让军饥溃；义军发现关左有一条禁谷，唐军平时禁止行人往来、谷中荆棘丛生，义军从禁谷绕到关后，前后夹击（史实）。
- **⑤ 结局**：**潼关归黄巢**（史实）；唐僖宗逃往蜀中，义军入长安，黄巢称帝，国号大齐（史实）。
- **⑥ 出镜**：入长安（B 档）。
- **⑦ 出处**：英文维基 *Huang Chao*；《新唐书·黄巢传》。
- **文案三件**：
  - **briefing**：公元八八〇年冬，黄巢的大军攻下洛阳，兵锋直指潼关。守关的唐军据说多是长安富家子弟花钱雇来的替身，连弓都拉不开。
  - **inviteText**：「弟兄们，关口守得再严，旁边总有路。那条长满荆棘的禁谷，就是我们进长安的门。」
  - **description**：义军从关旁的禁谷穿过荆棘，绕到了潼关背后，前后一夹，唐军一触即溃。潼关失守，唐僖宗仓皇逃往蜀中，黄巢进入长安，登基称帝，国号大齐。

### 场 3｜883–884 · 陈州（攻城，剧终）
- **片/段**：三 · 败退 / 段三 陈州
- **① 入镜**：潼关 → 长安 → 蓝田 → 商州 → 宛城 → 宛丘 → 陈州。
- **势力/地点**：攻 大齐｜守 唐。据点 陈州（库里没有；§二之二 可添加，离宛丘 20 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **黄巢**｜守 陈州刺史**赵犨**（库里没有）。
- **③ 起因**：黄巢东撤，部将孟楷攻陈州被赵犨擒斩，黄巢大怒，亲率大军围陈州（史实）。
- **④ 经过**：黄巢在陈州城外筑「八仙营」、立宫室百司，围城将近三百日；城中坚守，赵犨屡出奇兵（史实，数字不进文案）。
- **⑤ 结局**：李克用、朱温等援军赶到，黄巢解围而去（史实）。**不易主**。
- **⑥ 出镜**：剧终。884 年黄巢在中牟王满渡被李克用追击大败，退至泰山狼虎谷，被外甥林言所杀（一说自杀；史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Huang Chao*；《新唐书·黄巢传》。
- **文案三件**：
  - **briefing**：公元八八三年夏，黄巢撤出长安后东进，部将孟楷在陈州城下兵败被杀。黄巢勃然大怒，亲自率领大军把陈州团团围住，还在城外盖起了宫殿，据说打算一直耗下去。
  - **inviteText**：「弟兄们，陈州不过是一座小城，赵犨杀了孟楷，我要他拿命来偿。围住它，城里的人迟早会饿死。」
  - **description**：陈州刺史赵犨死守孤城，时常出城偷袭义军的营寨，围城一连许多个月都没能攻下。等到李克用、朱温的援军赶来，黄巢只得解围而去，他的义军从此一蹶不振。
