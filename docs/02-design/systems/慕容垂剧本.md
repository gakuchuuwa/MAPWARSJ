## 三、分场卡

### 场 1｜369 · 襄邑之战（野战）
- **片/段**：一 · 前燕吴王 / 段一 襄邑
- **① 入镜**：枋头（朝歌）→ 濮阳 → 雍丘 → 襄邑。
- **势力/地点**：攻 前燕（库里慕容 `murong` 等）｜守 东晋（桓温）。地点 襄邑（野战）。
- **② 人物**：攻 **慕容垂**（库里有）、**慕容德**（库里没有）｜守 东晋大司马**桓温**（库里有 `danyang_huanwen`）。主将队：古典时代鲜卑/草原英雄兵模（按 §二.5 先保年代）；对手古典华夏英雄兵模。
- **③ 起因**：桓温北伐至枋头，粮道被断，焚舟退兵。
- **④ 经过**：诸将要急追，慕容垂说桓温初退必严防，不如缓追，待其疲怠再击；他率八千骑尾随，到襄邑，慕容德先以四千骑埋伏在东涧，前后夹击（史实，数字不进文案）。
- **⑤ 结局**：晋军大败，死者三万人（史实，数字不进文案）。不易主。
- **⑥ 出镜**：因功高遭太傅慕容评、太后可足浑氏猜忌，370 年出奔前秦（B 档）。
- **⑦ 出处**：《晋书·慕容垂载记》；英文维基 *Murong Chui*；*Battle of Fangtou*（枋头之战条目，襄邑为其追击段）。
- **文案三件**：
  - **briefing**：公元三六九年秋，东晋大司马桓温北伐受挫，烧掉船只从陆路南撤。前燕诸将都要立刻追击，吴王慕容垂却按兵不动。
  - **inviteText**：「诸位，桓温刚退的时候一定防得很严，这时候追上去讨不到便宜。等他走累了、松懈了，再动手不迟。」
  - **description**：慕容垂率骑兵远远跟着晋军，一连走了好几天。到了襄邑，慕容德早已带兵埋伏在涧谷之中，两路燕军前后夹击，晋军大败，桓温一生的威名在此折损。

### 场 2｜394 · 长子（攻城）
- **片/段**：二 · 灭西燕 / 段二 长子
- **① 入镜**：雍丘 → 中山 → 邺 → 阏与 → 台壁 → 长子。
- **势力/地点**：攻 后燕｜守 西燕（库里没有）。据点 **长子** `city_shangdang`（战后 `cityUpdates` 归后燕 `dingzhou`）。
- **② 人物**：攻 **慕容垂**（年近七十，史实不进文案）｜守 西燕主**慕容永**（库里没有）。
- **③ 起因**：慕容垂要统一慕容氏，讨伐同族的西燕。
- **④ 经过**：慕容垂分兵多路，自己出滏口；慕容永料不到他走哪条路，把兵力集中在轵关等地；燕军自滏口入天井关，台壁一战大破西燕，围长子（史实）。
- **⑤ 结局**：西燕将领开城投降，慕容永被杀，西燕亡（史实）。**长子归后燕**。
- **⑥ 出镜**：北返中山。
- **⑦ 出处**：《晋书·慕容垂载记》；英文维基 *Western Yan*。
- **文案三件**：
  - **briefing**：公元三九四年，年迈的后燕皇帝慕容垂亲率大军，讨伐同是慕容氏的西燕。西燕主慕容永猜不透燕军会从哪一路来，把重兵都压在了南面的关口上。
  - **inviteText**：「诸位，慕容永守着南面的轵关，我们偏从东面的滏口进去。老头子打仗，靠的是算计。」
  - **description**：燕军从滏口翻越太行，在台壁大破西燕军，一路围住了长子。城中将领见大势已去，打开城门投降，慕容永被杀，慕容氏的两个燕国终于合而为一。

### 场 3｜396 · 平城（攻城，剧终）
- **片/段**：三 · 晚年亲征 / 段三 平城
- **① 入镜**：长子 → 中山 → 青岭 → 天门 → 大同。
- **势力/地点**：攻 后燕｜守 北魏（库里拓跋 `tuoba`，本城大同）。据点 **大同** `city_datong`（平城；战后按历史写「一度攻取、旋撤」，见疑点 2）。
- **② 人物**：攻 **慕容垂**｜守 北魏陈留公**拓跋虔**（库里没有）。
- **③ 起因**：395 年太子慕容宝在参合陂惨败于北魏拓跋珪，燕军降卒被坑杀（史实）；慕容垂抱病亲征复仇。
- **④ 经过**：燕军秘密出兵，凿山开道，越青岭、出天门，突然出现在平城下；拓跋虔毫无防备，出战而死，部众尽降（史实）。
- **⑤ 结局**：平城归后燕（史实）；但慕容垂途经参合陂，见去年战死者尸骨堆积如山，燕军痛哭，慕容垂惭愤吐血，病重，撤军途中卒于上谷沮阳（史实）。
- **⑥ 出镜**：剧终。北魏随即南下，后燕走向衰亡（见 [`拓跋珪剧本.md`](拓跋珪剧本.md)）。
- **⑦ 出处**：《晋书·慕容垂载记》；英文维基 *Murong Chui*。
- **文案三件**：
  - **briefing**：公元三九六年春，去年太子慕容宝在参合陂惨败，被坑杀的燕军据说不计其数。年迈的慕容垂拖着病体亲自出征，悄悄凿开山路，要给北魏一个措手不及。
  - **inviteText**：「诸位，参合陂的仇，我要亲手去报。走山路，不要让拓跋家的人察觉。」
  - **description**：燕军翻山越岭，突然出现在平城城下，北魏守将拓跋虔仓促迎战，战死城下。可在回军途中，燕军经过参合陂，看见遍地的同袍尸骨，全军痛哭。慕容垂又羞又愤，当场吐血，不久便病死在了归途。
