## 三、分场卡

### 场 1｜641 · 诺真水之战（野战）
- **片/段**：一 · 北破薛延陀 / 段一
- **① 入镜**：晋阳 → 宁武关 → 大同 → 固阳塞 → 诺真水。
- **势力/地点**：攻 唐｜守 薛延陀（库里薛延陀系势力，做事件时查）。地点 诺真水（野战）。
- **② 人物**：攻 朔州行军总管**李勣**（库里有）｜守 薛延陀大度设（真珠可汗之子，库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：薛延陀趁唐太宗东封泰山，发兵南下攻突厥李思摩部。
- **④ 经过**：薛延陀军演练「步战」之法——四人一组，一人牵马、三人步战，胜后再上马追击；李勣先以突厥兵迎战失利，随后唐军精骑冲锋，一面射马、一面冲阵，薛延陀步卒来不及上马（史实，数字不进文案）。
- **⑤ 结局**：薛延陀大败，大度设逃走（史实）。不易主。
- **⑥ 出镜**：回长安；随太宗征高句丽。
- **⑦ 出处**：英文维基 *Battle of Nuozhen River*（条目名以站内为准）；《旧唐书·李勣传》。
- **文案三件**：
  - **briefing**：公元六四一年冬，薛延陀趁唐太宗东去泰山封禅，大举南下。他们据说学会了一种新战法——下马步战，打赢了再上马追杀。李勣率领精骑日夜兼程赶到诺真水。
  - **inviteText**：「诸位，他们下了马，马就在后面有人牵着。先射他们的马，没了马，步兵就跑不掉了。」
  - **description**：唐军骑兵一面放箭射马，一面冲进薛延陀的步阵。薛延陀的士兵想回头上马，马却已受惊四散，阵脚大乱，大度设只好弃军逃走。

### 场 2｜645 · 辽东城（攻城）
- **片/段**：二 · 征高句丽 / 段二 辽东城
- **① 入镜**：固阳塞 → 晋阳 → 幽州方向 → 柳城 → 渡辽水 → 襄平。
- **势力/地点**：攻 唐｜守 高句丽（库里 `gaogouli`）。据点 **襄平** `city_liaoyang`（辽东城；战后 `cityUpdates` 归唐）。
- **② 人物**：攻 **唐太宗李世民**（库里有，见 [`李世民剧本.md`](李世民剧本.md)）、辽东道行军大总管**李勣**、江夏王**李道宗**（库里没有）｜守 高句丽辽东城守军（主将史书未载名）。
- **③ 起因**：高句丽权臣渊盖苏文弑君专权，唐太宗亲征。
- **④ 经过**：李勣先攻下盖牟城；围辽东城十二日昼夜不息，唐太宗亲至；南风大起，唐军以抛车击城、纵火焚城西南楼，火延烧城中，将士登城（史实，数字不进文案）。
- **⑤ 结局**：辽东城陷落，**襄平归唐**（史实），唐改置辽州。
- **⑥ 出镜**：进攻白岩、安市（B 档；驻跸山见李世民线）。
- **⑦ 出处**：英文维基 *Siege of Liaodong*（条目名以站内为准）；*Goguryeo–Tang War*。
- **文案三件**：
  - **briefing**：公元六四五年夏，唐太宗亲征高句丽，李勣率领前锋渡过辽水，把辽东城围得水泄不通。城池坚固，唐军日夜攻打，城头上的高句丽守军据说一刻也没有合眼。
  - **inviteText**：「诸位，陛下亲自来了。今天南风正大，把火点起来，让风替我们攻城。」
  - **description**：唐军用抛车猛轰城墙，又趁着南风点燃了城楼，大火蔓延进城里，将士们冒着浓烟攀上城头，辽东城终于陷落。

### 场 3｜668 · 平壤（攻城，剧终）
- **片/段**：二 / 段三 平壤
- **① 入镜**：襄平 → 国内城方向 → 平壤。
- **势力/地点**：攻 唐（与新罗）｜守 高句丽。据点 **平壤** `city_pyongyang`（战后 `cityUpdates` 归唐）。
- **② 人物**：攻 辽东道行军大总管**李勣**（七十余岁，年岁不进文案）、**薛仁贵**（库里有）、新罗**金仁问**（库里没有）｜守 高句丽莫离支**泉男建**、宝藏王**高藏**（库里没有）。
- **③ 起因**：渊盖苏文死后诸子内讧，长子泉男生降唐，唐高宗命李勣大举东征。
- **④ 经过**：唐军会合新罗军围平壤月余；宝藏王出降，泉男建仍闭门拒守；泉男建所信任的僧人信诚暗中通唐，打开城门，唐军入城纵火（史实）。
- **⑤ 结局**：平壤陷落，高句丽亡（史实）。**平壤归唐**，唐置安东都护府，薛仁贵为都护。
- **⑥ 出镜**：剧终。李勣凯旋，次年（669）卒（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Fall of Pyongyang*（条目名以站内为准）；*Goguryeo–Tang War*。
- **文案三件**：
  - **briefing**：公元六六八年秋，高句丽的权臣渊盖苏文死后，他的儿子们反目成仇。年迈的李勣再一次率军东征，与新罗的军队一起，把高句丽的都城平壤团团围住。
  - **inviteText**：「诸位，渊盖苏文的儿子们互相残杀，高句丽的人心已经散了。围住平壤，城门自己会开。」
  - **description**：围城一个多月，高句丽的宝藏王出城投降，泉男建却仍然死守。最后，他身边的僧人信诚暗中打开了城门，唐军涌入城中，历经许多代君王的高句丽就此灭亡。
