## 三、分场卡

### 场 1｜1639 · 济南（攻城）
- **片/段**：一 · 戊寅入塞 / 段一 济南
- **① 入镜**：沈阳 → 喜峰口方向 → 无终 → 保定 → 真定 → 历下。
- **势力/地点**：攻 清｜守 明。据点 **历下** `city_licheng`（济南；战后 `cityUpdates` 按历史写归清，见疑点 2）。
- **② 人物**：攻 奉命大将军**多尔衮**（库里有）、**岳托**（库里没有）｜守 明济南巡按**宋学朱**、山东左布政使**张秉文**（库里没有）；明德王朱由枢被俘（史实）。主将队：帝国时代东北/满洲英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：皇太极派多尔衮、岳托分两路入塞，深入明境劫掠（史实）。
- **④ 经过**：清军横扫畿辅、山东，明军卢象昇战死巨鹿（史实）；清军攻济南，城中兵少，守臣力战殉城（史实）。
- **⑤ 结局**：济南城破，德王被俘，城中军民遭屠（史实，文案只写「据说」）。清军劫掠后北返（史实）。
- **⑥ 出镜**：出塞北归。
- **⑦ 出处**：英文维基 *Dorgon*；*Qing invasion of Ming (1638–1639)*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一六三九年正月，清军在多尔衮的率领下破长城南下，横扫京畿，一路打进了山东。济南城里的守军不多，巡按宋学朱和布政使张秉文据说决心与城共存亡。
  - **inviteText**：「弟兄们，明朝的大军都在关外防着我们，腹地空虚得很。济南城里有王爷，拿下它。」
  - **description**：清军猛攻济南，守城的官员们力战殉城，明朝的德王成了俘虏。据说城里死伤惨重。清军在关内劫掠了大批人口和财物，满载北归。

### 场 2｜1644 · 山海关之战（野战，主角一方守，剧终）
- **片/段**：二 · 入关 / 段二 山海关
- **① 入镜**：历下 → 沈阳 → 徒河 → 宁远城 → 山海关。
- **势力/地点**：攻 大顺（李自成，库里大顺系势力，做事件时查）｜守 吴三桂与清联军。地点 山海关西石河一带（野战），战后按历史 `cityUpdates` 写 **山海关** 归清。
- **② 人物**：攻 大顺皇帝**李自成**（库里没有）、**刘宗敏**（库里没有）｜守 明宁远总兵**吴三桂**（库里没有）、清摄政王**多尔衮**。
- **③ 起因**：李自成攻陷北京，崇祯帝自缢；吴三桂拒降，引清兵入关（史实）。
- **④ 经过**：吴三桂军与大顺军在石河激战多时，双方力竭；多尔衮令清军埋伏不出，待午后大风扬沙，清军铁骑自吴军阵右侧突然杀出（史实）。
- **⑤ 结局**：大顺军大败，李自成退回北京、旋即西撤（史实）。**山海关归清**。
- **⑥ 出镜**：剧终。清军入北京，多尔衮迎顺治帝迁都北京（1644，B 档）；此后摄政七年，1650 年死于喀喇城（史实，数字不进文案；B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Shanhai Pass*。
- **文案三件**：
  - **briefing**：公元一六四四年春，李自成攻陷北京，崇祯皇帝自缢煤山。镇守山海关的吴三桂拒绝投降，转而向关外的清朝借兵。多尔衮的大军来到关下，据说却不急着出战。
  - **inviteText**：「弟兄们，让吴三桂和李自成先打。等他们都累了，风沙一起，我们再冲出去。」
  - **description**：吴三桂的军队与大顺军在石河边厮杀了很久，双方都已精疲力尽。午后狂风卷起黄沙，清军铁骑突然从吴军的阵侧杀出，大顺军猝不及防，全线崩溃，李自成仓皇退回北京。山海关的大门，从此向清军敞开。
