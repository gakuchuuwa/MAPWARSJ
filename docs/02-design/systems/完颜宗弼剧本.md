## 三、分场卡

### 场 1｜1129 · 建康（攻城）
- **片/段**：一 · 搜山检海 / 段一 建康
- **① 入镜**：开封 → 寿春 → 历阳方向 → 马家渡 → 金陵。
- **势力/地点**：攻 金｜守 南宋（库里 `song`）。据点 **金陵** `city_nanjing`（建康；战后 `cityUpdates` 归金）。
- **② 人物**：攻 **完颜宗弼**（库里有）｜守 宋江淮宣抚使**杜充**（库里没有），陈淬、岳飞等部将。主将队：城堡时代东北/女真英雄兵模（1129 年属城堡段，按 §二.5 看样貌选）。
- **③ 起因**：金军大举南下，欲擒宋高宗。
- **④ 经过**：金军自马家渡渡江，杜充派陈淬、岳飞等迎战，陈淬战死，其余诸将溃散；杜充投降（史实）。
- **⑤ 结局**：**建康归金**（史实）。
- **⑥ 出镜**：追击宋高宗至明州、入海（B 档）。
- **⑦ 出处**：英文维基 *Wuzhu*；*Jin–Song Wars*。
- **文案三件**：
  - **briefing**：公元一一二九年冬，金国四太子兀术率大军渡过长江，直扑南宋的陪都建康。守城的宋将杜充据说早已心生降意，手下的将领们各自为战。
  - **inviteText**：「诸位，宋朝的皇帝就在江南，他跑到哪里，我们就追到哪里。先拿下建康。」
  - **description**：金军渡江后连败宋军，宋将陈淬战死，其余诸将溃散，杜充开城投降。兀术占领建康，随即挥师东进，一路追赶宋高宗，直追到了海上。

### 场 2｜1130 · 黄天荡之战（野战·水战，主角守）
- **片/段**：一 / 段二 黄天荡
- **① 入镜**：金陵 → 杭州 → 延陵 → 黄天荡。
- **势力/地点**：攻 南宋｜守 金。地点 黄天荡（野战·水战）。
- **② 人物**：攻 **韩世忠**（库里有 `sizhou_hanshizhong`）、夫人**梁红玉**（库里没有）｜守 **完颜宗弼**。
- **③ 起因**：宗弼满载掳掠北归，韩世忠以海船截击于镇江江面。
- **④ 经过**：金军被困黄天荡四十八天（史实，数字不进文案）；梁红玉亲自擂鼓助战（通行说法）；宗弼悬赏求计，有人献计开凿老鹳河故道通秦淮河（史实）；后又有人献计，趁无风时以小舟火箭射宋海船帆篷（史实）。
- **⑤ 结局**：宋军海船着火，金军突围北归（史实）。不易主。经此一役，金军不敢再轻易渡江。
- **⑥ 出镜**：北返，转战陕西。
- **⑦ 出处**：英文维基 *Battle of Huangtiandang*。
- **文案三件**：
  - **briefing**：公元一一三〇年春，兀术带着满船的战利品北归，却在镇江江面被韩世忠的大海船拦住，退进了黄天荡这条死水港汊。据说韩世忠的夫人梁红玉亲自登上战船擂鼓。
  - **inviteText**：「诸位，宋人的船大，可大船要靠风。等哪天江上没有风，就是我们出去的时候。」
  - **description**：金军被困了很久，挖开旧河道想绕出去又被截住。终于等到一个无风的日子，金军乘小船靠近，用火箭射燃了宋军大船的帆篷，大船动弹不得，烧成一片。兀术趁乱突围北归，从此不敢再轻易渡江。

### 场 3｜1131 · 和尚原之战（野战）
- **片/段**：二 · 川陕 / 段三 和尚原
- **① 入镜**：金陵 → 开封 → 长安 → 岐山 → 和尚原。
- **势力/地点**：攻 金｜守 南宋。地点 和尚原（野战）。
- **② 人物**：攻 **完颜宗弼**｜守 宋将**吴玠**（库里有 `fengzhou_wujie`）、其弟**吴璘**（库里没有）。
- **③ 起因**：金军欲入川，和尚原扼大散关要道。
- **④ 经过**：吴玠以强弓劲弩轮番发射，号「驻队矢」，金军仰攻不利；宋军又夜袭金营、断其粮道（史实）。
- **⑤ 结局**：金军大败，宗弼身中流矢，剃须而逃（史实，「剃须」为通行说法，据说如此）。不易主。
- **⑥ 出镜**：北归。
- **⑦ 出处**：英文维基 *Battle of Heshangyuan*。
- **文案三件**：
  - **briefing**：公元一一三一年冬，兀术率大军西攻和尚原，想打开入川的大门。守在原上的宋将吴玠，据说早已备好了成堆的强弓劲弩。
  - **inviteText**：「诸位，宋人躲在山上射箭，可箭总有射完的时候。冲上去，拿下和尚原。」
  - **description**：宋军的弓弩一排接一排地轮番发射，金军仰攻山坡，死伤惨重。宋军又趁夜袭营、截断粮道，金军大溃。兀术身中流矢，据说剃掉了胡须才混在乱军里逃了出去。

### 场 4｜1140 · 顺昌（攻城）
- **片/段**：三 · 河南 / 段四 顺昌
- **① 入镜**：大散关 → 长安 → 开封 → 顺昌。
- **势力/地点**：攻 金｜守 南宋。据点 **顺昌** `city_shunchang`（战后不易主）。
- **② 人物**：攻 **完颜宗弼**、「铁浮屠」「拐子马」（史实）｜守 东京副留守**刘锜**（库里有 `yingzhou_d_liuqi`）。
- **③ 起因**：金毁和约，宗弼南下河南；刘锜赴任途中据顺昌死守。
- **④ 经过**：刘锜凿沉船只，示无退路（史实）；时值酷暑，刘锜在颍水上游及草中下毒（史实），待金军人马饥渴疲惫，以长斧劈砍铁浮屠（史实）。
- **⑤ 结局**：金军大败撤围（史实）。**不易主**。
- **⑥ 出镜**：退往开封，转战郾城。
- **⑦ 出处**：英文维基 *Battle of Shunchang*。
- **文案三件**：
  - **briefing**：公元一一四〇年夏，金国撕毁和约，兀术亲率大军南下，围住了小小的顺昌城。城里的宋将刘锜据说把船都凿沉了，摆明了要死守到底。
  - **inviteText**：「诸位，顺昌城小，宋兵又少，何必用得着铁浮屠？一脚就能把它踢倒。」
  - **description**：那年夏天酷热难当，金军人马在城外饥渴交加。刘锜在水源和草丛里下了毒，等金军疲惫不堪时开城出击，宋军用长斧专砍铁浮屠的马腿，金军大败，兀术只好撤围而去。
