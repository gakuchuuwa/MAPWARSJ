## 三、分场卡

**1｜352 · 廉台之战**　同 [`冉闵剧本.md`](冉闵剧本.md) 第 3 场，这里是慕容恪视角：冉闵步兵十战十胜，慕容恪选五千善射鲜卑骑兵，用铁锁连马组成方阵，诱冉闵入平地后合围（史实）。②攻 **慕容恪**（库里有）｜守 冉闵。主将队：待看素材定。⑤冉闵被俘，冉魏亡。⑦英文维基 *Murong Ke*。

**2｜356–357 · 广固（攻城）**　①→ 邺 → 历下 → 广固。②攻 慕容恪｜守 自称齐王的**段龛**（库里没有）。③段龛据青州与前燕为敌。④慕容恪在淄水先破段龛，然后围广固而不急攻，说「急攻伤士卒，不如坐待其困」，筑营屯田（史实）。⑤城中粮尽，段龛出降（史实）。⑥⑦同上。

**3｜365 · 洛阳（攻城，剧终）**　①广固 → 邺 → 洛阳。②攻 慕容恪｜守 东晋冠军长史**沈劲**（库里没有）。③前燕要夺取东晋守着的洛阳。④沈劲兵不满五百（通行说法），死守城池，城破被俘不屈而死（史实）。⑤**洛阳归前燕**。⑥剧终：367 年慕容恪病逝，临终荐慕容垂为统帅，未被采纳，三年后前燕亡于前秦（B 档）。⑦同上。
