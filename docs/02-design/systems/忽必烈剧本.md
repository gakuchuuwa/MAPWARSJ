# 忽必烈 · 剧本底本（一部人物传记）

> 年代：1253–1287。主角 **忽必烈**——**库里有**：武将 `yuan_d_hubilie`，势力 `yuan_d`（大元），本城 `city_shangdu` 上都（建立年代 1256）。
> 忽必烈即位后的大战（襄阳、崖山、东征日本、南征安南）多由部将统兵，本线只收他**本人亲征**的三次。

## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜1253 冬 · 大理（攻城）**　①上都 → 临洮 → 金沙江 → 大理。②攻 **忽必烈**（库里有）与兀良合台｜守 大理国主**段兴智**、权臣高泰祥（库里没有）。主将队：待看素材定。③蒙哥汗命忽必烈绕道西南攻大理，从侧后包抄南宋。④蒙古军用羊皮筏（革囊）渡金沙江，兵分三路进逼大理城；忽必烈下止杀令（通行说法）。⑤大理城破，高泰祥被杀，段兴智出逃后被俘，大理国亡（史实）。**羊苴咩归元**（`city_dali_city` → `yuan_d`）。⑥北返。⑦英文维基 *Kublai Khan*、*Mongol conquest of the Dali Kingdom*（条目名以站内为准）。

**2｜1259 · 鄂州（攻城）**　①→ 上都 → 汝南 → 渡江 → 鄂州。②攻 忽必烈｜守 南宋右丞相**贾似道**督援、鄂州守军（库里没有）。③蒙哥汗大举伐宋，忽必烈率东路军攻鄂州。④围城期间传来蒙哥汗在钓鱼城下死去的消息（史实）。⑤忽必烈与贾似道议和撤围，急返北方争汗位（史实）。不易主。⑥北返。⑦英文维基 *Mongol conquest of the Song dynasty*（鄂州之战独立条目**待核**）。

**3｜1287 夏 · 平乃颜（剧终）**　①→ 上都 → 应昌 → 辽河上游。②攻 **忽必烈**（七十二岁，史实）｜守 东道诸王**乃颜**（库里没有）。③乃颜联合海都起兵反元。④年迈的忽必烈坐在四头大象驮着的木楼里亲临战场（马可·波罗记载，史实），先以汉军、蒙古军分列两阵，自午战至黄昏。⑤乃颜被擒处死（史实）。⑥剧终：1294 年忽必烈卒（B 档）。⑦英文维基 *Nayan (Mongol prince)* <https://en.wikipedia.org/wiki/Nayan_(Mongol_prince)>。

## 四、B 档背景
1260–1264 与阿里不哥争位（昔木土脑儿之战等，他本人未必亲临）· 1268–1273 襄阳之战（阿术、刘整）· 1274、1281 东征日本（主角不在场）· 1279 崖山海战（张弘范）· 1294 卒。
