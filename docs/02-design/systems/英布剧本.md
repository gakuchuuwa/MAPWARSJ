## 三、分场卡

### 场 1｜前206 · 函谷关（攻城·关隘）
- **片/段**：一 · 项羽先锋 / 段一 入关
- **① 入镜**：巨鹿 → 濮阳 → 新安 → 渑池 → 函谷关。
- **势力/地点**：攻 楚（项羽，库里西楚 `xichu`）｜守 汉（刘邦）。据点 **函谷关** `city_hanguguan`（战后 `cityUpdates` 归楚）。
- **② 人物**：攻 **英布**（项羽派为先锋）｜守 刘邦所遣守关将士（史书未载主将名）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：刘邦先入关，派兵守函谷关，不让项羽的诸侯军进来（史实）。
- **④ 经过**：项羽大怒，派英布等从小路绕过关隘，前后夹击，攻破函谷关（《史记》，史实）。
- **⑤ 结局**：**函谷关归楚**，项羽大军入关，屯兵鸿门（史实）。
- **⑥ 出镜**：鸿门宴（B 档），受封九江王。
- **⑦ 出处**：《史记·项羽本纪》《黥布列传》；英文维基 *Ying Bu*。
- **文案三件**：
  - **briefing**：公元前二〇六年冬，项羽带着诸侯联军来到函谷关前，却发现关门紧闭，守关的竟是刘邦的人。项羽勃然大怒，把这件事交给了麾下最勇猛的英布。
  - **inviteText**：「诸位，关门不开，我们就从山里的小路绕过去。等守关的人回头，看到的只能是我们的刀。」
  - **description**：英布带兵从小道迂回到关后，与正面的楚军前后夹攻，一举攻破函谷关。项羽的大军长驱直入，驻扎在鸿门，刘邦只好亲自前来谢罪。

### 场 2｜前196 秋 · 富陵之战（野战）
- **片/段**：二 · 淮南王反 / 段二 淮上
- **① 入镜**：函谷关 → 六安 → 寿春 → 盱眙 → 富陵。
- **势力/地点**：攻 淮南（库里九江 `liu`）｜守 荆（汉宗室，库里没有）。地点 富陵（野战）。
- **② 人物**：攻 **英布**｜守 荆王**刘贾**（刘邦从兄，库里没有）。
- **③ 起因**：韩信、彭越相继被诛，英布心惊，恐祸及己，起兵反汉（史实）。
- **④ 经过**：英布先东击荆国，刘贾兵败走死富陵（《史记》）。
- **⑤ 结局**：荆王刘贾战死，其军尽降（史实）。不易主（荆国之地归英布，库里无对应据点）。
- **⑥ 出镜**：渡淮西击楚王刘交，再北上。
- **⑦ 出处**：《史记·黥布列传》《荆燕世家》；英文维基 *Ying Bu*。
- **文案三件**：
  - **briefing**：公元前一九六年秋，韩信、彭越先后被刘邦所杀，据说彭越的肉酱还被送到了英布的面前。淮南王英布再也坐不住了，起兵反汉，先向东扑向荆王刘贾。
  - **inviteText**：「诸位，韩信死了，彭越也死了，下一个就轮到我。与其等死，不如先动手。」
  - **description**：英布出兵迅猛，荆王刘贾措手不及，兵败逃到富陵，战死在那里，他的部众全都投降了英布。

### 场 3｜前196 冬 · 会甀之战（野战，主角守，剧终）
- **片/段**：二 / 段二
- **① 入镜**：盱眙 → 符离 → 会甀。
- **势力/地点**：攻 汉（刘邦亲征，库里汉系势力）｜守 淮南。地点 蕲县西会甀（野战），战后按历史 `cityUpdates` 写 **六安** 归汉（淮南国除，史实）。
- **② 人物**：攻 **刘邦**（库里有，做事件时查 id）｜守 **英布**。
- **③ 起因**：刘邦抱病亲征。
- **④ 经过**：英布军阵形仿项羽，刘邦望见心中厌恶，隔阵问他为何反，英布答「欲为帝耳」（《史记》，史实）；两军大战，刘邦中流矢（史实）。
- **⑤ 结局**：英布兵败南逃，被长沙王吴臣诱杀于番阳（史实）。**六安归汉**。
- **⑥ 出镜**：剧终。刘邦箭伤复发，次年卒（B 档）。
- **⑦ 出处**：《史记·黥布列传》《高祖本纪》；英文维基 *Ying Bu*。
- **文案三件**：
  - **briefing**：公元前一九六年冬，汉高祖刘邦不顾病体，亲自领兵来到蕲县以西。英布的军阵排得和当年的项羽一模一样，刘邦远远望见，据说心里很不是滋味。
  - **inviteText**：「诸位，刘邦问我为什么反？告诉他，我也想当皇帝。」
  - **description**：两军大战，汉军拼死冲阵，刘邦被流矢射中，英布却终究抵挡不住，大败南逃。他投奔长沙王吴臣，却被吴臣骗到番阳杀死。
