## 三、分场卡

### 场 1｜529 · 睢阳（攻城）
- **片/段**：一 · 白袍北伐 / 段一 睢阳
- **① 入镜**：谯县（铚县）→ 永城 → 商丘。
- **势力/地点**：攻 南梁（送北海王元颢）｜守 北魏。据点 **商丘** `city_shangqiu`（睢阳；战后 `cityUpdates` 归梁）。
- **② 人物**：攻 **陈庆之**（库里有）、北魏北海王**元颢**（库里没有）｜守 北魏征东将军**丘大千**（库里没有）。主将队：封建时代华夏英雄兵模（529 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：北魏河阴之变后，北海王元颢投梁，梁武帝派陈庆之护送他北归称帝。
- **④ 经过**：丘大千连筑九城据守，陈庆之从早晨攻到申时，连拔三城（史实，数字不进文案）。
- **⑤ 结局**：丘大千投降（史实）。**睢阳归梁**，元颢在睢阳城南即帝位。
- **⑥ 出镜**：西进。
- **⑦ 出处**：《梁书·陈庆之传》；英文维基 *Chen Qingzhi*。
- **文案三件**：
  - **briefing**：公元五二九年夏，南梁将军陈庆之护送着北魏的北海王元颢北上。他手下的兵马少得可怜，全军披着白袍。挡在路上的睢阳，北魏守将丘大千修了一连串的营垒。
  - **inviteText**：「诸位，我们人少，拖不起。今天从早上打到天黑，能拔几座营垒就拔几座。」
  - **description**：白袍军从清晨攻到午后，接连拔下了好几座营垒，丘大千只得出城投降。元颢在睢阳城南登上了帝位，洛阳的方向已经敞开了。

### 场 2｜529 · 荥阳（攻城）
- **片/段**：一 / 段二 荥阳、虎牢
- **① 入镜**：商丘 → 雍丘 → 开封方向 → 荥阳。
- **势力/地点**：攻 南梁｜守 北魏。据点 荥阳（库里没有；§二之二 可添加，离虎牢关 17 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **陈庆之**｜守 北魏左仆射**杨昱**（库里没有）；城外元天穆、尔朱吐没儿援军将至（史实）。
- **③ 起因**：北魏集结重兵于荥阳、虎牢一线，企图阻截梁军。
- **④ 经过**：荥阳城坚，梁军久攻不下，北魏援军又从后面压来，梁军士卒恐惧；陈庆之解鞍秣马，对部下说我们一路杀人父兄、掠人子女，此地没有退路，只有攻下此城才能活；亲自擂鼓，将士蚁附登城（史实）。
- **⑤ 结局**：荥阳城破，擒杨昱；梁军随即出城迎击北魏援军，大破之（史实）。荥阳归梁。
- **⑥ 出镜**：进逼虎牢。
- **⑦ 出处**：《梁书·陈庆之传》；英文维基 *Chen Qingzhi*。
- **文案三件**：
  - **briefing**：公元五二九年，白袍军兵临荥阳城下，城墙高大，一连几天攻不下来。北魏的援军又从背后压来，据说军中的士卒都有了惧色。
  - **inviteText**：「诸位，我们一路北上，杀过人家的父兄，掠过人家的子女，没有一个人会放过我们。只有拿下这座城，才有活路。」
  - **description**：陈庆之亲自擂鼓，白袍军奋勇攀城，一举攻破荥阳，擒获守将杨昱。紧接着他们又出城迎击北魏援军，以少击众，大破敌军。

### 场 3｜529 · 虎牢（攻城·关隘，剧终）
- **片/段**：一 / 段二
- **① 入镜**：荥阳 → 虎牢关。
- **势力/地点**：攻 南梁｜守 北魏。据点 **虎牢关** `city_hulaoguan`（战后 `cityUpdates` 归梁）。
- **② 人物**：攻 **陈庆之**｜守 北魏**尔朱世隆**（库里没有）。
- **③ 起因**：虎牢是洛阳东面门户。
- **④ 经过**：尔朱世隆闻荥阳失守，弃关而走（史实）。
- **⑤ 结局**：**虎牢关归梁**（史实）；北魏孝庄帝北逃，元颢入洛阳（史实）。陈庆之自铚县至洛阳，前后作战四十七次，攻下三十二城，所向无敌（史实，数字不进文案）；洛阳童谣「名师大将莫自牢，千兵万马避白袍」（史实）。
- **⑥ 出镜**：剧终。元颢入洛后骄奢，不听陈庆之之议；尔朱荣率大军南下，河桥之战元颢败死（见 [`尔朱荣剧本.md`](尔朱荣剧本.md) 场 2）；陈庆之全军覆没，剃发扮作僧人，只身逃回江南（史实，B 档尾声）；539 年卒。
- **⑦ 出处**：《梁书·陈庆之传》；英文维基 *Chen Qingzhi*。
- **文案三件**：
  - **briefing**：公元五二九年，荥阳失守的消息传到虎牢关，镇守关口的尔朱世隆大惊失色。洛阳的东大门，就这样摆在了白袍军的面前。
  - **inviteText**：「诸位，过了虎牢，就是洛阳。披上白袍，让他们远远就能认出我们。」
  - **description**：尔朱世隆不敢迎战，弃关而逃，白袍军兵不血刃拿下了虎牢关。北魏孝庄帝仓皇北逃，元颢进入洛阳。洛阳城里的孩子们传唱着一首童谣，说再有名的大将也别逞强，见了白袍军就该躲开。
