## 三、分场卡

### 场 1｜661–662 · 天山之战（野战）
- **片/段**：一 · 天山 / 段一
- **① 入镜**：长安 → 姑臧 → 张掖 → 敦煌 → 哈密卫 → 天山。
- **势力/地点**：攻 唐｜守 铁勒九姓（库里铁勒系势力，做事件时查）。地点 天山（野战）。
- **② 人物**：攻 **郑仁泰**（主帅，库里没有）、**薛仁贵**（库里有）｜守 铁勒九姓诸部（首领史书未详名）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选，薛仁贵以白袍著称）。
- **③ 起因**：铁勒九姓叛唐，唐高宗派郑仁泰、薛仁贵讨伐。
- **④ 经过**：铁勒派数十骁骑挑战，薛仁贵连发三箭射死三人，其余下马请降（《旧唐书》，史实，数字不进文案）。
- **⑤ 结局**：铁勒大败，军中歌曰「将军三箭定天山，战士长歌入汉关」（史实）。不易主。
- **⑥ 出镜**：调往辽东。
- **⑦ 出处**：《旧唐书·薛仁贵传》；英文维基 *Xue Rengui*（天山之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元六六一年冬，铁勒诸部起兵叛唐。唐军行军副总管薛仁贵随大军来到天山脚下，铁勒派出最精悍的骑士前来挑战。
  - **inviteText**：「诸位，他们派了最好的骑手来。那就让他们看看，大唐的弓箭有多准。」
  - **description**：薛仁贵张弓连射，挑战的铁勒骑士应弦落马，其余的人吓得下马请降。铁勒大军随之溃散，军中传唱着「将军三箭定天山」的歌谣。

### 场 2｜668 · 扶余城（攻城）
- **片/段**：二 · 灭高句丽 / 段二 扶余
- **① 入镜**：哈密卫 → 长安 → 洛阳 → 襄平 → 国内城方向 → 扶余城。
- **势力/地点**：攻 唐｜守 高句丽（库里 `gaogouli`）。据点 扶余城（库里没有；§二之二 可添加，离八面关 13 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **薛仁贵**｜守 高句丽扶余城守军（主将史书未载名）。
- **③ 起因**：唐与新罗合攻高句丽，李勣为主帅；扶余城是高句丽北境重镇。
- **④ 经过**：诸将以为兵少，薛仁贵说「在主将善用耳，不在多」，率三千人为先锋，大破高句丽军，攻拔扶余城（史实，数字不进文案）。
- **⑤ 结局**：扶余城归唐，扶余川中四十余城望风请降（史实，数字不进文案）。
- **⑥ 出镜**：南下会攻平壤（见 [`李勣剧本.md`](李勣剧本.md)）。
- **⑦ 出处**：《旧唐书·薛仁贵传》；英文维基 *Goguryeo–Tang War*。
- **文案三件**：
  - **briefing**：公元六六八年春，唐军兵分几路直捣高句丽。北境重镇扶余城城坚兵众，薛仁贵手下的兵却不多，诸将都劝他再等等援军。
  - **inviteText**：「诸位，兵不在多，在于将领会不会用。跟着我冲上去就是了。」
  - **description**：薛仁贵亲率先锋冲击高句丽军，一战将其击溃，随即攻下了扶余城。附近的城池听到消息，纷纷派人前来请降，唐军的北路就此打开。

### 场 3｜670 · 大非川之战（野战）
- **片/段**：三 · 西北与北疆 / 段三 大非川
- **① 入镜**：扶余城 → 平壤 → 长安 → 姑臧 → 大非川。
- **势力/地点**：攻 唐｜守 吐蕃（库里吐蕃系势力，做事件时查）。据点 **大非川** `city_dafeichuan`（本场为野战，地点取该据点坐标；战后不易主）。
- **② 人物**：攻 逻娑道行军大总管**薛仁贵**、副将**郭待封**（库里没有）｜守 吐蕃大相**论钦陵**（库里没有）。
- **③ 起因**：吐蕃攻陷西域十八州，唐派薛仁贵援吐谷浑、击吐蕃。
- **④ 经过**：薛仁贵留郭待封守辎重于大非岭，自率轻骑突袭乌海，先胜；郭待封不听节制，擅自带辎重前进，被吐蕃截击，粮草尽失；薛仁贵退守大非川，论钦陵率大军合围（史实）。
- **⑤ 结局**：唐军大败，薛仁贵与吐蕃约和而还（史实），坐罪除名为民。不易主。
- **⑥ 出镜**：被流放象州，后遇赦（B 档）。
- **⑦ 出处**：英文维基 *Battle of Dafei River*。
- **文案三件**：
  - **briefing**：公元六七〇年秋，吐蕃大相论钦陵攻占了西域，又吞并了吐谷浑。薛仁贵奉命西征，副将郭待封却自恃出身名门，据说一直不愿听他的号令。
  - **inviteText**：「郭将军，辎重就留在大非岭，千万不要擅动。我带轻骑去乌海，速去速回。」
  - **description**：薛仁贵在乌海打了胜仗，郭待封却带着辎重擅自前进，被吐蕃截击，粮草全失。唐军退到大非川，被论钦陵的大军团团围住，最终大败，薛仁贵只能与吐蕃约和而还。

### 场 4｜682 · 云州之战（野战，主角守，剧终）
- **片/段**：三 / 段四 云州
- **① 入镜**：大非川 → 长安 → 晋阳 → 宁武关 → 大同。
- **势力/地点**：攻 东突厥（后突厥，库里突厥系势力，做事件时查）｜守 唐。地点 云州城外（野战）。
- **② 人物**：攻 东突厥**阿史德元珍**（库里没有）｜守 瓜州长史、代州都督**薛仁贵**（年近七十，年岁不进文案）。
- **③ 起因**：东突厥复叛，入寇云州。
- **④ 经过**：突厥问唐将是谁，唐军说是薛仁贵；突厥说听说薛将军已死，怎么还在；薛仁贵脱下头盔露出面孔，突厥人相顾失色，下马列拜，陆续退走（史实）；薛仁贵乘势追击（史实）。
- **⑤ 结局**：突厥大败，斩首万余、俘获二万余（史实，数字不进文案）。不易主。
- **⑥ 出镜**：剧终。683 年薛仁贵卒（史实，B 档尾声）。
- **⑦ 出处**：《旧唐书·薛仁贵传》；英文维基 *Xue Rengui*。
- **文案三件**：
  - **briefing**：公元六八二年，东突厥又一次南下，兵临云州城外。突厥人远远问道，唐军的主将是谁？唐军答道，是薛仁贵。突厥人据说不信，都以为那位白袍将军早已不在人世。
  - **inviteText**：「告诉他们，薛仁贵还活着。我这就把头盔摘下来，让他们看清楚。」
  - **description**：年迈的薛仁贵摘下头盔，露出面容，突厥将士面面相觑，纷纷下马行礼，慢慢往后退去。薛仁贵趁势挥军追击，大破突厥，这是他一生的最后一战。
