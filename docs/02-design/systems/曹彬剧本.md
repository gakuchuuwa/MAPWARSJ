## 三、分场卡

### 场 1｜974–975 · 金陵（攻城）
- **片/段**：一 · 灭南唐 / 段一 金陵
- **① 入镜**：江陵 → 巴陵 → 武昌 → 柴桑 → 姑孰 → 金陵。
- **势力/地点**：攻 北宋｜守 南唐（库里南唐系势力，做事件时查）。据点 **金陵** `city_nanjing`（战后 `cityUpdates` 归 `song`）。
- **② 人物**：攻 升州西南面行营都部署**曹彬**、**潘美**（库里没有）｜守 南唐后主**李煜**（库里没有）、神卫都军头**皇甫继勋**（库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：南唐称臣而不入朝，宋太祖决意灭之。
- **④ 经过**：宋军在采石架设浮桥，大军如履平地渡过长江（史实）；围金陵近一年；城将破时，曹彬称病不视事，诸将来问，他说「吾之病非药石所能愈，愿诸公共为信誓，破城之日不妄杀一人，则自愈矣」，诸将焚香立誓（史实）。
- **⑤ 结局**：金陵城破，李煜出降，南唐亡（史实）。**金陵归宋**。
- **⑥ 出镜**：凯旋，只奏「奉敕江南干事回」（史实）；任枢密使。
- **⑦ 出处**：《宋史·曹彬传》；英文维基 *Song conquest of Southern Tang*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元九七四年冬，宋将曹彬领着水陆大军顺江东下，在采石架起了浮桥，渡过了长江。南唐后主李煜是个多情的词人，据说直到城下已经围满了宋军，他还在宫中填词。
  - **inviteText**：「诸位，城破之日，不许妄杀一人。你们发了这个誓，我的病就好了。」
  - **description**：宋军围城将近一年，城破之前，曹彬忽然称病不出。诸将前来探望，他说只要大家立誓破城后不滥杀百姓，病就会好。诸将焚香起誓，宋军入城秋毫无犯，李煜出宫投降，南唐就此灭亡。
