## 三、分场卡

### 场 1｜208 · 长坂桥（野战，主角守）
- **片/段**：一 · 荆州 / 段一 长坂
- **① 入镜**：樊城（襄阳）→ 当阳 → 长坂。
- **势力/地点**：攻 曹操｜守 刘备。地点 长坂坡（野战）。
- **② 人物**：攻 **曹操**所遣虎豹骑（主将曹纯，库里没有）｜守 **张飞**（库里有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：刘备弃樊城南逃，百姓随行，一日行十余里；曹操亲率轻骑一日一夜追三百余里，在当阳长坂追上（史实，数字不进文案）。
- **④ 经过**：刘备弃妻子逃走，令张飞率二十骑断后；张飞据水断桥，瞋目横矛说「身是张益德也，可来共决死」，曹军无人敢近（《三国志》，史实）。
- **⑤ 结局**：刘备得以脱身（史实）。不易主。
- **⑥ 出镜**：随刘备退到夏口；此后赤壁之战（B 档）。
- **⑦ 出处**：英文维基 *Battle of Changban*；《三国志·张飞传》。
- **文案三件**：
  - **briefing**：公元二〇八年秋，刘备带着逃难的百姓一路南撤，曹操的虎豹骑在当阳长坂追了上来。刘备丢下妻儿逃走，把断后的重任交给了张飞。
  - **inviteText**：「身是张益德也，可来共决死！」
  - **description**：张飞拆断了河上的桥，横矛立马站在河边，瞪大眼睛向曹军大喝。曹军骑兵面面相觑，竟没有一个人敢上前，刘备趁机逃出了险境。

### 场 2｜214 · 江州（攻城）
- **片/段**：二 · 入蜀 / 段二 江州
- **① 入镜**：当阳 → 江陵 → 夷陵 → 溯江 → 重庆。
- **势力/地点**：攻 刘备｜守 刘璋（库里益州系势力，做事件时查）。据点 **重庆** `city_chongqing`（江州；战后 `cityUpdates` 归刘备方）。
- **② 人物**：攻 **张飞**｜守 巴郡太守**严颜**（库里没有）。
- **③ 起因**：刘备围雒城，诸葛亮、张飞、赵云奉命溯江入蜀增援。
- **④ 经过**：张飞破江州，生擒严颜，喝问何不投降；严颜答「我州但有断头将军，无有降将军」，张飞怒令斩之，严颜面不改色说「斫头便斫头，何为怒邪」，张飞壮而释之，引为宾客（《三国志》，史实）。
- **⑤ 结局**：**江州归刘备**（史实）。
- **⑥ 出镜**：分定巴西诸郡，会刘备于成都。
- **⑦ 出处**：《三国志·张飞传》；英文维基 *Zhang Fei*（江州之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元二一四年，张飞随诸葛亮溯江入蜀，来到巴郡的江州城下。守城的巴郡太守严颜据说是个硬骨头，发誓绝不投降。
  - **inviteText**：「诸位，城里的老将军脾气硬，我倒要看看，他的骨头到底有多硬。」
  - **description**：张飞攻破江州，生擒严颜，喝问他为何不降。严颜说益州只有断头的将军，没有投降的将军，张飞怒令推出去斩首，严颜却面不改色。张飞被他的气节打动，亲手为他松绑，待为上宾。

### 场 3｜215 冬 · 瓦口之战（野战，主角守，剧终）
- **片/段**：二 / 段三 巴西
- **① 入镜**：重庆 → 成都 → 隆城 → 宕渠 → 瓦口。
- **势力/地点**：攻 曹魏｜守 刘备。地点 宕渠瓦口（野战）。
- **② 人物**：攻 曹魏**张郃**（库里有，做事件时查）｜守 **张飞**（时任巴西太守）。
- **③ 起因**：曹操平定汉中后，张郃南下巴西，想把当地百姓迁往汉中（史实）。
- **④ 经过**：两军在宕渠相持五十余日；张飞率精卒从小路截击张郃，山道狭窄，张郃军前后不能相救（史实）。
- **⑤ 结局**：张郃大败，弃马缘山、与部下十余人从小路逃回南郑（史实，数字不进文案）。不易主。
- **⑥ 出镜**：剧终。219 年随刘备取汉中，任车骑将军；221 年刘备伐吴前夕，张飞在阆中被部将张达、范强刺杀（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Baxi*；《三国志·张飞传》。
- **文案三件**：
  - **briefing**：公元二一五年冬，曹魏大将张郃领兵南下巴西，想把这里的百姓迁往汉中。巴西太守张飞在宕渠拦住了他，两军在山谷间对峙了很久。
  - **inviteText**：「诸位，张郃守着大路，我们就走山间小道。山路窄，他首尾顾不上。」
  - **description**：张飞率精兵从小路绕到魏军侧后，山道狭窄，魏军首尾不能相救，顿时大乱。张郃丢下战马，攀着山崖逃走，只带着少数亲兵狼狈退回了南郑。
