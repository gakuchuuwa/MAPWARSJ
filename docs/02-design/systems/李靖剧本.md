## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜621 秋 · 江陵（攻城）**　①夔州 → 三峡 → 夷陵 → 江陵。②攻 **李靖**（库里有；名义主帅是赵郡王李孝恭）｜守 梁帝**萧铣**（库里没有）。主将队：待看素材定。③萧铣据江陵称帝。④秋天江水暴涨，萧铣以为唐军不敢出三峡，未加防备；李靖力主乘水势直下，先破文士弘于清江口，缴获战船数百艘，并把船只全部放入江中漂流，让萧铣援军以为江陵已破而不敢进（史实）。⑤萧铣出降（史实）。**江陵归唐**（`city_ying` → `tang`）。⑥抚定岭南（B 档）。⑦英文维基 *Li Jing (Tang dynasty)* <https://en.wikipedia.org/wiki/Li_Jing_(Tang_dynasty)>。

**2｜630 春 · 夜袭定襄**　①江陵 → 长安 → 晋阳 → 马邑 → 恶阳岭。②攻 李靖 三千骑（史实）｜守 东突厥**颉利可汗**（库里没有）。③东突厥连年南侵，626 年兵临渭水便桥，唐太宗决意反击。④李靖在正月严寒中率三千骑从马邑出发，进屯恶阳岭，夜袭定襄。⑤颉利可汗以为唐军全军已到，大惊逃往碛口（史实）。⑥追击。⑦*Tang campaign against the Eastern Turks* <https://en.wikipedia.org/wiki/Tang_campaign_against_the_Eastern_Turks>。

**3｜630 春 · 阴山之战**　①定襄 → 阴山。②攻 李靖 一万骑（史实）｜守 颉利可汗（通行说法数万，按 §一.2 封顶）。③颉利可汗遣使请降，想拖到草青马肥再逃往漠北。④李靖趁唐使在突厥营中、对方放松戒备，带一万精骑、二十日粮夜袭，前锋苏定方率两百骑借大雾直逼牙帐。⑤突厥溃败，颉利可汗后被俘，东突厥灭亡（史实）；唐太宗被各族尊为「天可汗」。⑥⑦*Battle of Yinshan* <https://en.wikipedia.org/wiki/Battle_of_Yinshan>。

**4｜635 · 征吐谷浑（剧终）**　①阴山 → 长安 → 狄道 → 青海。②攻 李靖（年逾六十）｜守 吐谷浑**伏允可汗**（库里没有）。③吐谷浑屡扰河西。④吐谷浑烧光野草、退入大漠；李靖分兵追击，侯君集、李道宗穿越两千余里无人区，在高原上嚼冰、马啃雪（史实）。⑤伏允可汗自杀，吐谷浑归附（史实）。**伏俟城归唐**。⑥剧终：649 年李靖卒，著有兵书（B 档）。⑦英文维基 *Li Jing (Tang dynasty)*（征吐谷浑独立条目**待核**）。

## 六、疑点
1. 第一场出发地：规则取本城恶阳岭（在北方），史实从夔州出兵。
2. 江陵之战名义主帅是李孝恭（同塞琉古加沙之战一类）。
3. 定襄、阴山两场突厥兵力按 §一.2 封顶，文案只写「以少击众」。
4. 归化城 1575 年才建，阴山战场附近前后都没有唐代据点。
