## 三、分场卡

### 场 1｜548 · 涡阳之战（野战，主角守）
- **片/段**：一 · 叛东魏 / 段一 涡阳
- **① 入镜**：悬瓠 → 新蔡 → 蒙城 → 涡阳。
- **势力/地点**：攻 东魏（库里北齐 `gaoqi_d`）｜守 侯景。地点 涡阳（野战）。
- **② 人物**：攻 东魏大将**慕容绍宗**（库里没有）｜守 **侯景**。主将队：封建时代草原/北方英雄兵模（548 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：高欢死，高澄掌权，侯景据河南十三州叛东魏，先投西魏、再降南梁；高欢临终前说能制侯景的只有慕容绍宗（史实）。
- **④ 经过**：侯景令部下披短甲、执短刀，专砍马腿，一度击退东魏军；慕容绍宗站稳后散布消息说侯景部下的家眷都安然无恙、投降可保全，侯景军中北人纷纷逃散（史实）。
- **⑤ 结局**：侯景大败，只带八百骑南逃，袭据梁的寿阳（史实，数字不进文案）。不易主。
- **⑥ 出镜**：据寿阳，暗中勾结梁宗室萧正德，谋渡江。
- **⑦ 出处**：英文维基 *Hou Jing*（涡阳之战独立条目待核）；《梁书·侯景传》。
- **文案三件**：
  - **briefing**：公元五四八年正月，东魏大将慕容绍宗率大军来讨伐叛将侯景。高欢临终前曾说，天下能对付侯景的，只有慕容绍宗一人。
  - **inviteText**：「兄弟们，东魏的马多，我们就砍马腿。披短甲、拿短刀，贴着地面冲过去。」
  - **description**：侯景的士兵专砍马腿，东魏骑兵一度被打退。慕容绍宗却派人喊话，说他们留在北方的家人都平安无事，只要回去就能团聚。侯景军中的北方士兵纷纷逃散，侯景只带着少数骑兵逃到了寿阳。

### 场 2｜548–549 · 台城之围（攻城）
- **片/段**：二 · 乱梁 / 段二 台城
- **① 入镜**：蒙城 → 寿春 → 历阳 → 采石渡江 → 姑孰 → 金陵。
- **势力/地点**：攻 侯景｜守 南梁。据点 **金陵** `city_nanjing`（建康台城；战后 `cityUpdates` 归侯景一方——库里没有侯景势力，见疑点 2）。
- **② 人物**：攻 **侯景**、内应梁临贺王**萧正德**（库里没有）｜守 梁武帝**萧衍**、太子**萧纲**、都官尚书**羊侃**（库里没有）；城外梁各路援军柳仲礼、韦粲等（史实）。
- **③ 起因**：梁武帝打算与东魏议和、交还侯景，侯景起兵反梁（史实）。
- **④ 经过**：萧正德为内应，为侯景备船渡江；侯景围台城，筑土山、造攻车，羊侃在城内一一破解（史实）；羊侃死后城中渐危；城外援军号称数十万，却各怀观望，坐视不救（史实）；城中粮尽、疫病横行（史实）。
- **⑤ 结局**：台城陷落，梁武帝被困饿死（史实）。**金陵归侯景**。江南经此一乱，人口锐减（史实）。
- **⑥ 出镜**：废立皇帝，西攻江陵湘东王萧绎。
- **⑦ 出处**：英文维基 *Hou Jing*；*Siege of Taicheng*（独立条目待核）。
- **文案三件**：
  - **briefing**：公元五四八年冬，叛将侯景在梁朝宗室萧正德的接应下，偷偷渡过长江，把梁武帝困在了建康的台城之中。据说城外的援军很多，却没有一路真心来救。
  - **inviteText**：「兄弟们，梁朝的皇帝老了，他的儿孙们都在等着看他死。我们只要围住这座城，就够了。」
  - **description**：侯景堆土山、造攻车，城里的老将羊侃一次次把它们毁掉。可羊侃死后，城中粮尽，瘟疫蔓延，城外的援军始终按兵不动。台城终于陷落，年迈的梁武帝被困在宫中，活活饿死。

### 场 3｜551 · 巴陵（攻城，剧终）
- **片/段**：二 / 段三 巴陵
- **① 入镜**：金陵 → 姑孰 → 柴桑 → 武昌 → 巴陵。
- **势力/地点**：攻 侯景｜守 南梁（湘东王萧绎一方）。据点 **巴陵** `city_baling`（战后不易主）。
- **② 人物**：攻 **侯景**、**任约**（库里没有）｜守 梁大都督**王僧辩**（库里没有）。
- **③ 起因**：侯景西攻江陵的萧绎，王僧辩据巴陵阻其锋。
- **④ 经过**：王僧辩偃旗息鼓，城中寂若无人；侯景军到城下，王僧辩一声令下，鼓噪而起，矢石俱下（史实）；侯景昼夜攻城不下，军中疫病、粮尽，别将任约又被陆法和所擒（史实）。
- **⑤ 结局**：侯景烧营东逃（史实）。巴陵**不易主**。
- **⑥ 出镜**：剧终。王僧辩、陈霸先顺江东下，552 年收复建康；侯景出海北逃，被部下所杀，尸体被分食（史实，文案不渲染，B 档尾声）。
- **⑦ 出处**：英文维基 *Hou Jing*；*Wang Sengbian*。
- **文案三件**：
  - **briefing**：公元五五一年夏，侯景溯江西上，要去攻打江陵的湘东王萧绎。挡在半路的巴陵城，城头上一面旗帜也没有，据说安静得好像一座空城。
  - **inviteText**：「兄弟们，巴陵城里没几个人，一鼓作气拿下来，江陵就在眼前。」
  - **description**：侯景的大军刚到城下，城头上突然战鼓齐鸣，矢石如雨。守将王僧辩早有准备，侯景昼夜强攻都攻不上去，军中又起了瘟疫，粮草也快吃完了，只得烧掉营寨，狼狈东逃。
