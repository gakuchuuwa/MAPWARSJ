## 三、分场卡

### 场 1｜1221 春 · 八鲁湾之战（野战，主角守）
- **片/段**：一 · 抗蒙 / 段一 兴都库什
- **① 入镜**：哥疾宁 → 喀布尔 → 八鲁湾。
- **势力/地点**：攻 蒙古（`menggu_d`）｜守 花剌子模。地点 八鲁湾（帕尔万，野战）。
- **② 人物**：攻 成吉思汗养弟**失吉忽秃忽**（库里没有）｜守 **札兰丁**、突厥将领**阿明·木勒克**、阿富汗诸部（库里没有）。主将队：城堡时代中亚/波斯英雄兵模（按 §二.5 看样貌）；对手城堡时代草原英雄兵模。
- **③ 起因**：札兰丁在哥疾宁聚集了旧部与各族兵马，成吉思汗派失吉忽秃忽追击。
- **④ 经过**：札兰丁命骑兵下马步战，用弓箭挡住蒙古骑兵的冲锋；第二天蒙古军在马上缚草人充数，札兰丁不为所动，全军上马反冲（志费尼，通行说法）。
- **⑤ 结局**：蒙古军大败，这是西征中蒙古军少有的败仗（史实）。战后札兰丁手下诸将为战利品争吵，部众离散。
- **⑥ 出镜**：成吉思汗亲率大军追来，札兰丁退向印度河。
- **⑦ 出处**：英文维基 *Battle of Parwan*。
- **文案三件**：
  - **briefing**：公元一二二一年春，花剌子模王子札兰丁在兴都库什山下收拢了残兵。成吉思汗的养弟失吉忽秃忽追来了，据说蒙古人还在空马上绑了草人，想让对手以为援军已到。
  - **inviteText**：「兄弟们，父亲死在了孤岛上，都城也丢了。可蒙古人不是不会输，今天就让他们尝尝。」
  - **description**：札兰丁让骑兵下马列阵，用弓箭挡住了蒙古骑兵的冲锋。第二天他看穿了草人的把戏，全军上马反冲，蒙古军大败而逃，这是西征以来蒙古人少有的败仗。

### 场 2｜1221 冬 · 印度河之战（野战，主角守）
- 同 [`成吉思汗剧本.md`](成吉思汗剧本.md) 场 6（数据以那边为准）。
- **⑤ 结局补**：札兰丁兵败，纵马跃下河岸泅渡印度河逃生，成吉思汗指着他对诸子说「为父者当有此子」（志费尼，据说如此）。
- **inviteText**（札兰丁线专用）：「兄弟们，背后是大河，前面是成吉思汗。没有退路了，那就往前冲。」

### 场 3｜1225 夏 · 加尔尼西之战（野战）
- **片/段**：二 · 高加索 / 段三 格鲁吉亚
- **① 入镜**：阿托克 → 流亡印度 → 伊斯法罕 → 大不里士 → 加尔尼西。
- **势力/地点**：攻 花剌子模｜守 格鲁吉亚（库里 `gelujiya`）。地点 加尔尼西（野战）。
- **② 人物**：攻 **札兰丁**｜守 格鲁吉亚阿塔贝格**伊瓦奈·姆哈尔格尔泽利**（库里没有）。
- **③ 起因**：札兰丁西返后夺取阿塞拜疆，转攻格鲁吉亚。
- **④ 经过**：格鲁吉亚军据守山地，札兰丁诱敌下山后反击；格鲁吉亚诸将不和，一部按兵不动（通行说法）。
- **⑤ 结局**：格鲁吉亚军大败（史实）。不易主。
- **⑥ 出镜**：北上第比利斯。
- **⑦ 出处**：英文维基 *Battle of Garni*。
- **文案三件**：
  - **briefing**：公元一二二五年夏，札兰丁从印度回到了西方，夺下了阿塞拜疆。格鲁吉亚的大军据守在加尔尼的山地上，他们的将领之间，据说并不怎么和睦。
  - **inviteText**：「兄弟们，我们在印度躲了好几年，现在回来了。先打赢这一仗，才有地方重新立国。」
  - **description**：札兰丁引诱格鲁吉亚军下山，在谷地里回身猛攻。格鲁吉亚诸将互不救援，有的按兵不动，大军溃败。

### 场 4｜1226 春 · 第比利斯（攻城）
- **片/段**：二 / 段三
- **① 入镜**：加尔尼西 → 第比利斯。
- **势力/地点**：攻 花剌子模｜守 格鲁吉亚。据点 **第比利斯** `city_dibilisi`（战后 `cityUpdates` 归花剌子模 `huarazim`）。
- **② 人物**：攻 **札兰丁**｜守 格鲁吉亚守军（女王鲁苏丹已避走库塔伊西；库里没有）。
- **③ 起因**：格鲁吉亚主力新败，都城空虚。
- **④ 经过**：城中穆斯林居民开门接应，花剌子模军入城（通行说法）。
- **⑤ 结局**：**第比利斯归花剌子模**（史实）；城中基督徒遭屠戮（史实，文案只写「据说」）。
- **⑥ 出镜**：南下；1227 年在伊斯法罕城下迎战蒙古军（B 档）。
- **⑦ 出处**：英文维基 *Sack of Tbilisi (1226)*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一二二六年春，格鲁吉亚的都城第比利斯门户大开。女王鲁苏丹已经避走西方，城里的穆斯林据说早就暗中联络了札兰丁。
  - **inviteText**：「兄弟们，第比利斯的城门有人替我们打开了。进城之后，别忘了我们是来立国的。」
  - **description**：城中有人开门接应，花剌子模军一拥而入。据说札兰丁的士兵在城里大肆屠戮，第比利斯遭受了一场浩劫。

### 场 5｜1230 夏 · 亚斯切门之战（野战，主角守，剧终）
- **片/段**：三 · 败亡 / 段四 安纳托利亚
- **① 入镜**：第比利斯 → 大不里士 → 亚斯切门。
- **势力/地点**：攻 罗姆苏丹国与阿尤布联军（库里罗姆 `rum` 等，做事件时查）｜守 花剌子模。地点 亚斯切门（野战）。
- **② 人物**：攻 罗姆苏丹**凯库巴德一世**、阿尤布王子**阿什拉夫**（库里没有）｜守 **札兰丁**。
- **③ 起因**：札兰丁攻取阿尤布的阿赫拉特，引来罗姆与阿尤布结盟讨伐。
- **④ 经过**：札兰丁病中指挥，联军以步兵弓弩居前、骑兵两侧包抄，花剌子模军溃败（通行说法）。
- **⑤ 结局**：札兰丁大败（史实），从此失去了最后的根基。不易主。
- **⑥ 出镜**：剧终。1231 年蒙古将领绰儿马罕追至，札兰丁逃入库尔德山区，被当地库尔德人所杀（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Yassıçemen*。
- **文案三件**：
  - **briefing**：公元一二三〇年夏，札兰丁在阿赫拉特城下耗了太久，罗姆苏丹与阿尤布王子结成联盟，大军向他压来。据说此时的札兰丁正在生病。
  - **inviteText**：「兄弟们，我们打过蒙古人，打过格鲁吉亚人，今天连同为穆斯林的人也来打我们了。那就再打一场。」
  - **description**：联军步兵持弩居前，骑兵从侧面包抄，花剌子模军抵挡不住，溃散而去。札兰丁失去了最后的根基，第二年蒙古追兵到来，他逃进山里，死在了库尔德人的手中。
