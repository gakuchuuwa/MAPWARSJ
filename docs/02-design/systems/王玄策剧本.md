## 三、分场卡

### 场 1｜648 · 茶镈和罗城（攻城，剧终）
- **片/段**：一 · 借兵破天竺 / 段一
- **① 入镜**：泥婆罗 → 茶镈和罗城。
- **势力/地点**：攻 唐使王玄策（借吐蕃、泥婆罗兵，库里吐蕃系、泥婆罗系势力，做事件时查）｜守 中天竺篡位者阿罗那顺（库里没有）。据点 茶镈和罗城（库里没有；§二之二 可添加，离华氏城 61 km，按间距能过，添加前须 `--probe` 实测）。
- **② 人物**：攻 **王玄策**（库里有）、副使**蒋师仁**（库里没有）｜守 中天竺**阿罗那顺**（库里没有）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）；吐蕃、泥婆罗兵种按样貌选。
- **③ 起因**：戒日王死，大臣阿罗那顺篡位，发兵劫掠唐朝使团，从骑尽没，王玄策只身逃脱（史实）。
- **④ 经过**：王玄策檄召吐蕃、泥婆罗兵，与蒋师仁率之进至茶镈和罗城，连战三日，大破之（史实，数字不进文案）。
- **⑤ 结局**：斩首三千余级、溺死者万人，阿罗那顺弃城而逃，后被擒（史实，数字不进文案）；俘阿罗那顺献于长安（史实）。
- **⑥ 出镜**：剧终。王玄策后又两次出使天竺，著《中天竺国行记》（已佚）（史实，数字不进文案；B 档尾声）。
- **⑦ 出处**：英文维基 *Wang Xuance*；《旧唐书·天竺传》。
- **文案三件**：
  - **briefing**：公元六四八年，唐朝使臣王玄策出使天竺，正赶上戒日王去世，篡位的阿罗那顺竟然发兵劫掠了整个使团。王玄策只身逃到吐蕃边境，据说他没有回长安，而是在那里写下了求援的檄文。
  - **inviteText**：「吐蕃和泥婆罗的朋友们，大唐的使团被人劫了，这个仇不能不报。借我兵马，我去讨个公道。」
  - **description**：王玄策借来吐蕃与泥婆罗的兵马，与副使蒋师仁一路南下，在茶镈和罗城下连战数日，大破阿罗那顺的军队。阿罗那顺弃城逃走，最后被擒，王玄策押着他一路回到了长安。
