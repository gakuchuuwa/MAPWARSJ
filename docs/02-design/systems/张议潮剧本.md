## 三、分场卡

### 场 1｜848 · 沙州起义（攻城）
- **片/段**：一 · 河西归唐 / 段一 沙州
- **① 入镜**：阳关 → 敦煌。
- **势力/地点**：攻 沙州义军（张议潮）｜守 吐蕃（库里吐蕃系势力，做事件时查）。据点 **敦煌** `city_dunhuang`（战后 `cityUpdates` 归唐方 `shazhou`）。
- **② 人物**：攻 **张议潮**（库里有）、其兄**张议潭**、侄**张淮深**（库里没有）｜守 吐蕃沙州守将（史书未载名）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：吐蕃占据河西近百年，推行蕃化；842 年吐蕃赞普朗达玛遇刺，国内大乱（史实，数字不进文案）。
- **④ 经过**：张议潮联络沙州汉人豪族与各族百姓，被甲执兵，号令起事，吐蕃守将惊走（史实）。
- **⑤ 结局**：**沙州归唐**（史实）；张议潮摄州事，随即遣使绕道天德军入长安报捷（史实）。
- **⑥ 出镜**：东进收复瓜、肃、甘诸州（B 档）。
- **⑦ 出处**：英文维基 *Zhang Yichao*；*Guiyi Circuit*。
- **文案三件**：
  - **briefing**：公元八四八年，河西走廊已经被吐蕃占据了很久。沙州城里的汉人们据说仍然偷偷穿着唐人的衣裳，祭祀时向着东方哭拜。这一年，吐蕃国内大乱，张议潮觉得，时候到了。
  - **inviteText**：「乡亲们，我们的祖辈是唐人，我们也是唐人。拿起兵器，把沙州还给大唐。」
  - **description**：张议潮一声号令，沙州城里的汉人与各族百姓披甲执兵，一齐起事，吐蕃守将仓皇出逃。沙州光复之后，他立刻派出使者，绕过吐蕃的地界，历尽艰险把捷报送到了长安。

### 场 2｜861 · 凉州（攻城，剧终）
- **片/段**：一 / 段二 凉州
- **① 入镜**：敦煌 → 玉门关 → 嘉峪关 → 张掖 → 姑臧。
- **势力/地点**：攻 归义军｜守 吐蕃。据点 **姑臧** `city_wuwei`（凉州；战后 `cityUpdates` 归唐方）。
- **② 人物**：攻 **张议潮**｜守 吐蕃凉州守军（史书未载名）。
- **③ 起因**：凉州是河西首府，吐蕃仍据守，隔断河西与长安的通路。
- **④ 经过**：张议潮率蕃汉兵东征凉州，攻拔之（史实，细节简略）。
- **⑤ 结局**：**凉州归唐**，河西十一州尽数光复，丝路重新畅通（史实，数字不进文案）。
- **⑥ 出镜**：剧终。867 年张议潮入长安为质，872 年卒于长安（史实，B 档尾声）；侄张淮深继掌归义军。
- **⑦ 出处**：英文维基 *Zhang Yichao*；《新唐书·吐蕃传》。
- **文案三件**：
  - **briefing**：公元八六一年，张议潮已经收复了河西的大部分州城，只剩下最大的凉州还在吐蕃手里。凉州不下，河西通往长安的路就始终是断的。
  - **inviteText**：「乡亲们，拿下凉州，河西的路就通到长安了。去让长安的人看看，河西还是大唐的河西。」
  - **description**：归义军的蕃汉将士一齐攻城，凉州终于光复。河西走廊重新连成一片，从沙州到长安的道路又一次畅通，敦煌的壁画上后来画下了张议潮出行的盛大场面。
