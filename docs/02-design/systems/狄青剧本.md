## 三、分场卡

**1｜1053 · 夜夺昆仑关**　①开封 → 桂州 → 宾州 → 昆仑关。②攻 **狄青**（库里有，脸上刺字，戴铜面具冲阵）｜守 侬智高守军（库里有「侬智高」，做事件时再查）。主将队：待看素材定。③侬智高攻破邕州，建大南国，连下岭南八州。④狄青在宾州连宴三夜，上元节当夜借口身体不适离席，趁大风雨率军夜过昆仑关（史实）。⑤天亮时已过关，侬智高军措手不及（史实）。⑥⑦英文维基 *Di Qing*；*Nong Zhigao*。

**2｜1053 · 归仁铺之战（剧终）**　①昆仑关 → 归仁铺。②攻 狄青｜守 侬智高。③侬智高在归仁铺列阵迎战。④宋军步兵前锋失利，狄青亲自执白旗指挥蕃落骑兵从左右翼冲入敌阵（史实）。⑤侬智高大败，烧城逃往大理（史实）。**晋兴（邕州）归宋**。⑥剧终：回京任枢密使，因出身行伍受文臣猜忌，1057 年罢职后郁郁而终（B 档）。⑦同上。
