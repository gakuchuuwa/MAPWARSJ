## 三、分场卡

### 场 1｜194 · 濮阳（攻城，主角守）
- 同 [`曹操剧本.md`](曹操剧本.md) 场 2（数据以那边为准）。
- **② 人物**：主将队按 §二.5 看样貌选古典时代华夏英雄兵模（吕布以骑射骁勇著称）。
- **inviteText**（吕布线专用）：「诸位，曹操的老家被我们端了，他急着回来抢。让他进城来，我们在城里等他。」
- **description**（吕布线专用）：曹操夜里攻入濮阳东门，吕布的骑兵四面冲杀，曹军大乱，曹操的坐骑受惊，他本人被火烧伤手掌，险些被擒，突围而出。

### 场 2｜196 · 夺下邳（攻城）
- **片/段**：一 / 段二 徐州
- **① 入镜**：濮阳 → 定陶 → 小沛 → 下邳。
- **势力/地点**：攻 吕布｜守 刘备（张飞留守）。据点 **下邳** `city_xiapi`（战后 `cityUpdates` 归吕布 `pizhou`）。
- **② 人物**：攻 **吕布**｜守 **张飞**（库里有 `langzhou_zhangfei`）；下邳相**曹豹**（库里没有）。
- **③ 起因**：刘备与袁术相持于盱眙、淮阴，留张飞守下邳；张飞与曹豹不和，杀曹豹，城中大乱（史实）。
- **④ 经过**：袁术写信劝吕布袭下邳，许以粮草；吕布水陆东下，丹阳兵中郎将许耽开门接应（史实）。
- **⑤ 结局**：张飞败走，吕布虏刘备妻子，**下邳归吕布**（史实）。
- **⑥ 出镜**：刘备回兵求和，吕布让他屯小沛（B 档）。
- **⑦ 出处**：《三国志·吕布传》《先主传》；英文维基 *Lü Bu*。
- **文案三件**：
  - **briefing**：公元一九六年夏，刘备领兵在淮水边抵挡袁术，把下邳交给张飞看守。张飞与下邳相曹豹闹翻，据说一怒之下杀了曹豹，城里人心惶惶。袁术的使者这时找到了寄居在小沛的吕布。
  - **inviteText**：「诸位，刘备待我不薄，可下邳的门已经有人替我们打开了。天下乱成这样，谁不是为自己打算？」
  - **description**：吕布的军队水陆并进，趁夜来到下邳，城中的丹阳兵打开城门迎他进城。张飞仓皇出逃，刘备的家眷都落到了吕布手中，徐州就这样换了主人。

### 场 3｜198 · 下邳之战（攻城，主角守，剧终）
- 同 [`曹操剧本.md`](曹操剧本.md) 场 4（数据以那边为准）。
- **⑥ 出镜**：剧终。吕布被部将侯成、宋宪、魏续绑缚出降，求曹操收用；刘备在旁提醒丁原、董卓之事，曹操遂将吕布缢杀（史实）。
- **inviteText**（吕布线专用）：「诸位，城外的水越来越深，城里的人心越来越散。可只要我还骑得动赤兔，就没有人能拿下下邳。」
- **description**（吕布线专用）：曹军决开泗水、沂水灌城，围了很久。吕布的部将们终于绑了陈宫，打开城门投降，吕布登上白门楼，见大势已去，也下楼请降。他求曹操留他一命，刘备却在一旁提起了丁原和董卓，曹操于是下令将他缢死。
