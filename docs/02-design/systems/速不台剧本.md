## 三、分场卡

### 场 1｜1221 秋 · 胡南之战（野战）
- **片/段**：一 · 大迂回 / 段一 高加索
- **① 入镜**：哈马丹 → 大不里士 → 第比利斯方向 → 胡南。
- **势力/地点**：攻 蒙古（`menggu_d`）｜守 格鲁吉亚（库里 `gelujiya`）。地点 胡南（野战，`bf_*`）。
- **② 人物**：攻 **速不台**（库里有）、**哲别**（库里没有）｜守 格鲁吉亚王**乔治四世·拉沙**（库里没有）。主将队：城堡时代草原英雄兵模，按 §二.5 看样貌选；对手主将队选城堡时代高加索/拜占庭系英雄兵模。
- **③ 起因**：花剌子模沙摩诃末死于里海小岛，速不台、哲别奉成吉思汗之命继续西行侦察，进入高加索。
- **④ 经过**：蒙古军以轻骑诱格鲁吉亚骑士出阵，佯退后回身合击（通行说法）。
- **⑤ 结局**：格鲁吉亚军大败，乔治四世受伤（史实），蒙古军不攻城而去。不易主。
- **⑥ 出镜**：北上穿越杰尔宾特山口。
- **⑦ 出处**：英文维基 *Battle of Khunan*；*Subutai*；格鲁吉亚语维基未查。
- **文案三件**：
  - **briefing**：公元一二二一年秋，速不台与哲别追着花剌子模的残军一路西来，越过阿塞拜疆，闯进了格鲁吉亚的山谷。格鲁吉亚国王乔治四世率领骑士迎战，他恐怕还不知道，眼前这支骑兵只是一支侦察的偏师。
  - **inviteText**：「朋友，大汗叫我们往西看看天有多大。前面这些披甲骑士很骄傲，我们先退一退，让他们追上来。」
  - **description**：蒙古骑兵佯装败退，引着格鲁吉亚骑士追出很远，随后回身合击。乔治四世负伤退走，速不台没有攻城，继续北去。

### 场 2｜1223 夏 · 迦勒迦河之战（野战，主角守）
- **片/段**：一 · 大迂回 / 段二 草原
- **① 入镜**：第比利斯 → 打耳班 → 北高加索 → 顿河草原 → 迦勒迦河。
- **势力/地点**：攻 罗斯诸公国与库曼（库里 `luosi` 基辅等）｜守 蒙古。地点 迦勒迦河（野战）。
- **② 人物**：攻 加利奇大公**姆斯季斯拉夫·姆斯季斯拉维奇**、基辅大公**姆斯季斯拉夫三世**、库曼首领**科特扬**（库里都没有）｜守 **速不台**、哲别。
- **③ 起因**：蒙古军在北高加索击破库曼人，库曼首领科特扬向女婿加利奇大公求援，罗斯诸公联军东进。
- **④ 经过**：速不台连退多日，把联军拉长；联军各公互不统属，库曼人先接战溃退，冲乱了罗斯军阵；基辅大公据营不出，后被围降（史实）。
- **⑤ 结局**：联军大败，基辅大公投降后被压死在木板下（史实）。不易主。
- **⑥ 出镜**：东渡伏尔加河。
- **⑦ 出处**：英文维基 *Battle of the Kalka River*；俄文维基未查。
- **文案三件**：
  - **briefing**：公元一二二三年春夏之交，罗斯诸公与库曼人合兵东来，要替草原上的盟友报仇。速不台一退再退，把他们引到了迦勒迦河边。诸公之间谁也不服谁，这一点，速不台似乎早就看在眼里。
  - **inviteText**：「朋友，他们人多，可心不齐。我们再退几天，让他们自己把队伍拉散，到了河边再回头。」
  - **description**：库曼人先与蒙古军接战，一触即溃，冲乱了身后的罗斯军阵。基辅大公据营死守，终究被围而降，被压死在蒙古人庆功的木板之下。

### 场 3｜1223 冬 · 萨马拉弯之战（野战）
- **片/段**：一 · 大迂回 / 段二 草原
- **① 入镜**：卡尔卡河 → 东渡伏尔加河 → 萨马拉。
- **势力/地点**：攻 蒙古｜守 伏尔加保加尔（库里 `baojiaer`，本城喀山）。地点 萨马拉弯（野战）。
- **② 人物**：攻 速不台、哲别｜守 伏尔加保加尔人（主帅史书未载名，库里没有；按 §一.3 取「保加尔汗」泛称）。
- **③ 起因**：蒙古军东归途中进入伏尔加保加尔境内。
- **④ 经过**：保加尔人设伏诱敌，蒙古军中伏（通行说法；细节多出自伊本·艾西尔，史料少）。
- **⑤ 结局**：蒙古军败退东归（史实）。这是速不台少有的败仗。不易主。
- **⑥ 出镜**：东归与成吉思汗会合。
- **⑦ 出处**：英文维基 *Battle of Samara Bend*（条目可信度一般，史料单薄）。
- **文案三件**：
  - **briefing**：公元一二二三年冬，速不台的骑兵在草原上转了一个大圈，准备东归。伏尔加河畔的保加尔人却早已埋伏在河湾里。据说，这是速不台一生里难得的一次失手。
  - **inviteText**：「朋友，路走得太顺，人就容易大意。前面河湾里静得出奇，恐怕有埋伏。」
  - **description**：保加尔人佯退设伏，蒙古军追入河湾后遭到截击，死伤不少。速不台收拢残部，东归与成吉思汗会合。

### 场 4｜1232 春 · 三峰山之战（野战）
- **片/段**：二 · 灭金 / 段三 河南
- **① 入镜**：萨马拉 → 东归 → 哈拉和林 → 大同 → 南郑 → 邓州方向 → 三峰山。
- **势力/地点**：攻 蒙古｜守 金（库里有金/女真系势力，做事件时查）。地点 三峰山（野战）。
- **② 人物**：攻 **拖雷**（库里有 `borjigin_tuolei`）、**速不台**｜守 金将**完颜合达**、**移剌蒲阿**（库里没有）。
- **③ 起因**：窝阔台三路灭金，拖雷率右军借道宋境汉中，绕到金军背后，金军主力从邓州北上追击。
- **④ 经过**：蒙古军轮番袭扰，不与金军决战；天降大雪，金军饥寒交迫，蒙古军故意放开一条去钧州的路，在路上截杀（史实）。
- **⑤ 结局**：金军主力覆灭，完颜合达、移剌蒲阿死（史实）；金国从此再无野战之兵。钧州归蒙古（库里没有钧州，不写易主）。
- **⑥ 出镜**：北上围开封。
- **⑦ 出处**：英文维基 *Battle of Sanfengshan*；中文维基《三峰山之战》未查。
- **文案三件**：
  - **briefing**：公元一二三二年正月，拖雷和速不台绕过宋境，出现在金军的背后。金军主力从邓州一路北上追赶，却在三峰山下遇上了漫天大雪。
  - **inviteText**：「朋友，金人急着回去救汴京，我们就陪他们走一走。天要下雪了，雪对他们不利。」
  - **description**：蒙古军不与金军硬拼，只是日夜袭扰。大雪一连数日，金军又饿又冻，蒙古军故意让开去钧州的路，在半路截杀，完颜合达与移剌蒲阿先后战死。

### 场 5｜1232–1233 · 开封（攻城）
- **片/段**：二 · 灭金 / 段三 河南
- **① 入镜**：三峰山 → 新郑 → 开封。
- **势力/地点**：攻 蒙古｜守 金。据点 **开封** `city_bianliang`（攻城战，战后 `cityUpdates` 开封归 `menggu_d`）。
- **② 人物**：攻 **速不台**（窝阔台北返后留他主持围城）｜守 **金哀宗**完颜守绪（库里没有），后为西面元帅**崔立**（库里没有）。
- **③ 起因**：金军主力在三峰山覆灭，蒙古军围困金国都城。
- **④ 经过**：蒙古军用炮石日夜轰城，金军用「震天雷」「飞火枪」还击（史实，火器可用）；城中又逢大疫；金哀宗出城东走，崔立杀留守大臣，开城投降（史实）。
- **⑤ 结局**：**开封归蒙古**（史实）。
- **⑥ 出镜**：北返；1235 年随拔都西征。
- **⑦ 出处**：英文维基 *Siege of Kaifeng (1232)*；中文维基未查。
- **文案三件**：
  - **briefing**：公元一二三二年春，速不台的大军围住了金国都城汴京。城头上，金军点燃了震天雷与飞火枪，城下的蒙古军则用炮石回敬。围城一连数月，城里又闹起了瘟疫。
  - **inviteText**：「朋友，汴京城墙很高，可城里的人已经没有粮食，也没有援兵了。不必急着爬墙，等他们自己开门。」
  - **description**：蒙古炮石昼夜不停，金军以火器死守。瘟疫在城中蔓延，金哀宗弃城东走，留守的崔立杀了大臣，打开城门投降。

### 场 6｜1241 春 · 莫希之战（野战，剧终）
- **片/段**：三 · 长子西征 / 段四 匈牙利
- **① 入镜**：开封 → 西征（B 档）→ 梁赞 → 基辅 → 喀尔巴阡山口 → 莫希。
- **势力/地点**：攻 金帐/蒙古（与拔都线一致）｜守 匈牙利（库里 `mazhaer`）。地点 莫希（野战）。
- **② 人物**：攻 **拔都**（库里有 `gen_batu`）、**速不台**｜守 匈牙利国王**贝拉四世**（库里没有）。
- **③ 起因**：匈牙利收容了逃亡的库曼人，拒不交出。
- **④ 经过**：匈牙利军以车阵扎营于绍约河边；拔都夜攻河上石桥，速不台从下游搭桥偷渡，绕到车阵背后（史实）。
- **⑤ 结局**：匈牙利军覆没，贝拉四世逃走（史实）。不易主。

  - **inviteText**：「朋友，拔都攻桥，我去下游搭桥。等我们绕到他们背后，那座车阵就成了他们自己的牢笼。」
  - **description**：拔都连夜强攻石桥，速不台在下游渡河，绕到匈牙利车阵背后。匈牙利军被困在车阵里，突围时溃散，贝拉四世只身逃脱。
