## 三、分场卡

### 场 1｜1268–1273 · 襄阳之战（攻城）
- **片/段**：一 · 灭宋 / 段一 襄阳
- **① 入镜**：南郑 → 宛城 → 襄阳。
- **势力/地点**：攻 元｜守 南宋（库里襄州 `xiangzhou`，本城襄阳）。据点 **襄阳** `city_xiangyang`（战后 `cityUpdates` 归 `yuan_d`）。
- **② 人物**：攻 **阿术**（都元帅）、宋降将**刘整**（库里没有）｜守 襄阳守将**吕文焕**（库里有 `xiangzhou_lvwenhuan`）。主将队：城堡时代草原英雄兵模；对手城堡时代华夏英雄兵模。可用火器、回回砲（史实）。
- **③ 起因**：刘整献策「先取襄阳，浮汉入江」，忽必烈命阿术、刘整围襄阳。
- **④ 经过**：元军在襄樊四周筑堡连营，又训练水军封锁汉水；宋军张顺、张贵兄弟冒死运粮入城，战死（史实）；最后元军用西域工匠造的回回砲先破樊城，再轰襄阳城楼（史实）。
- **⑤ 结局**：吕文焕投降，**襄阳归元**（史实）。
- **⑥ 出镜**：随伯颜南下渡江。
- **⑦ 出处**：英文维基 *Battle of Xiangyang*。
- **文案三件**：
  - **briefing**：公元一二六八年秋，阿术与宋朝降将刘整来到汉水边的襄阳城下。襄阳与樊城隔江相望，被宋人称作国家的门户。元军一座接一座地修起了堡垒，要把这两座城活活困死。
  - **inviteText**：「朋友，襄阳的城墙我们爬不上去，那就围着它，今年不行就明年。刘整说过，拿下襄阳，长江就在眼前。」
  - **description**：围城一连数年，宋军冒死从汉水上运粮进城，张顺、张贵兄弟都战死在江中。后来西域的工匠造出了回回砲，先轰塌了樊城，再把巨石砸上襄阳城楼，吕文焕终于开城投降。

### 场 2｜1275 秋 · 焦山之战（野战·水战）
- **片/段**：一 · 灭宋 / 段二 江淮
- **① 入镜**：襄阳 → 郊郢 → 阳逻堡 → 武昌 → 大通 → 金陵 → 焦山。
- **势力/地点**：攻 元｜守 南宋。地点 焦山江面（野战，水战）。
- **② 人物**：攻 **阿术**、董文炳（库里没有）｜守 南宋**张世杰**（库里有 `luoping_zhangshijie`）、孙虎臣。
- **③ 起因**：张世杰集结战船于焦山，想在江上阻止元军东下。
- **④ 经过**：张世杰把战船每十艘连成一方，用铁索锁住，下锚江中，以示死战；阿术派善射者乘小船火攻，宋船连在一起无法散开，火势蔓延（史实）。
- **⑤ 结局**：宋军大败，张世杰退走（史实）。不易主。
- **⑥ 出镜**：北上围扬州。
- **⑦ 出处**：英文维基 *Battle of Jiaoshan*（独立条目待核）；*Zhang Shijie*。
- **文案三件**：
  - **briefing**：公元一二七五年七月，焦山脚下的江面上，宋将张世杰把战船用铁索一方方锁在了一起，据说是要以示死战、绝不后退。
  - **inviteText**：「朋友，船锁在一起，就跑不掉了，也躲不开。给弓手的箭头绑上火。」
  - **description**：元军小船冲近放出火箭，宋军战船被铁索连在一起，谁也散不开，大火一艘接一艘地烧了过去。张世杰大败而走，江上的宋军从此一蹶不振。

### 场 3｜1275–1276 · 扬州（攻城，剧终）
- **片/段**：一 · 灭宋 / 段二 江淮
- **① 入镜**：焦山 → 广陵。
- **势力/地点**：攻 元｜守 南宋。据点 **广陵** `city_yangzhou`（扬州；战后 `cityUpdates` 归 `yuan_d`）。
- **② 人物**：攻 **阿术**｜守 两淮制置使**李庭芝**、都统**姜才**（库里没有）。
- **③ 起因**：临安降元后，扬州仍拒不投降，谢太后、宋恭帝的诏书也被李庭芝拒绝（史实）。
- **④ 经过**：阿术筑长围，城中粮尽，甚至有人相食（史实，文案只写「粮尽」）；李庭芝出城东往泰州，想投奔南方的新朝廷，途中被截，扬州守将开城投降（史实）。
- **⑤ 结局**：**扬州归元**（史实），李庭芝、姜才被杀。
- **⑥ 出镜**：剧终。北返后随伯颜征叛王（B 档），1281 年卒。
- **⑦ 出处**：英文维基 *Aju (general)*；*Li Tingzhi*（扬州之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元一二七五年冬，临安已经降元，江北的扬州却仍然城门紧闭。守将李庭芝连太后的诏书都不肯接，阿术只好在城外筑起长长的围墙。
  - **inviteText**：「朋友，宋朝的太后都降了，扬州还在守。守城的人是条汉子，可城里恐怕快没有粮食了。」
  - **description**：围城几个月，城中粮尽，军民饿死不少。李庭芝突围东去，想投奔南方的宋朝新主，却在半路被截住，扬州随即开门投降。
