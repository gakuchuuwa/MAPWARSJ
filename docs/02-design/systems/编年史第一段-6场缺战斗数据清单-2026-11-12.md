## 三、6 场共同缺的字段（每条经典战都要）

```ts
battleId            // 例：ailan_julushi@-547 / gen_philip_ii@-348
battleName
battleYear / battleMonth
battleType          // 'field' | 'siege'
role                // 'attacker' | 'defender'
targetName
targetCityId        // 攻城必填；野战可空
targetLat / targetLng
myTroops / enemyTroops   // 史实兵力，钳到 1–2 万
enemyFactionId / enemyFactionName
enemyGeneralId      // 必须是 FactionGenerals 实名将；否则进不了战术模式
introLines          // 将/玩家各一段
rewardCityId        // 野战按史指定，可空
```

## 四、数据之外的 3 个硬缺口

1. **水战没有 `naval` 字段**：`GeneralFirstBattle` 只有 `field`/`siege`；阿卑多斯、基齐库斯、克尼多斯、西西里大港都是海战。要么加字段/适配，要么这几场只能叙事。
2. **多战役事件没有拆分**：一个事件 2–3 场仗，需要 `battleSteps[]` 分别给 `battleId`、`battleYear`、`battleMonth`；现在是「一事件一战术段」，文案也要按子战役切。
3. **缺实名敌将**：埃皮塔达斯、吉里普斯、明达鲁斯、萨莱图斯等不在库。按「进战术模式双方须为实名武将」，这些仗现在进不了战术模式。

## 五、建议顺序

1. **现在**：6 场全部按 `operation` 叙事推进，不停链。
2. **第一批补**：普特里亚、奥林索斯（各 1 场；城市/敌将基本齐，只缺坐标、兵力、台词、battleId）。
3. **第二批补**：西西里（`city_syracuse` 已有，补吉里普斯 + 水战适配）。
4. **第三批补**：米蒂利尼（要新建米蒂利尼据点）、阿卑多斯/基齐库斯（补明达鲁斯 + 水战）。
5. **最后**：奈米亚/克尼多斯/科罗尼亚（三场、跨主角、水陆混合，最费工）。
