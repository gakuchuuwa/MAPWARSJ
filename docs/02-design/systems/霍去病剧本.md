# 霍去病 · 剧本底本（一部人物传记）

> 年代：前123–119（汉武帝对匈奴战争）。主角 **霍去病**——**库里有**：武将 `suzhou_huoqubing`，挂在势力 `suzhou`、本城 `city_jiuquan` 嘉峪关（据点本位：河西）。
> 剧本期他史实上属**汉**（库里 `han_d` 汉国，按 §二之二 挂进汉的武将池）。
> 本底本不改数据、不新建任何东西。资料：网络搜索读英文维基摘要；**中文维基未能直接查**，细节依《史记·卫将军骠骑列传》通行说法；**路网未实测**（草原、戈壁道路稀少，末段离路恐怕很长）。

## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜前123 夏 · 漠南之战**　①长安 → 定襄 → 漠南。②攻 **霍去病**（库里有，时年十八岁）率轻勇骑八百（史实）｜守 匈奴（单于祖父辈籍若侯产部；库里没有）。③卫青率六将军出定襄击匈奴，霍去病任剽姚校尉。④他带八百骑离开大军数百里，直扑匈奴营帐。⑤斩首两千余，杀单于祖父辈籍若侯产、俘单于叔父罗姑比（史实），封**冠军侯**。⑥回长安。⑦中文维基「漠南之战」（本次未能直接查，**待核**）；英文维基 *Huo Qubing* <https://en.wikipedia.org/wiki/Huo_Qubing>；《史记》。

**2｜前121 春 · 皋兰山之战（河西之战第一次）**　①长安 → 陇西 → 皋兰山。②攻 霍去病 骠骑将军，骑兵一万（史实）｜守 匈奴**折兰王**、**卢侯王**（库里没有）。③汉武帝要打通河西。④六天转战五个匈奴部落，过焉支山千余里，在皋兰山下短兵相接。⑤斩折兰王、卢侯王，俘浑邪王子，获休屠王祭天金人（史实）。⑥夏天再出。⑦英文维基 *Huo Qubing*；中文维基「河西之战」（**待核**）。

**3｜前121 夏 · 祁连山之战（河西之战第二次）**　①皋兰 → 北地 → 居延泽 → 祁连山。②攻 霍去病｜守 匈奴诸王（库里没有）。③春战之后匈奴仍据河西。④霍去病与公孙敖约定会师，公孙敖迷路未到，霍去病孤军深入，绕过居延泽南下祁连山。⑤俘匈奴五王、单于阏氏，斩首三万余（史实）。当年秋浑邪王杀休屠王、率四万余众降汉，**河西归汉**（B 档）。⑥回长安。⑦同上。

**4｜前119 夏 · 漠北之战（剧终）**　①张掖 → 长安 → 代郡 → 漠北。②攻 霍去病 骑兵五万（史实，另有步兵、辎重数十万随后）｜守 匈奴**左贤王**部七万余（史实，据斩首数）。③汉武帝命卫青、霍去病各率五万骑，分两路深入漠北决战。④霍去病出代郡两千余里，大破左贤王，追至狼居胥山。⑤斩首七万余，**封狼居胥山、禅于姑衍**，临瀚海而还（史实）。此后「匈奴远遁，漠南无王庭」。⑥剧终：前117 年霍去病病逝，年二十四（B 档尾声）。⑦英文维基 *Battle of Mobei* <https://en.wikipedia.org/wiki/Battle_of_Mobei>。

## 六、疑点
1. **第一场出发地**：规则取本城嘉峪关，前123 年那里是匈奴地；按「军团此刻在哪」应是长安。长安建立年代表写 −202，前123 能上图。
2. **有无英文独立条目**：漠北之战有（*Battle of Mobei*）；漠南、河西两战本次搜索**没见到英文独立条目**，中文维基「漠南之战」「河西之战」是通行条目名，按 §一.1 要补查确认，若都无独立条目，这两场应降为 B。
3. **河西归汉到城一级**：张掖建立年代表写 −111（汉设张掖郡），前121 不能写归属；删丹等城建立年代未填，要核。
4. 草原、戈壁四处战场坐标都是推定，离路网恐怕很远。
