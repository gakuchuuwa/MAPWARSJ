# 亚历山大东征 · 逐路史料请求（给 NN）

> 缘起（主人 2026-09-26）：「如果把行军线，改为一段一段的。游戏中有 1500 左右条路，每条路一句话呢？根据路的长度来判断说什么。」

**一句话的范围**：军团这 20 段**实际走过 79 条路**（全库 1492 条，其余不在剧本路线上），折成 **79 句**、约 **8108 字**（与现在 8,285 字同量级）。

**三条尺子**（写稿时我照这个切）：

- 字数 ＝ **公里 ÷ 12.51 × 4.2**（每公里 0.336 字）。

- **一条路 150–500 公里**（🔴 例外：通向战场／被攻据点的那一段不受 150 下限）；**一条路 ＝ 一句话**，不拆句、不并句。

- 一条路再长也只算一句：话多就**在这一句内部**断成两三句短的连着念 —— 不加据点、不拆路、不并句。

**每行请 NN 填四栏。填不出就写「无记载」** —— 那我就按地理与行军写，绝不编史事：

| 栏 | 要什么 |
|---|---|
| 史料要点 | 这条路上／这一带，史书（阿里安《远征记》卷章、英文维基条目、当地语种维基）到底记了什么：经过哪些地方、有没有事件、谁降谁叛 |
| 出处 | 条目名与卷章号；查不到就写「无记载」 |
| 地形与行军 | 河谷／山口／渡口／沙漠、水源与井、季节（雨雪、汛期、酷暑）、路况（能不能走车、马匹与辎重怎么补） |
| 当年归属与守将 | 那一年这一段归谁管（行省／部族／王国），沿途据点守将是谁 |

**行文规范**（定稿时我照这个写，NN 给料不必顾）：不写量化词（兵力、里程、件数一律模糊说法，只有纪年与地名照旧）；
不写第三人称代词（他／他们／其，一律写名字）；不用关系称谓（父王／大王）；写成叙述文。

**【v2 · 2026-09-26】表里的「路」按什么排的**：起点＝**军团此刻在哪**（上一场落点：野战＝战场、攻城＝那座城），
再依次走这一场的行军路标，最后奔目标 —— 这是游戏真机走的那条路（第 2 场实测过：挂点必须落在真机走过的那几站上，
按「出兵据点」自己寻路算出来的那条会挂到走不到的站上，光标一卡，后面整场都不念）。**行号与「起 → 终」请照抄，不要重排。**
