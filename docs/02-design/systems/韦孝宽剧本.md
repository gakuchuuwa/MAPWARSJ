## 三、分场卡

### 场 1｜546 · 玉壁之战（攻城，主角守）
- **片/段**：一 · 玉壁 / 段一
- **① 入镜**：长安 → 潼关 → 龙门 → 玉壁。
- **势力/地点**：攻 东魏（高欢，库里北齐 `gaoqi_d`）｜守 西魏。据点 玉壁（库里没有；攻城战须有据点，§二之二 可添加，离龙门 41 km，**可过** 40 km 间距硬闸——添加前仍须 `--probe` 实测）。
- **② 人物**：攻 东魏丞相**高欢**（库里有 `gaoqi_d_gaohuan`）｜守 **韦孝宽**（库里有）。主将队：封建时代华夏英雄兵模（546 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：高欢倾东魏之兵西攻，玉壁扼汾水下游，是必经之路。
- **④ 经过**：高欢连营数十里，昼夜攻城；筑土山，韦孝宽在城楼上加木楼，始终高过土山；挖地道，韦孝宽沿城挖长堑，堑中积柴，地道一通便投火鼓风；用攻车撞城，韦孝宽用布幔缓冲；用火竿烧布幔，韦孝宽用长钩利刃割断火竿（史实）。高欢又射书城中悬赏韦孝宽首级，韦孝宽在书背写上答语射回（史实）。
- **⑤ 结局**：前后五十余日，东魏军战死、病死七万人（史实，数字不进文案）；高欢智力俱困，发病撤围，次年正月病死（史实）。**不易主**。
- **⑥ 出镜**：因功进骠骑大将军，长年镇守玉壁一带。
- **⑦ 出处**：英文维基 *Battle of Yubi*。
- **文案三件**：
  - **briefing**：公元五四六年秋，东魏的实际掌权者高欢率大军西攻，把小小的玉壁城团团围住。守城的韦孝宽兵少，据说城里的人都在担心，这座城能撑几天。
  - **inviteText**：「诸位，高欢有多少种攻城的办法，我们就有多少种守城的办法。他堆土山，我们就把城楼加高。」
  - **description**：东魏军堆土山、挖地道、造攻车，想尽了办法。韦孝宽把城楼加得比土山还高，在地道口堆柴放火，用布幔挡住攻车，又用长钩割断火竿。高欢久攻不下，死伤惨重，气急发病，只得撤军，不久便去世了。

### 场 2｜580 · 相州之战（攻城，剧终）
- **片/段**：二 · 平尉迟迥 / 段二 相州
- **① 入镜**：玉壁 → 长安 → 洛阳 → 虎牢关 → 安阳方向 → 邺。
- **势力/地点**：攻 北周（杨坚掌政）｜守 尉迟迥（相州总管，起兵反杨坚，库里没有）。据点 邺（库里没有；离安阳 26 km，过不了 40 km 间距硬闸，见疑点 3）。
- **② 人物**：攻 **韦孝宽**（七十余岁，年岁不进文案）、**高颎**（库里没有）、**梁士彦**、**宇文忻**（库里没有）｜守 相州总管**尉迟迥**（库里没有）。
- **③ 起因**：周宣帝死，杨坚专政，尉迟迥在邺起兵讨杨坚（史实）。
- **④ 经过**：官军在沁水、邺城下与尉迟迥决战；尉迟迥军一度占优，城中百姓数万出来观战，宇文忻下令向观战人群放箭，人群惊乱奔逃，冲乱了尉迟迥的军阵（史实）。
- **⑤ 结局**：尉迟迥兵败自杀，邺城被毁（史实）。邺归北周。
- **⑥ 出镜**：剧终。韦孝宽凯旋后不久病逝（580 年十一月，史实）；次年杨坚篡周建隋（B 档尾声）。
- **⑦ 出处**：英文维基 *Yuchi Jiong*；*Wei Xiaokuan*（相州之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元五八〇年秋，北周宣帝刚刚去世，丞相杨坚独揽大权。镇守邺城的老将尉迟迥起兵反对，天下震动。杨坚把平叛的大军交给了一位更老的将军——韦孝宽。
  - **inviteText**：「诸位，尉迟迥是宿将，他的兵也都是精兵。可他在邺城，我们在城外，城里的人心未必向着他。」
  - **description**：两军在邺城下决战，尉迟迥一度占了上风，城里的百姓成群出城观战。宇文忻下令朝观战的人群放箭，人群惊慌奔逃，反把尉迟迥的阵形冲乱了。官军趁势猛攻，尉迟迥兵败自杀。
