## 三、分场卡

### 场 1｜前209 冬 · 戏之战（野战，主角守）
- **片/段**：一 / 段一 关中
- **① 入镜**：咸阳（长安）→ 戏。
- **势力/地点**：攻 张楚（陈胜，库里没有）｜守 秦。地点 戏水（野战）。
- **② 人物**：攻 张楚将军**周文**（库里没有）｜守 **章邯**（库里有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：陈胜起义，周文率军长驱入关，逼近咸阳；秦廷仓促无兵。
- **④ 经过**：章邯请赦免骊山刑徒与奴产子，授以兵器迎击（史实）。
- **⑤ 结局**：周文大败出关，章邯追击，周文自杀（史实）。不易主。
- **⑥ 出镜**：出关东进。
- **⑦ 出处**：《史记·秦始皇本纪》《陈涉世家》；英文维基 *Zhang Han*。
- **文案三件**：
  - **briefing**：公元前二〇九年冬，陈胜的将军周文带着大军一路打进了关中，兵锋直逼咸阳。秦朝的朝堂上一片慌乱，据说仓促之间根本拿不出一支军队。
  - **inviteText**：「诸位，骊山上还有修陵的刑徒。赦了他们的罪，发给他们兵器，他们就是秦的军队。」
  - **description**：章邯领着刚刚放下锄头的刑徒迎战，竟一战击破周文。周文狼狈出关，被章邯一路追击，最终自杀。

### 场 2｜前208 夏 · 临济（攻城）
- **片/段**：一 / 段二 关东
- **① 入镜**：长安 → 函谷关 → 渑池 → 荥阳方向 → 临济。
- **势力/地点**：攻 秦｜守 魏、齐援军。据点 临济（库里没有；§二之二 可添加，离开封 28 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **章邯**｜守 魏王**魏咎**、齐王**田儋**（库里没有）。
- **③ 起因**：陈胜死后，章邯转攻魏，魏王求救于齐、楚。
- **④ 经过**：章邯夜间人衔枚突袭齐、魏援军，田儋战死（史实）。
- **⑤ 结局**：魏咎为保全百姓，约降后自焚（史实）。临济归秦。
- **⑥ 出镜**：东进追击项梁。
- **⑦ 出处**：《史记·魏豹彭越列传》《田儋列传》；英文维基 *Zhang Han*。
- **文案三件**：
  - **briefing**：公元前二〇八年夏，章邯围住了魏王魏咎所在的临济。齐王田儋亲自率军来救，秦军的营垒里却静悄悄的，据说章邯正在等夜色降临。
  - **inviteText**：「诸位，让士卒口中衔枚，今夜不许出声。齐人的营寨就在前面。」
  - **description**：秦军趁夜突袭，齐王田儋战死在乱军之中。魏王魏咎为了城中百姓与秦军约降，随后在火中自尽。

### 场 3｜前208 秋 · 定陶之战（野战）
- **片/段**：一 / 段二
- **① 入镜**：临济 → 定陶。
- **势力/地点**：攻 秦｜守 楚（项梁）。地点 定陶（野战），战后按历史 `cityUpdates` 写 **定陶** 归秦。
- **② 人物**：攻 **章邯**｜守 楚武信君**项梁**（项羽叔父，库里没有）。
- **③ 起因**：项梁连胜秦军，渐生骄意；宋义劝谏不听（史实）。
- **④ 经过**：秦廷增兵章邯，章邯衔枚夜袭楚营（史实）。
- **⑤ 结局**：楚军大败，项梁战死（史实）。
- **⑥ 出镜**：章邯以为楚地不足忧，北渡黄河攻赵。
- **⑦ 出处**：《史记·项羽本纪》；英文维基 *Battle of Dingtao*。
- **文案三件**：
  - **briefing**：公元前二〇八年秋，楚军统帅项梁接连打了几场胜仗，据说已经不把秦军放在眼里。谋士宋义劝他小心，他却听不进去。章邯的援军正在悄悄赶来。
  - **inviteText**：「诸位，项梁以为我们不敢再来了。今夜再衔一次枚。」
  - **description**：秦军在夜里突然杀进楚营，项梁仓促迎战，死于乱军之中。章邯以为楚人已经不足为虑，转身北渡黄河去攻打赵国。

### 场 4｜前207 冬 · 巨鹿之战（野战，主角守）
- 同 [`项羽剧本.md`](项羽剧本.md) 巨鹿一场（数据以那边为准）。
- **inviteText**（章邯线专用）：「诸位，王离将军围着巨鹿，我们在南面修甬道给他运粮。楚人若敢来，就让他们看看秦军的阵势。」
- **⑤ 结局补**：王离被俘，章邯退守棘原，后在殷墟向项羽投降（史实）；降卒二十万后被项羽坑杀于新安（史实，文案不写数）。

### 场 5｜前206–205 · 废丘（攻城，主角守，剧终）
- **片/段**：三 · 雍王 / 段四 关中
- **① 入镜**：巨鹿 → 殷墟降楚 → 函谷关 → 长安 → 废丘。
- **势力/地点**：攻 汉（库里汉系势力，做事件时查）｜守 雍。据点 废丘（库里没有；§二之二 可添加，离奉天 35 km、长安 40 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **韩信**（库里有 `xianyu_hanxin`）、**刘邦**｜守 雍王**章邯**。
- **③ 起因**：刘邦「明修栈道、暗度陈仓」，还定三秦，章邯战败退守废丘。
- **④ 经过**：汉军围城近一年，引水灌城（史实）。
- **⑤ 结局**：城破，章邯自杀（史实）。废丘归汉。
- **⑥ 出镜**：剧终。
- **⑦ 出处**：《史记·高祖本纪》；英文维基 *Zhang Han*。
- **文案三件**：
  - **briefing**：公元前二〇六年秋，刘邦从汉中杀回关中，雍王章邯连战连败，退守废丘。这位曾经击败陈胜、项梁的秦朝名将，如今被困在一座孤城里。
  - **inviteText**：「诸位，我降过一次楚，不想再降一次汉。废丘能守多久，就守多久。」
  - **description**：汉军把废丘围了很久，最后引水灌城。城破之日，章邯拔剑自刎，这位秦朝最后的名将就此落幕。
