## 三、分场卡

### 场 1｜前129 · 雁门之战（野战）
- **片/段**：一 · 飞将军 / 段一 雁门
- **① 入镜**：雁门关 → 塞外。
- **势力/地点**：攻 汉｜守 匈奴。地点 雁门塞外（野战）。
- **② 人物**：攻 **李广**（库里有）｜守 匈奴**军臣单于**所部（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：汉武帝首次四路出击匈奴，李广出雁门。
- **④ 经过**：匈奴以主力围李广，汉军覆没，李广受伤被俘；匈奴骑兵把他放在两马间的网兜里，他装死，途中纵身跃上一匹匈奴马，夺弓射杀追兵，逃回汉境（《史记》，史实）。
- **⑤ 结局**：李广按律当斩，赎为庶人（史实）。不易主。
- **⑥ 出镜**：闲居蓝田，后起为右北平太守。
- **⑦ 出处**：《史记·李将军列传》；英文维基 *Li Guang*（雁门之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元前一二九年，汉武帝开始主动出击匈奴，李广从雁门出塞。据说单于早就听说过他的名声，特意派了重兵，要活捉这位飞将军。
  - **inviteText**：「诸位，匈奴人想活捉我。那就让他们来，看他们有没有这个本事。」
  - **description**：匈奴主力围住了李广，汉军全军覆没，李广受伤被俘。押送途中他假装昏死，突然跃上一匹匈奴战马，夺过弓箭射倒追兵，一路逃回了汉地。

### 场 2｜前121 · 右北平之战（野战，主角守，剧终）
- **片/段**：一 / 段二 右北平
- **① 入镜**：彰国军城 → 马盂山 → 右北平战场。
- **势力/地点**：攻 匈奴｜守 汉。地点 右北平塞外（野战）。
- **② 人物**：攻 匈奴**左贤王**（库里没有）｜守 **李广**、其子**李敢**（库里没有）；张骞率一万骑后至（史实）。
- **③ 起因**：李广与张骞分道出右北平，李广先行，被左贤王四万骑包围。
- **④ 经过**：李广命李敢率数十骑直贯匈奴阵中，回报「胡虏易与耳」以安军心；汉军结圆阵向外，箭矢将尽，李广亲持大黄弩射杀匈奴裨将数人，匈奴稍解（《史记》，史实）。
- **⑤ 结局**：鏖战两日，死伤过半；张骞援军赶到，匈奴解围而去（史实）。不易主。
- **⑥ 出镜**：剧终。前119 年漠北之战，李广为前将军，迷路失期，自刎（史实，B 档尾声）。
- **⑦ 出处**：《史记·李将军列传》；英文维基 *Li Guang*。
- **文案三件**：
  - **briefing**：公元前一二一年，李广领着一支骑兵走在最前面，还没等到张骞的援军，就被匈奴左贤王的大军团团围住。汉军个个面如土色，李广却让儿子李敢带人冲进敌阵走一遭。
  - **inviteText**：「诸位，匈奴人看着多，其实不经打。李敢，你去冲一冲，让大家看看。」
  - **description**：李敢带着少数骑兵穿阵而过，回来大声说胡人不难对付，军心这才稳住。汉军结成圆阵死守，箭快射完了，李广亲手用大黄弩射杀了匈奴的几名将领。苦战之后张骞赶到，匈奴人才解围而去。
