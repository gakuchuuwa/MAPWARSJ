## 三、分场卡

**1｜1218 · 太原（攻城）**　①燕京 → 西京 → 太原。②攻 **木华黎**（库里有）｜守 金河东北路宣抚使**乌古论德升**（库里没有）。主将队：待看素材定。③成吉思汗西征前把华北交给木华黎。④攻破太原，乌古论德升自缢（史实）。⑤**晋阳归蒙古**。⑥⑦英文维基 *Muqali*。

**2｜1220 · 东平（攻城）**　①→ 真定 → 大名 → 东平。②攻 木华黎（汉军世侯严实来降）｜守 金将**蒙古纲**。③山东诸地降蒙。④围城多日不下（史实）。⑤木华黎留兵监视后撤，金守将后弃城（通行说法）。⑥西征关中。⑦同上。

**3｜1222–1223 · 凤翔（攻城，剧终）**　①→ 晋阳 → 长安 → 凤翔。②攻 木华黎（与西夏兵）｜守 金凤翔守军。③木华黎进攻关中。④围城不下（史实）。⑤木华黎撤围，东归途中 1223 年病逝于山西闻喜，临终说「我为国家助成大业，只恨汴京未下」（通行说法）。⑥剧终。⑦同上。

## 六、疑点
1. 第一场出发地：本城在漠北，1218 年木华黎经营燕京；北京建立年代 1421 过不了闸门。
2. 兵力全部推定；东平、凤翔两场战果不算胜利，是否值得单列要主人定。
