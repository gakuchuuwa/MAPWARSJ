## 三、分场卡

### 场 1｜747 · 连云堡（攻城）
- **片/段**：一 · 远征小勃律 / 段一
- **① 入镜**：盘橐 → 石头城 → 昏度多 → 连云堡。
- **势力/地点**：攻 唐｜守 吐蕃（库里吐蕃系势力，做事件时查）。据点 连云堡（库里没有；§二之二 可添加，离昏度多 70 km，按间距能过，添加前须 `--probe` 实测）。
- **② 人物**：攻 安西副都护**高仙芝**（库里有）、**李嗣业**、**田珍**（库里没有）、监军边令诚｜守 吐蕃连云堡守军（主将史书未载名）。主将队：封建时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：小勃律王娶吐蕃公主，倒向吐蕃，西北二十余国断绝朝贡（史实，数字不进文案）；唐玄宗命高仙芝远征。
- **④ 经过**：唐军翻越葱岭，至婆勒川；河水暴涨，高仙芝杀牲祭河，率军渡河，人不湿旗、马不湿鞯（史实）；李嗣业执旗率陌刀手攀崖而上，从辰时攻到巳时，大破吐蕃（史实）。
- **⑤ 结局**：连云堡归唐，斩首五千、俘千余（史实，数字不进文案）。
- **⑥ 出镜**：翻越坦驹岭，下至阿弩越城，擒小勃律王（B 档）；远征归来。
- **⑦ 出处**：英文维基 *Gao Xianzhi*；*Tang campaign against Lesser Balur*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元七四七年秋，高仙芝率领步骑翻越葱岭，要去攻打投靠了吐蕃的小勃律。挡在路上的连云堡建在绝壁之上，据说城下的婆勒川河水正在暴涨。
  - **inviteText**：「诸位，河水再深，也深不过我们走过的雪山。祭过河神，我们就渡过去。」
  - **description**：唐军渡过婆勒川，旗帜和马鞍竟然都没有沾湿。李嗣业举着大旗，领着陌刀手攀上悬崖，从早晨一直杀到上午，吐蕃守军大败，连云堡落入唐军之手。

### 场 2｜750 · 石国（攻城）
- **片/段**：二 · 西域争雄 / 段二 石国
- **① 入镜**：连云堡 → 孽多 → 石头城 → 盘橐 → 柘折城。
- **势力/地点**：攻 唐｜守 石国（库里柘折城 `tashkent` 系势力，做事件时查）。据点 **柘折城** `city_tashkent`（战后 `cityUpdates` 归唐）。
- **② 人物**：攻 安西四镇节度使**高仙芝**｜守 石国王**那俱车鼻施**（库里没有）。
- **③ 起因**：高仙芝以石国「无蕃臣礼」为由出兵（史实）。
- **④ 经过**：高仙芝先与石国约和，随后袭击，俘石国王，掠其财宝（史实）。
- **⑤ 结局**：**石国归唐**（史实）；石国王被押送长安斩首，王子出逃，向阿拔斯王朝求援（史实）。
- **⑥ 出镜**：押送俘虏回长安，受封；随后西进怛罗斯。
- **⑦ 出处**：《旧唐书·高仙芝传》；英文维基 *Gao Xianzhi*（石国之役独立条目待核）。
- **文案三件**：
  - **briefing**：公元七五〇年，安西节度使高仙芝以石国不守藩臣之礼为名，领兵西进。他先派人与石国约和，石国王大概以为，一场战争就这样避免了。
  - **inviteText**：「诸位，石国王已经信了我们的话。趁他们放松，今夜就动手。」
  - **description**：唐军背约突袭，石国王被俘，城中的财宝被洗劫一空。石国王被押到长安斩首，他的儿子却逃了出去，一路向西，去向阿拔斯王朝的大军求援。

### 场 3｜751 · 怛罗斯之战（野战，剧终）
- **片/段**：二 / 段三 怛罗斯
- **① 入镜**：柘折城 → 康卡 → 怛罗斯。
- **势力/地点**：攻 唐｜守 阿拔斯王朝（库里 `abasi`）与西域诸国。地点 怛罗斯河畔（野战）。
- **② 人物**：攻 **高仙芝**、**李嗣业**、**段秀实**（库里没有）；葛逻禄部为唐军盟友（史实）｜守 阿拔斯呼罗珊总督**阿布·穆斯林**所遣大将**齐亚德·伊本·萨利赫**（库里没有）。
- **③ 起因**：石国王子求援，阿拔斯王朝联合西域诸国东进；高仙芝先发制人，率军深入七百余里迎击（《旧唐书》，数字不进文案）。
- **④ 经过**：两军相持五日；葛逻禄部临阵倒戈，与阿拔斯军夹攻唐军（史实）。
- **⑤ 结局**：唐军大败，高仙芝率残部夜遁；李嗣业在前开路，段秀实斥责他弃众独走，李嗣业惭而收拢散兵（史实）。不易主。据说被俘唐军中有造纸工匠，造纸术由此西传（通行说法，学界有争议，文案写「据说」）。
- **⑥ 出镜**：剧终。755 年安史之乱起，高仙芝东守陕州、退保潼关，被监军边令诚诬陷，与封常清同被斩于潼关（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Talas*。
- **文案三件**：
  - **briefing**：公元七五一年夏，高仙芝率领唐军与西域诸国的兵马，在怛罗斯河边与阿拔斯王朝的大军相遇。两军对峙了好几天，谁也没能占到上风。
  - **inviteText**：「诸位，大食人要替石国出头，与其等他们打上门来，不如我们先去找他们。葛逻禄的兄弟们在侧翼，只要撑住，胜利就是我们的。」
  - **description**：就在相持不下的时候，唐军的盟友葛逻禄部突然倒戈，与大食军前后夹击，唐军阵脚大乱。高仙芝趁夜带着残兵撤退，据说许多被俘的唐军工匠后来把造纸的手艺带到了西方。
