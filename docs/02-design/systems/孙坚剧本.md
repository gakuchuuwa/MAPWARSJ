## 三、分场卡

### 场 1｜184 · 宛城（攻城）
- **片/段**：一 / 段一 宛城
- **① 入镜**：下邳 → 彭城 → 新郑方向 → 宛城。
- **势力/地点**：攻 东汉｜守 黄巾（库里没有）。据点 **宛城** `city_nanyang`（战后 `cityUpdates` 归汉）。
- **② 人物**：攻 右中郎将**朱儁**（库里没有）、佐军司马**孙坚**（库里有）｜守 黄巾**赵弘**、**韩忠**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：南阳黄巾据宛城。
- **④ 经过**：孙坚亲自当一面，登城先入，众军蚁附而上（《三国志》，史实）。
- **⑤ 结局**：宛城被攻破，黄巾大败（史实）。**宛城归汉**。孙坚因功拜别部司马。
- **⑥ 出镜**：西征凉州、南平长沙（B 档）。
- **⑦ 出处**：《三国志·孙破虏传》；英文维基 *Sun Jian*（宛城之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元一八四年，黄巾之乱席卷天下，南阳的黄巾占据了宛城。一个来自江东的年轻军官孙坚，跟着朱儁来到了城下。
  - **inviteText**：「诸位，城墙没什么可怕的，我先上，你们跟着我。」
  - **description**：孙坚亲自攀上城头，第一个登城。将士们见他如此勇猛，像蚂蚁一样争相攀城而上，宛城终于被攻破。

### 场 2｜191 · 阳人之战（野战，主角守）
- **片/段**：一 / 段二 阳人
- **① 入镜**：宛城 → 昆阳 → 广成关 → 阳人。
- **势力/地点**：攻 董卓（库里董卓系势力，做事件时查）｜守 孙坚（关东联军）。地点 阳人城外（野战），战后按历史 `cityUpdates` 写 **洛阳** 归孙坚一方（董卓西迁长安、孙坚入洛阳；史实）。
- **② 人物**：攻 董卓部将**胡轸**、骑督**吕布**（库里有 `pizhou_lvbu`）｜守 **孙坚**、**程普**、**黄盖**、**韩当**、**祖茂**（库里查到再用）。
- **③ 起因**：关东联军讨董卓，诸侯多逗留不进，唯孙坚进军（史实）。
- **④ 经过**：胡轸与吕布不和，吕布散布谣言说阳人城内贼已逃走，致胡轸军夜进至城下时疲惫惊乱；孙坚出城追击，大破之，斩都督华雄（史实）。
- **⑤ 结局**：董卓遣使求和亲，孙坚拒绝，进军大谷；董卓焚洛阳西迁长安（史实）。**洛阳归孙坚一方**。
- **⑥ 出镜**：入洛阳，修复汉室陵庙（B 档）；南归鲁阳。
- **⑦ 出处**：英文维基 *Battle of Yangren*。
- **文案三件**：
  - **briefing**：公元一九一年，关东诸侯起兵讨伐董卓，大多数人却只是在酸枣饮酒观望。只有孙坚一路北进，逼近了洛阳。董卓派胡轸和吕布前来迎击，据说这两人彼此并不和睦。
  - **inviteText**：「诸位，诸侯们在后面喝酒，我们在前面打仗。今夜董卓的人会来，让他们来。」
  - **description**：吕布故意散布谣言，搅得胡轸的军队夜里惊乱不安。孙坚趁势出城猛攻，大破董卓军，斩了都督华雄。董卓求和不成，焚毁洛阳，带着皇帝西迁长安。

### 场 3｜191 · 襄阳（攻城，剧终）
- **片/段**：二 · 争荆州 / 段三 襄阳
- **① 入镜**：广成关 → 洛阳 → 宛城 → 襄阳。
- **势力/地点**：攻 孙坚（袁术一方）｜守 刘表（库里荆州系势力，做事件时查）。据点 **襄阳** `city_xiangyang`（战后不易主）。
- **② 人物**：攻 **孙坚**｜守 荆州牧**刘表**、江夏太守**黄祖**（库里没有）。
- **③ 起因**：袁术派孙坚攻刘表。
- **④ 经过**：孙坚在樊城、邓县之间击败黄祖，渡汉水围襄阳；黄祖夜出，孙坚单马行岘山，被黄祖部将射杀（史实，一说为石所中）。
- **⑤ 结局**：孙坚战死，年三十七（史实，年岁不进文案）；襄阳**不易主**。
- **⑥ 出镜**：剧终。长子孙策收其余众，依附袁术，后渡江平定江东（见 [`孙策剧本.md`](孙策剧本.md)）。
- **⑦ 出处**：英文维基 *Battle of Xiangyang (191)*。
- **文案三件**：
  - **briefing**：公元一九一年冬，孙坚奉袁术之命南攻荆州，接连打败刘表的大将黄祖，渡过汉水，围住了襄阳。夜色里，他独自骑马走上了城外的岘山。
  - **inviteText**：「诸位，黄祖已经被我们打怕了，襄阳城指日可下。我去山上看看地形，你们守好营寨。」
  - **description**：黄祖的部下埋伏在岘山的竹林间，乱箭齐发，孙坚中箭身亡，也有人说他被山上滚下的石头砸中。江东之虎就这样死在了襄阳城外，他的儿子孙策带着父亲的旧部，投奔了袁术。
