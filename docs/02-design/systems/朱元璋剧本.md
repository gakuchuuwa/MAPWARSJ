# 朱元璋 · 剧本底本（一部人物传记）

> 年代：1356–1364（元末群雄）。主角 **朱元璋**——**库里有**：武将 `huai_zhuyuanzhang`，势力 `huai`，本城 `city_zhongli`（显示名「盱眙」，淮州治所）。
> 1364 年以后大战多由徐达、常遇春领兵，朱元璋不再亲征，所以本线到武昌为止。
> 本底本不改数据、不新建任何东西。资料：网络搜索读英文维基摘要；**中文维基未能直接查**，细节依《明史·太祖本纪》通行说法；**路网未实测**。

## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜1356 春 · 取集庆（攻城）**　①和州 → 采石矶 → 太平 → 集庆。②攻 **朱元璋**（库里有）｜守 元江南行台御史大夫**福寿**（库里没有）。主将队：待看素材定。③朱元璋渡江后要取江南重镇集庆。④水陆并进，先破城外蛮子海牙、陈兆先的营寨，陈兆先部三万余人投降（通行说法）。⑤城破，福寿战死；朱元璋改集庆为应天府（史实）。**金陵归朱**（`city_nanjing` → `huai`）。⑥以应天为根据地。⑦英文维基 *Hongwu Emperor*（集庆之战独立条目**待核**）。

**2｜1360 夏 · 龙湾之战（主角守）**　①金陵 → 龙湾。②攻 **陈友谅**（库里查不到）｜守 朱元璋。③陈友谅杀徐寿辉称帝，率舟师顺江东下，约张士诚夹攻应天。④朱元璋让陈友谅旧友康茂才写诈降信，约陈友谅从江东桥进兵；陈友谅到时发现是石桥，知道上当，改在龙湾登岸，被常遇春、冯胜等伏兵夹击。⑤陈友谅大败，乘小船逃走（史实）。⑥西向争江西。⑦英文维基 *Chen Youliang*（龙湾之战独立条目**待核**）。

**3｜1363 · 鄱阳湖之战**　①金陵 → 姑孰 → 豫章 → 鄱阳湖。②攻 朱元璋 约二十万（史实）｜守 陈友谅，号称六十万余、巨舰百余艘（史实，按 §一.2 封顶）。③陈友谅倾国来攻洪都，八十五天攻不下，朱元璋亲率水军来救。④陈友谅的巨舰连在一起，朱军船小难敌；朱元璋用火船借东北风冲入敌阵，烧毁大批巨舰；相持一个多月后在湖口截断陈军退路。⑤陈友谅被流矢射中身亡（史实）。⑥追击至武昌。⑦*Battle of Lake Poyang* <https://en.wikipedia.org/wiki/Battle_of_Lake_Poyang>。

**4｜1364 春 · 武昌（攻城，剧终）**　①鄱阳湖 → 武昌。②攻 朱元璋｜守 陈友谅之子**陈理**（库里没有）。③陈汉残部拥陈理退守武昌。④朱元璋亲至城下，攻下高冠山，断绝外援，派人入城劝降。⑤陈理出降，陈汉灭亡（史实）。**武昌归朱**（`city_wuchang` → `huai`）。⑥剧终：同年称吴王；1367 年灭张士诚、1368 年称帝建明，北伐由徐达、常遇春统兵（B 档）。⑦英文维基 *Chen Han* <https://en.wikipedia.org/wiki/Chen_Han>。
