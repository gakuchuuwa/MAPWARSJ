## 三、分场卡

### 场 1｜1122 · 西京大同（攻城）
- **片/段**：一 · 灭辽 / 段一 西京
- **① 入镜**：勃利（会宁）→ 中京 → 大同。
- **势力/地点**：攻 金｜守 辽。据点 **大同** `city_datong`（战后 `cityUpdates` 归金）。
- **② 人物**：攻 **完颜宗翰**（库里有）、**完颜宗望**（库里没有）｜守 辽西京守军（主将史书不详）。主将队：城堡时代东北/女真英雄兵模（1122 年属城堡段，按 §二.5 看样貌选）。
- **③ 起因**：金军攻下辽中京，辽天祚帝西逃。
- **④ 经过**：宗翰攻西京，城先降后叛，宗翰再攻克之（史实，细节简略）。
- **⑤ 结局**：**大同归金**（史实）。
- **⑥ 出镜**：追击天祚帝（B 档）。
- **⑦ 出处**：《金史·宗翰传》；英文维基 *Wanyan Zonghan*。
- **文案三件**：
  - **briefing**：公元一一二二年春，金军攻破辽国中京，辽天祚帝仓皇西逃。完颜宗翰追到西京大同城下，城中的辽人据说还在犹豫，是降金还是死守。
  - **inviteText**：「诸位，辽国的皇帝已经跑了，西京守不住的。降就降，不降就打。」
  - **description**：西京城先是开门投降，不久又反叛。宗翰挥军再攻，终于攻克大同，辽国西部的屏障就此崩塌。

### 场 2｜1125–1126 · 太原（攻城）
- **片/段**：二 · 灭北宋 / 段二 太原
- **① 入镜**：大同 → 彰国军城 → 雁门关 → 晋阳。
- **势力/地点**：攻 金｜守 北宋。据点 **晋阳** `city_taiyuan`（太原；战后 `cityUpdates` 归金）。
- **② 人物**：攻 西路军主帅**完颜宗翰**｜守 河东宣抚副使**王禀**、知府**张孝纯**（库里没有）。
- **③ 起因**：金灭辽后以宋收容叛将张觉为由南侵，宗翰为西路军。
- **④ 经过**：王禀坚守太原二百五十余日（史实，数字不进文案）；城中粮尽，宋援军种师中等多路被击败（史实）。
- **⑤ 结局**：城破，王禀力战，负太原府庙中宋太宗画像投汾水而死（史实）。**太原归金**。
- **⑥ 出镜**：南下会攻汴京。
- **⑦ 出处**：英文维基 *Siege of Taiyuan (1125–1126)*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一一二五年冬，金军兵分两路南下攻宋，宗翰率领西路军围住了太原。守将王禀据说发誓与城共存亡，宋朝的援军一路接一路地赶来，又一路接一路地被打败。
  - **inviteText**：「诸位，太原是宋人的北门，不拿下它，西路军就过不了黄河。围住它，不管多久。」
  - **description**：太原城坚守了很久很久，城里的粮食早已吃尽。城破之日，王禀仍在巷战，最后背着宋太宗的画像跳进了汾水。宗翰踏着太原的废墟，挥师南下。

### 场 3｜1126 · 汴京（攻城，剧终）
- **片/段**：二 / 段三 汴京
- **① 入镜**：晋阳 → 临汾 → 天井关 → 开封。
- **势力/地点**：攻 金｜守 北宋。据点 **开封** `city_bianliang`（战后 `cityUpdates` 归金）。
- **② 人物**：攻 **完颜宗翰**、东路军**完颜宗望**｜守 **宋钦宗**（库里没有）；宋廷任用号称能撒豆成兵的道士**郭京**（史实）。
- **③ 起因**：宋廷拒不割让三镇，金军两路会师汴京。
- **④ 经过**：郭京率「六甲神兵」开宣化门出战，一触即溃，金军乘势登城（史实）。
- **⑤ 结局**：汴京陷落；1127 年金军俘虏宋徽宗、宋钦宗及宗室后妃北去，史称「靖康之变」（史实）。**开封归金**。
- **⑥ 出镜**：剧终。宗翰北返，1135 年后被夺兵权，1137 年郁郁而终（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Jingkang incident*。
- **文案三件**：
  - **briefing**：公元一一二六年冬，金军东西两路在汴京城下会师。宋朝的朝廷里，据说有人把希望寄托在一个自称会撒豆成兵的道士郭京身上。
  - **inviteText**：「诸位，宋朝的皇帝请来了神仙帮他打仗。那就让我们看看，神仙挡不挡得住刀枪。」
  - **description**：郭京领着所谓的神兵打开宣化门出战，一触即溃，金军趁势攻上城头，汴京陷落。第二年，金军押着宋徽宗、宋钦宗和宗室后妃北去，北宋就此灭亡。
