## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜1367 · 平江（攻城）**　①金陵 → 湖州 → 杭州 → 平江。②攻 **徐达**（库里有）、常遇春｜守 吴王**张士诚**（库里没有）。主将队：待看素材定。③陈汉已灭，朱元璋转攻东吴。④围城十个月，徐达四面筑长围，架起高台用弓弩、火铳俯射城中（史实）。⑤城破，张士诚被俘后自缢（史实）。**姑苏归明**（`city_gusu` → 朱元璋所属势力）。⑥北伐。⑦英文维基 *Xu Da* <https://en.wikipedia.org/wiki/Xu_Da>（平江之战独立条目**待核**）。

**2｜1368 秋 · 大都（攻城）**　①→ 山东 → 河南 → 北上 → 大都。②攻 徐达（明军北伐主力）｜守 元大都守军（元顺帝已北逃）。③朱元璋定「先取山东、再下河南、断潼关、然后取大都」之策（史实）。④元顺帝连夜弃城北逃上都；明军攻入齐化门（史实）。⑤元朝在中原的统治结束，大都改名北平（史实）。**北京归明**。⑥西进山西。⑦英文维基 *Xu Da*、*Hongwu Emperor*。

**3｜1368 冬 · 太原（攻城）**　①北平 → 真定 → 太原。②攻 徐达｜守 元将**扩廓帖木儿**（王保保；库里有 `da_yuan_kuokuotiemuer`）。③扩廓帖木儿出兵想夺回北平，徐达反攻其老巢太原。④扩廓帖木儿回救太原，徐达派兵夜袭其营，扩廓帖木儿仓促间只穿一只靴子、带十八骑逃走（通行说法）。⑤**晋阳（太原）归明**（`city_taiyuan`）。⑥平定陕甘（B 档）。⑦同上。

**4｜1372 夏 · 岭北之战（剧终）**　①太原 → 大同 → 出塞 → 岭北。②攻 徐达（中路）｜守 **扩廓帖木儿**。③明军三路北伐，想一举消灭北元。④徐达孤军深入，在土剌河、岭北一带被扩廓帖木儿诱入伏击。⑤明军大败，据说阵亡数万（史实），此后明朝对漠北转为守势。⑥剧终：1385 年徐达卒于南京（B 档）。⑦英文维基 *Xu Da*（岭北之战独立条目**待核**）。
