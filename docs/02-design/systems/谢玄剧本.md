## 三、分场卡

### 场 1｜379 · 君川之战（野战）
- **片/段**：一 · 北府初战 / 段一 淮南
- **① 入镜**：广陵 → 盱眙 → 君川。
- **势力/地点**：攻 东晋｜守 前秦（库里前秦系势力，做事件时查）。地点 君川（野战）。
- **② 人物**：攻 **谢玄**（库里有）、北府将**刘牢之**、**何谦**（库里没有）｜守 前秦**俱难**、**彭超**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代，东晋属古典段）。
- **③ 起因**：前秦攻陷襄阳、彭城，南下围三阿，逼近广陵。
- **④ 经过**：谢玄自广陵驰救三阿，秦军退保盱眙；谢玄进击，何谦断秦军淮桥，刘牢之烧其舟船，四战四捷（史实，数字不进文案）。
- **⑤ 结局**：俱难、彭超北逃，秦军大败（史实）。不易主。北府兵一战成名。
- **⑥ 出镜**：回镇广陵。
- **⑦ 出处**：《晋书·谢玄传》；英文维基 *Xie Xuan*（君川之战独立条目待核）。
- **文案三件**：
  - **briefing**：公元三七九年夏，前秦的大军攻下了淮北的彭城与淮南的盱眙，兵锋直逼广陵。镇守广陵的谢玄刚刚招募了一支新军，军中多是从北方南逃的流民。
  - **inviteText**：「诸位，你们的家乡都在北方，是被秦人赶到江南来的。今天就让他们看看，北府兵是什么样的兵。」
  - **description**：谢玄率军北上，接连击败秦军。北府将何谦截断了淮河上的浮桥，刘牢之放火烧毁秦军的船只，秦军无路可退，大败北逃，北府兵的名号从此传开。

### 场 2｜383 冬 · 淝水之战（野战，主角守）
- **片/段**：二 · 淝水与北伐 / 段二 淝水
- **① 入镜**：盱眙 → 广陵 → 钟离 → 淝水。
- **势力/地点**：攻 前秦｜守 东晋。地点 淝水西岸（野战），战后按历史 `cityUpdates` 写 **寿春** 归东晋（秦军溃退后晋军收复寿阳；史实）。
- **② 人物**：攻 前秦天王**苻坚**（库里没有）、其弟**苻融**（库里没有）、降将**朱序**（阵中倒戈）｜守 前锋都督**谢玄**、征讨大都督**谢石**、**谢琰**、**刘牢之**、**桓伊**（库里没有）；坐镇建康的是谢安。
- **③ 起因**：苻坚统一北方后倾国南下，号称百万，前锋苻融攻陷寿阳，与晋军隔淝水对峙。
- **④ 经过**：刘牢之先在洛涧夜袭大破秦军前哨（史实）；谢玄遣使请秦军稍退，让晋军渡河决战，苻坚想半渡而击，允之；秦军一退便不可止，朱序在阵后大呼「秦军败矣」，晋军渡河猛击，苻融坠马被杀（史实）。
- **⑤ 结局**：秦军溃败，「风声鹤唳、草木皆兵」由此而来（史实）；苻坚中流矢北逃，前秦从此瓦解。**寿春归东晋**。
- **⑥ 出镜**：乘胜北伐。
- **⑦ 出处**：英文维基 *Battle of Fei River*。
- **文案三件**：
  - **briefing**：公元三八三年冬，前秦天王苻坚率领据说前所未有的大军南下，在淝水西岸扎营。东晋的前锋都督谢玄隔着淝水望去，秦军的营帐一眼望不到头。
  - **inviteText**：「苻天王，隔着一条河怎么决战？请您的大军稍稍后退，让我们过河来，一战分个胜负。」
  - **description**：苻坚想趁晋军渡河到一半时出击，便下令后退。谁知秦军一退就收不住了，阵后有人大喊秦军败了，全军顿时大乱。北府兵渡河猛攻，苻融坠马被杀，秦军溃逃时听到风声鹤鸣，都以为是晋军追来了。

### 场 3｜384 · 彭城（攻城，剧终）
- **片/段**：二 / 段三 彭城
- **① 入镜**：寿春 → 钟离 → 彭城。
- **势力/地点**：攻 东晋｜守 前秦。据点 **彭城** `city_pengcheng`（战后 `cityUpdates` 归东晋）。
- **② 人物**：攻 **谢玄**、刘牢之｜守 前秦徐州刺史**赵迁**（库里没有）。
- **③ 起因**：淝水战后东晋乘势北伐。
- **④ 经过**：谢玄进兵彭城，赵迁弃城而走（史实）。
- **⑤ 结局**：**彭城归东晋**（史实）；此后谢玄连下兖、青、司、豫诸州（B 档）。
- **⑥ 出镜**：剧终。谢安死后朝廷猜忌，谢玄以病请退，388 年卒（史实，B 档尾声）。
- **⑦ 出处**：《晋书·谢玄传》；英文维基 *Xie Xuan*。
- **文案三件**：
  - **briefing**：公元三八四年，淝水大胜之后，谢玄率北府兵乘胜北伐。前秦已经四分五裂，驻守彭城的秦将赵迁据说早已无心恋战。
  - **inviteText**：「诸位，秦人的天下正在崩塌。趁这个时候，把淮北、河南的故土都收回来。」
  - **description**：北府兵兵临彭城，赵迁弃城而逃，晋军不战而入。谢玄一路北上，收复了黄河以南的大片土地，这是东晋南渡以来疆域最广的时候。
