## 三、分场卡

### 场 1｜416 · 洛阳（攻城）
- **片/段**：一 · 北伐前锋 / 段一 洛阳
- **① 入镜**：彭城 → 谯县 → 商丘 → 虎牢关 → 洛阳。
- **势力/地点**：攻 东晋（刘裕）｜守 后秦（库里后秦系势力，做事件时查）。据点 **洛阳** `city_luoyang`（战后 `cityUpdates` 归东晋）。
- **② 人物**：攻 **檀道济**（库里有）、**王镇恶**（王猛之孙，库里没有）｜守 后秦征南将军**姚洸**（库里没有）。主将队：古典时代华夏英雄兵模（416 年属古典段，按 §二.5 先保年代）。
- **③ 起因**：后秦姚兴死，诸子争位，刘裕趁机北伐。
- **④ 经过**：晋军连下许昌、成皋、荥阳，一路势如破竹；姚洸在洛阳分兵据守，兵力分散，前线守将陆续投降（史实）。檀道济俘获秦军四千余人，诸将主张坑杀，檀道济说「伐罪吊民，正在今日」，全部释放，关中百姓闻之归心（史实，数字不进文案）。
- **⑤ 结局**：姚洸出降，**洛阳归东晋**（史实）；西晋故都沦陷百余年后重归（史实，年数不进文案）。
- **⑥ 出镜**：西进潼关。
- **⑦ 出处**：《宋书·檀道济传》；英文维基 *Liu Yu's northern expeditions*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元四一六年冬，刘裕的北伐大军以檀道济、王镇恶为前锋，一路打到了洛阳城下。后秦守将姚洸把兵力分散在各处，据说城里已经没有多少人了。
  - **inviteText**：「诸位，我们是来讨伐有罪之人、安抚百姓的。俘虏不许杀，都放回去，让他们告诉关中的人，晋军来了。」
  - **description**：晋军兵临洛阳，姚洸无力抵抗，开城投降。檀道济把俘获的秦军全都放了回去，关中的百姓听说之后，纷纷心向晋军。沦陷多年的故都，终于又插上了晋朝的旗帜。

### 场 2｜417 · 潼关（攻城·关隘，剧终）
- **片/段**：一 / 段二 潼关
- **① 入镜**：洛阳 → 渑池 → 函谷关 → 潼关。
- **势力/地点**：攻 东晋｜守 后秦。据点 **潼关** `city_tongguan`（战后 `cityUpdates` 归东晋）。
- **② 人物**：攻 **檀道济**、王镇恶、沈林子｜守 后秦鲁公**姚绍**（库里没有）。
- **③ 起因**：后秦以姚绍率重兵据守潼关，想把晋军挡在关外。
- **④ 经过**：两军在潼关相持，晋军粮尽，军心动摇，有人主张退兵；檀道济、沈林子说「今日之事，有进无退」（通行说法），坚守不退；王镇恶亲往弘农督民间租粮（史实）；姚绍屡攻不下，愤恚发病而死（史实）。
- **⑤ 结局**：**潼关归东晋**（史实）；王镇恶率水军溯渭水直入长安，后秦主姚泓出降（见 [`刘裕剧本.md`](刘裕剧本.md) 场 3）。
- **⑥ 出镜**：剧终。420 年刘裕篡晋建宋，檀道济为开国功臣；431 年北伐粮尽，以「唱筹量沙」全军而还（史实）；436 年被宋文帝猜忌杀害，临刑前怒掷头巾说「乃坏汝万里长城」（史实，B 档尾声）。
- **⑦ 出处**：《宋书·檀道济传》；英文维基 *Tan Daoji*。
- **文案三件**：
  - **briefing**：公元四一七年春，晋军被后秦大将姚绍挡在潼关之外。军粮快吃完了，军中有人开始劝说退兵，据说连主将们也犹豫过。
  - **inviteText**：「诸位，走到这里，已经没有回头的路了。今天的事，只有进，没有退。」
  - **description**：晋军咬牙守住营寨，王镇恶亲自去弘农筹粮。姚绍久攻不下，又急又气，竟病死在军中，潼关随之落入晋军之手。王镇恶的水军随即沿渭水直抵长安，后秦就此灭亡。
