## 三、分场卡

**1｜87 · 莎车（攻城）**　①疏勒 → 于阗 → 莎车。②攻 **班超**（库里有）率于阗等国兵二万五千（史实）｜守 莎车王与龟兹王派来的五万援军（史实）。主将队：待看素材定。③莎车依附龟兹，阻断南道。④班超佯装撤兵，故意放走俘虏报信；龟兹王分兵去截班超，班超却连夜回师直扑莎车营地（史实）。⑤莎车投降，龟兹援军散去（史实）。**渠莎归汉**。⑥⑦《后汉书·班超传》；英文维基 *Ban Chao*。

**2｜90 · 疏勒保卫战（主角守）**　①莎车 → 疏勒。②攻 贵霜（大月氏）副王**谢**（史料七万；攻方不设上限，库里没有）｜守 **班超**。③贵霜求娶汉公主被拒，发兵攻班超。④班超判断贵霜远道而来、粮草不继，坚壁清野；又预料谢会向龟兹求粮，派兵在路上截杀使者（史实）。⑤谢粮尽求和退兵，贵霜此后年年朝贡（史实）。⑥⑦同上。

**3｜94 · 焉耆（攻城，剧终）**　①疏勒 → 龟兹 → 焉耆。②攻 班超 发龟兹、鄯善等八国兵七万（史实）｜守 焉耆王**广**（库里没有）。③焉耆曾杀西域都护陈睦。④焉耆拆毁渡桥阻挡，班超绕道涉水进至城下；诱焉耆王出会，斩焉耆王广、尉犁王，传首京师（史实）。⑤西域五十余国全部归附汉朝（史实）。**员渠城归汉**。⑥剧终：97 年派甘英出使大秦；102 年七十一岁回洛阳，同年卒（B 档）。⑦同上。
