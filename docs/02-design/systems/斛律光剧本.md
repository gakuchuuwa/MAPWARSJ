## 三、分场卡

### 场 1｜564 · 邙山之战（野战）
- **片/段**：一 · 北齐长城 / 段一 洛阳
- **① 入镜**：晋阳 → 临汾 → 轵关 → 洛阳 → 邙山。
- **势力/地点**：攻 北齐（救洛阳）｜守 北周（围洛阳之军）。地点 邙山（野战）。
- **② 人物**：攻 太尉**段韶**、**斛律光**（库里有）、兰陵王**高长恭**（库里没有）｜守 北周**尉迟迥**、齐国公**宇文宪**（库里没有）。主将队：封建时代草原/鲜卑英雄兵模（564 年属封建段，按 §二.5 看样貌选）。
- **③ 起因**：北周大军围洛阳，筑土山、挖地道，洛阳危急。
- **④ 经过**：段韶居左、兰陵王居中、斛律光居右；兰陵王率五百骑冲入周军重围，直抵洛阳金墉城下，城上守军不识，兰陵王摘下头盔露出面容，守军才开门，内外夹击（史实，数字不进文案）。斛律光率右军与周军激战（史实）。
- **⑤ 结局**：周军解围退走，丢弃营帐辎重（史实）。不易主。北齐将士作《兰陵王入阵曲》歌颂此战（史实）。
- **⑥ 出镜**：回师，镇守西线。
- **⑦ 出处**：英文维基 *Battle of Mangshan (564)*（条目名以站内为准）；*Gao Changgong*。
- **文案三件**：
  - **briefing**：公元五六四年冬，北周大军把洛阳围得水泄不通。北齐的援军从晋阳、邺城赶来，在洛阳北面的邙山列阵，斛律光领着右军，兰陵王高长恭居中。
  - **inviteText**：「诸位，洛阳的城头已经撑不了多久了。兰陵王去冲他们的中阵，我们右军把周人压回去。」
  - **description**：兰陵王率领骑兵冲进周军的重围，一直杀到金墉城下，摘下头盔让守军认出了他。城内城外一齐杀出，斛律光在右翼压住了周军，北周大军丢下营帐辎重，解围而去。

### 场 2｜571 · 汾北之战（野战，剧终）
- **片/段**：一 / 段二 汾北
- **① 入镜**：洛阳 → 轵关 → 临汾 → 汾北。
- **势力/地点**：攻 北齐｜守 北周。地点 汾北（野战）。
- **② 人物**：攻 **斛律光**｜守 北周勋州刺史**韦孝宽**（库里有 `long2_weixiaokuan`）、宇文宪。
- **③ 起因**：北周筑城汾北，蚕食北齐西境；斛律光出兵争夺。
- **④ 经过**：斛律光在汾北连筑城堡，与韦孝宽相持；周军数攻不下，斛律光击败宇文宪，夺取周军据点（史实，细节简略）。
- **⑤ 结局**：齐军在汾北站稳脚跟，拓地数百里（史实，数字不进文案）。不易主（库里汾北无对应据点）。
- **⑥ 出镜**：剧终。韦孝宽编造童谣「百升飞上天，明月照长安」，散布于邺城，暗指斛律光谋反（史实）；572 年北齐后主高纬听信祖珽、穆提婆谗言，把斛律光召入宫中缢杀，满门抄斩（史实）；北周武帝闻讯大喜，五年后灭齐（B 档尾声）。
- **⑦ 出处**：英文维基 *Hulü Guang*（汾北之战独立条目待核）；《北齐书·斛律光传》。
- **文案三件**：
  - **briefing**：公元五七一年，北周在汾水北岸步步修城，一点点蚕食北齐的土地。北齐老将斛律光领兵西出，这一次，他的对手是当年在玉壁守住了城池的韦孝宽。
  - **inviteText**：「诸位，周人筑城，我们就筑得比他们更多。韦孝宽守城是一把好手，那就逼他出城来打。」
  - **description**：斛律光在汾北连筑城堡，周军几次进攻都没能撼动。他又击败了北周齐国公宇文宪，北齐的西境从此稳固。韦孝宽打不过他，便编了一首童谣，让人在邺城的大街小巷传唱。
