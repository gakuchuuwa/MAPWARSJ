## 三、分场卡

### 场 1｜1724 · 乌兰木和尔奔袭（野战）
- **片/段**：一 · 平青海 / 段一 柴达木
- **① 入镜**：浩门（西宁）→ 伏俟城 → 乌兰木和尔。
- **势力/地点**：攻 清｜守 和硕特蒙古罗卜藏丹津（库里没有）。地点 乌兰木和尔（野战），战后按历史 `cityUpdates` 写青海一带归清（清设青海办事大臣；史实）——库里伏俟城 `city_fusicheng` 为最近据点。
- **② 人物**：攻 奋威将军**岳钟琪**（库里有）｜守 和硕特首领**罗卜藏丹津**（库里没有）。主将队：帝国时代华夏英雄兵模（1724 年属帝国段，按 §二.5 看样貌选）；火枪可用。
- **③ 起因**：罗卜藏丹津起兵反清，欲恢复固始汗霸业（史实）。
- **④ 经过**：岳钟琪趁春草未生、蒙古马瘦之时，率精骑五千分三路，衔枚疾进，昼夜兼行（史实，数字不进文案）；直捣罗卜藏丹津大营，敌军尚未起身（史实）。
- **⑤ 结局**：罗卜藏丹津扮作女子逃往准噶尔（史实，据说如此），其母、妻被俘；青海平定，前后仅十五日（史实，数字不进文案）。
- **⑥ 出镜**：回师，受封三等公，任川陕总督。
- **⑦ 出处**：英文维基 *Yue Zhongqi*；*Lobzang Danjin*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一七二四年早春，青海的罗卜藏丹津起兵反清。奋威将军岳钟琪没有等到草长马肥的季节，据说他正是算准了此时蒙古人的马还瘦弱，跑不动。
  - **inviteText**：「诸位，春草还没长出来，他们的马饿了一冬。我们人衔枚、马摘铃，日夜不停，天亮之前冲进他们的大营。」
  - **description**：清军精骑昼夜疾驰，突然出现在罗卜藏丹津的营帐前，蒙古人还在睡梦之中就被冲散。罗卜藏丹津据说换上了女人的衣服才逃了出去，青海很快就平定了。

### 场 2｜1749 · 勒乌围（攻城，剧终）
- **片/段**：二 · 金川 / 段二 勒乌围
- **① 入镜**：伏俟城 → 浩门 → 皋兰 → 成都 → 美诺寨 → 勒乌围。
- **势力/地点**：攻 清｜守 大金川土司（库里金川 `jinchuan_g`）。据点 **勒乌围** `city_leweizhai`（战后 `cityUpdates` 归清）。
- **② 人物**：攻 四川提督**岳钟琪**、经略大学士**傅恒**（库里没有）｜守 大金川土司**莎罗奔**（库里没有）。
- **③ 起因**：大金川莎罗奔侵扰邻近土司，清军屡攻不下，讷亲、张广泗因此获罪（史实）；乾隆帝起用岳钟琪（史实）。
- **④ 经过**：金川碉楼林立、易守难攻；岳钟琪曾是莎罗奔的旧日上司，亲率数十骑入勒乌围劝降（史实，数字不进文案）。
- **⑤ 结局**：莎罗奔出降，第一次金川之役结束（史实）。**勒乌围归清**。
- **⑥ 出镜**：剧终。1754 年岳钟琪卒于资州军中（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Jinchuan campaigns*；*Yue Zhongqi*。
- **文案三件**：
  - **briefing**：公元一七四九年正月，清军攻打大金川已经很久了，山谷里的石砌碉楼一座座都难以攻破，前任主帅都因此获罪。年迈的岳钟琪再次被起用，据说金川土司莎罗奔当年还是他的旧部。
  - **inviteText**：「诸位，碉楼打不下来，那就不打。我去一趟勒乌围，跟莎罗奔叙叙旧。」
  - **description**：岳钟琪只带着少数随从，骑马进入了勒乌围。莎罗奔见昔日的老上司孤身前来，深为感动，终于出寨投降，这场旷日持久的金川之战就此结束。
