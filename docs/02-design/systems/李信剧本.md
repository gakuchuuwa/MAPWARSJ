## 三、分场卡

### 场 1｜前226 · 衍水之战（野战）
- **片/段**：一 · 追燕 / 段一 辽东
- **① 入镜**：蓟（真定）→ 渔阳方向 → 襄平 → 衍水。
- **势力/地点**：攻 秦｜守 燕。地点 衍水（野战）。
- **② 人物**：攻 **李信**｜守 燕太子**姬丹**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：荆轲刺秦失败，秦王大怒，命王翦攻燕；燕王与太子丹逃往辽东，李信率轻骑追击。
- **④ 经过**：李信追到衍水，大破燕军（《史记》）。
- **⑤ 结局**：太子丹藏匿衍水之中，燕王喜为求秦退兵，斩太子丹之首献秦（史实）。不易主。
- **⑥ 出镜**：回师咸阳。
- **⑦ 出处**：《史记·刺客列传》《王翦列传》；英文维基 *Li Xin*。
- **文案三件**：
  - **briefing**：公元前二二六年，荆轲刺秦王未成，秦王嬴政怒不可遏。年轻的秦将李信领着轻骑，一路追着燕太子丹到了辽东的衍水边。
  - **inviteText**：「诸位，派刺客来的人就在前面。他跑得再远，也跑不出秦的弓箭。」
  - **description**：李信在衍水追上了燕军，一战将其击溃。太子丹躲进了河水之中，走投无路的燕王喜竟亲手斩下儿子的头颅，献给了秦人。

### 场 2｜前225 · 平舆（攻城）
- **片/段**：二 · 伐楚 / 段二 淮北
- **① 入镜**：襄平 → 长安 → 函谷关 → 新郑 → 悬瓠 → 平舆。
- **势力/地点**：攻 秦｜守 楚（库里楚系势力，做事件时查）。据点 平舆（库里没有；攻城战须有据点，§二之二 可添加，离悬瓠 26 km，过不了 40 km 间距硬闸，见疑点 2）。
- **② 人物**：攻 **李信**｜守 楚平舆守军（史书未载名）。
- **③ 起因**：秦王问伐楚要多少兵，王翦说六十万，李信说二十万；秦王嫌王翦老怯，用了李信（史实）。
- **④ 经过**：李信攻平舆，蒙恬攻寝，大破楚军（史实）。
- **⑤ 结局**：平舆归秦（史实），但随即在城父之战后失守。
- **⑥ 出镜**：引兵西进，与蒙恬会于城父。
- **⑦ 出处**：《史记·王翦列传》；英文维基 *Li Xin*。
- **文案三件**：
  - **briefing**：公元前二二五年，秦王嬴政问诸将伐楚需要多少兵马。老将王翦说要倾国之兵，年轻的李信却说用不了那么多。秦王笑老将胆怯，把大军交给了李信。
  - **inviteText**：「诸位，王翦将军老了。楚国没有他说的那么难打，我们先拿下平舆给大王看。」
  - **description**：李信一路猛攻，拿下了平舆，另一路的蒙恬也攻下了寝邑。秦军势如破竹，李信大概觉得，灭楚已经近在眼前了。

### 场 3｜前225 · 城父之战（野战，主角守，剧终）
- **片/段**：二 / 段二
- **① 入镜**：平舆 → 城父。
- **势力/地点**：攻 楚｜守 秦。地点 城父（野战）。
- **② 人物**：攻 楚大将**项燕**（项羽祖父，库里没有）｜守 **李信**、**蒙恬**（库里有 `baiyang_mengtian`）。
- **③ 起因**：李信引兵西进与蒙恬会合，楚将项燕率军尾随其后。
- **④ 经过**：楚军三日三夜不停歇地追袭，攻破秦军两处营垒，杀秦军七名都尉（《史记》，数字不进文案）。
- **⑤ 结局**：秦军大败，李信逃回（史实）。不易主（平舆等城随之失守）。
- **⑥ 出镜**：剧终。秦王亲自到频阳请王翦复出，以六十万大军灭楚（见 [`王翦剧本.md`](王翦剧本.md)）；李信此后随王贲攻燕、代、齐（B 档），其后裔为陇西李氏（汉李广、唐李氏皆称其后，据说如此）。
- **⑦ 出处**：《史记·王翦列传》；英文维基 *Li Xin*。
- **文案三件**：
  - **briefing**：公元前二二五年，李信与蒙恬在城父会合，满以为楚军已经不堪一击。楚国大将项燕却一直悄悄跟在秦军身后，等待着出手的时机。
  - **inviteText**：「诸位，平舆已经拿下了，与蒙恬会合之后，就直取楚都。楚人还能怎样？」
  - **description**：项燕率楚军日夜不停地追击，秦军营垒接连被攻破，好几名都尉战死。李信大败而回，秦王这才明白老将王翦当初所言不虚。
