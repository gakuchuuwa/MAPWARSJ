## 三、分场卡

### 场 1｜1370 · 应昌（攻城）
- **片/段**：一 · 应昌 / 段一
- **① 入镜**：居庸关 → 兴和城 → 骆驼山 → 应昌。
- **势力/地点**：攻 明｜守 北元。据点 **应昌** `city_yingchang`（战后 `cityUpdates` 归明）。
- **② 人物**：攻 左副将军**李文忠**｜守 北元太子**爱猷识理达腊**（库里没有）；元顺帝于四月病死应昌（史实）。主将队：城堡时代华夏英雄兵模（按 §二.5 看样貌选）。
- **③ 起因**：徐达西征扩廓，李文忠东出追击元顺帝。
- **④ 经过**：李文忠途中得知元顺帝已死，昼夜兼程赶到应昌，攻克其城（史实）。
- **⑤ 结局**：**应昌归明**；俘元顺帝嫡孙买的里八剌及后妃、宫人、诸王、将相，获宋、元玉玺（史实）；爱猷识理达腊以数十骑北走和林（史实，数字不进文案）。
- **⑥ 出镜**：班师，受封曹国公。
- **⑦ 出处**：《明史·李文忠传》；英文维基 *Li Wenzhong*。
- **文案三件**：
  - **briefing**：公元一三七〇年夏，李文忠率明军出塞北上，追赶元朝的皇帝。半路上传来消息，元顺帝已经病死在了应昌。李文忠没有停下，反而催促全军日夜兼程。
  - **inviteText**：「诸位，元朝的皇帝死了，太子还在应昌。趁他们办丧事，一口气打过去。」
  - **description**：明军突然出现在应昌城下，一举攻克城池。元顺帝的孙子买的里八剌和大批后妃、宗王都成了俘虏，太子爱猷识理达腊只带着少数亲随逃往和林。

### 场 2｜1372 · 阿鲁浑河之战（野战，剧终）
- **片/段**：二 · 岭北东路 / 段二 土剌河
- **① 入镜**：应昌 → 居庸关 → 应昌 → 口温 → 胪朐河 → 土剌河 → 阿鲁浑河。
- **势力/地点**：攻 明｜守 北元。地点 阿鲁浑河（野战）。
- **② 人物**：攻 **李文忠**｜守 北元太师**蛮子哈剌章**（库里没有）。
- **③ 起因**：朱元璋三路北伐，徐达中路、李文忠东路、冯胜西路（见 [`徐达剧本.md`](徐达剧本.md) 岭北一场）。
- **④ 经过**：李文忠留辎重于胪朐河，率轻骑持二十日粮兼程北进（史实，数字不进文案）；至土剌河、阿鲁浑河，北元军且战且退，后大集骑兵来战；李文忠坐骑中矢，下马持短兵格斗（史实）；明军阵地被围，李文忠驱掠牛马纵之于野以示从容，元军疑有伏，引去（史实）。
- **⑤ 结局**：双方死伤相当，明军迷道、引还（史实）。不易主。
- **⑥ 出镜**：剧终。李文忠此后主持大都督府事，1384 年卒（史实，B 档尾声）。
- **⑦ 出处**：《明史·李文忠传》；英文维基 *Li Wenzhong*。
- **文案三件**：
  - **briefing**：公元一三七二年夏，明军兵分几路北伐。李文忠率东路军留下辎重，只带轻骑和干粮深入漠北，一直追到了土剌河边。北元太师蛮子哈剌章且战且退，据说正在暗中集结骑兵。
  - **inviteText**：「诸位，粮草不多了，只能进，不能拖。敌人来了，我们就在这里跟他们拼。」
  - **description**：北元骑兵突然大批杀到，李文忠的坐骑中箭倒地，他跳下马来持短兵死战。明军被围之后，他索性把掳来的牛马放到野外吃草，装出一副从容不迫的样子，北元军疑心有埋伏，竟然退走了，明军这才得以引还。
