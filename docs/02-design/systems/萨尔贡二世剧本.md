## 三、分场卡

**1｜前720 · 拉菲亚之战**　①尼尼微 → 叙利亚 → 加沙 → 拉菲亚。②攻 **萨尔贡二世**（库里有，待核）｜守 加沙王**哈努努**与埃及援军（库里没有）。主将队：古典段两河/波斯系候选（待看素材定）。③萨尔贡篡位即位，叙利亚、巴勒斯坦诸邦趁机反叛。④亚述在拉菲亚击败加沙与埃及联军（铭文，史实）。⑤哈努努被俘，**加沙归亚述**。⑥⑦英文维基 *Sargon II*。

**2｜前717 · 卡尔凯美什（攻城）**　①→ 卡尔凯美什。②攻 萨尔贡二世｜守 卡尔凯美什王**皮西里**（库里没有）。③皮西里与弗里吉亚王米达斯暗通。④攻下城池，把城并为亚述行省（史实）。⑤卡尔凯美什归亚述。⑥⑦同上。

**3｜前714 · 乌拉尔图与穆萨西尔**　①→ 尼尼微 → 扎格罗斯山 → 穆萨西尔。②攻 萨尔贡二世｜守 乌拉尔图王**鲁萨一世**与穆萨西尔（库里没有）。③亚述北方劲敌乌拉尔图。④萨尔贡翻越扎格罗斯山，在乌尔米亚湖一带击败鲁萨，再以千人奇袭乌拉尔图的圣城穆萨西尔，洗劫哈尔迪神庙（史实，萨尔贡的「第八次战役」铭文有详细记载）。⑤据说鲁萨闻讯自杀（通行说法）。⑥⑦同上。

**4｜前710 · 巴比伦（剧终）**　①→ 尼尼微 → 巴比伦。②攻 萨尔贡二世｜守 迦勒底人**马尔杜克-阿普拉-伊丁那二世**（《圣经》中的米罗达巴拉但，库里没有）。③迦勒底首领占据巴比伦十二年。④萨尔贡南下，对方弃城逃入沼泽（史实）。⑤萨尔贡进入巴比伦，自称巴比伦王（史实）。**巴比伦归亚述**。⑥剧终：前705 年萨尔贡在安纳托利亚征战时阵亡，尸体未能收回（B 档）。⑦同上。
