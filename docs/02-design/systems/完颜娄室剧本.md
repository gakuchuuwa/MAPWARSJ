## 三、分场卡

### 场 1｜1128 · 延安（攻城）
- **片/段**：一 · 经略陕西 / 段一 延安
- **① 入镜**：晋阳 → 临汾 → 龙门 → 绥德 → 肤施。
- **势力/地点**：攻 金｜守 南宋。据点 **肤施** `city_fushi`（延安；战后 `cityUpdates` 归金）。
- **② 人物**：攻 **完颜娄室**（库里有）｜守 宋延安府守军（主将史书不详；知府魏彦明，库里没有）。主将队：城堡时代东北/女真英雄兵模（1128 年属城堡段，按 §二.5 看样貌选）。
- **③ 起因**：金灭北宋后，西路军分兵经略陕西。
- **④ 经过**：娄室先破延安东城，守军据西城坚守，娄室再克之（史实，细节简略）。
- **⑤ 结局**：**延安归金**（史实）。
- **⑥ 出镜**：南下关中。
- **⑦ 出处**：《金史·娄室传》；英文维基 *Jin–Song Wars*。
- **文案三件**：
  - **briefing**：公元一一二八年，金军攻灭北宋之后，完颜娄室领兵西渡黄河，杀进了陕北。延安城分东西两城，据说宋军打算凭着西城死守。
  - **inviteText**：「诸位，东城拿下来，西城就是孤城。关中的门，得从延安敲开。」
  - **description**：金军先攻破了延安东城，宋军退守西城，拼死抵抗。娄室挥军再攻，终于拿下了西城，陕北的门户就此打开。

### 场 2｜1130 · 富平之战（野战，主角守，剧终）
- **片/段**：一 / 段二 富平
- **① 入镜**：肤施 → 长安 → 富平。
- **势力/地点**：攻 南宋｜守 金。地点 富平（野战），战后按历史 `cityUpdates` 写 **长安** 一带归金（宋军溃退后陕西大部入金；史实）。
- **② 人物**：攻 宋川陕宣抚处置使**张浚**、**刘锡**、**吴玠**（库里有）、**刘锜**（库里有）等五路｜守 **完颜娄室**、**完颜宗弼**（库里有）。
- **③ 起因**：张浚为牵制金军南侵江淮，集结陕西五路大军反攻（史实）。
- **④ 经过**：宋军阵前有大片芦苇沼泽，自恃金骑难以通过；娄室令士卒负土填泥、铺柴为道，骑兵越沼泽冲击宋军；环庆路赵哲部先溃，全线动摇（史实）。
- **⑤ 结局**：宋军大败，陕西五路精兵损失殆尽（史实）。**长安一带归金**。
- **⑥ 出镜**：剧终。1130 年冬娄室病卒（史实，B 档尾声）；宋军退守和尚原、仙人关（见 [`吴玠剧本.md`](吴玠剧本.md)）。
- **⑦ 出处**：英文维基 *Battle of Fuping*（条目名以站内为准）。
- **文案三件**：
  - **briefing**：公元一一三〇年秋，宋将张浚集结了陕西各路大军，在富平摆开阵势，据说声势浩大。宋军阵前是一大片芦苇沼泽，他们以为金军的骑兵过不来。
  - **inviteText**：「诸位，沼泽挡得住马蹄，挡不住泥土。每人背一袋土，给马铺出一条路来。」
  - **description**：金军背土填泥、铺柴为道，骑兵踏着新铺的路冲过了沼泽。宋军的环庆路先溃，大军随之崩溃，陕西各路的精兵在这一仗里几乎损失殆尽。
