## 三、分场卡

### 场 1｜214 · 皖城（攻城）
- **片/段**：一 / 段一 皖城
- **① 入镜**：濡须口 → 溯江 → 皖口。
- **势力/地点**：攻 孙吴｜守 曹魏。据点 **皖口** `city_wancheng`（战后 `cityUpdates` 归吴）。
- **② 人物**：攻 **孙权**、**吕蒙**、**甘宁**（库里有 `zhongxiang_ganning`）｜守 曹魏庐江太守**朱光**（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：曹操派朱光屯皖城，大开稻田，吕蒙说若任其收成必成大患（史实）。
- **④ 经过**：诸将议堆土山、造攻具，吕蒙说那要耗时日，不如趁雨水正盛、乘锐气四面急攻；甘宁为升城督，手执练，身缘城墙率先登城，吕蒙亲自擂鼓，士卒奋勇（史实）。
- **⑤ 结局**：清晨开始攻城，不到早饭时分就破城，擒朱光（史实）。**皖城归吴**。张辽援军赶到时城已陷落。
- **⑥ 出镜**：西进荆南。
- **⑦ 出处**：《三国志·吕蒙传》《甘宁传》；英文维基 *Battle of Wancheng*（独立条目待核）。
- **文案三件**：
  - **briefing**：公元二一四年夏，曹魏在皖城开荒屯田，稻子已经快要成熟了。吕蒙劝孙权说，等到秋天收了粮，皖城就再也打不下来了。
  - **inviteText**：「主公，不必造什么土山。趁着雨水多、士卒锐气正盛，四面同时攻上去，一个早上就够了。」
  - **description**：吴军清晨攻城，甘宁攀着城墙率先登城，吕蒙亲自擂鼓助阵。还没到吃早饭的时候，皖城就被攻破了，朱光被擒，曹魏的援军赶到时只能望城而返。

### 场 2｜215 · 零陵（攻城）
- **片/段**：一 / 段二 荆南
- **① 入镜**：皖口 → 柴桑 → 巴陵 → 长沙 → 泉陵。
- **势力/地点**：攻 孙吴｜守 刘备。据点 **泉陵** `city_yongzhou_hn`（零陵郡治；战后 `cityUpdates` 归吴）。
- **② 人物**：攻 **吕蒙**｜守 零陵太守**郝普**（库里没有）。
- **③ 起因**：刘备取益州后不肯归还荆州，孙权命吕蒙取长沙、零陵、桂阳三郡。
- **④ 经过**：长沙、桂阳望风归附；郝普坚守零陵。吕蒙让郝普的旧友邓玄之入城，谎称刘备被困汉中、关羽被困南郡，郝普信以为真，出城投降；吕蒙随后拿出孙权的书信给他看，郝普惭恨交加（史实）。
- **⑤ 结局**：**零陵归吴**（史实）。后孙刘湘水划界，零陵又还刘备（B 档，见疑点 3）。
- **⑥ 出镜**：驻陆口。
- **⑦ 出处**：《三国志·吕蒙传》；英文维基 *Lü Meng*。
- **文案三件**：
  - **briefing**：公元二一五年，吕蒙奉孙权之命南取荆州三郡。长沙、桂阳很快归附，只有零陵太守郝普闭城坚守。吕蒙找来了郝普的一位老朋友。
  - **inviteText**：「诸位，零陵不必硬攻。郝普最信他的旧友，就让旧友去告诉他，外面已经没有人会来救他了。」
  - **description**：郝普听旧友说刘备、关羽都被困住了，自知援兵无望，开城出降。吕蒙这才拿出孙权召他回军的书信给郝普看，郝普又惭愧又懊恼，据说把自己摔倒在了地上。

### 场 3｜219 · 白衣渡江·江陵（攻城，剧终）
- **片/段**：二 · 白衣渡江 / 段三 江陵
- **① 入镜**：泉陵 → 长沙 → 巴陵 → 柴桑 → 白衣渡江 → 江陵。
- **势力/地点**：攻 孙吴｜守 刘备（关羽）。据点 **江陵** `city_ying`（战后 `cityUpdates` 归吴）。公安亦降（库里没有公安）。
- **② 人物**：攻 **吕蒙**、陆逊（库里有 `yidou_luxun`）｜守 南郡太守**糜芳**、公安守将**士仁**（库里没有）；关羽正北攻樊城（见 [`关羽剧本.md`](关羽剧本.md)）。
- **③ 起因**：关羽北攻樊城，水淹七军，威震华夏；吕蒙称病回建业，以陆逊代之，麻痹关羽（史实）。
- **④ 经过**：吕蒙把精兵藏在船舱中，让士卒穿白衣扮作商人摇橹，昼夜兼行，沿江把关羽设的烽火台守兵全部擒获；士仁、糜芳先后开城投降（史实）。
- **⑤ 结局**：**江陵归吴**（史实）。吕蒙入城后约束部下不许取百姓一物，有同乡士兵取民家斗笠盖官铠，吕蒙垂泪斩之（史实）；关羽将士家眷得到善待，军心离散，关羽败走麦城被擒（B 档）。
- **⑥ 出镜**：剧终。吕蒙受封孱陵侯，不久病逝（219 年末，史实）。
- **⑦ 出处**：英文维基 *Lü Meng's invasion of Jing Province*。
- **文案三件**：
  - **briefing**：公元二一九年冬，关羽率大军在北面围攻樊城，荆州后方空虚。吕蒙早就称病回了建业，接替他的年轻人陆逊又写信把关羽大大恭维了一番，关羽大概放下了心。
  - **inviteText**：「诸位，把刀剑藏进船舱，换上白衣，摇起橹来。从现在起，我们都是商人。」
  - **description**：吴军扮成商船昼夜西行，沿江烽火台的守兵还没来得及点火就被擒获。江陵、公安的守将相继开城投降，吕蒙严令不许扰民，连一顶斗笠都不许拿。关羽的将士听说家人平安，纷纷离散而去。
