## 三、分场卡

### 场 1｜1240 夏 · 涅瓦河之战（野战）
- **片/段**：一 / 段一 涅瓦河
- **① 入镜**：诺夫哥罗德 → 拉多加方向 → 涅瓦河。
- **势力/地点**：攻 诺夫哥罗德（`liulike`）｜守 瑞典（库里瑞典系势力，做事件时查）。地点 涅瓦河与伊若拉河汇合处（野战）。
- **② 人物**：攻 **亚历山大**（时年约二十岁）｜守 瑞典统帅**比耶尔·雅尔**（通行说法，一说为乌尔夫·法西）（库里没有）。主将队：城堡时代斯拉夫/罗斯英雄兵模（按 §二.5 看样貌）；对手城堡时代北欧英雄兵模。
- **③ 起因**：瑞典人乘船在涅瓦河登陆，扎营于伊若拉河口，意图控制通往拉多加的水路。
- **④ 经过**：亚历山大不等援军，率亲兵与诺夫哥罗德民兵急行军，趁瑞典人扎营未稳突袭营地（编年史，史实）。
- **⑤ 结局**：瑞典人败退登船而去（史实）。亚历山大由此得名「涅夫斯基」（涅瓦河的）。不易主。
- **⑥ 出镜**：回诺夫哥罗德；同年冬与贵族失和出走（B 档）。
- **⑦ 出处**：英文维基 *Battle of the Neva*。
- **文案三件**：
  - **briefing**：公元一二四〇年夏，瑞典人的船队驶入涅瓦河，在伊若拉河口扎下营寨。诺夫哥罗德的年轻王公亚历山大没有等待父亲的援兵，带着亲兵连夜赶了过去。
  - **inviteText**：「兄弟们，神不在强权之中，而在真理之中。瑞典人还在搭帐篷，我们现在就去。」
  - **description**：诺夫哥罗德人趁瑞典人扎营未稳，突然冲进营地，砍倒了统帅的大帐。瑞典人仓皇登船退走，年轻的亚历山大从此被人称作「涅夫斯基」。

### 场 2｜1242 春 · 普斯科夫（攻城）
- **片/段**：一 / 段二 楚德湖
- **① 入镜**：诺夫哥罗德 → 普斯科夫。
- **势力/地点**：攻 诺夫哥罗德｜守 利沃尼亚骑士团（库里条顿系势力，做事件时查）。据点 **普斯科夫** `city_pusikefu`（战后 `cityUpdates` 归 `liulike`；库里普斯科夫本属 `pusikefu_gongheguo`，剧本期按史实归属表处理）。
- **② 人物**：攻 **亚历山大**、其弟**安德烈**（库里没有）｜守 骑士团驻军（两名骑士执事，史书未载名）。
- **③ 起因**：1240 年利沃尼亚骑士团夺取普斯科夫，并深入诺夫哥罗德境内。
- **④ 经过**：亚历山大突袭普斯科夫，驱逐骑士团驻军（编年史，史实）。
- **⑤ 结局**：**普斯科夫归诺夫哥罗德**（史实）。
- **⑥ 出镜**：西进爱沙尼亚，前锋受挫后退回楚德湖东岸。
- **⑦ 出处**：英文维基 *Alexander Nevsky*；*Livonian campaign against Rus'*（条目名以站内为准；普斯科夫收复独立条目待核）。
- **文案三件**：
  - **briefing**：公元一二四二年早春，亚历山大回到了诺夫哥罗德。西方的骑士团已经占了普斯科夫，他要先把这座城夺回来。
  - **inviteText**：「兄弟们，普斯科夫是我们的兄弟城。骑士们住进了城里，那就请他们出去。」
  - **description**：诺夫哥罗德军突然出现在普斯科夫城下，骑士团的驻军猝不及防，被赶出了城。亚历山大乘胜向西，追入了爱沙尼亚。

### 场 3｜1242 春 · 楚德湖之战（野战，主角守，剧终）
- **片/段**：一 / 段二
- **① 入镜**：普斯科夫 → 爱沙尼亚 → 退回楚德湖东岸。
- **势力/地点**：攻 利沃尼亚骑士团｜守 诺夫哥罗德。地点 楚德湖冰面（野战）。
- **② 人物**：攻 多尔帕特主教**赫尔曼**与利沃尼亚骑士团（库里没有）｜守 **亚历山大**、安德烈。
- **③ 起因**：骑士团追击后撤的诺夫哥罗德军。
- **④ 经过**：骑士以楔形阵冲入罗斯军中阵，被两侧包围；传说冰面在重甲骑士脚下碎裂、多人落水（后世传说，尤因电影流传，文案写「据说」）。
- **⑤ 结局**：骑士团大败（史实），此后议和，放弃所占罗斯土地。不易主。
- **⑥ 出镜**：剧终。1252 年受金帐汗国册封为弗拉基米尔大公（B 档），1263 年卒，后被东正教会封圣。
- **⑦ 出处**：英文维基 *Battle on the Ice*。
- **文案三件**：
  - **briefing**：公元一二四二年四月，冰雪还没有融化，骑士团的重甲骑兵追到了楚德湖边。亚历山大在湖东岸摆开了阵势，等着他们踏上冰面。
  - **inviteText**：「兄弟们，他们会像楔子一样扎进来。让他们扎进来，我们从两边夹住。」
  - **description**：骑士们排成楔形冲进了罗斯军的中阵，两侧的民兵和骑兵随即合拢。据说冰面在铁甲下裂开，不少骑士落进了冰冷的湖水里，骑士团大败，从此不敢东进。
