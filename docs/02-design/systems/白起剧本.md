# 白起 · 剧本底本（一部人物传记）

> 年代：前293–260（战国末，秦昭襄王时）。主角 **白起**——**库里有**：武将 `xin_baiqi`，势力 `xin`（上党）、本城 `city_shangdang` 长子（据点本位：长平、上党之战）。
> 剧本期他史实上属**秦国**（`qin`，库里有）；按 §二之二「剧本期一个势力可以挂多位武将」，做事件时归属写秦。战后易主一律写 `qin`。
> 本底本不改数据、不新建任何东西。资料：网络搜索读英文维基摘要；**中文维基未能直接查**（网络拦截），细节依《史记·白起王翦列传》的通行说法，做事件前补查中文维基；**路网未实测**。
> 📍 **坐标口径**：写「约」「推定」的战场坐标**不是**从英文维基信息框抄的，做事件前必须按 §一.1 到信息框核对；查不到就写「合理推定」并写明理由。

## 三、分场卡（①入镜 ②人物 ③起因 ④经过 ⑤结局 ⑥出镜 ⑦出处）

**1｜前293 · 伊阙之战**　①咸阳出函谷关东进。②攻 **白起**（库里有）120000｜守 魏将**公孙喜**、韩将**暴鸢**（库里查不到）240000（史实）。主将队：待看素材定（本时代华夏英雄兵模候选以素材样貌为准）。③韩魏合兵拒秦，屯于伊阙。④两国互相观望、都想让对方先打；白起以疑兵牵制韩军，集中主力先击魏军，魏败后再回头打韩。⑤联军覆没，斩首二十四万，公孙喜被俘（史实）。白起由左庶长升国尉。⑥回秦。⑦英文维基 *Battle of Yique* <https://en.wikipedia.org/wiki/Battle_of_Yique>（兵力、伤亡：史实）；《史记·白起王翦列传》。

**2｜前279 · 鄢之战（攻城）**　①洛阳 → 回秦 → 出武关南下。②攻 白起｜守 楚军（守将名不详）。兵力史书只写「数十万」死于城中，双方数目都是**合理推定**。③秦楚交兵，鄢是楚都郢的北面门户。④白起久攻不下，筑堤引西山长谷水（后世称「白起渠」）灌城，水从城西灌入、城东流出，城中军民溺死者据说数十万。⑤鄢城破，归秦（`cityUpdates` 写不进：鄢库里没有）。⑥南下郢都。⑦*Battle of Yan–Ying* 英文维基（条目名以站内为准，本次搜索只见到摘要）；《史记》。

**3｜前278 · 郢之战（攻城）**　①鄢 → 江陵。②攻 白起｜守 楚顷襄王的郢都守军（推定）。③鄢失，郢无险可守。④秦军攻入郢都。⑤**江陵（郢）归秦**（`cityUpdates`：`city_ying` → `qin`；该城建立年代正好写 −278）；随后烧夷陵（`city_yiling` → `qin`），楚迁都于陈；秦置南郡，白起封**武安君**（史实）。⑥北上。⑦同上。

**4｜前273 · 华阳之战**　①江陵 → 夷陵 → 襄阳 → 新郑 → 战场。②攻 **魏冉**（主帅）、白起、胡阳｜守 魏将**芒卯**、赵将**贾偃**。兵力条目未给总数，按伤亡「斩首十三万、沉赵卒二万」**合理推定**。③赵魏合攻韩之华阳，韩向秦求救。④秦军八日急行军赶到，出其不意大破魏军，又追击赵军，把两万赵卒赶进黄河淹死。⑤联军大败，魏割南阳求和（史实）。⑥此后白起连年攻韩（B 档）。⑦*Battle of Huayang* <https://en.wikipedia.org/wiki/Battle_of_Huayang>。

**5｜前260 秋 · 长平之战（剧终）**　①新郑 → 虎牢关 → 天井关 → 长子 → 战场。②攻 白起（秦先由王龁领兵，白起秘密接任）｜守 **赵括**（接替廉颇；库里查不到）。兵力待核（通行说法秦五十余万、赵四十五万）。③前262 年秦断韩上党与本土的联系，上党郡守冯亭把上党献给赵，秦赵为争上党在长平相持三年。④赵王中反间计以赵括换廉颇；白起佯败诱赵括出击，以奇兵两万五千断其后路、五千骑断其与营垒的联系，把赵军围困四十六天，断粮。⑤赵括突围战死，赵卒四十万降后被坑杀（史实）。**长子（上党）归秦**（`cityUpdates`：`city_shangdang` → `qin`）。⑥剧终：前259 年白起欲乘胜攻邯郸被秦相范雎所阻；前257 年因拒绝领兵被赐死于杜邮（B 档尾声）。⑦*Battle of Changping* <https://en.wikipedia.org/wiki/Battle_of_Changping>；《史记》。

## 六、疑点
1. **第一场出发地**：按规则取本城长子，但前293 年长子是韩地，白起人在秦国；按「出发据点＝军团此刻在哪」应是咸阳，库里没有。
2. **长平兵力**：「秦五十余万、赵四十五万」是通行说法，本次没看到英文信息框原文，待核；学界多认为数字夸大。
3. **鄢郢兵力**：史书没有双方兵力，全是推定。
4. 洛阳、长安、襄阳的建立年代表写 −300、−202、−202，前293–273 的途经地能否上图要核。
