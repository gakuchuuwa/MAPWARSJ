## 三、分场卡

### 场 1｜前61 · 湟水之战（野战，剧终）
- **片/段**：一 · 平西羌 / 段一 湟水
- **① 入镜**：皋兰（金城）→ 乐都 → 湟水。
- **势力/地点**：攻 西汉｜守 先零羌（库里羌系势力，做事件时查）。地点 湟水河谷（野战）。
- **② 人物**：攻 后将军**赵充国**（库里有）｜守 先零羌诸豪（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：先零羌与诸羌解仇结盟，攻金城、湟中；汉宣帝问谁可将，赵充国说「无逾于老臣者矣」（史实）。
- **④ 经过**：赵充国夜渡黄河，先遣三校衔枚先渡，立营陈；羌人数百骑来挑战，赵充国说「吾士马新倦，不可驰逐」，坚守不出（史实，数字不进文案）；后引兵至先零所在，羌人久屯懈弛，望见大军，弃车重欲渡湟水，道隘，赵充国徐行驱之（史实）。
- **⑤ 结局**：羌人赴水溺死及斩首数百、降者及俘获牛马车辆无数（史实，数字不进文案）；赵充国随即上《屯田奏》，罢骑兵、留步兵万人屯田湟中，次年羌众降者三万余（史实，数字不进文案）。不易主。
- **⑥ 出镜**：剧终。前60 年诸羌平定，赵充国振旅还朝；前52 年卒（史实，B 档尾声）。
- **⑦ 出处**：英文维基 *Zhao Chongguo*；《汉书·赵充国传》。
- **文案三件**：
  - **briefing**：公元前六一年秋，西羌诸部结盟反汉，攻掠金城、湟中。汉宣帝问朝中谁能领兵，年纪已老的赵充国站出来说，没有人比老臣更合适了。
  - **inviteText**：「诸位，兵马刚过黄河，还很疲惫，不要去追他们的挑战。羌人等久了自然松懈，到时候我们慢慢压过去。」
  - **description**：汉军过河之后坚守不出，羌人挑战了几次都没有回应，渐渐松懈下来。赵充国这才率军缓缓推进，羌人望见汉军大部队，丢下车辆辎重争着渡过湟水，河道狭窄，落水而死的人很多。此后赵充国没有穷追，而是留兵在湟中屯田，羌人陆续前来归降。
