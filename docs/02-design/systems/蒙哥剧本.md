## 三、分场卡

### 场 1｜1237 冬 · 梁赞（攻城）
- 同 [`拔都剧本.md`](拔都剧本.md) 场 1（数据、文案以那边为准）。
- **② 人物**：蒙哥随拔都出征，与贵由等诸王同在军中（史实）。
- **inviteText**（蒙哥线专用）：「朋友，我随堂兄拔都远征来了。罗斯人的城是木头的，雪地里的火会烧得很旺。」

### 场 2｜1259 · 钓鱼城（攻城，剧终）
- **片/段**：二 · 大汗伐宋 / 段二 四川
- **① 入镜**：梁赞 → 哈拉和林 → 六盘山 → 长安 → 大散关 → 南郑 → 剑门关 → 钓鱼城。
- **势力/地点**：攻 蒙古｜守 南宋（库里合州 `hezhou`，本城钓鱼城）。据点 **钓鱼城** `city_diaoyucheng`（战后不易主）。
- **② 人物**：攻 **蒙哥汗**｜守 合州知州**王坚**（库里有 `hezhou_wangjian`）、副将**张珏**（库里没有）。主将队：城堡时代草原英雄兵模；对手城堡时代华夏英雄兵模。
- **③ 起因**：蒙哥即位后三路伐宋，亲率西路入川，沿嘉陵江连下诸山城，唯钓鱼城不降。
- **④ 经过**：钓鱼城三面临江、山顶有田有泉，守军自给；蒙古军屡攻不下，前锋汪德臣劝降被砲石击伤而死；夏天暑热，军中疫病流行（史实）。
- **⑤ 结局**：蒙哥死于城下——一说中砲伤，一说染病（史料不一，文案写「据说」）。蒙古军撤围，**不易主**；各路蒙古军因争立大汗纷纷北返（史实）。
- **⑥ 出镜**：剧终。弟忽必烈与阿里不哥争位（见 [`忽必烈剧本.md`](忽必烈剧本.md)）。
- **⑦ 出处**：英文维基 *Siege of Diaoyu Castle*；*Möngke Khan*；中文维基《钓鱼城之战》未查。
- **文案三件**：
  - **briefing**：公元一二五九年春，蒙哥汗亲自领兵来到合州钓鱼城下。这座山城三面临江，山顶上有田有井，守将王坚据说早已备好了多年的粮草。
  - **inviteText**：「朋友，四川的山城一座接一座投降了，只剩下这一座。拿下它，顺江而下就是宋人的腹地。」
  - **description**：蒙古军从春天攻到夏天，始终攻不上山顶，劝降的将领反被砲石击伤而死。暑热中疫病蔓延，蒙哥汗也死在了城下，据说是中了砲伤，也有人说是染了病。
