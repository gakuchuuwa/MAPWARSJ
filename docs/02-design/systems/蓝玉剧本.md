## 三、分场卡

### 场 1｜1381 · 白石江之战（野战）
- 同 [`沐英剧本.md`](沐英剧本.md) 场 1（数据以那边为准）。
- **② 人物**：蓝玉为左副将军（史实）。主将队：城堡时代华夏英雄兵模（按 §二.5 看样貌选）。
- **inviteText**（蓝玉线专用）：「诸位，江对岸的元军看着人多，其实心虚。沐将军从下游绕过去，我们在正面把他们钉住。」

### 场 2｜1388 · 捕鱼儿海之战（野战，剧终）
- **片/段**：二 · 捕鱼儿海 / 段二 漠北
- **① 入镜**：曲靖 → 金陵 → 北京 → 大宁 → 应昌 → 捕鱼儿海。
- **势力/地点**：攻 明｜守 北元（库里北元系势力，做事件时查）。地点 捕鱼儿海（野战），战后按历史 `cityUpdates` 写 **捕鱼儿海** 归明（北元主力覆灭；史实）。
- **② 人物**：攻 征虏大将军**蓝玉**（库里有）、**王弼**（库里没有）｜守 北元天元帝**脱古思帖木儿**、太尉**蛮子**（库里没有）。
- **③ 起因**：纳哈出降明后，北元失去东翼，朱元璋命蓝玉率大军深入漠北。
- **④ 经过**：大军行至百眼井，不见敌踪，蓝玉欲退，王弼谏阻；探知北元主营在捕鱼儿海东北八十余里（史实，数字不进文案）；明军穴地而炊，不见烟火，趁大风扬沙白昼如夜，直抵北元营帐（史实）。
- **⑤ 结局**：北元大败，太尉蛮子战死，脱古思帖木儿与太子天保奴仅以数十骑逃走，俘其次子地保奴、妃嫔、官属及军士七万余人（史实，数字不进文案）。**捕鱼儿海归明**。北元从此一蹶不振，脱古思帖木儿不久被也速迭儿所杀（史实）。
- **⑥ 出镜**：剧终。蓝玉晋封凉国公，骄纵不法，1393 年以谋反罪被杀，株连一万五千余人，史称「蓝玉案」（史实，数字不进文案；B 档尾声）。
- **⑦ 出处**：英文维基 *Battle of Buir Lake*。
- **文案三件**：
  - **briefing**：公元一三八八年夏，大将军蓝玉率领大军深入漠北，寻找北元朝廷的踪迹。大军在草原上走了很久也不见敌人，蓝玉据说一度想要退兵，是部将王弼劝住了他。
  - **inviteText**：「诸位，北元的皇帝就在捕鱼儿海的东北。埋锅造饭不许冒烟，趁着风沙过去，让他们看不见我们。」
  - **description**：那天狂风大作，黄沙蔽日，明军顶着风沙一路疾进，一直冲到了北元的营帐前。北元将士猝不及防，太尉蛮子战死，脱古思帖木儿只带着少数亲随逃走，他的儿子、妃嫔和大批部众都成了明军的俘虏。
