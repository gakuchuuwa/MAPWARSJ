## 三、分场卡

### 场 1｜317–318 · 谯城（攻城）
- **片/段**：一 / 段一 谯城
- **① 入镜**：广陵（京口）→ 淮阴 → 盱眙 → 谯县。
- **势力/地点**：攻 东晋｜守 坞主樊雅（据谯城，库里没有）。据点 **谯县** `city_qiaojun`（战后 `cityUpdates` 归东晋）。
- **② 人物**：攻 **祖逖**（库里有）、得南中郎将王含援兵｜守 坞主**樊雅**、**张平**旧部（库里没有）。主将队：古典时代华夏英雄兵模（按 §二.5 先保年代）。
- **③ 起因**：祖逖渡江后在淮阴冶铁铸兵、招募士卒，北进时谯城坞主樊雅拒不归附（史实）。
- **④ 经过**：樊雅夜袭祖逖营，祖逖击退；后借王含、桓宣之兵攻谯城，桓宣单马入城劝降樊雅（史实）。
- **⑤ 结局**：樊雅出降，**谯县归东晋**（史实）。
- **⑥ 出镜**：北进雍丘。
- **⑦ 出处**：《晋书·祖逖传》；英文维基 *Zu Ti*。
- **文案三件**：
  - **briefing**：公元三一七年，祖逖带着自家的部曲渡江北上。据说船到江心时，他敲着船桨发誓，不能收复中原就不再渡江回来。走到谯城，当地的坞主樊雅却不肯让路。
  - **inviteText**：「诸位，我们不是来抢地盘的，是来收复中原的。樊雅若肯归附，就是自己人。」
  - **description**：樊雅夜里偷袭晋营，被祖逖击退。祖逖向朝廷借兵围城，又派桓宣单骑入城劝降，樊雅终于开门归附，谯城成了北伐军的立足之地。

### 场 2｜319–320 · 蓬陂之战（野战，剧终）
- **片/段**：一 / 段二 蓬陂
- **① 入镜**：谯县 → 雍丘 → 蓬陂。
- **势力/地点**：攻 东晋｜守 后赵（库里后赵系势力，做事件时查）。地点 蓬陂坞（野战），战后按历史 `cityUpdates` 写 **雍丘** 归东晋（祖逖进屯雍丘；史实）。
- **② 人物**：攻 **祖逖**、部将**韩潜**（库里没有）｜守 后赵将**桃豹**（库里没有）。
- **③ 起因**：祖逖与后赵桃豹分据蓬陂坞东西二台，相持四十日（史实，数字不进文案）。
- **④ 经过**：两军都缺粮；祖逖用布袋装土，假装是米，让一千人运上东台，又派几人挑真米走在后面、装作累了歇息；赵军来抢，抢到的正是真米，以为晋军粮足，军心动摇；后赵派人运粮接济，祖逖在汴水截获（史实）。
- **⑤ 结局**：桃豹连夜退走（史实）。祖逖进屯雍丘，黄河以南大多归晋。**雍丘归东晋**。
- **⑥ 出镜**：剧终。祖逖在河南劝课农桑、礼贤下士，后赵石勒不敢南犯，还派人修祖逖母亲的坟墓示好（史实）；321 年朝廷派戴渊节制北方，祖逖忧愤成疾，卒于雍丘（史实，B 档尾声）。
- **⑦ 出处**：《晋书·祖逖传》；英文维基 *Zu Ti*。
- **文案三件**：
  - **briefing**：公元三一九年，祖逖与后赵大将桃豹在蓬陂坞对峙，一个占东台，一个占西台。两边都快断粮了，谁先撑不住，谁就得走。
  - **inviteText**：「诸位，把布袋装满土，扛上东台，要让西台的人看清楚。再派几个人挑真米在后面慢慢走。」
  - **description**：赵军看见晋军源源不断地往东台运粮，又抢到了晋军挑夫丢下的真米，以为晋军粮草充足，顿时人心惶惶。后赵派来运粮的驴队又在汴水被祖逖截下，桃豹只好连夜撤走。
