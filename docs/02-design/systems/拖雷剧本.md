## 三、分场卡

### 场 1｜1221 · 木鹿（攻城）
- **片/段**：一 · 呼罗珊 / 段一
- **① 入镜**：撒马尔罕 → 布哈拉 → 马尔夫鲁德 → 木鹿。
- **势力/地点**：攻 蒙古｜守 花剌子模（木鹿库里挂 `seljuq`，剧本期按史实归属表处理）。据点 **木鹿** `city_merv`（战后 `cityUpdates` 归 `menggu_d`）。
- **② 人物**：攻 **拖雷**｜守 木鹿总督**木只儿·木勒克**（库里没有）。主将队：城堡时代草原英雄兵模（按 §二.5 看样貌）。
- **③ 起因**：成吉思汗命拖雷扫荡呼罗珊诸城。
- **④ 经过**：拖雷亲自绕城巡视六日，守军出城突击两次都被打回；拖雷许诺不杀，总督开城（志费尼，通行说法）。
- **⑤ 结局**：**木鹿归蒙古**（史实）；蒙古军随即背约屠城，只留下四百名工匠（志费尼，数字从史料，文案不写）。
- **⑥ 出镜**：西进尼沙布尔。
- **⑦ 出处**：英文维基 *Merv*；*Tolui*；*Mongol invasion of the Khwarazmian Empire*（木鹿围城独立条目待核）。
- **文案三件**：
  - **briefing**：公元一二二一年早春，拖雷来到呼罗珊的名城木鹿。据说他一连几天绕着城墙骑马察看，一句话也不说。城里的人出城突击了几次，都被打了回去。
  - **inviteText**：「朋友，这座城很大，城里的人很多。告诉他们，开了城门，就能活。」
  - **description**：守军突围失败，总督相信了拖雷不杀的许诺，打开城门出降。可蒙古军入城之后并没有守约，木鹿这座丝路上的名城从此一蹶不振。

### 场 2｜1221 · 尼沙布尔（攻城）
- **片/段**：一 · 呼罗珊 / 段一
- **① 入镜**：木鹿 → 萨拉赫斯 → 图斯 → 尼沙布尔。
- **势力/地点**：攻 蒙古｜守 花剌子模。据点 **尼沙布尔** `city_nishabuer`（战后 `cityUpdates` 归 `menggu_d`）。
- **② 人物**：攻 **拖雷**（其姐之夫脱忽察儿此前在城下中箭身亡）｜守 尼沙布尔守军（主将史书未详，库里没有）。
- **③ 起因**：上一年成吉思汗的女婿脱忽察儿攻尼沙布尔时中箭而死（史实）。
- **④ 经过**：蒙古军运来大批炮石与攻城器，猛攻数日破城（志费尼，通行说法）。
- **⑤ 结局**：**尼沙布尔归蒙古**（史实）。为给脱忽察儿报仇，城被屠，据说连猫狗都不留（通行说法，文案只写「据说屠城」，不渲染细节）。
- **⑥ 出镜**：赫拉特受降（B 档），东归。
- **⑦ 出处**：英文维基 *Nishapur*；*Tolui*。
- **文案三件**：
  - **briefing**：公元一二二一年春，拖雷兵临尼沙布尔。一年前，他的姐夫脱忽察儿就死在这座城下的一支箭上。蒙古人运来了成堆的炮石，城里的人恐怕也知道这一次凶多吉少。
  - **inviteText**：「朋友，姐姐要我替她的丈夫讨个说法。这座城，不会再有第二次谈条件的机会。」
  - **description**：炮石昼夜轰击，城墙被打开缺口，蒙古军蜂拥而入。据说这座城被屠戮殆尽，脱忽察儿的遗孀亲自监看，只为给丈夫报仇。

### 场 3｜1232 春 · 三峰山之战（野战，剧终）
- 同 [`速不台剧本.md`](速不台剧本.md) 场 4（数据以那边为准；拖雷为主帅）。
- **① 入镜**：尼沙布尔 → 东归 → 哈拉和林 → 大同 → 岐山 → 大散关 → 南郑 → 宛城 → 三峰山。
- **⑥ 出镜**：剧终。战后与窝阔台会师；北返途中窝阔台病重，据说拖雷饮下巫师的咒水代兄受病，1232 年死（《元史》《秘史》，据说如此；B 档尾声）。
