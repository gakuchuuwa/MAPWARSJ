# 武将技 · 设定总纲

> 定稿日期：2026-07-22。本文档 = 武将技系统的**权威设定**，与 `AGENTS.md`「武将六槽铁律 / 铁律零·战力环」互为正文。
> 数值唯一标准源 = `vite.config.ts` 的 `SE_TIERS`；六计判据唯一权威 = `src/data/TacticalSkillCatalog.ts` 的 `EFFECT_TO_SIX_SET`。
> 本文取代此前分散且部分过时的设计稿（三势适性系统设计.md 等）。

---

## 一、定位（一句话）

武将技是**观赏型直播游戏**里的「戏码」——胜负主轴永远是 **兵力 > 攻守适性 / 势 > 条件 > 技能**，武将技只是最后那点**锦上添花**，绝不能单独翻越兵力或势。

**设计红线：**
- 无玩家操作，一切为观众可辨认的演出与收视率服务，技能必须有可见的戏。
- 一个 ×1.2 的顶格技，最多把等兵力对决从 50% 推到 ~70%；1.6:1 的兵力优势方，哪怕对面放技能也基本必胜。
- 名将「更强」由**独立的名将光环环**负责（见第五节），不靠武将技破格实现。

---

## 二、战力环模型（一切数值的底座）

一场战斗的胜负**不看兵力比，看「九环乘完的有效战力比」**（`BattleField.effectivePowerRatio`；局势、时长判定同此，见 `resolveSituationKind`：>1.5 优势 / <0.67 劣势 / 其间均势）。

```
有效战力 = 兵力(基数) × 九环连乘
九环全为纯战力加成系数乘区（绝不含兵力基数）
```

**铁律：每个方向性系数环恒落 [0.8, 1.2]，满值 = 1.2**（本位/优势 1.2、双行 1.1、均势 1.0、错位/劣势 0.8）。代码定死在 `src/combat/TacticalConstants.ts`：

| 环 | 常量 | 取值 |
|----|------|------|
| 三势适性 | `APTITUDE_POWER_MULT` | 本命 1.20 / 均势 1.00 / 优势错配 0.90 / 劣势错配 0.80 |
| 攻防风格 | `ATTACK_STYLE_POWER_MULT` | 专精本位 1.20 / 双行 1.10 / 专精错位 0.80 |
| 名将光环 | `FAMOUS_GENERAL_MULT` | 名将 1.20 / 普将 1.00 |
| **武将技** | 见第四节 | 战力型效果等效落 [0.8,1.2]，满值 ×1.2 |

**推论（红线）**：任何「加/减战力」的武将技数值必须落在 [0.8,1.2]。它只是众环之一，**1.2 就是满值、不是过强**——严禁因为「×1.2 单独算胜率偏高」就往下压，那是把一环误当终值。

**唯一例外 = 运气 / 变随机环**：均值锁死 1（`luckMin + luckMax = 2`），因不移动均值，区间可超出 [0.8,1.2] 以加大戏剧性。判据：**移均值的方向环 → 守 [0.8,1.2]；不移均值的随机环 → 可更宽**。

## 三、六计 × 三势 结构

战术技的运作分类 = **三势六计**。每个武将配 **六槽**（攻/守 × 优/均/劣），**六计各一、不得缺漏或重复**（`TacticalSkillResolver` 硬依赖）。

| 势 | 两槽 | 两计（互补） |
|----|------|-------------|
| 优势 | atkAdvantage + defAdvantage | **攻战计** + **胜战计** |
| 均势 | atkBalance + defBalance | **敌战计** + **混战计** |
| 劣势 | atkDisadvantage + defDisadvantage | **并战计** + **败战计** |

**运行时选池（四/四/六，攻守同池）**：引擎按【当前势】从池中等概率抽一技——
- 优势 → 攻战/胜战/敌战/混战（**不含劣势组** → 优势方摸不到翻盘钥匙）
- 劣势 → 并战/败战/敌战/混战（不含优势组）
- 均势 → 全六计随机

> **悬念铁律**：六计中**只有败战计能反转胜负**，而败战计只在劣势池 → **只有劣势方摸得到翻盘钥匙**。

`atk*/def*` 字段名只是存储位，**选技已不分攻防**（`_isAttacker` 作废）；攻守数值差由第四层攻防环负责，不在技能层重复表达。

## 四、六计机制与定档参数（唯一标准源 = `SE_TIERS`）

在册 = 技有 `ownerGeneralId`（名将专属署名）；不在册 = 通用共享技。**在册取环强端、不在册取中端**。

| 计 · 别名 | 局 | 机制（引擎效果） | 在册 | 不在册 |
|-----------|----|-----------------|------|--------|
| **攻战·机** | 优 | 加己战力 `ally_power_mult` | ×**1.2** | ×**1.1** |
| | | 守减敌战力 | ×0.8 | ×0.9 |
| **胜战·全** | 优 | 减敌兵 `enemy_sub_troops_opening`（比值 1/(1-x)） | **16.7%** ⇒ ×1.20 | **9%** ⇒ ×1.10 |
| | | 加己兵 `ally_add_troops_opening`（幽灵，暂无技用） | 20% | 10% |
| **敌战·衡** | 均 | 变随机 `luck_variance_*`（均值恒=1） | **[0.6,1.4]** | **[0.7,1.3]** |
| **混战·乱** | 均 | 否决 `negate_enemy_skill`（概率） | **0.8** | **0.4** |
| | | 夺技 `steal_enemy_skill`（否决+复制，**封顶 0.5**） | 0.5 | 0.5 |
| **并战·借** | 劣 | 减己损 `win_casualty_reduction`（胜时少损） | **0.2** | **0.1** |
| | | 咬人 `lose_enemy_casualty_boost`（败时放大敌损） | ×**1.5** | ×**1.25** |
| **败战·险** | 劣 | 翻盘重掷 `recompute_comeback`（**唯一能反转胜负**） | 重掷幅 [0.25,0.45] | [0.30,0.40] |

**注：**
- 变随机的 `magnitude` 是死字段（恒=1），真参数在 `luckMin/luckMax`。
- 败战计触发阈值 = `COMEBACK_TROOP_THRESHOLD`（兵力掉到该比例才触发）；重掷幅 = `COMEBACK_LUCK_RANGE`（在册 [0.25,0.45] / 不在册 [0.30,0.40]，均值同 0.35，在册更宽 → 更可能绝地翻盘或崩盘）。
- 减敌兵 16.7% 与加己兵 20% 不是同一百分比：要同为 ×1.20，减敌走 1/(1-x)、加己走 (1+x)。

## 五、平衡原则

1. **每环带内**：任何战力型技等效落 [0.8,1.2]，单技不可越 ×1.2 满值。
2. **运气不偏袒**：变随机均值恒=1（公平铁律），名将版只是区间更宽（戏更足），不给胜率溢价。
3. **夺技封顶 0.5**：否决+复制是双收益，不设 100%。
4. **唯一翻盘 = 败战计**，且门控在劣势池 → 不污染均势/优势。
5. **六计溢价差异化**：不是每计都给「胜率溢价」——
   - 攻战 / 胜战 / 混战 / 败战：名将版给看得见的胜率/翻盘优势。
   - 敌战（变随机）/ 并战（减己损·咬人）：机制上给不了胜率溢价，名将版体现为**方差更大 / 残兵更多**。这是刻意的差异化，不是缺陷。

**六格「谁最厉害」的结构性答案**：优势看兵力、均势借势称雄、劣势唯逆势（+败战翻盘）有戏；同势内换通用技只挪个位数百分点。

## 六、名将差异归谁

「名将更强」由**三处**共同体现，**不由武将技环破格**承担：
1. **名将光环环** `FAMOUS_GENERAL_MULT`：名将 ×1.2 / 普将 ×1.0（独立一环）。
2. **专属技名 + 演出 + 典故**：同一机制可挂多条不同名条目（「同效不同名」），名将配更贴其历史形象的技名与 Cut-in 演出。
3. **在册/不在册两档**：名将专属技取环强端。

> 武将技环本身**只管平衡**；名将的「特殊」靠光环环与演出体现，不靠技能数值凌驾兵力/势。

## 七、数据与工程落地

- **技目录**：`src/data/TacticalSkillCatalog.ts`（`ts_*` 条目：displayName / baseEffect / magnitude / luck / condition / phase / 六计 / 三势 / 典故主）。
- **数值唯一标准源**：`vite.config.ts` 的 `SE_TIERS`（六计各家族的合法档值）。改档位一律走**武将技编辑器**（`/skill-editor.html`），`magnitude` 不接受自由数字，只接受档位、服务端查表写标准值。
- **漂移校验（规则 11.13）**：`serverValidateEntities` 于 build 时逐条比对每技 magnitude/luck 是否命中 `SE_TIERS` 该家族标准档，不中即报 error（防手改 / 复制旧值 / 老数据留下带外值）。
- **六计判据唯一权威**：`EFFECT_TO_SIX_SET`（只按 `baseEffect` 查表，禁按 condition 改判六计）。
- **佩戴铁律**：每技至少一名武将佩戴（无孤儿技）；每将六槽六计各一（无缺漏重复）。
