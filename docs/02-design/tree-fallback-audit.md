## 2. 漏网之鱼清单（6 类，共 25 座明确不合理 + 若干勉强）

### 2.1 gr4 默认柳树 → 乌克兰南部（5 座）🔴
- 塞契(47.8,35.2)、雅西(47.2,27.6)、阿克曼(46.2,30.3)、阿速城(47.2,39.7)、萨尔克尔(47.7,42.3)
- **原因**：日托米尔那次修复只补了「东欧框」的 gr4，但东欧框南界是 48N，这 5 座黑海北岸城在 46~48N，掉在框外，仍回落到 gr4 默认柳树。
- **历史**：黑海北岸是草原（黑土草原带），不是江南水乡，柳树不是优势种。

### 2.2 gr3 默认白桦 → 华北（8 座）🔴
- 安阳、北京、邯郸、保定、邢台、范阳、濮阳、朝歌
- **原因**：华北中原框的 `bases` 是 `ds3/gr2/grs/for`，**漏了 gr3**。这些华北城底图是 gr3，落回 gr3 默认白桦。
- **历史**：华北优势是温带落叶阔叶林（栎类/榆槐），白桦是东北/半干旱的优势种。

### 2.3 gravel_default 默认亚洲松 → 青藏东部（7 座）🔴
- 玛曲、甘孜、理塘、德格、八宿、芒康、阿墩子（经度都在 96~104E）
- **原因**：藏西/昆仑/帕米尔框的经度是 72~96E，**没盖住 96E 以东**的青藏高原东部（川西、甘南）。
- **历史**：青藏东部优势是亚高山针叶林（云杉/冷杉/藏柏），不是亚洲松。

### 2.4 gr5 默认橡树 → 缅甸（2 座）🔴
- 蒲甘(21.2,94.9)、因瓦(21.9,96.1)
- **原因**：中南半岛框的 `bases` 是 `ds4/ds3/gr6/fo2/grs/gr2`，**漏了 gr5**。缅甸这两座城底图是 gr5，落回 gr5 默认橡树。
- **历史**：缅甸是热带季风落叶林（柚木等），不是温带橡树。

### 2.5 gr2 默认亚洲枫 → 关中长安（1 座）🟡
- 长安(34.3,108.9)
- **原因**：华北中原框经度是 110~122E，长安在 108.9E，**西界差 1.1°** 没盖住。
- **历史**：关中优势是栎类，亚洲枫勉强（关中槭/栎混交，可接受，但偏枫不对）。

### 2.6 gr6 默认茂竹 → 加勒比/大西洋（2 座）🟡
- 哈瓦那(23.1,-82.4)、安格拉(38.7,-27.2)
- **原因**：gr6（丛林草地）默认 LUSH_BAMBOO，但这俩在美洲/大西洋，竹子是东亚/东南亚的。
- **注意**：这是「大陆级错配」，`tools/audit-tree-origin.mts` 的 ORIGIN 表已把 LUSH_BAMBOO 限制在 68~150E，理论上能拦，但**该脚本没拦 gr6 默认**（只拦地区框配的树）。

### 2.7 勉强类（可接受，记录备查）
- **pal 默认棕榈**（蒙古戈壁几座，如燕然勒石 45.2,104.7）：蒙古戈壁绿洲是胡杨/红柳不是棕榈，但素材库里没有，先用棕榈凑合。
- **underbrush_leaves 默认亚洲松**（俄罗斯针叶林：诺夫哥罗德、喀山等）：俄罗斯针叶林是西伯利亚松/云杉，亚洲松是东亚的，属「大陆级」勉强。

## 4. 关于「28 个区域是不是太少」

**结论：28 个不算错，但确实偏粗，可以补到 35~40 个。**

- **为什么 28 个 ≠ 太少**：这 28 个是「优势植被带」，和 65 个「文化区」是**两个维度**——文化区管「谁在这里」（历史归属），植被框管「这里长什么」（自然地理）。一个植被带里可以有好几个文化区（比如「温带阔叶林带」同时有中原、日本、欧洲十几个文化）。
- **为什么又确实偏粗**：§2 那 6 类漏网，本质都是「某一小片植被带的优势种和大框不一样」，靠 28 个大框盖不住。这些地方该拆成独立小框：
  - 黑海北岸草原（乌克兰南部）—— 草原疏树，不是柳树
  - 缅甸热带落叶林 —— 热带阔叶，不是橡树
  - 青藏东部针叶林 —— 云杉/冷杉/藏柏，不是亚洲松
  - 加勒比/大西洋岛屿 —— 热带阔叶，不是竹
  - 西伯利亚针叶林 —— 西伯利亚松/云杉，不是亚洲松
- **方向**：不是无脑把框加到 65 个跟文化对齐，而是**按「优势植被」细分**，每加一个框都要能回答「这一片的优势种是什么」，守 §5.6.13「什么最多」那条铁律。

## 5. 落地顺序建议

1. 先做 §3 的 6 项「补 bases / 调边界」（零风险，只影响漏网那几十座城）。
2. 再跑 `npx tsx tools/audit-tree-fallback.mts` 复验，掉回默认的城里那 6 类应清零。
3. 最后决定要不要扩「黑海草原 / 缅甸 / 青藏东部 / 加勒比 / 西伯利亚」几个新框（需要逐一定优势种）。

## 6. 执行结果（2026-08-30 已完成「先修复、再扩充」）

### 6.1 修复（7 处补 bases / 调边界，§3 全部落地）
