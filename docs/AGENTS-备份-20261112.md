- 🔴 **不许擅自添加无关逻辑**（2026-11-11）：点名改哪一处就只改那一处，**不许顺手加辅助函数、加兜底分支、加阈值/计时器/新机制、加屏幕提示或战报用语**。做点名的事确实非得新逻辑不可时，先说明「要加什么、加在哪、为什么绕不开」，等主人点头再写；主人没点头就只报告缺口。**也不许删改原有逻辑**：只删自己这一轮加的、主人否掉的东西，碰到别人（含旧轮次）写的代码先问，误删一律按原样还原。

## 二、武将 · 势力 · 据点

1. **武将资格、本名与唯一身份**：
   - 🔴 **传说人物可入将，神话人物不可入将**（2026-11-10）：无信史实名人物时，可用**史源转述的凡人传说君王/统帅**（亚瑟王、贝里格、罗宾汉等）；**禁用神、半神、创世神等神话人物**。注释写「史源转述、传说成分」，立绘留空、缺实胜列普将，不另拟名。
   - 🔴 **武将名只留本名**（2026-10-24）：禁职位/称号前缀；本名+序数或通用尊称（成吉思汗、熙德、彼得大帝、齐顷公、单于）可用；**只有职位/称号无真名或拟名的一律删除**。
   - **同人一个身份**（2026-10-22）：同一人限一个 `generalId`、一套「势力＋军团＋精锐」（`scratch/audit_general_identity.mts`）。全库武将必有据点。
2. **据点范围与武将安置**：
   - **据点代表 50km**（2026-10-23）：不专属势力或时代（长安＝咸阳；**邺城归安阳**，邯郸留给战国赵）；50km 内不新建。
   - 🔴 **一城可多将；一个武将＝一个势力、一个精锐、一个军团、一个旗号**（2026-10-23）：全跟武将走；在场将全在外才算 `spawnGeneralUsed`。
   - 🔴 **可挂据点的四种关系**（2026-10-24）：① **长期驻扎／居住**（都城/治所/封地/镇所）；② **镇守**（守将/太守/刺史/节度使）；③ **打过守城／防御战**；④ **出征集合地**（大军集结/出塞城，用于无将据点补同文化将）。出生地、籍贯、攻打过、路过、死葬地、遥领未到任不算；多处符合取最知名处。
   - 🔴 **三步走：据点 → 武将 → 军团**（2026-11-07，因果只许正向）：
     - **第一步 · 只审据点**：按历史实体建筑落 **67 文化键之一**，无精确对应取最近者作代理（`note` 写「代理」；河西键＝`HEXI`，仅地区键/立绘目录/DE 素材留 `KHITAN`）。**一城一文化，67 键每键至少 1 城**；两说都通判给**据点较少**的文化（`scratch/_step1_count_by_culture_20261107.mts`）。无史料证伪原值不动，禁为迁就武将/军团改据点文化。**只做第一步时禁动武将字段或 `GeneralCulture.ts`**（`scratch/_step1_city_style_audit_20261107.mts`）。
     - **第二步 · 再放武将**：**武将文化＝据点 `buildingStyle`**（`getGeneralCulture` 与 `GeneralCulture.ts` 须一致）。① **长期居住/镇守即同化，就地保留，不挪 `cityId`**；② 明确未长住过才移往本文化据点（镇守/居住 → 民族或势力起源地同名据点 → 离首战最近据点）；③ 两说都通取据点少的文化。同势力跨据点有不同文化武将是史实（大明南京江南、北京河朔），不拆势力。
     - **第三步 · 军团自动配**：军团＝势力时代 × 据点文化（`scratch/audit_culture_consistency.mts`、`scratch/audit_culture_chain.mts`）。
3. **势力划分与命名**（见 `docs/AGENTS/faction-naming.md`）：
   - 🔴 **势力＝武将所在政权**（2026-11-05）：**政权名、军阀与军队统称（董卓、西凉军、魏博）、土司与家族名、史料族称、现代少数民族名**合格。**不合格**：纯地名/战场/水源/驿站/要塞、殖民地/属地/公司/氏族（并入本国/本族）、**与本势力武将重名的人名**（本势力内重名时势力改政权全称，跨势力同名不算；`scratch/_probe_faction_same_name.mts`）。
   - **用当时自称／正史国号**（2026-10-29）：① 不用「XX朝」；② 「大XX」只给正式国号带大的政权（窦建德写「夏」）；③ **皇族姓氏＋国号防叠念**（李唐/赵宋/刘汉/慕容燕/宇文周/拓跋魏/赫连夏国/沮渠凉国/秃发凉国/乞伏秦国）。
   - 🔴 **合并与新建**（2026-11-11 GG第五轮，**取代**「同系分立」）：**同族同祖的政权一律并入主干**（西辽/东辽→大辽、古格→吐蕃；`FactionLineage` 已清空）；不打同政权合并。**势力必须是历史上公认的政权**，不合格者（外来泛称、以人名命名、纯地名、属地/公司）删除；**武将缺政权时新建公认政权**（古蜀、夏威夷王国…），同批登记旗号/色/首府/时代/军团兜底。台账 `docs/AGENTS/GG第五轮落地报告-2026-11-11.md`。
4. **旗帜与旗号**（见 `docs/AGENTS/中国旗号单字国号-2026-10-26.md`）：
   - 🔴 **旗面四种**（2026-10-25）：**一字旗／二字旗／符号旗／叛军无字旗**。正规势力必有唯一旗号（`SANDBOX_DISPLAY_NAMES`，1–2 字，不含「州」「国」）、唯一色（同系除外）及「旗形＋色」组合；`factionFlagMap` 值＝旗号，禁填武将名。**符号旗**限史有明证专属纹章（一 `FACTION_EMBLEM` 限一家），余用字旗。验收 `scratch/_audit_flag_gaps_20261025.mts`、`scratch/_audit_flag_dupes_20261025.mts`、`scratch/_audit_flag_kinds_20261025.mts`。
   - 🔴 **字旗取字**（2026-11-03）：① **中国政权一字优先**：国号一字、加方位/前后前缀（东晋→晋、前凉→凉、西辽→辽）、或「大」仅尊称（大夏/大周/大燕/大梁）写单字；「大」或方位字不可拆或拆后撞异国号写两字（大理/大西/大顺/大越/东夏/南越/南诏）；**同国号可同字重旗**，靠色＋旗形区分。② **「一字＋州/国/族/氏/家/部/人/朝」缩一字**（`src/data/FlagOneChar.ts:toFlagText`）：非西方文化、单字能代表该势力、未撞他家单字旗时缩一字（傣/羯/孟/寮/石/羌/附）。③ **其余非汉字文化区一律 2 字简称**；「地名＋民族」禁各截一字。
5. **精锐（五级制）**（见 `docs/AGENTS/精锐五级制-2026-11-01.md`）：
   - 🔴 **归属六级优先级**（2026-11-07）：**① 符合历史 → ② 跟武将 → ③ 跟势力 → ④ 跟民族（`src/data/FactionPeoples.ts`）→ ⑤ 区域 → ⑥ 据点**（⑤⑥只作取名依据，不限跨区驻防；**精锐不要求与据点文化对应**）。别国/别时代武将用自己的 `eliteName/eliteTier`。

2. **经典战＝编年史剧本战**（2026-11-12）：🔴 **不再随机寻将，一律按战争编年史顺序接战**（`src/data/chronicle/`，真源云盘《双段播报总表》；每事件先战略播报、开战后战术播报；`docs/02-design/systems/编年史自动推进-设计方案-2026-11-12.md`）；**只做名将代表战**（普将有问题直接删）；**双方武将须实名在场**（`enemyGeneralId` 禁泛称/职位拟名；`BattlefieldCharacters.ts` 只留真名）。敌将史失其名时，**先换该名将另一场敌将有实名的经典战，换无可换才删首战**。新增武将按四闸（`docs/AGENTS/expedition-elite.md` §12.3，缺一即普将）配齐五表，立绘留空。**攻守兵力 1 万～2 万**（`FIRST_BATTLE_MIN/MAX_TROOPS = 10000 / 20000`），**兵力比 ≤ 1:2**（赢家劣势 ≥1:2 拉平；`scratch/_fix_firstbattle_troops_20261028.mts`）。本城距战场 **>300km** 去打仗处接，**≤300km** 在本城接。野战/守城全歼敌军团、攻城克城算胜；野战仅在写了史实 `rewardCityId` 时奖据点；战败军团溃散、脱离势力换下一家（`PlayerQuestSystem.ts`）。战前由 `announceBriefing` 播报背景（`GeneralFirstBattleBackgrounds.ts`，见 `docs/AGENTS/首战历史背景播报-单一口径.md`）。
3. **义军与叛军**（2026-11-05）：**义军**＝历史起义首领独立政权（按史实命名，禁用「地名＋义军」；`panjun` 已删），可出征；**叛军（`panshu`）**＝无将据点无主状态，**无字旗、不出征**，校验跳过（`skipFactions`），禁补数据。**播报战败方必冠势力名**（`SpeechAnnouncer.announceCityCapture`）。
4. **建成年门槛、退场、长寿与默认模式**（2026-11-12）：🔴 **未到建城年的大/中/小城与险要（`pass`）降为城寨（`stockade`）**，到年恢复（`cityFoundedTypeSync.ts`）；🔴 **战场到 `scriptYear` 才显示**（`getWonderGateYear()`），奇观到 `WONDER_FOUNDED_YEAR` 才显示；🔴 **百岁模式武将一律按生卒年在场 [登场年（默认 20 岁）, 卒年]，无开局排队/延迟退场；开局年＝前 550**（`generalOnStage.ts`、`GameConfig.TIME.TIMELINE_START_YEAR`）；🔴 **无在场将时守将名为「去时代前缀与军团后缀的军团名＋将军」**（`formatLegionGeneralName`）；🔴 **关闭百岁模式马匹生老病死**；🔴 **开局默认＝百岁模式（`centenarian`）**，默认归属 `getDefaultCityFactionId(cityId)` 取首位当家将（名将优先）政权；乱斗每城由 `meleeRandomOwners` 抽一家当家并由 `setMeleeCityHomeFactionProvider` 锁定，一局一朝不串将。

## 五、据点与建筑

1. **分类与定级**（2026-10-25，离最近据点 >50km 才可新建；按最著名历史阶段判）：① 无人迹 → **战场 `bf_*`**；② 军事设施（关/隘/渡/堡/戍/镇/哨卡，有石墙/包砖/夯土墙或名带「关」/史载为关，且未成 ≥1 万居民城；「兵家必争之地」非判据）→ **险要 `pass`**；③ 居民城按 ≤1700 年城居人口峰值定级（直接史料 → 有依据推算 → 按城郭判；写进 `note`）：**≥50 万（容差 ≥40 万）大城｜≥10 万（容差 ≥8 万）中城｜≥1 万小城｜<1 万或算不出：石墙/包砖墙为小城，夯土墙/木栅/无墙为城寨**。
2. **城型与城寨围栏**：城寨＝古典、小城＝封建、中城＝城堡、大城＝帝国。小城石墙/木栅走 `cityWallShared.smallCityUsesStoneWall()`（含石墙例外**太宰府 `city_taizaifu`**，`scratch/verify_small_city_walls.mts`）。城寨三件套（NE/SE 墙、转向必有且不相邻城垛、左下正中单门）统一 import `cityWallShared`；圆城/八角/椭圆只许 FENCE 荆篱（`legacyFenceRoundWall / legacyFenceOctagonWall`）；院内 9/8/7 栋（余量 ≥5px，`scratch/verify_stockade_shape_parity.mts`、`scratch/_measure_stockade_contain.mjs`）。战术四城型一律四门。
3. 🔴 **海路与港口**（2026-11-10，见 `docs/02-design/海路网-单一口径-2026-10-24.md`）：**每座港口连 2–8 条海路**（史实成立即连；内陆城退港；缺线海港补 2–3 条；内河/湖港不补；全球 198 港除里海外连通，不画巴拿马运河；`VectorSeaRouteData.ts`，验收 `scratch/audit_port_degrees.mts`）。🔴 **战略地图码头/港口只放开放海边（`isOpenOcean`），绝不放内河/内湖；且只给大中小城，险要（`pass`）与城寨（`stockade`）不放**（`CityLifeAmbientLayer.ts`）。

## 七、剧本与军事科技

- **剧本**（见 `剧本工序-单一口径.md` ＋ `路的规则.md`）：**先点后路，先路后文案**；剧本军团名一律「XX军团」，事件攻守只选剧本军团；文案写「公元前 X 年」，念古典名，禁「古城/古都/旧都」及后人结局词，大转折交代前进原因，据点写名字，字数 ≤ 路长 1.5 倍。
