## 三、历史胜负判定六条铁律（评审与自检必读）

1. **本场本判，严禁拿长时段战争总结局倒推单场胜负**：
   - 每一条事件只判**该条事件当场战役**的历史胜负。
   - 例：第二次布匿战争最终罗马获胜，但**坎尼会战**本身必须是 `历史胜方：迦太基`、`失败方：罗马共和国`；安史之乱最终唐室平叛，但**潼关之战（哥舒翰出关）**本身必须是 `历史胜方：大燕`、`失败方：李唐`。
2. **只认客观军事结果，严禁按后世褒贬或悲情色彩倒判**：
   - 守军虽死战殉国、流芳百世，但只要最终防线被突破、城池陷落，当场胜方就是攻方。
   - 例：**温泉关之战（`evt_0081`）**波斯军突破关隘、列奥尼达战死 → `胜负判定："攻方胜"`，`历史胜方` 为波斯（阿契美尼德帝国），`失败方` 为斯巴达（或希腊联军）；**睢阳之战**张巡死守十月终致城陷殉国 → `胜负判定："攻方胜"`（其屏障江淮的历史作用可在 `战争结果` 简述中点明，绝不可把败方填成胜方）。
3. **攻城不克 / 围城撤兵 ＝ 守方胜，严禁误标「胜负未分」**：
   - 凡 `攻城战`、`守城战`、`关隘战` 中，攻击方未能攻克目标城池或关塞而退兵（无论是强攻受挫、粮尽退走、疫病撤围还是城下受挫议和退兵），只要守方保住城塞，**一律判 `"守方胜"`**（如前 499 年纳克索斯围城战 `evt_0056`、前 548 年巢门攻城战 `evt_0004`）。
4. **严控「胜负未分」门槛（全库占比一般不超过 2%）**：
   - 只有在一手史料明确记载**两军野战/海战死伤相当、均未击退对方、各自收兵回营或就地对峙罢兵**（如前 547 年普特里亚之战 `evt_0005`、1769 年老官屯之战 `evt_2446`）时，才允许判 `"胜负未分"`（此时 `历史胜方` 与 `失败方` 均填 `"无"`）。
   - 凡是「惨胜」（如阿斯库路姆之战皮洛士占领战场击退罗马军），仍属胜负已分，判占领战场/击退敌军的一方获胜，在 `战争结果` 写明「惨胜」即可，不许混入 `"胜负未分"`。
5. **双阶段连写事件按该事件的最终收束结局判**：
   - 部分事件含「先奇袭小胜、旋遭反扑覆灭」或「野战破敌并乘胜克城」（如 `evt_0002` 曲沃奇袭与绛都平叛战：栾盈先袭绛都败退曲沃，晋军围破曲沃灭栾氏），一律按该事件落幕时的**最终结局**判（`evt_0002` → `"守方胜"`，胜方 `晋国`，败方 `晋国栾氏军`）。
   - **极个别攻守角色倒置核查**：若核对史料发现原库某条事件的 `攻击方势力` 与 `防守方势力` 填反了，仍以真实历史定 `历史胜方` 与 `失败方`；此时 `胜负判定` 按原条目的攻守槽位如实对应（即 `历史胜方` 落在原条目 `攻击方势力` 槽位则填 `"攻方胜"`，落在 `防守方势力` 槽位则填 `"守方胜"`），并在 JSON 该条额外加 `"备注": "原库攻守槽位与史实相反，建议互换"` 供导演部修库。
6. **政权称呼红线（与 `AGENTS.md` 完全一致）**：
   - 🔴 **严禁使用「朝 / 王朝」称呼政权**（仅国号本含朝字的 `朝鲜` 允许；中国同国号政权用 `刘汉 / 东汉 / 曹魏 / 拓跋魏 / 李唐 / 赵宋 / 朱明 / 大元 / 大清` 等规范政权称呼，其余政权用当时国号或 `王国 / 帝国 / 汗国 / 苏丹国 / 埃米尔国 / 哈里发国 / 共和国 / 幕府 / 同盟` 等）。
   - 🔴 公元 330 年以后，东罗马一律称 **`东罗马帝国`**，严禁称 `拜占庭`。
   - 若原库 `攻击方势力` / `防守方势力` 已符合本条规范，请直接沿用原字面填入 `历史胜方` / `失败方`（保证脚本精确比对）；若原库字段残留「`XX朝 / XX王朝`」或 330 年后误写「`拜占庭`」，请在 `历史胜方` / `失败方` 中**直接改用合规政权名**。

VALID_VERDICTS = {"攻方胜", "守方胜", "胜负未分"}
FORBID_CHARS = re.compile(r'[0-9０-９()（）“”‘’"\'《》【】\[\]；;\n\r]')
DYNASTY_BAD = re.compile(r'(王朝|[秦汉新晋隋唐宋元明清魏蜀吴齐梁陈周商夏辽金]朝)')
LAZY_TEMPLATE = re.compile(r'^(攻方|守方|攻击方|防守方)?(击败|战胜|击退)(守方|攻方|防守方|攻击方|敌军)(获胜|取得胜利|得胜)。?$')

counts = {"攻方胜": 0, "守方胜": 0, "胜负未分": 0}

for idx, (s, d) in enumerate(zip(src_events, done_events), 1):
    eid = s["事件ID"]
    tag = f"#{idx} {eid}《{s['事件名称']}》"
    if d.get("事件ID") != eid:
        errors.append(f"{tag}: 事件ID 顺序错位，实际为 {d.get('事件ID')}")
        continue

    verdict = d.get("胜负判定", "")
    winner = (d.get("历史胜方") or "").strip()
    loser = (d.get("失败方") or "").strip()
    result_text = (d.get("战争结果") or "").strip()

    if verdict not in VALID_VERDICTS:
        errors.append(f"{tag}: 非法胜负判定 {repr(verdict)}")
        continue
    counts[verdict] += 1

    if verdict == "胜负未分":
        if winner != "无" or loser != "无":
            errors.append(f"{tag}: 胜负未分时历史胜方/失败方必须均填「无」，实际为 {winner} / {loser}")
    else:
        if not winner or not loser or winner == "无" or loser == "无":
            errors.append(f"{tag}: 已分胜负但历史胜方或失败方为空/无（{winner} / {loser}）")
        if winner == loser:
            errors.append(f"{tag}: 历史胜方与失败方同名（{winner}）")

        # 防止攻守胜败填反：检查当原势力名未涉违规词时是否严丝合缝对应
        atk_raw = s["攻击方势力"].strip()
        def_raw = s["防守方势力"].strip()
        if verdict == "攻方胜" and (winner == def_raw or loser == atk_raw):
            errors.append(f"{tag}: 标为「攻方胜」，但胜败方却填反成守方胜（胜={winner}, 败={loser}）")
        if verdict == "守方胜" and (winner == atk_raw or loser == def_raw):
            errors.append(f"{tag}: 标为「守方胜」，但胜败方却填反成攻方胜（胜={winner}, 败={loser}）")

    # 红线校验
    for fname, fval in [("历史胜方", winner), ("失败方", loser), ("战争结果", result_text)]:
        if DYNASTY_BAD.search(fval):
            errors.append(f"{tag} {fname} 命中「朝/王朝」红线：{DYNASTY_BAD.search(fval).group(0)}")
        if s["年份year"] >= 330 and "拜占庭" in fval:
            errors.append(f"{tag} {fname} 330年后误称「拜占庭」（应称东罗马帝国）")

    if not (10 <= len(result_text) <= 40):
        errors.append(f"{tag}: 战争结果字数越界（{len(result_text)} 字，要求 10–40 字）：{result_text}")
    m = FORBID_CHARS.search(result_text)
    if m:
        errors.append(f"{tag}: 战争结果含禁符 {repr(m.group(0))}")
    if LAZY_TEMPLATE.match(result_text):
        errors.append(f"{tag}: 战争结果疑似套用空话模板：{result_text}")

# 校验 CSV 行数与事件ID同步
with open(OUT_CSV, encoding="utf-8-sig", newline="") as f:
    rows = list(csv.DictReader(f))
if len(rows) != len(src_events):
    errors.append(f"CSV 行数不匹配：真源 {len(src_events)} 行，实际 {len(rows)} 行")
else:
    for idx, (d, r) in enumerate(zip(done_events, rows), 1):
        if r.get("事件ID") != d.get("事件ID") or r.get("胜负判定") != d.get("胜负判定") or r.get("历史胜方") != d.get("历史胜方") or r.get("失败方") != d.get("失败方"):
            errors.append(f"CSV 第 {idx} 行（{r.get('事件ID')}）与 JSON 内容不一致")
            break

draw_ratio = counts["胜负未分"] / max(1, len(src_events))
if draw_ratio > 0.03:
    errors.append(f"「胜负未分」占比过高（{counts['胜负未分']} 场，{draw_ratio:.1%} > 3%），请复核是否将攻城撤围或惨胜误判为未分胜负")

print("统计汇总：", counts)
if errors:
    print(f"❌ 检出 {len(errors)} 处问题：")
    for e in errors[:50]:
        print("  -", e)
    sys.exit(1)
else:
    print(f"🎉 全部 {len(src_events)} 场战争事件胜负标注验收通过，0 报错！")
