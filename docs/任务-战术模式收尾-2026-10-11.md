## 0. 接手前必读（三条，都是本会话踩出来的）

1. **写 `.ts` 必须保留 CRLF**。用 Node 改文件要 `readFileSync` → `split('\r\n')` → `join('\r\n')`；否则整文件换行符被改成 LF，`git diff` 显示 2816 行全变、逐行审阅失效（本会话已犯过一次，已 revert 重放修好）。
2. **改完必须贴 `git diff --stat` ＋逐行 diff**；`--stat` 的改动行数应等于你打算改的行数，多一行都要回退。
3. **headless 环境不可信**：
   - 战术战斗**初始化不稳定**：`men` 0/10 随机、`deCity` 常为 null、`assetsReadyOnce` 恒 false、CSS 淡入以爬行速度推进（实测 2 分钟 0→0.49）⇒ ⑤⑩⑪ 类探针在无头里出**假红**；
   - **并发会话改文件会触发 Vite HMR 整页刷新**，销毁探针页面上下文（报 `Execution context was destroyed`）⇒ 已建探针专用配置；
   - 探针专用配置：`scratch/vite.probe.config.mts` = `mergeConfig(项目配置, { server: { hmr: false } })`（**第一版写成独立 `defineConfig` 会丢项目插件，`virtual:portrait-manifest` 解析失败，应用起不来**）。
