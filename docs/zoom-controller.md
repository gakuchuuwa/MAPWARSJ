> # 🔴 铁律 · 兵种归属只看「子分类 + 文化区挨不挨着」
>
> 判断一个兵种能不能进某支军团，**只看两条**：
>
> 1. **兵种子分类对不对** —— 近战骑兵 / 弓骑兵 / 枪骑兵 / 步弓手 / 重步兵 / 攻城器…
>    要补的是哪一类，就从那一类里挑。
> 2. **文化区在地理上挨着** —— 这个兵的本源文化区，和要用它的文化区，别隔太远。挨着就行，不必同族。
>
> 兵种 id 里的民族词（女真 / 波兰 / 越南 / 图皮 / 库曼…）、中文兵名、`age` 时代标签，**都不是判据**。
> 那是《帝国时代 2 DE》的出处标签，不是本作里这个兵属于谁。
>
> **正例**：铁浮屠是**近战骑兵**、本源**东北** → 朝鲜、北方、草原、契丹、女真、西夏、蒙古**都能用**。
> 　　　　西辽挨着蒙古、离女真远 → 西辽 4 档用**怯薛军**比铁浮屠更合适。
> **反例**：图皮黑木弓箭手（南美）给阿伊努（北海道）—— 子分类虽同是步弓，但隔着太平洋，**太远，不行**。
>
> **禁止**：只因为兵名里带别族的民族词，就说「跨国乱炖 / 不符合历史」。这条已被主人当场抓过三次：
> - 「契丹军团用女真铁浮屠 = 乱炖」→ **错**，同是东北近战骑兵，文化区挨着。
> - 「库曼钦察弓骑不该给东北民族」→ **错**。
> - 「捷克军团 4 档是波兰奥布奇战锤兵 = 乱炖」→ **错**，波兰捷克接壤。
>
> 另一条同级铁律：**别人（主人 / 其他 AI）已经做好的编制，不许擅自改。**
> 只有改动前就是红的（格位不符阵型 / 兵种不存在 / 象攻城违规 / 战力离群）才准动，其余一律先问。

# 自动缩放系统（ZoomController）

> 最后更新：2026-07-26  
> 代码：`src/app/ZoomController.ts`  
> 入口：`GameAppLoop.ts` 主循环每帧调用 `app.zoomController.tick()`

---

## 一、规则

| 模式 | zoom 范围 | 交替规则 |
|------|----------|---------|
| 行军 | 8 ↔ 9 | 跨行军段交替（第一次 8，第二次 9，第三次 8…） |
| 战斗 | 10 ↔ 11 | 跨战斗段交替（第一次 10，第二次 11，第三次 10…） |

- **开战**：立刻切到战斗 zoom
- **停战**：等 5 秒后检查军团状态，若在行军则切到行军 zoom
- **最短间隔**：两次 zoom 切换之间至少 15 秒
- **已在范围内不切**：当前 zoom 已在目标区间内 → 不动，下标不翻

---

## 二、计时规则

**只在实际切了 zoom 时重置计时器。** 模式切换不等于切 zoom。

```
lastZoomChangeAt = 0  （初始值，首次检查永远通过）

开战：
  if now - lastZoomChangeAt ≥ 15s AND 当前zoom ∉ [10,11]:
    切到 combat zooms[combatNext]，轮替下标，lastZoomChangeAt = now

停战（等 5s 后）：
  if 军团在行军 AND now - lastZoomChangeAt ≥ 15s AND 当前zoom ∉ [8,9]:
    切到 march zooms[marchNext]，轮替下标，lastZoomChangeAt = now
```

---

## 三、典型场景追踪

```
初始：行军 zoom=8

行军 20s → 开战：≥15s ✓, 8∉[10,11] ✓ → 切 10           【8→10】
战斗 5s  → 停战：等5s, 10s<15s → 不切                    【保持10】
行军 20s → 开战：≥15s ✓, 10∈[10,11] → 不切              【保持10】
战斗 20s → 停战：等5s, 25s≥15s ✓, 10∉[8,9] ✓ → 切 8     【10→8】

行军 20s → 开战：≥15s ✓, 8∉[10,11] ✓ → 切 11            【8→11】
战斗 5s  → 停战：等5s, 10s<15s → 不切                    【保持11】
行军 20s → 开战：≥15s ✓, 11∈[10,11] → 不切              【保持11】
战斗 20s → 停战：等5s, 25s≥15s ✓, 11∉[8,9] ✓ → 切 9     【11→9】
```

## 四、特殊场景

### 4.1 军团战死换将

战斗结束 → 5s 冷却启动 → 新军团被跟随。

- 5s 内新军团开战 → 冷却取消，保持战斗 zoom
- 5s 到期新军团仍在战斗 → 不切，不计时
- 5s 到期新军团在行军 → 按规则切行军 zoom

### 4.2 战斗间隙（瞬间停战又开战）

停战检测到 → 5s 冷却启动 → 期间又检测到战斗 → 冷却取消，不切。

### 4.3 手动关闭

右侧面板「🔍 自动缩放」取消勾选 → `enabled = false` → `tick()` 直接 return，完全不干预 zoom。

## 五、边界情况

| 情况 | 行为 |
|------|------|
| 无跟拍军团 | `tick()` return，不动 |
| 首次开战 | `lastZoomChangeAt=0`，永远 ≥15s，立刻切 |
| 连续短战斗（每次 <10s） | 计时器累计不足 15s，永远不切 |
| zoom 已在目标区间 | 下标不翻，下次切出再切回时用同一档 |
| 手动缩放 | `applyZoom` 检测 Leaflet 当前 zoom 与目标相同则跳过 |
