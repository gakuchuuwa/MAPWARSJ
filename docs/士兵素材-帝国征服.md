# 士兵素材 ② 帝国征服（AoE2 原版/HD）设定

> 来源：AoE2 原版（1999）+ 征服者扩展，SLP 2.0N 格式。
> 铁律：**套用哪套游戏，就按哪套游戏原生做法；发现与游戏不符 → 照游戏改。**

## 目录与命名

- 目录：`public/SUCAI/SAMURAI/`
- 命名：`{action}_{0-7}.png`，action ∈ `idle / move / attack / death`

## 格式

SLP 2.0N，从原版 `Data/graphics.drs` 提取（武士 SLP 编号 attack=974 / death=977 / idle=980 / walk=984）。

## 方向

AoE2 原版只存 **5 方向**（`0=南 1=西南 2=西 3=西北 4=北`），东边 3 向运行时**水平镜像**（官方 "mirror west angles to east"）。

`DIR_MAP`（游戏 dir8 → (AoE2 方向, 是否镜像)）：

```
0 NE = (3, 镜像)   1 E  = (2, 镜像)   2 SE = (1, 镜像)
3 S  = (0, 不镜像) 4 SW = (1, 不镜像) 5 W  = (2, 不镜像)
6 NW = (3, 不镜像) 7 N  = (4, 不镜像)
```

## 动作与帧数

`idle / move / attack / death` 4 个，`DAMAGE` 复用 `attack`（原版无受击动画）。

AoE2 原版 moving object = **10 keyframes / 方向**（openage 权威），**保留全部 10 帧，不抽稀**（2026-08-15 由 8 帧抽稀改为全帧）。

## 玩家色（游戏原生机制，已复刻 ✅）

AoE2 原版玩家色 = **调色板索引** `PAL[16..23]`（8 个色阶，P1 蓝从深到浅）。
游戏渲染时把这 8 个索引**替换成当前玩家的 8 个颜色阶**。

MAPWAR 已实装：解码时 `player_gray()` 把玩家色转成 **PAL[16..23] 亮度中性灰**（8 级明暗保留），
同时导出**玩家色区域遮罩 `.pc.png`**（玩家色=255，其余透明）；`SpriteTinter.applyMaskTint` 走
luminance-preserving hue shift（保留中性灰亮度、换势力色相），结果与「势力色 H/S + PAL 亮度」的
调色板映射**逐像素等价**（2026-08-15 视觉验证通过）。

描边命令：`0x4E/0x5E`（Outline1 玩家色描边）→ 玩家色最暗阶 + 入遮罩；`0x6E/0x7E`（Outline2 盾牌描边）→ 黄色 `PAL[243]`，不入遮罩。

## 提取工具

- `scratch/aoe_tools/slp2png.py`：纯 Python 解 DRS + SLP 2.0N（含 `player_gray` / PAL）
- `scratch/aoe_tools/samurai_convert3.py`：5 向+镜像 → 8 向 → 10 帧全保留 + `.pc.png` 玩家色遮罩
