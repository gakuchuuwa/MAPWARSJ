## ② 攻击结算 · 逐步伪代码（依据：反编译原文）

> **引用约定**：`motion_map.txt:NNNN` 指 `C:\tools\rea-env\ghidra_out\motion_map.txt` 的行号（该文件内的反编译原文，可逐行核对）。

### 2.1 入口：`FUN_14114FF00`（= `CombatObject::attack(targetID, force)`）

```
CombatObject::attack(param_1 = this(对象), param_2 = targetUnitId, param_3 = flag)
  1) uVar5 = 时间戳 = func_1416041F0(时间管理器)          // 写进 this[0x32]
  2) lVar6 = 世界.取对象(param_2)                        // 0x141617DB0
     if (lVar6 == 0) return                              // 目标无效
  3) 若 (param_3 == 0) 且 (this->mAIAction(0x420) 有效):
        若 该 AI 动作的 target 已 == lVar6 且 动作类型 ∈ {9, 7}
           → 打印 "I'm already attacking Unit #%d, returning TRUE." 直接 return   // 0x1432A8070
     // 即：已经有同一目标的攻击动作 → 不重复建
  4) 若 攻击者是「建筑/塔」类 且 目标同类 → 走另一分支（this[0x84] 的动作类型 0x7E）
  5) if (this 的类型 == 4 /*某个对象类*/)   // 由混淆常量 (param_1[2]^-...) 比较得出
        挂点对象 = 世界->[0x298] 或 世界->[0x928]（按 this 的某标志位二选一）
        if (挂点 != 0) this->vfn_0x98(挂点, 0)          // 设置攻击挂点/朝向目标
  6) 分配 攻击动作对象：p = 分配(0xB8=184字节)           // 0x142d6ba78 / 0x142d6e3b7(清零)
        p[+0x28] = *(u16*)(this->data + 0x??)   // 见下「动作对象字段」
        p[+0x2C] = *(u16*)(this->data + 0x??)
        p[+0x18] = this->vfn_0x248()            // = 攻击量/攻击速度值（attAmountHeld 的来源）
        p = FUN_140B6CB00(p, this, 目标对象, 0) // ActionAttack 初始化（0x1411503D3）
  7) if (p == 0) 打印 "Error!  newAction is NULL."        // 0x1432A80A8
       else { this->mAIAction(0x84) = ...; this->vfn_0x8C0(p) }   // 装上动作
  8) 打印 "CombatObject::attack exiting: state=%d, worldTime=%d, attAmountHeld=%f."
                    // 0x1432A80D0，三个值 = this[0x31], this[0x2d], (int)this[0x32] 同源
```

**动作对象字段（实测）**：`0xB8(=184)` 字节；`+0x18` = **攻击量/攻击计时（日志里叫 `attAmountHeld`）**；`+0x28`/`+0x2C` = 两个 16 位字段（由 `this->data` 的两个 u16 拷入，未定位其语义）；`+0x2A` = 第三个 float（`0x141152A0E` 一带写入）。
**依据**：`0x1411502EE`（分配）、`0x14115030E`（清零 0xB8）、`0x1411503D3`（`FUN_140B6CB00` 调用）、`0x1411504D4`（打印 `attAmountHeld`）。
> ⚠️ 上面 6) 里两个 u16 的取址用了**常量混淆**（`param_1[2] + -0x774a063b3d174d8a` 这类），其真实偏移**未解出** → ⑤「未找到」。

（`param_8` 在 `do_attack` 块里由「基础值 × 倍率」算出后传入；见 ②.4）

### 2.4 `do_attack`（攻击真正执行处）—— Ghidra 未识别为函数的代码块

**证据 A（字符串）**：`0x1432A7C10` = `"do_attack"`，有两个代码引用：`0x141152D1E`、`0x1412C6B27`。
**证据 B（capstone 定点反汇编 `0x141152C80`–`0x141152E3A`，该块 Ghidra 报 `(none)`）**：

```
0x141152C81  ; 一段混淆的常量比较（C5 前缀的 AVX 编码，capstone 需 1 字节重同步）
0x141152CE3  cmp ax, cx ; je 0x141152D18      // 类型/ID 相等则跳过
0x141152CE8  mov rax,[rbx] ; r10 = [rax+0x358] ; call r10   // 对象 vfn 0x358（发事件/UI）
0x141152D18  mov r8d, 0x50C
0x141152D1E  lea rdx, [rip+..] -> 0x1432A7C10 "do_attack"    // ★ 本块的身份
0x141152D25  lea rcx, [rip+..] -> 0x144353180（调试/日志通道）
0x141152D2C  call 0x140903680                               // 日志输出
0x141152D31  btr eax, 0x1F
0x141152D35  imul rcx, rax, 0x64                            // ×100
0x141152D39  movabs rax, 0x8000000100000003
0x141152D43  imul rcx ; sar rdx, 0x1E ; …                   // 定点百分数除法（= v*100/100，四舍五入）
0x141152D57  movsx rax, word ptr [rbp+0x2DE]
0x141152D5F  cmp rdx, rax ; jle 0x141152D72                  // 与一个 16 位阈值比较
0x141152D64  cmp word ptr [rbp+0x2DC], r12w ; jl 0x141152DF9 // 与另一个 16 位阈值比较（不满足 → 直接返回）
0x141152D72  movups xmm0,[r14] ; movups xmm1,[r14+0x10]      // 攻击变换/朝向（16+16 字节）
0x141152D86  rcx = rbx（自身）; rdx = rsi（目标）
0x141152D93  call qword ptr [rax+0x208]                      // ★ 自身 vfn 0x208 → 返回 xmm0 = 一个 float
0x141152DCE  mulss xmm3, dword ptr [rsp+0xF0]                // ★★ xmm3 *= [rsp+0xF0]（倍率，来自调用方栈）
0x141152DF6  call r9                                          // ★★★ r9 = [目标对象 vtable + 0xF0] → 「目标受击」
0x141152DF9  … 恢复 + ret
```

**⇒ 攻击结算的**可证实骨架**是：
`目标受击(目标, 攻击变换, 攻击者ID, 倍率 × (自身 vtable+0x208 的返回值), …)`，
即 **一次攻击的伤害量 = 一个由「自身虚函数 +0x208」给出的基础值，乘以一个外部倍率（`[rsp+0xF0]`），再交给目标对象的 `vtable+0xF0` 处理**。
**但完整公式（攻 − 防、加成、最小伤害）没有在这三处出现** —— 见 ⑤「未找到」。

### 2.5 命中判定 / 装填 / 打空（本轮的确定结论）

| 问题 | 结论 | 依据 |

## ⑤ 三档结论

### ✅ 已证实（有反编译/反汇编原文＋VA）

1. **攻击发起三段**：`CombatObject::attack(单位)` `0x14114FF00`、`attack(地点)` `0x1411504F0`，都**构造一个 184 字节的动作对象**（`FUN_140B6CB00`）装上，并把 `attAmountHeld`（攻击计时/攻击量）从对象的 `vfn+0x248` 拷进去。
2. **伤害落地** `CombatObject::damage` `0x141151490`：进入时打印 HP、按属性槽 `0xA1` 做一次护甲/特效判定、**HP 更新 = `vfn_0xB8(基准HP − HP变更量)`**（原文 `0x141151535`：`vfn+0xB8` 收到 `(float)uVar17 - param_8`）、触发 `DamageTaken` 通知与音效（通道 5）、更新统计计数器、调用全局伤害钩子 `0x144297830`、退出时再打印 HP。**HP 变更量是入参**。
3. **`do_attack` 代码块**（`0x141152C80`–`0x141152E3A`，Ghidra 识别不到函数）：先与两个 16 位阈值比较做筛除，然后 `call [自身vtable+0x208]` 得基础值，`mulss` 一个外部倍率，最后 `call [目标vtable+0xF0]` —— **这是「攻击→目标受击」的调用点**。
4. **转向速率钳制**：`motion.cpp` 的 `FUN_141110750` = **`BMotion::calculateYawAngle`**，公式 `maxYaw = mMaximumYawPerSecond(BMotion+0xA0) × dt`，再对当前角度**取小钳制**，负方向时**翻转符号位**；溢出保护条件是 `(mMaximumYawPerSecond > 1.0f) && (dt == FLT_MAX)`。
5. **到达判定**：`motion.cpp` `FUN_141115760` 用 `距离 ≤ 10.0f` 判定到达（另有 `距离 − 半径 − 0.1f` 的剩余量算法、`3.0f` 第二阈值）。
6. **避让（插值）**：同一函数，**仅当「距离平方 ≥ 4.0」时**做 `0.2 × 新 + 0.8 × 旧` 的向量混合；「友军碰撞圈缩放」由 `mFriendlyCollisionCircleScale` 控制。
7. **巡逻暂停**：巡逻态且已到队列末尾 → 用「单位半径」作为剩余量并暂停一帧（有专属日志）。
8. **路点推进状态机**：状态 `2 = 推进`、`4 = 到达/等待`、`5 = 阻塞/重规划`；主循环**每次最多 20 轮**。
