# 霍去病封狼居胥脚本「打完不动」问题 — 解决文档

**日期**：2026-07-21
**涉及文件**：`src/ai/bt/LegionBehaviors.ts`、`src/app/HuoQubingExpedition.ts`
**对照参照**：`src/app/YuefeiExpedition.ts`（打完黄龙府无此问题）

---

## 一、现象

霍去病封狼居胥脚本在**多个点位反复出现"打完战斗后军团呆立不动"**：

1. **弓庐水之战后** — 军团停在弓庐水，顶栏目标已是「狼居胥山」，但不再移动。
2. **打下终点贝加尔后** — 封狼居胥功成，军团又呆立不动。

用户敏锐指出：**同一脚本在两处同时出问题，绝非巧合，必有共因**；并追问「为什么岳飞打完黄龙府就没事」。

---

## 二、共同根因：远征军团「无家可归」

**霍去病军团在起兵时把 `homeCityId` 清成了 `null`**（`HuoQubingExpedition.ts` 起兵段）：

```ts
army.homeCityId = null;           // 清掉灵仙锚点，精锐名走 army.name 而非据点查表
(army as any).setSourceCityId?.(null);
```

而普通军团行为树选目标时**强依赖出发点**（`LegionBehaviors.ts` `FindTarget`）：

```ts
const originCityId = getArmyOriginCityId(ctx.army);   // = homeCityId ?? getSourceCityId()
if (!originCityId) {
    // 无出发点 → 直接失败 → 军团选不了任何目标 → 呆立不动
    return BTStatus.FAILURE;
}
```

**只要脚本把军团交回普通 AI（`expeditionTargetCityId` 变 null），无家的军团就会在 `FindTarget` 直接失败 → 呆立。** 这就是"打完不动"的共因，两处只是它的两种触发场景：

| 触发点 | 交回普通 AI 的方式 |
|--------|-------------------|
| 弓庐水（远征中途） | 野战后脚本把 `expeditionTargetCityId` 置 null，休整期短暂落入普通 AI |
| 贝加尔（远征完成） | 功成后 `expeditionTargetCityId` **永久**置 null 并 `stop()`，永久落入普通 AI → 永久冻结 |

---

## 三、为什么岳飞打完黄龙府就没事

**岳飞脚本保留了家城郾城**（`YuefeiExpedition.ts` 起兵段**不清** `homeCityId`）。所以打完黄龙府、`expeditionTargetCityId` 置 null 交回普通 AI 时，军团**有出发点（郾城）** → `FindTarget` 正常选目标 → 继续作为普通军团活动，从不冻结。

**连锁的第二层**：游戏本体 `ExpeditionUI` 有个「自动远征」系统，**只对被镜头跟拍的军团生效**——脚本结束后主角军团仍被跟拍，兵力≥4 万即自动重新解锁远征、并按 `applyExpeditionEliteRename`（据家城精锐番号）改名、再派历史目标。

- **岳飞**：家城郾城的精锐番号**恰好 = 「背嵬军」**，与脚本设定的军团名相同 → 自动改名**无可见变化** → 完全看不出问题。
- **霍去病**：若给家城=贝加尔，其精锐番号是**「丁零游骑」≠「轻勇骑」** → 自动改名就**露馅**（番号被改坏）。

**这就是为什么"岳飞碰巧没事、霍去病处处出事"**：不是霍去病脚本写错了单点，而是它「无家」的设计从根上与普通 AI / 自动远征系统不兼容，只是岳飞的家城精锐名恰好和脚本名撞上，把问题掩盖了。

---

## 四、正确的家 = 肃州（酒泉），不是贝加尔

**关键订正（主人 2026-07-21 指出）**：霍去病属**肃州（suzhou）势力，真正的家 = 肃州首都酒泉（`city_jiuquan`）**；脚本只是把**出发点**改成了灵仙（代县），出发点 ≠ 家。原脚本把 `homeCityId` 清成 null（本意让番号走 `army.name`），等于把他的家丢了。

**为什么"补家=酒泉"是唯一正解、且与岳飞完全对称**：精锐番号表 `buildCityEliteLegionMap` 按**势力→首都城**映射——`STARTING_CAPITALS['suzhou']='city_jiuquan'`，`ALL_FACTION_ELITE_LEGIONS['suzhou']={name:'轻勇骑'}`（`HexiExpeditionLegions.ts`）。故 **`getCityEliteConfig('city_jiuquan')` = 「轻勇骑」= 脚本 ELITE_NAME**。

于是打完贝加尔、补家=酒泉、交回普通 AI 后：

```
打下贝加尔 → 功成 → expeditionTargetCityId=null → 补家=酒泉(city_jiuquan) → stop()
        │
        ├─ FindTarget 有出发点(酒泉) → 正常选目标 → 不冻结 ✅
        └─ 仍被跟拍 → ExpeditionUI 自动远征触发
                 → applyExpeditionEliteRename 按家城酒泉精锐改名「轻勇骑」= no-op ✅（番号不变）
                 → 派历史目标狼居胥山，霍去病作为肃州·轻勇骑继续征战 ✅
```

**对照岳飞**：郾城精锐=「背嵬军」= 岳飞脚本名，所以岳飞打完黄龙府被自动远征改名也是 no-op → 从来看不出问题。**两脚本机制此时完全一致**——霍去病之前出错，纯粹是因为丢了家（homeCityId=null）。补回真家酒泉即彻底对齐，**无需 cancelFollow 之类绕弯**。

> 反面教训：曾误把家设成"终点贝加尔"，贝加尔精锐是「丁零游骑」≠「轻勇骑」→ 自动远征把霍去病改名「丁零游骑」露馅。家必须是他**真正的势力首都酒泉**，不是路过/占领的城。

## 五、修复方案

### 修复 1：远征中途重寻路（治弓庐水）
**文件**：`src/ai/bt/LegionBehaviors.ts` — `resolveExpeditionState`

旧代码「目标 id 未变就跳过重设战略目标」的守卫，导致野战把军团挪位后、因目标城 id 不变而不重新寻路 → 卡在战场。改为**每 tick 幂等重设战略目标**（`setStrategicTarget` 只写黑板 `targetCityId/targetPosition`，无副作用），任何打断后都按军团**当前位置**重新锁定→重新寻路。此为通用修复，岳飞 / 长驱深入等所有远征同样受益。

### 修复 2：完成时补回真家酒泉（治贝加尔）
**文件**：`src/app/HuoQubingExpedition.ts`

新增常量 `HOME_CITY_ID='city_jiuquan'`（肃州首都酒泉）与 `finishHandoff(army)`，**只在 `stop()` 那一刻调用**（此后 tick 不再运行、不会被每帧的 `expeditionUnlocked=true` 覆盖）：

```ts
private finishHandoff(army: ScriptArmy): void {
    army.homeCityId = HOME_CITY_ID;   // 家=酒泉/肃州(真家)：FindTarget 有出发点→不冻结；
                                      // 酒泉精锐=「轻勇骑」=ELITE_NAME→自动远征改名 no-op→番号不变
    army.expeditionTargetCityId = null;
    army.isElite = true;              // 保精锐+主将
    army.name = ELITE_NAME;           // 保险：稳定为「轻勇骑」
}
```

**关键时序**：功成后先播 15 秒 finale 语音（此间 `homeCityId` 仍为 null → 自动远征因「无精锐名」不触发）；finale 播完、`stop()` 前才 `finishHandoff` 补真家酒泉。此后军团=肃州·轻勇骑，被自动远征接管继续征战、番号不变（与岳飞一致），**不需要 cancelFollow**。

> 备注：把家写成酒泉而非"起兵点代县"或"终点贝加尔"，是因为只有他真正的势力首都酒泉的精锐才等于「轻勇骑」。`HOME_CITY_ID` 常量与 `finishHandoff` 均已加详细注释。

## 七、给后人的经验（避免再犯）

1. **远征/脚本军团若要交回普通 AI，必须有合法同势力家城**，否则 `FindTarget` 因「无出发点」冻结。**家 = 该武将真正的势力首都**（霍去病=肃州酒泉，岳飞=郾城），不是起兵点、更不是路过/占领的城。别为「番号显示」清 `homeCityId`——番号在地图上取 `army.name`（`GlobalUnitRenderer` `eliteText = unit.name`），与 `homeCityId` 无关。
2. **被跟拍的军团会被 `ExpeditionUI` 自动远征接管并按家城精锐改名**。只要家城=武将真正的势力首都，其精锐名本就等于脚本番号（酒泉=轻勇骑、郾城=背嵬军），自动改名即 no-op、番号不变——**这正是选对家城的附带好处，无需 cancelFollow 之类绕弯**。反之若把家设成别的城，就会被改成那座城的精锐名（曾误设贝加尔→被改「丁零游骑」）。
3. **收尾动作要放在 `stop()` 一刻**，别放在「完成检测」块——后者之后还有若干 tick 会用 `expeditionUnlocked=true` 等覆盖你的赋值。
