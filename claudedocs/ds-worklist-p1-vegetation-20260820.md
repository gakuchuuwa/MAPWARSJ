# 🔴 紧急修正指令（2026-08-20，主人报「地铺的不对」）

## 撤销 `paintTerrain` 的镜像/旋转 —— 这是 CC 引入的错误

**现象**：铺地出现规则的方格边界，块与块之间明暗跳变（主人截图实锤）。

**根因（实测数据，非推测）**：
| 测项 | 值 |
|---|---|
| DE 原图 2048² 左右边缘差 | 17.25 |
| 图内随机两列差（纹理自身噪声水平） | 26.04 |
| 我们的 512²（LANCZOS 降采样）边缘差 | 13.94 |
| **纯重复铺 2×2 的接缝色差** | **13.94** |
| **加镜像/旋转后的接缝色差** | **19.27** ❌ |

结论：**DE 地形本身是无缝的**（边缘差 17.25 远低于随机两列 26.04），降采样也没破坏。
问题出在 CC 加的「每块镜像 + 90° 旋转打散重复」——DE 地形贴图带**整体光照渐变**，
旋转后相邻块的明暗方向对不上，接缝色差从 13.94 涨到 19.27，就成了肉眼可见的方格网。
「无缝纹理镜像后接缝仍匹配」这个假设**对带方向性光照的纹理不成立**。

## 怎么改

`paintTerrain()` 改成**最朴素的纯重复平铺**，一行变换都不要：

```ts
const pat = g.createPattern(im, 'repeat');
if (!pat) return;
g.fillStyle = pat;
g.fillRect(0, 0, cv.width, cv.height);
```

- **原尺寸铺**（512²，不缩放）——DS 最早那版压成 256 会丢一半细节，也别退回去。
- **删掉** `terrainSeed` 字段和那套哈希取朝向的代码（连同注释），不留死代码。
- 「每场只选一张、全场统一」保持不变，这条是对的。

## 重复感怎么办 —— 现在不用管

512 周期在 1920 宽下重复约 3.75 次，确实看得出。但：
1. **AoE2 原版也是同一张纹理重复铺**，玩家不觉得难看——靠树/石/建筑打断视线；
2. 我们现在恰好处在「三国树刚删、DE 树还没接」的空场过渡态，草地一览无余才显得重复；
3. **P1 把树接回来后再看**。届时若仍嫌单调，正确手段是叠一层**极淡的大尺度低频噪声**
   （柔和明暗斑块，尺度远大于 tile），它不产生硬边——**绝不再用旋转/镜像**。
